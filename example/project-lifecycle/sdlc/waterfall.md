# Waterfall

## Plan

1. Record the requirements, and have them signed off.
2. Record the design against those requirements, and have it signed off.

## Deliver

1. Implement the signed-off design.
2. Integrate the work with the system it joins.
3. Hold any change to requirements or design until it is signed off again.

## Verify

1. Run the system tests against the requirements.
2. Record the stakeholders' acceptance.
