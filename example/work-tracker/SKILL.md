# Work Tracker

Work Tracker plans work as tracker issues and keeps the plan current until the work is delivered. The issues are the plan:

- **Initiative**  States a goal and lists its epics.
- **Epic**  Lists its tasks in a Work Breakdown table.
- **Task**  One pull request's worth of work.

## Dispatch

A link whose text opens with `»` names material a sub-agent compiles. Compile the marked link and hand it to a sub-agent. Each mode links this section from its preamble, so a bundle of that mode carries it.

## Modes

Select the mode as appropriate to fulfill the user request:

- **[Plan](modes/plan-mode.md)**
  - Forward-looking, scoped to one approved proposal
  - Turning an approved proposal into initiatives
  - Raising, breaking down and restructuring initiatives and epics
  - Review passes of a plan against its goal
