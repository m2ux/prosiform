# Guide

A code span naming `[[page]]` is prose about a wiki link rather than one.

An escaped \[\[page\]\] is the literal text the author asked for.

A paragraph mentioning {#custom-id} names no section.

```text
[[page]]
[^1]: a footnote definition in an example
## Title {#custom-id}
```

A regular expression `[^abc]` matches one character.
