# § Instructions

Run `pf`, then follow the guidance it prints. Follow [Tally](#tally) next.

# Tally

Count one source's lines, by its kind and under one counting rule.

Follow the [Steps](#steps) under the [Contract](#contract).

## Contract

### Given

- The source.

### Answers

- `tallied`, with the count

## Steps

1. Read [the source's material](#source).
2. Count its lines as [its kind](#prose) and [the counting rule](#strict) state.
3. Answer `tallied`, with the count.

# Source

The source is `notes.md` in the run folder.

# Prose

A line is a run of text ending at a line break.

# Strict

A line counts only where it holds a word.
