## Overview

The edge workflows' corpus test and scenarios read the bundles I10:E06 publishes, and write no mark E06 retires: every bundle opening with the run-pf line, an inline `⇉` link at each dispatched file and `In parallel` sections of `⇉` items, no Prosiform section, no `¬⇉` or `¬⫽`, `↳` as the composition mark in place of the arrow directive, and one `compiled` form in place of `staged`.

## Problem

- **The test reads the retired section.**
  The corpus test W12 added holds a dispatched bundle reaching a deferred line to `Before following this bundle, [run pf first](#run-pf-first).` above `# Prosiform`, and `subagent-first-run`'s scenarios state it. Once E06's bundles reach E04's base, that test fails.
- **Scenarios write retired marks.**
  `deferred-dispatch` (W10) is built on `¬⇉`, and `subagent-first-run` (W12) writes `¬⇉` at its second hop; E06 refuses both, so their sources no longer compile. (The `¬⫽` cases the plan names in `dispatch-depth` and `subagent-first-run` are not in their sources at the epic base.)
- **Scenarios compose with an arrow.**
  `deferred-composition` and its nested deferrals (W06), `preset-deferral` (W07), `conditional-composition` (W08), `directive-labels` (W09) and `subagent-first-run` (W12) compose with the arrow directive E06 refuses.

## Proposal

**The scene.** `test_workflow.py` compiles each scenario's bundles with the build under test and holds the scenarios to them.

- **The first-run test reads the run-pf line.**
  A dispatched bundle's sub-agent is held to its `pf` runs by the line every bundle opens with, and to the inline `⇉` links and `In parallel` items by the files they link.
- **Staged scenarios move to `compiled`.**
  E06 W07 folds `staged` into `compiled`, so every scenario written only in `staged` is written in `compiled`, which carries the build and a `pf` shell. The fold landed in the merge of `main` into the epic base (step 1 of the delivery): the `staged/` trees became `compiled/`, and the compiled workspace holds the sources beside the bundle set, since a `↳` line names its target from the sources.
- **Composition moves to `↳`.**
  Each `[→](p.md#s)` becomes `[↳ Title](p.md#s)` and each `[¬→](p.md#s)` becomes `[¬↳ Title](p.md#s)`, the title being the target section's heading. `directive-labels`, which measures a composition beside a footnote link, keeps the footnote link and measures the `↳` composition beside it.
- **The retired marks are rewritten.**
  `deferred-dispatch` keeps its scenarios: `Pack` defers the loading crew's section with `¬↳`, and that section dispatches the lift and the strap, so the run on the line writes the bundle dispatching them. The review's `¬⇉` in `subagent-first-run` becomes a `¬↳` line in the same way. Each scenario keeps stating actions only a sub-agent's `pf` run defines.
- **The corpus reader follows the new bundles.**
  A link enters a state where the heading it links is titled as the state, so a `↳` title leads into the section composed under it; a deferred line is the `↳` line under the heading a step's link names; a source's `¬↳` reached under a condition is followed for the dispatches its material makes. A heading is matched by its slug.
