**Component:** src/prosiform/cli.py

## Overview

A run that publishes several bundles validates every one before it writes any, writes each atomically, and on any failure writes none. A caller then reads either the whole set a run produced or the set that was there before it, never a mixture. A run publishes one bundle until dispatched targets arrive in W03, so the publication step takes a set now and the tests hold it over sets they construct.

## Problem

[`execute`](https://github.com/m2ux/prosiform/blob/0e75ab3d99a1c50d3ff7a8aac4ecbfac191d045b/src/prosiform/cli.py#L1913-L1999) composes, validates and publishes one bundle. [`publish_file`](https://github.com/m2ux/prosiform/blob/0e75ab3d99a1c50d3ff7a8aac4ecbfac191d045b/src/prosiform/cli.py#L1766-L1797) is atomic for that file alone, so a run of several bundles that fails on the third would leave the first two written beside stale copies of the rest.

## Proposal

A run compiles its entry and two dispatched targets; the second target crosses its output budget.

- **Validate all, then write.**
  Every bundle is composed and held to the output budget before the first write; a failure in any ends the run with its diagnostic and writes nothing.
- **Warnings travel with their bundle.**
  A bundle carries the warnings it raises, and they are emitted once the whole set has validated, in the order a single-bundle run emits them today.
- **Stage every bundle, then rename each.**
  Every bundle's bytes go to a temporary file beside its destination before any destination is replaced, so a refused write leaves every destination as it was.
- **`-c` writes nothing.**
  A validation-only run validates every bundle the run would publish and writes none.
- **Other files are left alone.**
  The run neither removes nor rewrites a file in the output folder that it does not produce.
- **A rename refused part-way.**
  It is `E_PUBLICATION_FAILED` naming that path. The bundles renamed before it stay published, and the refused destination and every later one stay as they were, as the design's Publication clause states.
