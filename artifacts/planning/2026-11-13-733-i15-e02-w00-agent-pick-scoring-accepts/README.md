# First-Run Pick Scoring — November 2026

> Task · Created 2026-11-13

## Executive Summary

The diagram-following eval's agent-pick scenarios accept either path to a pick: a first-run `--pick` beside the link as written, or the alternatives listing followed by the rerun with `--pick`. The scorer records which path each session took.

The guide tells an agent that knows its pick to pass `--pick` on its first run, so a scorer holding every session to the listing run marks a guide-compliant session as uncompiled, and the real-use agent-pick run would understate the invocation.
