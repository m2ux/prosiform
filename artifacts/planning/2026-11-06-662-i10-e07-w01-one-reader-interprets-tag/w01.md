**Component:** main:src/prosiform/tags.py

## Overview

One reader interprets tag lists. It returns an immutable set of complete, case-folded names from the decoded list a Markdown title or command argument supplies.

## Problem

The source and command layers need one normalization rule for comma-separated preset names.

## Proposal

**The scene.** A parsed Markdown title and a shell-decoded command argument each supply an optional string under the [preset-selection contract](https://github.com/m2ux/prosiform/blob/c67cf78f020923c4e5bd25d95497ced206be7161/artifacts/planning/2026-10-17-prosiform-v1/design.md#presets).

Implement `prosiform.tags.read(text)` using string splitting, whitespace trimming and Unicode case folding. Its `frozenset[str]` discards empty and duplicate tokens and gives input order no meaning. Preset declaration matching, implicit default and declaration-order layering belong to the selection consumer; the reader retains every nonempty complete token. Commas are literal separators; token contents have no separate quoting or escaping grammar.
