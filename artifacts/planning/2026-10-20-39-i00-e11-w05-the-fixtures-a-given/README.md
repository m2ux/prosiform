# I00:E11:W05 The Fixtures a Given Piece of Work Unblocks, Reported on Request - October 2026

> Task Plan - Created 2026-10-20

## Executive Summary

This record holds the local plan for the row that reports, from the corpus and on request, the fixtures awaiting one named piece of work. A fixture declares the work it awaits, and the report answers which fixtures a session starting that work unblocks.

It matters because a session learns what its work turns green from a red run or by asking, and neither scales with a corpus that declares its own waiting. A report over the corpus makes the dependency readable before the work starts.
