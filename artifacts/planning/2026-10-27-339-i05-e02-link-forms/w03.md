**Component:** src/prosiform/__init__.py

## Overview

The profile becomes `skill-markdown-v3`, and the bundling rules, glossary and design state every diagram link form it follows.

## Problem

[`PROFILE`](https://github.com/m2ux/prosiform/blob/ad2e7338c65259e546a97be83b0964e705d64bc5/src/prosiform/__init__.py#L8) names `skill-markdown-v2`, released in v0.13.0. Under it a class `link` line and a sequence menu are text, and the [Diagram links rule](https://github.com/m2ux/prosiform/blob/ad2e7338c65259e546a97be83b0964e705d64bc5/invocation.md#L73) names `click` lines alone. A reader of a v2 bundle and of this release's bundle of the same source would see different documents.

## Proposal

A source whose class diagram writes `link` bundles differently once the reader widens. The profile name is what tells a reader which rules made a bundle.

- **The name.**
  `PROFILE` is `skill-markdown-v3`, and every place that states the profile name reads it.
- **The rule.**
  `invocation.md`'s Diagram links rule names `click`, class `link`, sequence `link` and `links`, and any-case keywords, with the C4, Kanban and escaped-value boundary.
- **The vocabulary.**
  The glossary's **reference** entry and the design's Examples rule name the same forms.
