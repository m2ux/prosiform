# I00:E03:W02 Eligible Section Extraction and Boundaries - October 2026

> Task Plan - Created 2026-10-19

## Executive Summary

This record holds the local plan for the second row of [I00:E03] Outline Hierarchy. A fragment naming an eligible heading selects that heading and the blocks up to the next document-level heading of equal or higher level. A heading nested inside a list, a blockquote or any other container does not terminate a section, and a fragment naming one fails with its declared error code.

It matters because where a named section ends is a decision, and a heading inside a container looks like a terminator without being one. It is also the row the rest of the initiative waits on: [I00:E04:W03](https://github.com/m2ux/prosiform/issues/6) and [I00:E05:W01](https://github.com/m2ux/prosiform/issues/7) both name it, and under the board's row rule they wait for the whole of this epic to close. The row covers AC1 and AC2 and extends the source model, reading the heading index [W01](https://github.com/m2ux/prosiform/pull/64) delivered.
