# I00:E12:W06 Root Confinement on Entry References — October 2026

> Task Plan · Created 2026-10-21

## Executive Summary

This record holds the local plan for the row that confines the root to the caller's entries. An entry reference naming a path outside the allowed source root fails, because the run cannot perform it; a reference inside a source naming such a path is emitted as authored, because it is the author citing something the bundle does not carry.

It matters because one refusal served both cases while a mark selected dependencies. With position deciding, a source's outward reference is ordinary prose, and only the caller's own entry can ask the tool for work outside the root it was given.
