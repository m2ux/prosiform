**Component:** src/prosiform/cli.py

## Overview

The command compiles a positional file while each source supplies the root for its own links.

## Problem

Source traversal uses a caller-supplied shared root and file-relative links.

## Proposal

Capture the entry under existing limits and no-follow access. Resolve each source's optional prosiform.root relative to its file directory; every absent root uses the invocation working directory, including linked sources. Resolve path-bearing Markdown links from the declaring source's effective root, and apply the target's own metadata to its outgoing links. Capture bytes by canonical physical identity. Use each source's declaration or the invocation working directory consistently when a shared file is reached through different parents. Preserve cycle detection and deterministic deduplication under the normative contract. Preserve fragment-only self references, deferred validation, limits, original locations, source rechecks and per-source rooted access. Different valid roots are permitted. Remove -r. Update source identities, diagnostics, active fixtures, -f semantics, installed-wheel smoke and directly affected consumers in this same unit.
