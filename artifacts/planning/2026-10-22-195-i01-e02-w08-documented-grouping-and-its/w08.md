## Overview

The documented grouping examples and the diagrams beside them, carrying what a run of them emits.

## Problem

The documented commands and their rendered diagrams show the overview wrapper where it is no longer emitted and the mixed heading casing, so the documentation describes output no run now produces.

## Proposal

The examples beside the documented commands carry the arrangement and heading spelling a run emits. The worked examples show a group whose preambles need Overview and a heading-free group whose named members sit directly beneath Rules. The README SVGs and PNGs carry title-cased bundle headings while source filenames retain their spelling; the retained planning SVGs carry the same design.
