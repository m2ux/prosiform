# A Group Declared Per Folder — October 2026

> Delivery Record · Created 2026-10-25

## Executive Summary

The example now carries thirty artifact files, ten modes, six protocols and one reference, and a bundle of any mode must compose the folders those documents sit in rather than list them flat. This row declares a group on every file that belongs to a folder, so a bundle shows the artifacts as one group of thirty members and the protocols and the reference as groups named for their folders.

The declarations are the difference between a tree that looks like a skill and a bundle that reads like one. Without them a run has a filesystem path and no instruction about what belongs together, so each mode's bundle arrives as a sequence of documents in whatever order its links reached them.
