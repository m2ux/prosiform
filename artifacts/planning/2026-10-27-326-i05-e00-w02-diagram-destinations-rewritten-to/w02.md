**Component:** src/prosiform/bundle.py

## Overview

The bundle carries a diagram whose click destinations name the anchors of the groups it bundled, so a reader following a diagram link lands on the document it names.

## Problem

[`rewrite`](https://github.com/m2ux/prosiform/blob/30636a72aed3c780bd583ea5ed995458032eba7b/src/prosiform/bundle.py#L354-L388) edits the lines inline tokens occupy, so a fence is carried byte for byte and a click destination still names a source path once the document it names is bundled.

## Proposal

The fence reader yields each destination's line and offset. Emission replaces the quoted destination there and nothing else.

- **One rewrite path.**
  `rewrite` walks the selected fence tokens beside the inline ones, and for each diagram destination asks [`target`](https://github.com/m2ux/prosiform/blob/30636a72aed3c780bd583ea5ed995458032eba7b/src/prosiform/bundle.py#L391-L421) for the anchor. The [grouping caller](https://github.com/m2ux/prosiform/blob/30636a72aed3c780bd583ea5ed995458032eba7b/src/prosiform/grouping.py#L278) receives the rewritten lines as it does now.
- **Carried as written.**
  A destination `target` gives none to — outside the root, or naming no Markdown document — keeps the bytes the source wrote. A non-Markdown file under the root raises the resource-portability warning an inline link to it raises, and the fixture's expected diagnostics record it.
- **Offsets in physical coordinates.**
  `Click.offset` counts within the line as the fence token holds it, which excludes container markers and the fence's indent. The fence line is the trailing text of the physical line, so the replacement column is the physical line's length less the fence line's length, plus the offset.
- **Line identity holds.**
  A replacement edits one physical line and adds none, so the token maps the group slices by still name the same content.
