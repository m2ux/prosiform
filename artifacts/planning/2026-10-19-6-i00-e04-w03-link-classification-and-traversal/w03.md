## Overview

Classification of references by the mark their authors wrote, and recursive traversal of the marked ones to a fixed point.

## Problem

A reference's shape says what it points at and nothing about whether the bundle must carry it. Under the rule this row replaces, every local Markdown link was a dependency, so an author had no way to mention a document without requiring it: one entry reference reached fifty-eight per cent of the documents under `skills/`, and nineteen citations of shared material put two skills' closures above their own directories. [P03](https://github.com/m2ux/prosiform/issues/55) measured both.

Instruction sets also link back to one another, so a traversal without a fixed point repeats regions or does not terminate, and a traversal bounded by recursion depth refuses a cyclic graph that is perfectly valid.

## Proposal

A **dependency** is a reference its author marked: the link text opens with `¬`. It is resolved against the document carrying it, read under the allowed source root, bundled, and — at [E05:W02](https://github.com/m2ux/prosiform/tree/engineering/artifacts/planning/2026-10-17-prosiform-v1/i00-e05/w02.md) — rewritten to a bundle destination. Every other reference is text the bundle carries as its author wrote it. *Linking cites material; marking requires it.*

The mark is ordinary text to the profile, so the grammar recognizes no new construct, nothing must be refused, and a renderer knowing nothing of this tool shows the link.

### What Each Class Does

| Class | What the run does with it |
| --- | --- |
| A marked local Markdown reference | Resolves it against the document carrying it, reads it, bundles it, and traverses its own selected content |
| An unmarked local Markdown link | Emits it as authored. It is not resolved, the document it names is not opened, and it stays as authored even where the bundle carries that document because another reference marked it |
| A marked fragment-only link | Resolves against the heading index of the document carrying it, then follows the same rules |
| A reference carrying a scheme or an authority | Emits it as authored and never opens, fetches or interprets it. Marking one changes nothing |
| An image or another non-Markdown reference | Text by the same rule. Never opened, never traversed |
| An apparent link inside a code span or a code block | An example. The parser produces no link, so nothing classifies it |

A citation may therefore name material the allowed source root cannot contain and the run still succeeds. **Marking** one that does is the failure, and it fails with `E_SOURCE_OUTSIDE_ROOT` naming the resolved path and the line the reference was written on. That is [D33](https://github.com/m2ux/prosiform/tree/engineering/artifacts/planning/2026-10-17-prosiform-v1/decisions.md) made observable: a collection is rooted at its own directory, and a citation leaves it.

### The Components That Hold It

Nothing moves between modules and each keeps its one reason to change.

| Module | What this row adds |
| --- | --- |
| `source.py` | `links(tokens, regions)` — what a given run of regions links to, read from the parser's own events: each link's destination, the literal text its content opens with, and the line of its block |
| `closure.py` | `marked(opening)` — whether a link's author marked it. `inside(document, text)` — one reference a source carries, resolved against the document carrying it. A `Reference` also holds where it was written |
| `cli.py` | `required(...)` — the dependencies one source's selected content marks. `traverse(...)` — the worklist that runs to the fixed point |

`closure.py` still reaches no filesystem, `access.py` still does the walking, and `cli.py` still touches the filesystem for no part of grouping. Group identity remains the one the normalization produced, so no path resolution was reintroduced to name a group — the hole [W02](https://github.com/m2ux/prosiform/pull/71) closed stays closed.

### The Traversal

The entry references are the first frontier. Each round reads the sources its frontier names, then reads every group's selected content for the dependencies it marks.

| Step | What the round does |
| --- | --- |
| 1 | Reads each source its frontier names, parses it, and refuses it where the profile refuses a construct it carries |
| 2 | Groups every reference found so far by the path it normalized to, and computes each group's selection |
| 3 | Reads each group's selected regions for links, and keeps the marked ones |
| 4 | Resolves each against the document carrying it, discarding one that carries a scheme or an authority and one naming a file outside the profile's suffixes |
| 5 | Adds each reference naming a document and section the run does not already carry; the ones it added are the next frontier |

**The fixed-point condition is that a round adds nothing.** Identity is the pair the normalization produced — the root-relative path and the decoded fragment — so a cycle terminates on what a reference names rather than on how many hops reached it, and each reachable region is present once. There is no recursive-call-depth cap, because one would refuse a valid cyclic graph. The expansion-depth budget that does bound the graph's shape is [W06](https://github.com/m2ux/prosiform/tree/engineering/artifacts/planning/2026-10-17-prosiform-v1/i00-e04/w06.md)'s.

Every group is read again each round, because a group's selection grows as later content marks more of its document. The traversal returns what the bundle is composed from, so the bundle follows from the closure rather than from the order its documents were discovered in.

### The Entry Line Names Entries Alone

A document only a dependency selected contributes its file group and no entry. Before this row every reference reaching a group was an entry reference, so the selection marked every heading it resolved to as one; now a discovered reference must select without entering the line. The selection is therefore told which of its references the caller named, and a whole document only a dependency selected is a selection of every region with no entry rather than the file-heading entry a whole-document entry reference produces.

### No Code Is Added

The catalogue stays at 21. The two codes this row draws, `E_SOURCE_OUTSIDE_ROOT` and `E_TARGET_NOT_FOUND`, are both in it, and both are already drawn by an entry reference. Nothing is added to `design.md` or to `manifest.schema.json`, so neither side of the two-branch catalogue check moves.

## Criteria

- **AC1.** A marked local Markdown link in selected content is resolved, bundled and present in the published bundle, as the traversal fixtures show.
- **AC2.** A cyclic reference graph bundles to a fixed point with each reachable region present once, as the cycle fixtures show.
- **AC12.** An image, a web URL or another non-Markdown reference in selected content is preserved without being opened, fetched or traversed as a dependency, as the resource-classification fixtures show.
- **AC15.** An unmarked local Markdown link is emitted as authored, resolves as no dependency, and is left unrewritten even where the bundle carries the document it names, as the unmarked-link fixtures show.
- **AC16.** A document whose unmarked references name material outside the allowed root bundles successfully, while marking one of them fails the run with its declared error code, as the citation fixtures show.

## The Definition This Row Corrects

`docs/glossary.md` defines a dependency as "A target reached by a reference from selected content. Only a Markdown link creates one." A mark creates one, and an unmarked link creates none, so the second sentence states the rule this row implements backwards.

It is corrected here because the file lives in the repository rather than on `engineering`, so it moves only on a delivery branch, and this is the row whose own work the definition describes. The vocabulary check holds the design's italicised terms to having an entry, not to the entry being true, so nothing else reports it.

The entry now reads: *A target its author marked as required, by opening the reference's link text with `¬`. It is resolved, bundled and rewritten; a reference left unmarked cites the document it names and creates none.* The **closure** entry beside it follows marked references rather than references. No term is added, so the vocabulary check's second direction — every definition carried by the contract — is unmoved.

## The Behaviours the Merged Base Settled and Nothing Observes

Four behaviours exist only once outline hierarchy and dependency closure sit on one base. The integration that merged them verified each by hand and left none of them in the corpus, so this row carries their fixtures.

- **An escaped fragment resolves to the decoded heading.** `guide.md#run%2Dit` reaches the heading `Run It`, because the resolution decodes the fragment before the lookup. The merge settled this in the closure's favour; neither epic had tested it, and the contract's resolution sequence is what it follows.
- **A parent segment normalizes, then selects.** `docs/../guide.md#run-it` normalizes to a confined path and selects a section from it, so normalization and selection compose.
- **Two spellings of one document form one group.** `guide.md#stop` beside `./guide.md#run-it` names one group carrying both selections in source order, because group identity is the path the normalization produced rather than the text a reference was written as.
- **A fragment-only reference selects from its referrer.** `--from guide.md '#stop'` selects the named section of the document `--from` names.

Each is the ordinary path of the merged design rather than an adversarial edge, so each is a passing fixture rather than a marker.

## What This Row Does Not Do

**The mark reaches the bundle, and a marked destination is not rewritten.** [D32](https://github.com/m2ux/prosiform/tree/engineering/artifacts/planning/2026-10-17-prosiform-v1/decisions.md) states that a *rewritten* link carries the text that followed the mark and not the mark itself, and the design says the same: the mark is dropped by the rewrite, which is [E05:W02](https://github.com/m2ux/prosiform/tree/engineering/artifacts/planning/2026-10-17-prosiform-v1/i00-e05/w02.md). Dropping it here would mean editing inline content inside a region, which is the source-preserving edit that epic exists for and which this row has no destination map to perform. Until that row lands, a bundle carries `[¬ the shared rules](rules.md)` as its source wrote it, and every expected bundle this row authors whose source carries a marked link changes when it does.

**A marked resource is left as text.** The design says images and other non-Markdown references are text by the same rule as a scheme, so a marked `theme.css` is emitted as authored and never opened. That puts a mark in a bundle by a path D32's invariant does not cover. No fixture here asserts either reading; it is raised as a finding instead.
