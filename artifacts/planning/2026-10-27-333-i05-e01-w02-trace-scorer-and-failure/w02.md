**Component:** evals/diagram-following/score.py

## Overview

A deterministic scorer that reads one finished workspace and says whether the agent followed the workflow, and if not, how it went wrong.

## Problem

An agent's run leaves a trace and action files. Without a scorer, judging them is reading transcripts by hand, which no baseline can rest on.

## Proposal

The scorer takes a workflow, a scenario and a workspace, and returns a verdict.

- **Pass.**
  `trace.log` equals the expected path, each state on it has its action file with the stated content, and the last state is terminal.
- **Failure classes,** from the first divergence:
  - *wrong branch* — the agent entered a valid successor of the state other than the expected one;
  - *skipped state* — the agent entered a state further along a valid walk, omitting one;
  - *invented state* — a name the diagram does not hold;
  - *loop miscount* — the loop was taken more or fewer times than the inputs require;
  - *missing action* — the path is right and an action file is absent or wrong;
  - *unfinished* — the trace stops before a terminal state.
- **Output.**
  A verdict record: pass, class, the divergence index and both paths, as JSON the runner and report read.

| Plan | `score(workflow, scenario, workspace)` in `evals/diagram-following/score.py` returns a `Verdict`. The trace is `trace.log`'s lines with surrounding whitespace removed and blank lines dropped; names are otherwise exact, so case or punctuation that differs is a name the diagram does not hold; an absent `trace.log` is an empty trace. An action is done when `actions/<file>` exists and its content, surrounding whitespace removed, is the value its section states. The expected path is the scenario's. Classes follow the first index where the trace and the expected path differ, taken in this order: the trace equals the path → *missing action* when a state on it lacks its action, else pass; the trace is a proper prefix of the path, the empty trace included → *unfinished*; otherwise the entered state, against the one before it (the `start` marker at index 0): a name the diagram does not hold → *invented state*; a state an edge leads to from a decision on a trace count → *loop miscount*; a state an edge leads to from any other decision → *wrong branch*; a state a walk of two or more edges reaches → *skipped state*; a state no walk reaches, which includes any state entered after a terminal → *invented state*. The divergence index is that first differing index, the trace's length for *unfinished*, the first trace index whose action is wrong for *missing action*, and none for a pass. `Verdict.record()` is the JSON-serialisable dict W03 writes and W04 reads: `passed` (bool), `failure` (`wrong_branch`, `skipped_state`, `invented_state`, `loop_miscount`, `missing_action`, `unfinished`, or null), `divergence` (int or null), `expected` and `actual` (lists of state names), `actions` (action file names absent or wrong, over the diagram states the trace entered, in trace order). Tests sit beside the reader (`test_score.py`), run by `make harness`: a pass for every scenario, one hand-made trace per class, and the normalisation rules. |
