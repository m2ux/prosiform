**Component:** src/prosiform/cli.py

## Overview

A redirected positional entry and a redirected referrer, and the filename a run derives when either is substituted — with the two fixtures that show each.

## Problem

`derived_name` composes the name from an entry's path relative to the working directory, and `execute` derives it from the references `entry` returns. W01 applied the mapping there, so a redirected entry resolved to its substitute before the name was derived. What remained was the evidence, and two of this page's own predictions about the build were wrong: the corpus runner names no output folder, and two entries naming one substitute derive one selection rather than a refused collision.

## Proposal

**The scene.** `execute` normalizes the referrer and the entries, builds the mapping, then traverses and derives the name. Both the referrer and each entry are references the mapping serves, and both are resolved before the closure reads anything.

**The design.**

- **The redirect reaches the entry and the referrer.** Both are resolved through the mapping where `execute` normalizes them, so a fragment-only entry against a substituted referrer names a section of the substitute.
- **The name follows the substitute.** `derived_name` reads the substituted entry, so the name is the name of what the file holds.
- **A section entry keeps the substitute's fragment.** A substitute carrying a fragment contributes that fragment in place of the authored one, so the `__` segment of the name names the section the bundle carries.
- **Two entries naming one substitute derive one selection.** They resolve to one identity, so `selections` counts one and the run publishes one bundle. That is not the collision refusal, which is for two distinct selections deriving one name.
- **`-o` names the folder, not the file,** so the derived name follows the substitute with or without it.

## Fixtures

| Fixture | What its source tree and manifest declare |
| --- | --- |
| `fixtures/mock/a-redirected-entry-derives-its-name-from-the-substitute` | `entry.md` links `rules.md`. The run is given `-m entry.md=stand-in.md entry.md`. The run publishes `stand-in.bundles/stand-in.bundle.md`, not `entry.bundles/entry.bundle.md`, and the runner's comparison of the folder a run creates is what states the difference. |
| `fixtures/mock/a-redirected-referrer-carries-its-entry` | `guide.md` links `rules.md` and holds `## Run`. The run is given `-m guide.md=stand-in.md -f guide.md '#run'`. The fragment resolves against the substitute, so the bundle carries the substitute's `Run` section under `stand-in__run.bundle.md`, and `W_MOCK_SUBSTITUTED` names the referrer. |
