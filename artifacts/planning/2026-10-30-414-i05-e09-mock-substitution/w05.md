**Component:** src/prosiform/cli.py

## Overview

Withheld references redirected: the deferred and dispatched targets a run resolves without compiling, and the destinations a bundle publishes for them.

## Problem

A deferral and a dispatch withhold a compilation but not the resolution. `withheld` yields each target, the run confirms the document and heading exist, and `rebased` publishes the target's working-directory-relative path for a later run to follow. A mapping applied only to compiled dependencies would leave those destinations naming material the mock never touched, and the later run would compile the real document out of a bundle built to avoid it.

## Proposal

**The scene.** `withholding_target` resolves through `resolvable` for both operators, and `bundle.target` reads `withholding_target` again while rewriting the link. The dispatch analysis reads the same resolution through `dispatches`, and a run-set through `run_sets`.

**The design.**

- **The seam covers them already.** `withholding_target` takes the mapping, so both operators resolve to the substitute and everything downstream reads it: the existence check, the heading check, `rebased`, and the chain a diagnostic carries.
- **`rebased` publishes the substitute's path.** It reads `found.path`, which is the substitute's, so a deferred destination in a mocked bundle names the substitute. Its fragment follows the substitute, so a substitute carrying one publishes that section.
- **Dispatch analysis follows the substitute.** `onward` compiles a dispatched target as an entry, and it compiles the substitute, because the hop it is given is the redirected reference. A substitution in a dispatched closure therefore raises its own warnings.
- **A candidate comparison reads the same answer.** `candidate` asks `withholding_target`, so the published destination the comparison expects is the substitute's, and a run that resolved without the mapping would report a destination the bundle invented.
- **The heading check is asked of the substitute.** A substituted deferred target must carry the heading its own fragment names, because that is the document the later run reads.
