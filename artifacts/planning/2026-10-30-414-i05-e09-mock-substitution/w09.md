**Component:** invocation.md

## Overview

The `-m, --mock` row in the documented invocation, reproducing the command's help text word for word, with the guide's one-line form of what a mapping entry does.

## Problem

`make invocation` compares the documented option table with the command's own help output in both directions. An option the command offers and no table names fails with "the command offers this option and no table names it", and a row whose `Effect` cell differs from the help text by one character fails too. The option cannot be documented before it exists, and it cannot ship before it is documented.

That pair is also why the row cannot wait for this row. W01 lands the option, so from that pull request onward the command offers `-m` and no table names it, and `make check` runs the check that says so. The row therefore lands with W01; this row is what remains: the guide's prose and the classification page's detail.
    10|
## Proposal

**The scene.** `checks/invocation.py` reads the `Option` and `Effect` cells of `invocation.md`'s table and compares each with the help output the build under test prints, forgiving only runs of whitespace. The same check holds the exit-status table and the profile identifier.

**The design.**

- **The row has landed.** `-m, --mock ORIGINAL=ALTERNATIVE` stands in the table between `-f DOC` and `-o DIR`, its `Effect` cell copied from the build's help rather than composed for the table, with the default the grammar declares: none. It landed with W01 for the reason the Problem states.
- **The guide states the one-line form.** `invocation.md`'s `## Bundling` says what a mapping entry does in a sentence or two and links the classification page, so the detail has one home.
- **The classification page carries the detail.** `docs/references.md` is where the guide sends a reader for classification and operators, and it now states the matching: a key matched on the identity a reference normalizes to, a fragment key redirecting one section and taking precedence over a document key, and both sides resolving from the invocation working directory rather than the writing source's root. W01 landed this too, because the page would otherwise have documented an option the guide named and left unexplained. This row confirms it rather than writing it again.
- **What is left to this row.** A read of both passages against the help output and against the design's clause, and `make invocation` and `make links` on the branch head. A second copy of the matching rule is what this row must not add.
