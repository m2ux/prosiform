**Component:** src/prosiform/cli.py

## Overview

The `-m ORIGINAL=ALTERNATIVE` option: its spelling, its parsing into the mapping, and the command lines it refuses.

## Problem

The grammar admits no option carrying a pair of references. `override`, the only value parser the command has, admits a positive decimal integer, and `parser()` declares each option explicitly, so a new option is new surface in the help output and in the documented invocation together.

## Proposal

**The scene.** `parser()` builds the grammar and `execute` reads it. A value the grammar cannot admit becomes a `Failure` with `E_INVALID_USAGE` and exit status 2, which is the outcome the contract already gives a command line the grammar refuses.

**The design.**

- **The option.** `-m`, long form `--mock`, `action="append"`, metavar `ORIGINAL=ALTERNATIVE`, so its help text names the shape it takes. No default: an absent option is no mapping.
- **A value parser of its own.** A local `mapping(value)` beside `override`, splitting on the first `=` and refusing a value that carries none or whose side is empty. Each side then resolves through `entry`, so a malformed reference is reported with the diagnostic and chain a malformed entry already carries, rather than a second rule for the same defect.
- **The mapping is built once, in `execute`,** after `referring` and `requested` are normalized, so every stage receives one instance.
- **A substitution must not be culpable for the tool's own output.** A mapping whose key or value normalizes to a path a run would publish is refused as invalid usage, as an output path naming an input source already is.
- **Refusals.**
  - Two keys normalizing to one identity, because the second would silently win.
  - A key and its value normalizing to one identity, because it states nothing and reads as a substitution that took effect.
  - A value naming no Markdown document, because no document is what the run would carry.
  - A key or value outside the working directory, refused by the resolution the grammar already performs.
