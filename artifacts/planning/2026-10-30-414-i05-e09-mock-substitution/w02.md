**Component:** src/prosiform/cli.py

## Overview

The three mapping shapes that state nothing and must be refused, with the fixtures that show each refusal and the run it leaves unpublishing.

## Problem

A repeatable option admits values the grammar cannot tell apart by shape. Two keys normalizing to one identity means the second silently wins, and a key whose sides normalize to one identity is a substitution that changed nothing while reading as one that took effect. Neither is visible in a bundle, and neither fails any other check.

## Proposal

**The scene.** A value the grammar cannot admit becomes a `Failure` carrying `E_INVALID_USAGE` and exit status 2, which is the outcome the contract gives a command line it refuses. The refusals are decided where the whole mapping is known, which is after every entry has been parsed rather than per value.

**The design.**

- **Duplicate keys.** Each entry contributes its key's identity to a set; a second entry with an identity already there is refused, naming both spellings the author wrote rather than the one identity they normalize to, so the message says which two options to edit.
- **A self-mock.** An entry whose key and value normalize to one identity is refused, because the redirect is what the option states and it states none.
- **A fragment-only key.** A key of the form `#section` names no document to redirect, so it is refused rather than resolved against something the option does not name.
- **Each refusal names its own fault.** All three carry `E_INVALID_USAGE`, and the message names the references concerned, so a caller reading the code is sent to the command line rather than to a document.
- **Nothing is published.** The refusals are raised before any source is read, so a refused run opens nothing and writes nothing, which is what the fixture's `absent` declaration holds.
- **The row is not divisible further.** Both refusals are decided from the same identity set, and a pull request carrying one without the other leaves a mapping shape that silently wins. They land together.
