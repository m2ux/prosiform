**Component:** invocation.md

## Overview

The option's row states the folder form beside the document form, the help string states it too, and one example-skill scenario exercises a whole folder.

## Problem

The mapping is documented and demonstrated one document at a time.

- **The documented row states one pairing shape.** `invocation.md` names a document and a section, and its bundling paragraph states that a section key takes precedence over a document key. A folder key's precedence is a rule a caller writing two of them needs and no page states.
- **`make invocation` compares both directions.** The option table and the build's help output must name the same options, so the row and `cli.parser`'s help string change together or the check fails.
- **W08 proves one stub.** `make mock-scenarios` copies the example tree, redirects one artifact and one conventions file. A mode's protocols are several documents, so exercising a mode against stand-ins drawn from a folder is a different case and the one the folder pairing exists for.
- **A stub folder needs a tree to be written into.** It cannot ship inside the skill, and a `usage-example` fixture reaches the tree through a symbolic link, so the run-time copy W08 already makes is where a folder of stubs can be written.

## Proposal

**The scene.** `invocation.md`'s row reads `-m, --mock ORIGINAL=ALTERNATIVE`, its bundling paragraph states the matching rule, and `make mock-scenarios` copies `example/work-planner` into a temporary directory and runs `pf` against the copy with `-o -`.

**The design.**

- **The row states the folder form.** A side ending in a separator names a folder, both sides carry it or neither does, and the grammar refuses a pair that disagrees.
- **The precedence is stated in one sentence.** An exact key answers before a folder key, and of two folder keys holding one reference the longer is used.
- **The help string is edited with the row**, so the two-way comparison holds them.
- **One folder pair replaces every entry per file.** The scenario passes `-m protocols/=stubs/protocols/`, the copy's `stubs/` holding a stand-in for each protocol the mode reaches, and the bundle carries each stand-in where the real protocol's heading stood.
- **The stubs declare.** Under the inclusion rule a redirect reaches a document because the substitute declares, so each stub carries `prosiform`, and the check states that as part of what it demonstrates.
- **The check compares the outline rather than the bytes.** Each protocol's heading is where the stub's heading stands, which is the property the row states, and a byte comparison would restate every stub's prose in the check.
