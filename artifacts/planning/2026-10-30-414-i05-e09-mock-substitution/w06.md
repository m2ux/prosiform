**Component:** src/prosiform/closure.py

## Overview

Mapping keys that name a section rather than a whole document, so a fixture can redirect one section and leave the rest of that document real.

## Problem

A key without a fragment covers a document and every fragment of it, which is what a caller wants when the whole document is the thing being replaced. A caller rehearsing one branch of a procedure wants a single section redirected while the document's other sections compile as they ship, and a whole-document key cannot express that.

## Proposal

**The scene.** `identity` joins a path and a fragment into the name two spellings of one dependency share, and a fragment on a `Reference` is the decoded section name a later `section` lookup resolves against.

**The design.**

- **Precedence.** The lookup asks for the exact `(path, fragment)` key first and the `(path, None)` key second. The exact key wins, so a document-wide redirect and one section's redirect coexist in one mapping and the narrower one takes the section it names.
- **A key's fragment is a section name,** decoded as any fragment is. It is matched against the identity a link normalized to, so `rules.md#escalation` matches a link written `./rules.md#escalation` and does not match `rules.md#Escalation`.
- **A fragment-only key is refused.** A key of the form `#section` names no document to redirect, so the value parser refuses it rather than resolving it against something the option does not name.
- **The fragment a link carries is not required to be the key's.** A key may redirect `rules.md#escalation` to `stand-in.md`, and the substitute carries no fragment, so the whole substitute is the target.
- **A redirected fragment is the substitute's.** Where the substitute carries a fragment, that is the section the bundle selects, because the redirect replaces the reference rather than only its path.
