**Component:** src/prosiform/closure.py

## Overview

The substitution mapping, the option that carries it, and the identity it matches on — with the three fixtures that show a redirected link, the documented option, and the exemption from the writing source's root. The mapping and the option are one change: a mapping nothing can be passed is unobservable, and an option with nowhere to put its pairs is unused.

## Problem

Resolution is reached through `inside`, `resolvable`, `bundled` and `withholding_target`, and each returns a `Reference` its caller reads directly. A mapping has nowhere to sit that a caller cannot bypass, and the grammar admits no option carrying a pair of references: `override`, the only value parser the command has, admits a positive decimal integer.

## Proposal

**The scene.** `cli.required` asks `inside` for each link in selected content, `bundle.target` asks `bundled` and `withholding_target` while rewriting the same link, `candidate` asks both again while comparing the emitted text, and `cli.entry` resolves a positional reference before any source is read. Four of those five are one question asked at different times.

**The design.**

- **One seam per resolution path.** The mapping is a parameter of `inside`, threaded through `resolvable`, `bundled` and `withholding_target` beside the `root` each already takes. `entry` normalizes a positional reference and `-f` through `resolve` directly, before any source is read, so it takes the mapping too. Both paths apply it in the same place: to the reference a caller authored, before the name of the file the run opens is decided.
- **The mapping is applied after the root check, not before.** `inside` holds a normalized path to `covers(root, path)` and raises `OutsideRoot` where it fails. A substitute is exempt from the writing source's root, so applying the mapping before that check would refuse every substitute kept beside the tree under test — which is the case the feature exists for. The mapping is applied to the reference `inside` returns, after the check has been made against the authored path.
- **A mapping value.** An immutable type holding keys to references, offering one lookup: the exact `(path, fragment)` key first, then `(path, None)`. A lookup returns the substitute's `Reference` whole, so the resolved path and fragment are the substitute's.
- **Both sides resolve from the invocation working directory.** Each passes through `resolve` with parent bootstrap permitted, as a positional entry does, so percent decoding, control-character refusal and `..` normalization are the grammar already there. Neither is held to the writing source's root.
- **The option.** `-m`, long form `--mock`, `action="append"`, metavar `ORIGINAL=ALTERNATIVE`. A local value parser splits on the first `=` and resolves each side through `entry`, so a malformed reference is reported with the diagnostic an entry already carries.
- **The carried walk is the substitute's.** `walk` becomes the substitute's authored path, so the no-follow walk, the bound root and the recheck read the file the parameter named.
