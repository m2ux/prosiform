usage: prosiform --root DIR [OPTIONS] REF [REF ...]

Bundle the local Markdown closure of one or more entry references into one validated document.

positional arguments:
  REF                   an entry reference: a root-relative document, a
                        document and a fragment, or a fragment alone with
                        --from

options:
  --root DIR            the allowed source root; required, and resolved from
                        the working directory
  --from DOC            the root-relative referring document a fragment-only
                        reference resolves against
  -o, --output FILE     publish the validated bundle to FILE, atomically;
                        default or - is standard output
  --group SLUG:DEPTH    merge every document under a directory named SLUG at
                        source heading level DEPTH, 1 through 6; repeatable,
                        once per slug
  --check               discover, bundle and validate without emitting or
                        publishing the bundle; accepted with --output
  --diagnostics {text,json}
                        the diagnostic format on standard error; default text
  --fault {source-changed,internal}
                        perform a fault on the run itself, so a conformance
                        run reaches an outcome no source tree states; none by
                        default
  --max-files N         the budget of distinct source documents opened; a
                        positive decimal integer, default 256
  --max-file-bytes N    the budget of raw bytes in one source; a positive
                        decimal integer, default 1048576
  --max-input-bytes N   the budget of raw source bytes, counted once per
                        source; a positive decimal integer, default 16777216
  --max-output-bytes N  the budget of bytes of the complete bundle; a positive
                        decimal integer, default 262144
  --max-targets N       the budget of distinct document and section targets
                        discovered; a positive decimal integer, default 4096
  --max-links N         the budget of authored link and image occurrences in
                        selected content; a positive decimal integer, default
                        32768
  --max-nesting N       the budget of levels of container nesting in one
                        source; a positive decimal integer, default 64
  --max-expansion-depth N
                        the budget of link hops from the nearest entry
                        reference; a positive decimal integer, default 8
  --codes               report the error and warning codes this build can emit
  --version             report the tool version and the profile identifier
  --help                show this usage, the defaults, and the exit-status
                        meanings

exit statuses:
  0  successful compilation, validation, or informational response
  1  input, dependency, policy, safety, or resource-limit failure
  2  invalid usage or option combination
  3  output publication or delivery failure, a broken pipe among them
  4  unexpected internal error
