# Compact Command Interface — October 2026

> Standalone task plan · Created 2026-10-22

## Executive Summary

Prosiform's compact interface uses `pf`, short flags and a concise command specification for agents. The user confirmed short forms as the primary interface.

The task reduces invocation and reference-reading token costs while retaining the command contract. Reproducible measurements and behavior checks establish both savings and fidelity.
