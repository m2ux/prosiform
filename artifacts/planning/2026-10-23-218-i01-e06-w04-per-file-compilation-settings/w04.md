**Component:** src/prosiform/cli.py

## Overview

The compiler assembles selected files from their own metadata and exposes one structural configuration path.

## Problem

Membership and depth come from a global CLI rule map, so linked sources cannot govern their own arrangement.

## Proposal

Aggregate explicit memberships from contributing Source records after closure selection. Validate shared group depth deterministically with both field locations. Feed the existing renderer and candidate validator the same validated groups; preserve source ordering and destination identity. Remove -g, global directory rules, unused-rule diagnostics and their obsolete tests. Update affected invocation, diagnostic and grouping fixtures alongside this behavior. Preserve existing renderer naming for groups unrelated to directory names; exercise duplicate basenames and anchor collisions before changing any naming helper.
