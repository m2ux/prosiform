**Component:** `checks/triage.py`, `checks/README.md`, `Makefile`

## Overview

A behaviour change moves what the build produces, and the corpus states what it produced before, so a red run has to be read before any of it is accepted. Triage names each stale fixture under the category its difference falls in, so a change accepts the drift it intended and leaves every other category for a reader.

## Problem

Bringing `main` back from a red run took two hand-written scripts and one judgement no script made.

- **A rewrite at fixture scale is unreviewable by hand.**
  186 fixtures failed that run, and reading 186 diffs by hand is what a maintainer does instead of reading the one that matters.

- **Nothing distinguishes accepting intended drift from accepting all of it.**
  Without a category to select on, a rewrite takes everything a red run names, including the fixtures whose clauses the change was not about.

- **The useful scripts exist twice and are reachable from nowhere.**
  `scripts/regenerate.py` was committed with the fix and a second copy was written for the planning record, so the next red run writes a third.

## Proposal

- **Drift is classified before a byte is compared.**
  Triage reports whether lines were inserted, removed, both, or rewritten in place, per fixture, under the declared categories.

- **A category can be selected.**
  `--only` restricts a rewrite to the category it names, which is how a change accepts the drift it intended.

- **The tool lives where the corpus maintains itself.**
  It joins `checks/`, imports the same `runner.py` the corpus uses, and is named in `checks/README.md` beside the checks it serves.

- **Scope boundary.**
  Triage reports and classifies; it adjudicates nothing. Whether a difference is drift or a defect is the reader's judgement.

## Work Breakdown

| Part | Description |
| --- | --- |
| Analysis | Read `checks/runner.py`'s result type and the corpus's comparison, and the categories the failed run's fixtures fall into |
| Plan | Declare the categories, the selection flag, and the guide entry the tool is reached from |
| Implementation | The triage command over the runner's result, with `--only` |
| Review | Confirm a fixture declaring an internal error is read as identical rather than as drift |
| Test | A corpus holding one fixture of each category, with one selected |

## Acceptance Criteria

- [ ] **AC1.** Triage reports each fixture's difference as one declared category, and a run over a corpus holding one of each category names each fixture under its own, as that run shows.
- [ ] **AC2.** `--only` restricts the rewrite to the category it names, as a run over a corpus holding two categories with one selected shows.
- [ ] **AC3.** A green corpus run leaves the tool reporting nothing to rewrite, as the tool run over `make corpus`'s passing tree shows.
