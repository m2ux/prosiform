## Overview

Restatement refuses a fixture whose run failed in itself, so a fault never becomes a fixture's expectation.

## Problem

- **A fault is recorded as the expectation.**
  A fixture whose run reports an internal error looks like a fixture that failed, so a regeneration driven from that verdict writes the crash into the corpus.

## Proposal

- **A fault is refused rather than recorded.**
  Restatement reads the runner's verdict for each fixture. A fixture whose run failed in itself is named and skipped and the exit status is nonzero, so a pipeline that regenerates on a red build cannot write a crash into the corpus.
