## Overview

A deferral naming a document that declares alternatives is checked against the run that compiles it later. That run compiles the published link as its entry, and needs an alternative in force only where one changes what the entry selects, so a deferral to content no alternative changes names none.

## Problem

- **A deferral needs a pick the later run does not.**
  The check refuses a deferral naming no alternative whatever its target selects, though the later run compiles a section no alternative changes with none in force.
- **The two link forms disagree.**
  `[Hand-off](stage.md#hand-off)` compiles and `[¬ Hand-off](stage.md#hand-off)` fails with `E_UNSUPPORTED_CONSTRUCT`, where `stage.md` declares alternatives and none changes its Hand-off section.

## Proposal

- **The check follows the later run.**
  A deferral naming no alternative is accepted where `routed` finds no alternative changing what the published link selects when compiled as an entry.
- **The refusal stands where a pick is needed.**
  A deferral naming no alternative to content an alternative changes fails with `E_UNSUPPORTED_CONSTRUCT`.
- **A pick that is made is honoured.**
  A deferral naming one alternative, or carrying `?`, publishes as authored, and a `?` dispatch keeps its check.
