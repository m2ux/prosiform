## Overview

`evals/diagram-following/README.md` states every form, scenario field and scoring class as the merged build and the pinned design have it.

## Problem

- **The page was written epic by epic.**
  Each epic amended the parts it touched, so the page as a whole was never read against the merged build.
- **A stale claim reads as current fact.**
  A reader of the MVP takes the page as the contract.

## Proposal

**The scene.** `evals/diagram-following/README.md` documents every form, scenario field and scoring class.

**The design.**

- **The page is read whole against the build.**
  Each claim is checked against `make harness`, `workflow.py` and `score.py`, and each behaviour of its subject the build has is stated.
- **The evidence is recorded.**
  The pull request lists each claim corrected or added and what showed it.
