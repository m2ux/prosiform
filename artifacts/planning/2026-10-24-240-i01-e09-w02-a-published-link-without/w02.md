**Component:** src/prosiform/rewrite.py

## Overview

A published bundle reads as prose where an author deferred a link, because the mark that told the compiler to wait is authoring syntax rather than content.

## Problem

The invocation guide requires the mark and the spaces after it to survive emission, so nine expected stdout files carry `¬` into a document written for one reader. `[¬ Codex](rules/codex.md)` publishes as `[¬ Codex](rules/codex.md)`, and the sentence around it reads as a fragment.

## Proposal

Emit a deferred link's text with the mark and the spaces following it removed, keeping the text and the destination `rebased` produces. Leave classification alone: `¬` still withholds the compilation, its target still must exist and name the heading it names, and discovery, emission and candidate validation still read one answer from `deferring`. Regenerate the expected stdout files that carry the mark and revise the test modules that assert it survives. State the published text in the invocation guide's deferred-links clause, the glossary entry and the design's deferral clauses.
