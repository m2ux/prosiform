The documentation describes a tree that is no longer the example.

- **`fixtures/README.md` is already correct.**
  W06 changed it as it repointed the fixtures, so it names `example/work-planner`. Verify rather than rewrite.

- **Both documents name `example/work-planner`.**
  Every path, link and command points at the tree the corpus now sources.

  The output blocks cite the fixtures W06 re-recorded. A block whose cited fixture changed is updated to match it.

- **`fixtures/README.md` is verified, not restated.**

## Implementation Findings

- **The stale excerpt was not the only one.**
  The record named the `## Prerequisites` block. Every other block was stale too: the artifact declaration gained `group-heading: false`, the merged bundle lost its `# Artifacts` heading and its members changed, the bare-fragment bundle's preamble changed, the my-skill block showed source spelling rather than the emitted paths, and the two procedure bundles were 5,057 bytes where they are now 203,906. Each was re-read as the brief directs, and each was replaced.

- **`make links --online` is not a command make accepts.**
  Make reads `--online` as its own option and exits `2`. The `links` target already passes `--online` to `checks/links.py`, so `make links` is the online run. AC10's instrument is recorded as `make links`.

- **The tree needed no change for its documentation to work.**
  All eight published commands exit `0` from the directories the pages name. Nothing under `example/work-planner` was edited.

- **`example/work-tracker` remains reachable and still bundles.**
  `README.md`'s `## Usage` and `src/tests/test_handoff_round_trip.py` both bundle it. Neither is one of AC10's three documents. Both are deferred.
