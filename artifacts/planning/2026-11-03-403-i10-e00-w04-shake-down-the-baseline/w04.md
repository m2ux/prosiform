**Component:** main:evals/diagram-following/RUNBOOK.md

## Overview

The baseline's runbook proven on the hardened corpus: a session shakes it down before the run on the user's model and sets its budget, so the baseline run carries no judgement of its own.

## Problem

- **The baseline's runbook is written before its corpus exists.**
  E05 W00 writes every runbook's text, but the harder scenarios W01 adds arrive later, so the runbook's budget and stop rules are unmeasured.
- **The baseline's model is unrecorded.**
  The runbook's Baseline names its model as still to be recorded, and the runner's default `--models` holds two models where the default matrix has one.

## Proposal

**The scene.** `RUNBOOK.md` holds the triage rubric and a runbook per live run; a run row follows its runbook and escalates what the rubric marks a defect. `make eval-diagrams` runs the default matrix within `EVAL_BUDGET_TOKENS`, at the runner's default session cap.

**The design.**

- **The default matrix's model is recorded.**
  `RUNBOOK.md` records `claude-haiku-5-5` on the `claude` harness, the model the user named on 2026-11-03, as the baseline's model, and the runner's default `--models` is that one model, so the default matrix is the baseline's: 74 cells, five repetitions, 370 sessions.
- **A shakedown over the hardened corpus.**
  The baseline runbook carries a Shakedown: one repetition of every cell of the default matrix, 74 sessions, at the proof shakedown's 400 000-token session cap, within a USD 5 spending cap. The session runs it, fixes every harness, scenario or plumbing fault it finds in this pull request, and records the run and its measured cost in the runbook.
- **The default budgets follow the measured sessions.**
  By the proof's rule, the baseline's session cap is the shakedown's largest session doubled and rounded up to the next 10 000, its token budget the sessions times that cap, and its cost cap the sessions times the mean session cost, doubled and rounded up to the next dollar. The runner's default session cap takes the baseline's, `EVAL_BUDGET_TOKENS` covers the default matrix at it, and the README states both.
- **The rubric meets the new scenarios.**
  Every failing session the shakedown produces takes a rubric disposition; a class the rubric cannot decide gains the entry that decides it.
