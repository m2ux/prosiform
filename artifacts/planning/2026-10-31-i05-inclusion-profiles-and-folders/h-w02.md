**Component:** src/prosiform/closure.py

## Overview

A preset's pair resolves from the file that declares it, so one declaration reads the same wherever the run starts.

## Problem

The pair's sides are references, and a reference has a base.

- **`entry` resolves from the working directory.** `mock(value)` calls `entry` on each side, which resolves from the captured invocation directory, so the declaration means different documents when run from different places.
- **Every other path in a document resolves from that document.** A link resolves from the file that writes it. A pair declared in that file's frontmatter is a path the file states, so the same rule applies.
- **`resolve` already takes a base.** `closure.resolve(text, base, allow_parent=True)` is exactly the call a link makes, so the grammar and its normalisation are unchanged.
- **A parent segment still reaches upward.** With the declaring file as the base, `../stub.md` names the parent of that file's directory, which is what an author writing in `modes/` expects.

## Proposal

**The scene.** `mock(value)` returns a pair of `Reference` values, and `Substitution` holds them keyed by the identity each normalises to.

**The design.**

- **The base is the declaring file's directory.** A preset's pair is read with that directory, so `rules.md=stub.md` in `modes/plan-mode.md` names `modes/rules.md` and `modes/stub.md`.
- **The grammar is the reference grammar.** Percent decoding, control-character refusal, drive-path refusal and `..` normalisation are all unchanged, because the call is the one a link makes.
- **A parent segment is admitted.** `../rules.md` names the directory above the declaring file, which is how a mode in `modes/` names the skill root's rules.
- **A preset is portable.** The same declaration copied to another directory names its neighbours there, which is what a per-file setting should do.
- **The option's basis is not preserved.** [I08:E07](https://github.com/m2ux/prosiform/issues/414) resolved from the working directory because a command line has no declaring file. A preset does, so the rule differs and the clause states it.
