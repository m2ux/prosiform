**Component:** fixtures/mock

## Overview

Every landed fixture that passes `-m` and whose behaviour survives states its pair in a preset's `subst` instead with its expected result unchanged, and each fixture for a retired capability is withdrawn by the row that retires it.

## Problem

All 25 fixtures under `fixtures/mock/` pass the option, and they are the mapping's only evidence.

- **They pass `-m ORIGINAL=ALTERNATIVE` in `arguments`.** Some state behaviour that survives the channel; others state a capability another row retires: `a-substitute-root-bounds-its-own-links` and `a-citation-outside-the-root-is-redirected` (`root`, E00), `a-redirected-referrer-carries-its-entry` (`-f`, E03), `a-redirected-entry-derives-its-name-from-the-substitute` (W07) and the six folder fixtures (W08).
- **Each declares an expected result.** The bundle carrying the substitute, or the exit status a key naming an absent document produces. Neither changes when the channel does.
- **The pair's path basis changes with the channel.** A fixture's declaration moves into its `source/` tree, so the sides are written from the file that declares them rather than from the fixture's working directory.
- **The fixtures are the evidence the mechanism moved.** A changed expected result would mean the substitution moved, when only where it is written should.

## Proposal

**The scene.** A fixture declares a `source/` tree, an `invocation`, and the bundle the run must write.

**The design.**

- **Each pair moves into the `default` preset of the document that writes the link.** `default` is always in force, and a pair substitutes only the links its declaring document writes — the rule [I08:E01](https://github.com/m2ux/prosiform/issues/436) states.
- **The sides are rewritten from the declaring file.** A pair that read `rules.md=stand-in.md` from the working directory becomes the same two names resolved from the entry's directory, which in most cases is the same text.
- **No expected result changes.** The task's evidence is that every manifest's `expected` block is untouched.
- **A fixture asserting the option's absence is new.** `fixtures/cli/the-mock-option-is-gone` states that a command line passing it is invalid usage.
- **The corpus names no option.** A check that no manifest's `arguments` holds `-m` makes the removal complete rather than mostly complete.
