**Component:** src/prosiform/cli.py

## Overview

The selected preset is the whole argument set for its compilation. Nothing outside it reaches that compilation, so `-m` is the default only where no preset is selected.

## Problem

Two layers of arguments would otherwise meet at one lookup.

- **`-m` is run-wide.** `cli.substitution(options)` folds the command line's pairs before any source is read, and every compilation reads that one mapping.
- **A preset states its own.** A preset holding a `mock` states what its compilation substitutes, and a command-line pair it does not name is a second answer for a compilation that already has one.
- **A collision is already refused.** `main` refuses two pairs normalising to one identity, and a pair whose sides normalise to one identity, so a preset's entries carry the same two refusals.
- **A preset naming nothing is not meaningless.** It states a compilation that substitutes nothing, which is a different claim from one that inherits `-m`.

## Proposal

**The scene.** `substitution(options)` folds the command line's pairs into a `Substitution`, and `compiled` reads it for its compilation.

**The design.**

- **Subsumption is one decision.** Where a preset is selected, its `mock` replaces the command line's for that compilation; where none is selected, `-m` applies as it does today.
- **A preset's refusals are its own.** Two entries normalising to one identity and a key and value normalising to one identity are refused where the preset is read, with the profile's location so the author is pointed at the document.
- **Each entry is a pair string.** Read by the option's parser, so percent decoding, `..` normalisation and the Markdown-suffix test are the grammar the command line already applies.
- **The command line is never silently narrowed.** A compilation that selects a preset and substitutes nothing is a statement the preset makes, and a run given `-m` over a tree whose sections all select presets is a run where `-m` reaches no compilation — which `W_MOCK_UNUSED` states.
- **One fold per compilation.** `Substitution` is built from the selected preset's pairs where there is one, and from the command line's otherwise.
