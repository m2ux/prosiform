**Component:** src/prosiform/cli.py

## Overview

A preset is the whole setting of its compilation, so nothing outside it reaches that compilation and a compilation selecting none substitutes nothing.

## Problem

Substitution has to come from somewhere, and the only somewhere is a preset.

- **The mapping is folded once.** `cli.substitution(options)` builds a `Substitution` from the command line before any source is read, and every compilation reads that one value. [I08:E06](https://github.com/m2ux/prosiform/issues/461) retires the option, so the fold has a different source.
- **`Substitution` holds the pairs.** Its lookup answers exact-first then the document key, and none of that changes; what changes is which pairs it holds.
- **A preset naming nothing is meaningful.** It states a compilation that substitutes nothing, which is the absence of a mapping rather than an empty one.
- **A name normalising to nothing is refused.** Two entries in one preset naming one identity, and a pair whose sides normalise to one identity, are each refused where the preset is read.

## Proposal

**The scene.** `compiled` builds one bundle from its entries, `traverse` resolves every reference through a `Substitution`, and the selected preset is what supplies it.

**The design.**

- **The preset is the whole setting.** Where a compilation selects one, its `mock` is the `Substitution` that compilation resolves through, and nothing else contributes.
- **A compilation selecting none substitutes nothing.** It is not a default and not an inheritance: with no preset selected, `Substitution({})` holds no pair, so every reference stays as authored. That is a statement an author reads in the clause rather than a fallback.
- **The refusals are the preset's own.** Two entries normalising to one identity and a pair whose sides normalise to one identity are refused where the preset is read, with the entry's location so the author is pointed at the document.
- **Each entry is a pair string.** Read by the reference grammar [I08:E06](https://github.com/m2ux/prosiform/issues/461) states, with its sides resolving from the declaring file.
- **One fold per compilation.** `Substitution` is built from the selected preset's pairs, so a document reached under two different presets resolves two ways, which is the coverage rule working.
