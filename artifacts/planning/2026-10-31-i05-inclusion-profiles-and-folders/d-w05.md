**Component:** src/prosiform/source.py

## Overview

A level written after the section name tells two headings of one name apart, so a carve-up can exclude one of a repeated pair.

## Problem

A document may carry two headings of one name, and the tool has one answer for that.

- **Inclusion refuses the ambiguity.** `source.section` raises `Ambiguous` where two headings produce one fragment, and `selection` reports it as `E_AMBIGUOUS_SOURCE_HEADING`. An exclusion has the same question with no way to answer it.
- **An exclusion cannot fall back to the refusal.** A file that must withhold one of a pair of same-named sections has no spelling for "the level-3 one", so the author would be forced to retitle a heading — the shape of problem the mock feature exists for.
- **The level is already known.** `heading.level` is the level each heading opens at, decoded from its token's tag, so a lookup by name and level is a filter over the index rather than a new parse.

## Proposal

**The scene.** `source.section(tokens, fragment)` returns the regions one fragment selects, or `None`, or raises `Ambiguous` carrying the lines the headings sit on.

**The design.**

- **A level is a filter over the heading index.** `source.section` gains an optional level. Where it is given, the headings matching the fragment are narrowed to that level before the ambiguity test, so one heading of a repeated pair answers and none of the others does.
- **The level selects the heading, not the cut.** What is removed beneath the chosen heading is the whole section, by the rule `section` already applies, so a level never changes how much goes — only which of a repeated name goes.
- **An exclusion naming a level the file carries nowhere is still silent.** It matches nothing, which is the ordinary miss, and no diagnostic is raised.
- **A level leaving two headings is refused.** Two headings of one name at one level are still ambiguous, and the run reports `E_AMBIGUOUS_SOURCE_HEADING` as inclusion does, with the lines both sit on.
- **The level is one through six.** No heading sits outside that range, and a value beyond it is refused where the exclusion is read rather than reaching this lookup.
