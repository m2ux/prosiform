**Component:** src/prosiform/cli.py

## Overview

A reference whose target is emptied by that preset's exclusions is refused, so a carve-up cannot publish a bundle the file empties.

## Problem

An exclusion is written independently of what reaches it.

- **The two are stated apart.** A preset's exclusion is written in frontmatter and the reference arrives from a link, and nothing compares them, so a document excluding every section it holds contributes nothing.
- **An empty contribution composes silently.** Every invariant candidate validation holds is a property of the construction, and a document contributing no region satisfies all of them. The bundle carries the other documents and reports nothing about this one.
- **The case compounds with presets.** A preset governing one reference excludes everything while a second reference under a preset excluding nothing carries the target whole, so the emptiness is per reference rather than per file.
- **A `-c` run is no different.** Check mode reports what a publishing run would publish, so a reference emptied by its exclusions is refused there too rather than passing because nothing was written.

## Proposal

**The scene.** `compiled` composes one bundle from its entries and the documents they reach. Each reference carries a settled region set, and the bundle concatenates every contributing reference's regions.

**The design.**

- **The refusal is decided where the reference's contribution is known.** `traverse` holds each reference's settled selection, so it is where an emptied contribution is visible. It raises `E_EMPTIED_ENTRY`, exit status `1`, nothing published.
- **The diagnostic names the reference and the exclusions.** It carries the writing source and the link as authored, the target's identity, and each exclusion that removed a region of it, so an author with several exclusions is told which did the removing.
- **A dispatched compilation is held to it too.** A dispatch's target is compiled as its own entry, so a preset emptying it refuses that compilation and the run publishes nothing, exactly as a refused dispatch target does today.
- **One surviving region is enough.** The threshold is emptiness rather than a share, because a share is a judgement the tool cannot make.
- **A withheld target is not a case.** A `¬` link's target contributes no content by design, and its regions are never settled, so nothing is refused for it.
- **The refusal precedes publication.** It is raised in the pass that composes the bundle, which runs before the run folder is written, so an earlier set stands untouched.
