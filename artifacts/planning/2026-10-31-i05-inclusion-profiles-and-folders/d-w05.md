**Component:** src/prosiform/cli.py

## Overview

An exclusion whose section holds content another reference selected is refused. The bundle cannot carry material beneath a heading its author removed, and the carve-up is corrected rather than half-applied.

## Problem

Exclusion and selection can reach the same region from opposite directions.

- **Consolidation unions before it settles.** Two references to one document overlap, and the union is the selection. An exclusion removes a region, and a second reference may have selected content inside it.
- **A structural ancestor is the tempting repair, and it is wrong here.** Selecting `### Detail` under `## Beta` emits `Beta` as a heading with no body, because nothing selected `Beta` itself. An exclusion is different: the author stated that `Beta` is gone, so emitting it as a heading contradicts the statement, and dropping `Detail` beneath a heading the author never wrote is worse.
- **The two readings are both silent.** Applying the removal and keeping the content publishes a bundle with a re-parented section; applying the removal and dropping the content publishes a bundle missing material another reference asked for. Neither states which the author meant.
- **The case is reachable.** A preset excluding a section of one document, over a run whose entry also selects that section, is one command line.

## Proposal

**The scene.** `traverse` holds each document's settled selection and the chain that reached it. `selection` raises the same input failures a fragment naming no heading raises, with the reference, the resolved document and the chain.

**The design.**

- **The refusal is decided where the settlement is.** `selection` knows the selected regions and the excluded ones, so it is where the intersection is visible. It raises `E_EXCLUDED_CONTENT`, exit status `1`, nothing published.
- **The diagnostic names three things.** The exclusion as the author wrote it, the section it removed, and the reference whose route selected the content inside it, which is the one fact an author needs to find the conflict.
- **A region excluded by one document's scope is no conflict elsewhere.** The test is per document, so an unqualified exclusion colliding in one document is refused for that document and the run states which.
- **A withheld target inside an excluded section is no conflict.** A `¬` link's target contributes no content, so the region holding the link is the only thing removed and no selected material sits beneath the exclusion.
- **The refusal is not a warning.** A half-applied carve-up is a bundle a consumer receives with material it should not have had, and no exit status reports that to the reader of the bundle.
