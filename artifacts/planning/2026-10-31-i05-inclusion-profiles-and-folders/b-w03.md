**Component:** src/prosiform/metadata.py

## Overview

The two remaining preset entries are stated: `exclude` holds names and single-entry name-to-level mappings, and `mock` holds `ORIGINAL=ALTERNATIVE` strings.

## Problem

Three preset entries need one shape each, and they do not share one.

- **An exclusion names a section, not a reference.** A `#Draft` spelling would read as a reference and be resolved against a document, which is what the entry does not do. The name is the section's text and the entry's meaning says so.
- **A level needs a home.** A document may carry two headings of one name, which inclusion refuses as ambiguous. An exclusion needs to say which one, and a bare name cannot.
- **A mock's sides are references.** A mapping key would put a path in key position, where a colon in the path collides with the separator the other two fields use, so the pair keeps the `=` the option writes.

## Proposal

**The scene.** [I08:E01](https://github.com/m2ux/prosiform/issues/436)'s key rule makes every `prosiform` key a preset, and each preset holds its settings as a mapping.

**The design.**

- **`exclude` holds a name, or a name and a level.** A list whose entries are `"Draft"` or `{"Tests": 3}`, the two forms in one list. Naming a section is the entry's meaning, so no `#` is written.
- **The level is an integer where a mapping is used.** It is validated as one and names the heading at that level, so a repeated name is excludable and no suffix has to be parsed back out of a string.
- **A mapping entry holds one string key and an integer value.** Two keys, a non-string key and a level outside one through six are refused as invalid metadata, so the single-entry shape is grammar rather than convention.
- **`mock` holds pair strings.** Each entry is read by the option's parser, so the sides keep the reference grammar, the percent decoding and the `..` normalisation the command line already applies.
- **The two shapes are stated together because they are read together.** A preset holding both is one mapping, and a reader meets the pair encodings in one place rather than discovering the second later.
