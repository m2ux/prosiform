**Component:** src/prosiform/cli.py

## Overview

A preset's exclusion is applied where the reference it governs is resolved, so one seam removes the material and every stage reads one answer. The grammar is a bare name with an optional level, and an exclusion naming nothing the target carries is silent.

## Problem

Selection is built once per document and read by five stages.

- **`cli.selection` returns the region set.** It resolves each reference a document's fragments name and unions them. It takes the document's tokens and the references naming it, so an exclusion has no parameter to arrive through.
- **Five stages read the result.** `required` follows the dependencies the selected content carries, `withheld` yields its withheld targets, `dispatches` its dispatched ones, `refusals_of_operators` refuses its contradictory marks, and `assemble` emits it. A stage reading its own answer would disagree with the four beside it.
- **A whole-document selection is `None`.** The parent group opens the bundle on its own title because its selection is `None` rather than a region set, so an exclusion has to narrow that case into an explicit region set.
- **The exclusion arrives with the reference, not with the document.** The governing preset is known where the reference is resolved, so that is where the carve belongs, and a second reference to the same document under a preset excluding nothing settles its own selection independently.
- **A silent miss is not an error.** One preset governs many references and many targets, so an exclusion naming a heading one of them lacks is an ordinary result rather than a fault.
- **A malformed exclusion is a metadata fault.** The run cannot state it against a source location, so it is refused where the frontmatter is read, before any link is resolved.

## Proposal

**The scene.** `traverse` computes `chosen = selection(path, parsed[path], selecting, requested)` for each reference it resolves and passes it to each stage. `metadata.decode` returns the exclusions a file's presets declare.

**The design.**

- **The settlement narrows per reference.** `selection` takes the exclusions the governing preset states, and returns the regions the reference carries less the excluded ones. Every stage already receives that value for that document, so no call site changes and none can forget the rule.
- **The carve applies only to a whole-file reference.** A reference carrying a fragment settles the section it names and consults no `exclude`, because explicit selection is the more specific statement.
- **An exclusion matches a document-level heading only.** A heading a container carries roots no section, so it is no more excludable than it is selectable, and the exclusion simply does not match there.
- **The section is removed whole.** The excluded heading's own region and every region beneath it are dropped, read by the rule `source.section` uses to select them, so the two sets are complements.
- **A whole-document selection becomes explicit.** Where a document's selection would be `None` and the governing preset excludes something from it, the selection becomes every region the document holds less the excluded ones. Where no exclusion applies, `None` stays.
- **A heading the target does not carry is skipped.** Matching is per target against that target's heading index, so a miss is silent and the exclusion applies wherever else it does match. No diagnostic is raised.
- **Two malformed shapes are refused at the metadata key.** An empty section and a level outside one through six fail with `E_INVALID_CONVERSION_METADATA` naming the entry, so one fault is stated once.
