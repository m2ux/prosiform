**Component:** src/prosiform/cli.py

## Overview

The option, the reference grammar it reads, and the three shapes it refuses before any source is opened.

## Problem

The command has no subtractive option, and the value parsers it has read numbers and pairs.

- **`override` and `mock` are the only value parsers.** `override` admits a positive decimal integer and `mock` a pair of references. An exclusion is a reference carrying an optional level, which neither reads.
- **`-x` and `-e` are taken.** `-x` injects a conformance fault and `-e` is the expansion-depth budget, so a short letter is not free in the range a caller reaches for.
- **A malformed exclusion is a command-line fault.** The run cannot state it against a source, since the author wrote it on the command line, so it is refused as invalid usage before any source is read.

## Proposal

**The scene.** `cli.parser()` declares each option with a `type=` parser, and `cli.entry` reads a reference through `closure.resolve` with parent bootstrap permitted.

**The design.**

- **One option, repeatable, long only.** `--exclude SECTION`, `action="append"`, metavar `SECTION`. No short form, so the letters the option table has left stay free and the help output states one spelling.
- **The section is a reference.** `closure.resolve` reads the path and fragment, so percent decoding, control-character refusal, drive-path refusal and `..` normalisation are the grammar already there. A bare `#Section` produces a reference with no path, which is what states the unqualified scope.
- **The level is a suffix on the fragment.** A trailing `:N` is split before the fragment is decoded, so an encoded colon inside a heading name stays a character of that name. N is one through six, since no heading sits outside that range.
- **Three refusals.** An empty section, a level outside the range and a section carrying a query each fail with `E_INVALID_USAGE` and exit status `2`, naming the entry as the author wrote it.
- **`diagnostic_format` reads it.** That function walks the value of every option taking one so a `-d` written after it is still found, and an option missing from its set leaves a later `-d` unread.
