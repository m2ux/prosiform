**Component:** src/prosiform/cli.py

## Overview

A document's exclusion is applied where its contribution settles, so one seam removes the material and every stage reads one answer. The grammar is a bare name with an optional level, and an exclusion naming nothing the file carries is silent.

## Problem

Selection is built once per document and read by five stages.

- **`cli.selection` returns the region set.** It resolves each reference a document's fragments name and unions them. It takes the document's tokens and the references naming it, so an exclusion has no parameter to arrive through.
- **Five stages read the result.** `required` follows the dependencies the selected content carries, `withheld` yields its withheld targets, `dispatches` its dispatched ones, `refusals_of_operators` refuses its contradictory marks, and `assemble` emits it. A stage reading its own answer would disagree with the four beside it.
- **A whole-document selection is `None`.** The parent group opens the bundle on its own title because its selection is `None` rather than a region set, so an exclusion has to narrow that case into an explicit region set.
- **A silent miss is not an error.** A preset is written once and applied across documents that vary, so an exclusion naming a heading one of them lacks is an ordinary result rather than a fault.
- **A malformed exclusion is a metadata fault.** The run cannot state it against a source location, so it is refused where the frontmatter is read, before any link is resolved.

## Proposal

**The scene.** `traverse` computes `chosen = selection(path, parsed[path], selecting, requested)` and passes it to each stage. `metadata.decode` returns the exclusions a file's `prosiform` declares.

**The design.**

- **The settlement narrows in place.** `selection` takes the exclusions and returns the selected regions less the excluded ones. Every stage already receives that value, so no call site changes and none can forget the rule.
- **An exclusion matches a document-level heading only.** A heading a container carries roots no section, so it is no more excludable than it is selectable, and the exclusion simply does not match there.
- **The section is removed whole.** The excluded heading's own region and every region beneath it are dropped, read by the rule `source.section` uses to select them, so the two sets are complements.
- **A whole-document selection becomes explicit.** Where a document's selection would be `None` and an exclusion applies to it, the selection becomes every region the document holds less the excluded ones. Where no exclusion applies, `None` stays.
- **A heading the file does not carry is skipped.** Matching is per document against that document's heading index, so a miss is silent and the exclusion applies wherever else it does match. No diagnostic is raised.
- **Two malformed shapes are refused at the option and at the metadata key alike.** An empty section and a level outside one through six fail with `E_INVALID_USAGE` on the command line and `E_INVALID_CONVERSION_METADATA` in frontmatter, so one fault is stated once wherever it is written.
