**Component:** main:checks/corpus.py

## Overview

Every corpus source declares its settings in a preset, and every fixture's expected bundle is unchanged.

## Problem

The corpus carries flat fields the field rules refuse.

- **Fixture sources declare `group` flat.**
  Each is refused by the field rules the epics before this one land.
- **Each family writes its own tree.**
  Each source carries `prosiform` for inclusion and a group only where the fixture is about grouping, so the rewrite is small per fixture and broad in count.
- **An expected bundle changing is a finding.**
  The migration rewrites a spelling, so a changed expectation means a field moved.

## Proposal

**The scene.** A fixture declares a `source/` tree, an invocation and the bundle the run must write.

**The design.**

- **Each flat pair becomes a `default` preset.**
  A fixture's own sources state each setting as a preset entry.
- **A source declaring only inclusion is unchanged.**
  A document whose `prosiform` holds no setting already satisfies the shape.
- **No expected bundle changes.**
  The evidence is that every `expected/` file is untouched by this task.
- **A corpus-wide check states the removal.**
  No fixture source declares a retired field, so a missed one fails rather than passing over a field the build refuses.
