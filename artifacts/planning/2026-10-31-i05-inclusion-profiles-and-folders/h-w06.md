**Component:** src/prosiform/closure.py

## Overview

A `subst` pair redirects only the links its declaring document writes. The document it links, the document linking it, a substitute and a dispatched target are each governed by their own presets alone.

## Problem

The delivered mapping is one value for the whole run.

- **`cli.substitution` builds one `Substitution` before any source is read.** Every call to `closure.inside` receives it, so a pair reaches every document's links, not the declaring document's.
- **A dispatched bundle inherits it.** `cli.compiled` passes the run's mapping into each dispatched target's own compilation, so a link inside the dispatched document resolves the caller's substitute.
- **A substitute's own section link is redirected again.** `closure.inside` redirects a fragment-only link through the mapping, so a substitute that is also a key sends `[part](#part)` to the next substitute: `pf -m a.md=b.md -m b.md=c.md guide.md`, with `b.md` holding `[part](#part)`, fails naming `c.md#part`.
- **No criterion holds the reach.** The revised model states that a preset governs only the document that declares it, and nothing would fail if a pair reached further.

## Proposal

**The scene.** Each document's selected presets are known where its content is compiled, and `closure.inside` resolves each link that document writes.

**The design.**

- **The mapping is the writing document's.** Each link resolves through the `subst` pairs of the presets governing the document that writes it, and through no other document's.
- **A substitute is governed by its own presets.** A link the substitute writes, a fragment-only one included, resolves through the substitute's own pairs, so `[part](#part)` names the substitute's own section.
- **A dispatched target's bundle reads its own presets.** The run's dispatches compile each target under that target's presets, selected by the section holding the dispatch.
- **The record stays the run's.** `W_SUBST_USED` and `W_SUBST_UNUSED` still report once per pair, now keyed by the declaring document and its pair.
