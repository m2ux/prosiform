**Component:** src/prosiform/metadata.py

## Overview

The key set opens by rule: a key naming an argument is an argument, a key holding a mapping is a preset, and anything else is a misspelled field. A preset is decoded into the shapes the mapping already holds.

## Problem

`metadata.decode` decides one question per key and refuses every key it does not know.

- **The refusal is total.** `fields` accepts `("root", GROUP, DEPTH)` and raises `E_INVALID_CONVERSION_METADATA` for anything else, so a preset key is refused before its value is read.
- **A preset's entries are the mapping's entries.** A preset holds substitution pairs and budget overrides, and `cli.mock` and `override` already parse those shapes on the command line. Duplicating their grammar in `metadata.py` would put one rule in two parsers.
- **A key's kind is not knowable from its name alone.** `mock` is an argument name and also a plausible preset name; `procedure` is a preset name and no argument. The value decides, which is why the rule is stated as a shape rather than a list.

## Proposal

**The scene.** `decode` iterates the `prosiform` mapping's pairs, refuses a key outside a fixed tuple, checks each field's type, and returns a `Conversion` carrying the three values.

**The design.**

- **Three kinds of key.** A key in the argument-name set carries a scalar and is decoded as that argument is; a key whose value is a mapping is a preset, decoded into the pairs and overrides it holds; any other key is refused with the existing code, naming the key.
- **The settable set is named, not derived.** The options that shape the bundle are `mock`, `exclude` and the budgets `-F`, `-B`, `-I`, `-O`, `-T`, `-L`, `-N` and `-E`. Read from the parser's table, an option that writes or reports — `-o`, `-c`, `-d`, `-x` — would be settable by a document, so a document could redirect its own bundle or silence diagnostics. The set is one tuple beside the parser, and a test holds it to the options the help output declares, so adding an option fails until someone decides which side it belongs on.
- **Every argument value is a list.** A repeatable option and a single-valued one hold one shape, each entry read by the option's own parser. A scalar is refused, so `mock: ["rules.md=stub.md"]` is the only spelling and `exclude` reads the same way.
- **A preset's entries are parsed by the command's own parsers.** `Conversion.presets` holds, per name, the pairs `cli.mock` returns and the overrides `cli.override` returns, so a malformed pair or a non-positive budget is refused with the message the command line carries.
- **An empty preset is refused.** A preset holding nothing states a name that governs nothing, and the run cannot tell it from a misspelling; it fails with `E_INVALID_CONVERSION_METADATA`, naming the preset.
- **A shape the command does not carry is refused.** A preset key holding a scalar, a pair whose sides are not references and a budget naming no option each fail with the code and the location the caller's other metadata faults carry.
