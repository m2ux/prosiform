**Component:** src/prosiform/cli.py

## Overview

One repeatable `--budget NAME=VALUE` replaces the eight letters, and its value parser states the names, the integer rule and the duplicate refusal.

## Problem

The family is generated from a loop and its validity lives in the grammar.

- **The parser loops over `BUDGETS`.** Eight `add_argument` calls come from one loop, each with `dest=budget.dest` and `type=override`, so the letters are a rendering of the table.
- **`override` states the integer rule.** A positive decimal integer and nothing else, with zero refused rather than read as unlimited, and that rule is unchanged.
- **`budgets(options)` reads eight attributes.** It builds `Limits` from `getattr(options, budget.dest)`, so a collapsed option changes that read to one mapping.
- **`diagnostic_format` walks value-taking options.** An option missing from its set leaves a later `-d` unread, so the new option joins that set as the eight did.

## Proposal

**The scene.** `parser()` declares each option with a `type=` parser, and `budgets(options)` returns the `Limits` in force.

**The design.**

- **One option, `action="append"`.** `--budget NAME=VALUE`, metavar `NAME=VALUE`, with no short form: the letters are what the collapse removes.
- **The value parser splits on the first `=`.** An entry carrying none, an empty name and an empty value each raise the parser's own error, so the message a caller sees is the one `argparse` renders for a bad value.
- **The name is resolved against `BUDGETS`.** A name matching no budget raises the same error, naming the eight admitted.
- **The value is read by `override`.** The existing integer rule is applied to the right side, so zero is still refused and still does not mean unlimited.
- **A name given twice is refused.** The parser collects the pairs and refuses a repeat, naming the ceiling, because two entries for one ceiling state one thing twice.
- **The result is a mapping.** `budgets(options)` turns the parsed pairs into `Limits` by looking each name up, so the read is one mapping rather than eight attributes.
