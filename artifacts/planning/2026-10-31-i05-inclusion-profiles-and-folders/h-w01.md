**Component:** src/prosiform/cli.py

## Overview

The option is removed, its value parser goes with it, and the mapping a preset holds as `path-sub` is read where the reference it governs is resolved.

## Problem

The option and its plumbing sit in one file.

- **`parser()` declares it.** `--mock` with `dest="mock"`, `action="append"` and `type=mock`, so the grammar admits the pair.
- **`substitution(options)` folds its pairs.** That function builds a `Substitution` from `options.mock` before any source is read, and every compilation reads it.
- **`mock(value)` parses a pair.** The split on `=` and the two `entry` calls are the grammar a preset's pair needs, so the function survives the option; its folder branch goes with the folder pair in [h-w08](h-w08.md).
- **`diagnostic_format` walks its value.** An option missing from that set leaves a later `-d` unread.

## Proposal

**The scene.** `main` parses the command line, `compiled` builds one bundle from its entries, and `traverse` resolves every reference through a `Substitution`.

**The design.**

- **The option is removed.** `parser()` declares no `--mock`, and `diagnostic_format` no longer lists it.
- **`path_sub(value)` survives as the preset's pair parser.** A preset entry is read by the same function the option used, so percent decoding, `..` normalisation and the Markdown-suffix test are unchanged. It is named for the entry it parses.
- **`substitution(options)` is replaced by a read of the governing presets.** The `Substitution` for a reference comes from the presets governing it, not from a `Namespace`, so one fold remains and its source changes.
- **A pair resolves from the declaring file.** `path_sub(value)` gains the declaring document's directory as its base, so `entry` is called with a `base` rather than from the working directory.
- **An empty mapping is what a reference under no `path-sub` reads.** `Substitution({})` is already the absence, so nothing new states it.
