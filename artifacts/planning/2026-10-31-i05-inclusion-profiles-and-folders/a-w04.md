**Component:** src/prosiform/cli.py

## Overview

A link naming nothing is text, and the two shapes that still fail keep failing. Responsibility is stated by the mark an author writes, not by the directory a path lands in.

## Problem

`E_TARGET_NOT_FOUND` is raised by presence of path rather than by the author's statement.

- **The refusal follows the boundary.** `cli.read_document` raises `TARGET_NOT_FOUND` for a path under the root that names no document, and `cli.required` treats a path outside the root as a citation. With no boundary, every absent link would be text and a misspelled dependency would reach the bundle as a link to nothing.
- **An operator states responsibility already.** `refusals_of_operators` requires an operator's target to be a Markdown document or section, and it resolves the target through `resolvable` — which, after W03, answers a target declaring nothing as no dependency, so every marked link to a silent document would be refused as though it named a resource.
- **A fragment-only link has no absent form.**
  `inside` returns the carrying document for a fragment-only link, so the document exists by construction and only the heading can be missing. `selection` refuses that with `NESTED_SECTION_TARGET` for a container-carried heading but has no code for one the document never wrote.

## Proposal

**The scene.** `cli.required` iterates the uses in selected content, resolves each through `inside`, and yields a dependency where `is_markdown` holds and the link neither withholds nor leaves the root. The traversal then reads each yielded path, and `read_document` decides absence.

**The design.**

- **A link naming nothing is text.** `required` yields no dependency for a reference whose target the probe declined to find, so it expands nothing and reaches the bundle as authored. The probe reports absence as a distinct outcome from a declined declaration, so the two are never confused.
- **An operator's target must exist and declare.** `refusals_of_operators` asks the probe for the target, and refuses with `E_TARGET_NOT_FOUND` where the document is absent, carrying the operator's own diagnostic shape. A marked link to a document that exists and declares nothing remains refused, on the ground the design already states: an operator names a compilation of a Markdown document, and a document that declares nothing is content no compilation carries.
- **A withheld target must exist and declare.** `withheld` yields only a target the probe found and whose declaration it read, so a deferral or a dispatch still fails on an absent target and still succeeds on a document that travels.
- **A fragment-only link keeps its refusal.** `selection` raises `E_TARGET_NOT_FOUND`, naming the fragment and the document that does not carry it, where a fragment resolves to no heading. The code is already in the catalogue; this gives it the second shape its contract row will state.
- **`read_document` loses its absence branch.** A path it is asked to read was probed, so absence there is a source changed between the probe and the capture, which the publication recheck already names.
