**Component:** src/prosiform/cli.py

## Overview

A bare exclusion applies wherever its name appears, a qualified one to the document it names, and the two may be given together.

## Problem

The exclusion reaches documents the author may not have had in mind.

- **One source is read by several roles.** A rules document may be reached from two procedures, and a section named `Checks` in one procedure is unrelated to `Checks` in the rules. One option giving one scope would force a choice between two harms: exclude both or write an entry per document.
- **A reference already carries a path.** `closure.resolve` returns a `Reference` whose `path` is empty for a fragment-only spelling and the normalised identity otherwise, so the scope is already in the value the option produced.
- **A document's identity is its canonical path.** Matching runs against the path the run resolved, which is relative to the invocation working directory, so a qualified exclusion is written the way every other reference is.

## Proposal

**The scene.** Each document the run reads is settled once, keyed by its canonical path. The exclusion list arrives as a sequence of resolved references.

**The design.**

- **Scope is the path's presence.** A reference with no path is unqualified and matches every document; one with a path matches that document alone. No separate field states it, because the grammar already does.
- **The qualified path is an identity, not a spelling.** It normalises through `closure.resolve`, so `./rules.md#Checks` and `rules.md#Checks` name one exclusion, exactly as two spellings of a mapping key name one key.
- **An unqualified exclusion is per-document.** It is tried against each document's heading index in turn, and a document that does not carry the name is untouched.
- **Two exclusions may both apply.** A qualified exclusion removes a section in its document and an unqualified one removes a section of the same name elsewhere, and the removal is the union of what they name.
- **The path is not bounded by the writing source.** An exclusion is a command-line or frontmatter value rather than authored text, so it resolves from the invocation working directory as a mapping side does, and a document above the writing source's directory is named by its own path.
