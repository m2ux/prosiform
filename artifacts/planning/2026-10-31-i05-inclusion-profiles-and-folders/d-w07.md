**Component:** docs/selection.md

## Overview

The selection page states exclusion as the subtractive half of the same shape, scoped to the file that declares it, and the source page states the key that carries it.

## Problem

A carve-up is a selection rule, and the pages state selection as an addition.

- **`docs/selection.md` states consolidation as a union.** It says overlaps union, the larger region wins, and a child selection is satisfied by its parent. An exclusion contradicts none of that and is not mentioned by it, so a reader concludes the selection only grows.
- **`docs/sources.md` states the key set.** [I05:E13](https://github.com/m2ux/prosiform/issues/436) adds the presets and argument keys; an `exclude` whose value is a list is one more shape stated there.
- **The glossary carries no term.** A subtraction from a selection needs a name, and `make vocabulary` holds the glossary to every term the design marks.
- **The two codes belong in the validation page.** `docs/validation.md` lists the input failures a run reports, and two new ones that refuse a carve-up are met only here.

## Proposal

**The scene.** `docs/selection.md` states closure, consolidation, placement and structural ancestors; `docs/sources.md` states the frontmatter keys; `docs/validation.md` states the codes.

**The design.**

- **The selection page gains one section.** *Exclusion* states that a section a file withholds is removed from what that file contributes, that the removal happens before consolidation settles, that a link inside an excluded section is no dependency, that a deferral is not carried across, and that the two refusals protect a carve-up from being half-applied.
- **The source page states the list value.** An `exclude` holds a list of sections and an entry may carry a level, stated beside the other argument keys.
- **The validation page gains two rows.** `E_EXCLUDED_CONTENT` and `E_EXCLUDED_ENTRY`, each with what raises it and what the author does instead.
- **The glossary gains the term.** *Exclusion* is one sentence: the sections a file withholds from its own contribution.
- **No option row is added.** There is no `--exclude`; the exclusion is a frontmatter key, so `make invocation`'s table is untouched by this epic.
