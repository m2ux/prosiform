**Component:** example/work-planner/SKILL.md

## Overview

Every document in the example tree and every corpus source declares its settings inside a preset, and none declares `group`. The published bundles are unchanged, which is what proves the migration moved no content.

## Problem

The tree declares flat fields that this epic refuses.

- **44 documents declare `group` and `group-depth` flat.** `rg -l 'group:' example/work-planner` returns 44, and each carries the pair as two top-level keys. [I05:E11](https://github.com/m2ux/prosiform/issues/434) left them untouched because it removed only `root`.
- **A flat pair is refused outright.** W02's rule fails any preset carrying `group`, so the tree stops compiling the moment that row lands. The example is what `make corpus` and `make examples` read, so nothing downstream survives it.
- **The corpus mirrors the tree.** The `usage-example/` family reaches it through symbolic links, so a tree that will not compile takes the corpus with it.
- **The migration is mechanical and must be proved so.** A pair becomes a single-entry mapping inside `default`, and no heading, group name or depth changes, so every published bundle is byte-identical.

## Proposal

**The scene.** A grouped file currently opens with:

```yaml
---
prosiform:
  group: "protocols"
  group-depth: 1
---
```

**The design.**

- **Each pair moves into a `default` preset.** A file declaring a group and a depth becomes:

  ```yaml
  ---
  prosiform:
    default:
      group-depth: [{protocols: 1}]
  ---
  ```

  `default` is what keeps it grouped when it arrives as a dependency, which is how most of the tree is reached.
- **A file declaring nothing keeps an empty `prosiform`.** A document that declares to be included and states no setting keeps the block [I05:E11:W06](https://github.com/m2ux/prosiform/issues/434) left, and a document declaring no preset at all is unchanged.
- **No group name and no depth changes.** The migration rewrites a pair's spelling, so the merged groups, the member names and the level shifts are the ones the tree publishes today.
- **The corpus sources follow.** Each fixture source that declares a group moves the same way, and `fixtures/usage-example/`'s expected bundles are unchanged, which is the evidence that nothing moved.
- **The check reading the declaration is rewritten.** [I05:E11:W06](https://github.com/m2ux/prosiform/issues/434) removed `checks/authoring.py`'s root reader; its group reader follows the same field.
