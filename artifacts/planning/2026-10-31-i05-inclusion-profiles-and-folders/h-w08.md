**Component:** src/prosiform/closure.py

## Overview

A `path-sub` side ending in a separator is refused, and the folder lookup, its refusals and its six fixtures are removed. A preset states one pair per entry.

## Problem

The folder form retired with `-m` and survives in the code.

- **The lookup answers for folders.** `Substitution.folders`, the folder branch of `Substitution.answering`, `Reference.folder` and `Pairing.folder` redirect every document under a key folder.
- **The parser reads the marker.** `cli.marked`, `cli.folderless` and the folder branch of `cli.mock` read a trailing separator before normalisation, and [h-w01](h-w01.md) keeps `mock` as the `path-sub` parser, so a preset would accept `rules/=stubs/`.
- **A diagnostic names a folder key.** `cli.missing` and the folder remedy in `read_document` report a path a folder key derived.
- **Six fixtures assert it.** `a-folder-key-redirects-each-reference-under-it`, `an-exact-key-beats-a-folder-key`, `a-folder-substitute-that-is-absent-fails`, `an-unused-folder-key-warns`, `a-half-folder-pair-is-refused` and `a-folder-key-carrying-a-section-is-refused`.

## Proposal

**The scene.** A preset's `path-sub` entries are read into document pairs when the declaring document is decoded.

**The design.**

- **A side ending in a separator is refused.** The entry fails with `E_INVALID_CONVERSION_METADATA` naming it, because a folder is no reference and a preset states one pair per entry.
- **The folder code is removed.** The lookup, the marker, the folder refusals and the folder diagnostic go together, leaving the exact and the document lookups.
- **The six fixtures are withdrawn.** A refusal fixture replaces them.
