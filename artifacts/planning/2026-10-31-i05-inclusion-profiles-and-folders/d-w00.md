## Overview

The clause stating exclusion as the subtractive half of selection, scoped to the file that declares it, the two codes it carries, and the pin that lets a fixture name it.

## Problem

The design states a selection that only grows.

- **Consolidation unions.** The design states that overlapping selections are unioned and the larger region wins, so a run carries every region anything reached. No clause admits a region a document withholds.
- **An exclusion has no home in the key set.** `prosiform` admits its fields and a preset, so the clause that states what a preset may hold is where an exclusion belongs.
- **Two refusals need codes.** An exclusion holding selected content, and one withholding a file's whole contribution, are each a shape the run refuses, and `-C` and the design's catalogue must agree on each code.

## Proposal

**The scene.** The selection clause states closure, consolidation and placement order; the conversion-metadata clause states the keys `prosiform` admits; the code catalogue states each error.

**The design.**

- **One clause, stated where consolidation is.** Exclusion removes named sections from what a document contributes, settled before consolidation unions the run's regions, so a region a document withheld cannot be restored by a selection that also reached it.
- **The scope is the declaring file.** A preset is written by the file it governs, so its exclusion removes from that file's contribution and names no document. A top-level `exclude` states the same for every compilation of that file.
- **The shape is the selection's.** An exclusion names what a fragment names — a document-level heading and everything beneath it — and an optional level tells two headings of one name apart.
- **Two codes join the catalogue.** `E_EXCLUDED_CONTENT` for an exclusion holding content another reference selected, and `E_EXCLUDED_ENTRY` for a file withholding every region it holds. Both are input failures with exit status `1`.
- **The pin moves after the clause merges.**
