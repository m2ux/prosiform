## Overview

The clause stating exclusion as the subtractive half of selection, applied to a whole-file reference under the preset that governs it, the code it carries, and the pin that lets a fixture name it.

## Problem

The design states a selection that only grows.

- **Consolidation unions.** The design states that overlapping selections are unioned and the larger region wins, so a run carries every region anything reached. No clause admits a region a document withholds.
- **An exclusion has no home in the key set.** `prosiform` admits its fields and a preset, so the clause that states what a preset may hold is where an exclusion belongs.
- **The scope is the declaring document, per link.** A preset is selected by the section that links its document, so the clause states that an exclusion carves the declaring document's own content where that link names it whole.
- **A refusal needs a code.** An exclusion withholding everything a target holds is a shape the run refuses, and `-C` and the design's catalogue must agree on the code.

## Proposal

**The scene.** The selection clause states closure, consolidation and placement order; the conversion-metadata clause states the keys `prosiform` admits; the code catalogue states each error.

**The design.**

- **One clause, stated where consolidation is.** Exclusion removes named sections from the content a reference carries, settled before consolidation unions the run's regions. A region a preset withheld arrives only by a second reference that presets differently, which is a second statement rather than a restoration.
- **The carve applies to a whole-file reference.** A reference of the form `document#fragment` names one section, so there is nothing to subtract and the entry does not apply. Explicit selection is the more specific statement, and the clause says so where the entry is stated.
- **The names are the declaring document's own.** The clause states that an exclusion names headings of the document that declares it, and that no document qualifier is written because a preset governs only that document.
- **The shape is the selection's.** An exclusion names what a fragment names — a document-level heading and everything beneath it — and an optional level tells two headings of one name apart.
- **One code joins the catalogue.** `E_EMPTIED_ENTRY` for a reference whose target is emptied by that preset's exclusions. It is an input failure with exit status `1`. `E_EXCLUDED_CONTENT` retires: a second reference that carries the section states no contradiction, so nothing is refused.
- **This row does not move the pin.** [I08:E00:W00](https://github.com/m2ux/prosiform/issues/434) moves it once for every clause in this initiative, so this amendment lands beside that one and the pin names the revision carrying all of them.
