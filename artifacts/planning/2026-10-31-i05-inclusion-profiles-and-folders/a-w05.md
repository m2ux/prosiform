**Component:** src/prosiform/cli.py

## Overview

A document's boundary is derived from the links it writes, and there is one command that states it. The boundary confines a positional entry reference and is what a diagnostic names; it refuses no authored link.

## Problem

`root` was three things and the derived boundary is one of them.

- **The declaration supplied a directory identity.** `cli.read_document` walked the declared root, kept its device and inode in `Capture.directories`, and `recheck` compared them before publication. With the declaration gone, nothing re-checks a directory the run depends on.
- **The boundary has no statement.** A caller asking what a document may reach, and a check holding an author to it, both need the answer as a value rather than as a by-product of a run.
- **A positional entry still needs confinement.** `cli.entry` normalises a positional reference with parent bootstrap permitted, so `pf ../../etc/notes.md` names a path above the working directory. The boundary that used to refuse it went with the root and nothing states what replaces it.

## Proposal

**The scene.** `cli.traverse` reads each source, then `required` resolves that source's links. `selections` and `run_name` name the output from the entry references.

**The design.**

- **The boundary is computed where a source is read.** For each source, the local Markdown paths its own links name are normalised from its directory, and the boundary is the longest common directory holding them, or the source's own directory where it names none. It is a field on `Source` beside `root` was.
- **Computed from the whole document, not the selection.** The links a document writes are a property of the document, so a boundary that moved with the selected region would be two answers for one file. The parsed token stream already holds every link.
- **The identity check follows the derived directories.** The walk that the declaration supplied is replaced by the walk to each link's own directory, recorded in `Capture.directories` as `cli.read_document` records a declared root's today, so `recheck` still compares device and inode for every directory the run resolved through.
- **A positional entry is confined to the working directory.** `cli.entry` refuses a reference normalising above the captured working directory with `E_SOURCE_OUTSIDE_ROOT`, which is the one path boundary the run keeps and the one its message already states.
- **The boundary is observable.** `make boundary` prints each source's derived boundary over a tree, so an author can see what the run decided and a check can hold it.
