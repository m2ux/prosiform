**Component:** src/prosiform/cli.py

## Overview

A compilation's preset is chosen by the heading text its entry section resolves to. The run joins it to that compilation's options, and leaves every other compilation alone.

## Problem

The run holds one set of options and builds each bundle from it.

- **Options are read once.** `main` parses the command line into a `Namespace` and every `compiled` call reads `budgets(options)` and the substitution from it. There is one mapping and one budget set for the whole run.
- **A section is resolved per compilation already.** `selection` resolves a fragment against the document's heading index and `assigned` keys destinations by `(path, fragment)`, so the resolved heading is in hand at the point a compilation starts.
- **The entry document is the one that declares.** The run's own entry is a reference the caller named, and a dispatched target's entry is a hop. Either way the document whose declaration is read is the document the reference names, so the preset lookup is a lookup on that document's `Conversion`.

## Proposal

**The scene.** `compiled(root, referrer, requested, options, folder)` reads `budgets(options)` and `substitution(options)`, calls `traverse`, and composes the bundle. `dispatched_set` calls it again per hop with the same `options`.

**The design.**

- **`compiled` takes a `Preset`.** A value holding the substitution entries and budget overrides that govern one compilation, built from `options` before the call and joined with whatever the entry document declares. `traverse` and every stage below it read the preset rather than the namespace.
- **The name is the resolved heading text.** `selection` already resolves the fragment; the same lookup answers the preset's name, so a run of `rules.md#Checks` matches a preset named `Checks` and one named `checks` does not, which is the rule the design states.
- **A whole-document entry selects a preset named for the document.** An entry naming no fragment has no section name, so the preset matched is the one named for the document's title where it has one, and none otherwise. This is a rule the clause states rather than a fallback.
- **A compilation's options are its own.** `budgets` is called with the overrides already applied, so `-O` in a preset bounds that bundle's bytes and the run's `-O` bounds every other; a preset's pair joins `Substitution` before the first resolution, so classification and emission read the joined mapping.
- **A dispatched target inherits nothing.** A dispatch's compilation matches its own entry document's declaration, so a preset on the entry document does not follow the dispatch. A preset the target's own document declares under the target's section applies there.
