**Component:** src/prosiform/metadata.py

## Overview

A preset carries an `exclude` of sections, decoded into the list the exclusion grammar reads. The names are the declaring document's own headings, and the entry applies only where the link that selected the preset names that document whole.

## Problem

An exclusion has one home, and the key rule decides how it is written.

- **A preset is the only home.** [I08:E01](https://github.com/m2ux/prosiform/issues/436) makes every `prosiform` key a preset name whose value is a mapping, so `exclude` is a preset entry and a top-level `exclude` is a key whose value is a list rather than a preset.
- **The value is a list of names and single-entry mappings.** A bare name removes a whole section and a mapping names one heading level, so the two forms sit in one list and neither needs a `#`.
- **A malformed entry is a metadata fault.** There is no command-line form for an exclusion, so the frontmatter is the only place one is written and the code the frontmatter's other shape faults carry is the one that states it.
- **The scope moved with selection.** The preset is now chosen by the section that writes the link, so the entry carves the target that link names rather than the declaring file's own contribution.

## Proposal

**The scene.** `metadata.decode` reads the `prosiform` mapping, admits a preset holding its pairs, placements and exclusions, and returns a `Conversion`.

**The design.**

- **The preset entry is a list of sections.** Each is read by the exclusion grammar W04 states, so a level and an empty section are refused with the message the grammar carries.
- **The names are the declaring document's own.** The entry names headings of the document that declares it, and states no document qualifier because a preset governs only that document.
- **The entry applies to a whole-file reference only.** A reference carrying a fragment settles explicit content, so a preset's `exclude` is not read for it. W03 owns that rule and this row states it where the entry is declared.
- **A top-level `exclude` is refused.** `prosiform` carrying it fails with `E_INVALID_CONVERSION_METADATA`, because every top-level key is a preset and this one's value is a list.
- **An absent `exclude` states nothing.** A preset declaring none withholds nothing, and no diagnostic accompanies that.
- **An invalid entry is a metadata fault.** A value that is not a list of strings fails with `E_INVALID_CONVERSION_METADATA`, naming the key and its location. A well-formed string naming a malformed section is the grammar's refusal instead, so one fault is stated once.
