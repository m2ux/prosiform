**Component:** src/prosiform/cli.py

## Overview

A selection whose every region the exclusions remove is refused, so a carve-up cannot publish a bundle carrying no document.

## Problem

An exclusion is written independently of the selection it meets.

- **The two are stated apart.** The entry references are the command line's positions and the exclusions are an option, and nothing compares them, so `--exclude '#Guide'` over a run naming `guide.md` is one command line that removes everything the run selected.
- **An empty bundle validates and publishes.** Every invariant candidate validation holds is a property of the construction, and a bundle carrying no region satisfies all of them. A run publishing an empty file exits `0` and reports nothing.
- **The case compounds with presets.** A preset carrying an exclusion applies to its own compilation, so a preset may empty the very section it governs while every other compilation is unaffected.
- **A `-c` run is no different.** Check mode reports what a publishing run would publish, so an entry emptied by its exclusions is refused there too rather than passing because nothing was written.

## Proposal

**The scene.** `compiled` composes one bundle from its entries and the documents they reach. A document's settled selection is a region set, and the bundle is the concatenation of every contributing document's selected regions.

**The design.**

- **The refusal is decided per compilation.** `compiled` knows every contributing document's settled selection, so it is where "nothing survived" is visible. It raises `E_EXCLUDED_ENTRY`, exit status `1`, nothing published.
- **The diagnostic names the entry and the exclusions.** It carries the entry reference the author wrote and each exclusion that removed a region of it, so an author with several exclusions is told which did the removing.
- **A dispatched compilation is held to it too.** A dispatch's target is compiled as its own entry, so a preset emptying it refuses that compilation and the run publishes nothing, exactly as a refused dispatch target does today.
- **One surviving region is enough.** The refusal is not raised where a document contributes something, even if a large exclusion removed most of it; the threshold is emptiness rather than a share, because a share is a judgement the tool cannot make.
- **The refusal precedes publication.** It is raised in the pass that composes the bundle, which runs before the run folder is written, so the earlier set stands and `W_EARLIER_SET_RETAINED` need not appear.
