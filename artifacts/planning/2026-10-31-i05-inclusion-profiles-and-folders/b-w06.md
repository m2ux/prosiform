**Component:** src/prosiform/diagnostics.py

## Overview

A preset no compilation selected is stated. The warning names the document and the preset, and a preset a deferral will read is not warned about.

## Problem

A preset is invisible in a run's output.

- **A preset that applied changes nothing observable on its own.** `W_MOCK_SUBSTITUTED` names a redirected target where the preset substituted one, so a preset that took effect is stated by its substitution's warning.
- **A preset that applied to nothing is stated by neither.** A document reached but never compiled, or one whose sections were all named by no caller, leaves its declaration inert and silent.
- **A deferral is the case that looks unused and is not.** A document reached only through a `¬` link contributes to no bundle, so its preset applies to no compilation in this run — and to one in the next, which the deferral names.
- **A document compiled under another preset is not unused.** Its other presets applied to nothing here, and that is the fact the warning states.

## Proposal

**The scene.** `compiled` returns a `Compiled` holding its diagnostics, and `main` renders them once every bundle is compiled, so a warning needing the whole run's answer has somewhere to sit.

**The design.**

- **`W_PRESET_UNUSED`** names the document carrying the preset and the preset's name. It joins the trailing diagnostics, so it is emitted once after every compilation.
- **A preset is used when a compilation selected it.** The set of selected names is collected as the run goes, and the warning is raised for each declared name the set does not hold.
- **A deferred-only document is excluded.** The traversal records which sources reached no bundle through a deferral, and a preset on one of those is not warned about, because the run that follows the deferral reads it.
- **A whole-document entry counts as a selection.** It selects `default` where one is declared, so a `default` preset is used by exactly the compilations that matched nothing else.
- **The code is declared.** `-C` lists it and the design's catalogue carries its row, because `make conformance` compares the codes the build reports against the codes the contract declares.
