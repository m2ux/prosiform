**Component:** fixtures/inclusion

## Overview

A new `inclusion/` family states the declaration, and every family that declared a root declares its targets instead. The corpus is the contract, so it is what states the new rule.

## Problem

The corpus states the old rule in two places.

- **A family is named for the root.** `confinement/`, and the fixtures `cli/an-allowed-source-root-naming-no-directory`, `reference/a-document-outside-the-root-is-text`, `traversal/a-reference-under-the-root-is-bundled` and their siblings, each declare a root in a source and expect the run to classify by it.
- **Citations are stated as root escapes.** `reference/a-document-outside-the-root-is-text` carries a document above the run's root that the bundle must not open. Under inclusion by declaration, a document above the writing directory is opened when it declares, so the fixture states the opposite of the rule it is named for.
- **The new rule has no family.** A declaration, a silent target, an empty block, a refused root and a probed target are five facts, and none is stated anywhere in the corpus.

## Proposal

**The scene.** A fixture is a directory with `manifest.toml`, `source/` and `expected/`. Its `invocation.arguments` carry the command line and its `clauses` name the design clauses it encodes.

**The design.**

- **A new `inclusion/` family.** Nine fixtures across this epic's rows: a declaring target compiled, a silent target as text, an empty block declaring, no block not declaring, a declared root refused, an oversized silent target as text, a link naming no document as text, an operator keeping the refusal, and a fragment naming no heading.
- **Existing families declare instead of rooting.** Each source that declares a root declares `prosiform` and keeps its group fields, and each fixture whose clause was about the root's edge is either renamed to the clause that survives or withdrawn into `inclusion/`.
- **A clause is renamed where its subject moved.** `reference/a-document-outside-the-root-is-text` becomes a fixture about a silent target above the writing directory, so its name states what it proves. Its clauses list names the clause at the new pin.
- **`confinement/` keeps what it is about.** A symbolic link, an unreadable root and a path above the working directory are still confined; only the fixtures about a *declared* root are reworked, and the directory's name states confinement rather than a declaration.
- **Every expected bundle is re-derived rather than copied.** A fixture whose expectation was produced under the old rule and edited to match the new one states neither, so each reworked fixture is run against the build and its bundle read before it is committed.
