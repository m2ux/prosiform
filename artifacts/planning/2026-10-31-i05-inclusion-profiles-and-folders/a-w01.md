**Component:** src/prosiform/metadata.py

## Overview

Frontmatter declares or it does not, and `root` is refused. Presence becomes a value of its own, because an empty `prosiform` block and an absent one are the same value today and must not be.

## Problem

`metadata.decode` answers with a `Conversion()` whose every field is `None` in three cases: no frontmatter, a `prosiform` mapping holding nothing, and frontmatter holding no `prosiform` key. A caller asking whether a document declares has no fact to read.

- **Absence is inferred from the fields.** `Conversion.root` is `None` for a document declaring `proc` `group` alone, so a caller cannot tell a document that declares from one that does not.
- **`root` is admitted.** `fields` accepts `("root", GROUP, DEPTH)` and validates `root` as a nonempty relative directory path; the walk, the bound-directory identity and `E_ROOT_NOT_FOUND` all follow from that admission in `cli.read_document`.
- **An unknown key is the only refusal.** A key outside the three fails, so the key set is the whole of what a document may declare.

## Proposal

**The scene.** `decode` builds `fields` from the `prosiform` mapping's children, refuses a key outside the admitted set, validates each field's type, and returns `Conversion` holding the three values or nothing.

**The design.**

- **`Conversion.declared`.** A boolean field, `True` where a `prosiform` key was read — including a mapping holding nothing, which today returns early at the `metadata is None` test's false branch and then through the empty-fields path. Absence, an empty block and an unrelated frontmatter value all return `declared=False`.
- **`root` refused.** The admitted set narrows to `(GROUP, DEPTH)`. A `prosiform` mapping carrying `root` raises `InvalidMetadata` with `E_INVALID_CONVERSION_METADATA`, naming `prosiform.root`, the location of the key and the remedy: the document declares its inclusion and states no boundary.
- **The root's validation goes with it.** The relative-path test, its message and the `root`/`root_location` fields leave `Conversion`, so `metadata.py` no longer holds a rule about paths.
- **Nothing else moves.** The group and depth grammar, the paired-field refusal, the printable-character rule and the YAML grammar are unchanged.
