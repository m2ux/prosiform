**Component:** src/prosiform/cli.py

## Overview

One settled region set is what every stage reads, and the derived boundary refuses no authored link. Both follow from where the code sits, and both are held by a check so a later change cannot remove either silently.

## Problem

Two invariants are true of the construction and asserted nowhere.

- **Five stages ask one selection.** `required`, `withheld`, `dispatches`, `refusals_of_operators` and `assemble` each read the settled region set `traverse` computes. That is what makes them agree, and it is a property of the call graph rather than a check: a stage that re-read the document for itself would answer differently and nothing would report it.
- **The boundary is derived from links, so it cannot refuse one.** W05 computes it as the deepest directory holding every local Markdown path a document names. A defect there would refuse an authorised link, and the symptom is a run failing on material its own author wrote.
- **Neither is reachable by an author.** An author cannot construct a tree where the stages disagree or where the boundary excludes its own link, so a corpus fixture cannot produce the fault directly. Each is held by observing the outcome over a tree chosen to exercise it.

## Proposal

**The scene.** `traverse` computes `chosen` per document and passes it to each stage. `read_document` derives the boundary from the parsed links and records each directory it walked.

**The design.**

- **One selection is asserted by a fixture spanning the readers.** A document holds a selected region and an unselected one, and the unselected region carries a link, a `¬` link and a dispatch. Every reader must answer for the selected region and none for the other, so a stage reading the document whole is caught by whichever assertion it breaks.
- **The boundary property is asserted where the boundary is observable.** `make boundary` prints each source's derived boundary, and the assertion is that every local Markdown path a document writes normalises inside it. A boundary excluding one of its own links fails.
- **Neither adds a refusal.** There is no code for either, because neither is reachable by an author. They are invariants held by a check, which is what the plan's standard asks for a property a fixture cannot produce directly.
