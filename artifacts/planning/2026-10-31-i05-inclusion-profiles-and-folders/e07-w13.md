**Component:** src/prosiform/bundle.py

## Overview

A substitution is recorded only for a reference in content the run selected, so a key whose only reference sits in a heading outside the selection warns as unused.

## Problem

Reading a heading's visible text resolves every withheld link in the document.

- **`shown_text` reads every heading.** `bundle.shown_text` and `emitted_visible` call `withholding_target` with the run's mapping for every heading the document holds, selected or not.
- **The lookup records what it resolves.** `Substitution.redirect` marks the key served and writes a record with no location.
- **The run reports a substitution it never made.** With `guide.md` holding `## Keep` and `## [¬ Rules](rules.md)`, `pf -m rules.md=stub.md 'guide.md#keep'` exits `0` with `W_MOCK_SUBSTITUTED` and no location, and raises no `W_MOCK_UNUSED`.

## Proposal

**The scene.** Discovery records a substitution with the link's position, and emission and validation resolve the same links again.

**The design.**

- **Text reading records nothing.** The heading-text path resolves through the mapping without recording, so it decides what a heading shows and nothing about what the run substituted.
- **The record is discovery's.** A key is served by a reference discovery reached in selected content, which is where the position is known.
