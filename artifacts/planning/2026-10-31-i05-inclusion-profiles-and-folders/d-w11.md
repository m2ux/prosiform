**Component:** docs/selection.md

## Overview

The selection page states exclusion as the subtractive half of the same shape, applied to a whole-file reference under the preset that governs it, and the source page states the key that carries it.

## Problem

A carve-up is a selection rule, and the pages state selection as an addition.

- **`docs/selection.md` states consolidation as a union.** It says overlaps union, the larger region wins, and a child selection is satisfied by its parent. An exclusion contradicts none of that and is not mentioned by it, so a reader concludes the selection only grows.
- **`docs/sources.md` states the key set.** [I08:E01](https://github.com/m2ux/prosiform/issues/436) adds the presets and entry keys; an `exclude` whose value is a list is one more shape stated there.
- **The glossary carries no term.** A subtraction from a selection needs a name, and `make vocabulary` holds the glossary to every term the design marks.
- **The code belongs in the validation page.** `docs/validation.md` lists the input failures a run reports, and a code that refuses a carve-up is met only here.

## Proposal

**The scene.** `docs/selection.md` states closure, consolidation, placement and structural ancestors; `docs/sources.md` states the frontmatter keys; `docs/validation.md` states the codes.

**The design.**

- **The selection page gains one section.** *Exclusion* states that a section a preset withholds is removed from the content a whole-file reference carries, that a reference naming a section is not carved, that the removal happens before consolidation settles, that a link inside an excluded section is no dependency, that a deferral is not carried across, and that the refusal protects a carve-up from publishing an emptied document.
- **The source page states the list value.** An `exclude` holds a list of sections and an entry may carry a level, stated beside the other preset entries.
- **The validation page gains one row.** `E_EMPTIED_ENTRY`, with what raises it and what the author does instead.
- **The glossary gains the term.** *Exclusion* is one sentence: the sections a preset withholds of a document a link names whole.
- **No option row is added.** There is no `--exclude`; the exclusion is a frontmatter key, so `make invocation`'s table is untouched by this epic.
