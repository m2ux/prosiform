**Component:** src/prosiform/closure.py

## Overview

A folder key answers for every reference under it, the remainder decides the substitute, and the reference keeps its section. Exact keys answer first and the longest folder wins.

## Problem

`Substitution.key` performs one two-step lookup.

- **The lookup knows two keys.** `Substitution.key` asks `(path, fragment)` then `(path, None)`. A reference under a folder matches neither.
- **A section has to survive the redirect.** `substitute` takes the substitute's path and walk and keeps the reference's section where the key named a document. A folder key names a directory, so the section is always the reference's.
- **Precedence between folders is a decision.** `rules/visual/` and `rules/` both hold `rules/visual/red.md`, and the answer cannot be whichever a dictionary happens to yield.
- **The redirect has to be total.** A reference to `rules/red.md` under the *inclusion* rule of [Declared Inclusion](epic-a-declared-inclusion.md) is compiled only when its target declares — and here the target is the substitute, so the declaration read is the substitute's rather than the authored path's.

## Proposal

**The scene.** `Substitution.substitute(found)` asks `key(found)` and returns a `Reference` with the substitute's path and walk; `key` asks exact-first then the document key.

**The design.**

- **Exact, then longest folder.** `key` asks `(path, fragment)`, then `(path, None)`, then each folder key whose prefix holds the path, longest first. The first answer wins, so a document key beats any folder and a narrower folder beats a wider one.
- **The remainder is appended.** A folder key `k` answering for path `p` yields `substitute_path + p[len(k):]`, which keeps the directory shape the key stated.
- **The section is the reference's.** `substitute` keeps `found.fragment` for a folder match, so `rules/red.md#Checks` redirects to `stubs/red.md#Checks`.
- **The substitute is probed, and its declaration is the one that decides.** Under inclusion by declaration, the reference is compiled because the substitute declares. A folder of stubs therefore states its own inclusion, and a stub folder whose documents declare nothing publishes a bundle carrying none of them, which `W_MOCK_SUBSTITUTED` reports as a redirect that reached no document.
- **A substitute the folder does not hold fails.** `key` answers nothing when the substitute path holds no file, and the caller refuses with `E_TARGET_NOT_FOUND` naming the reference, the key and the path the redirect resolved to.
- **A matched folder key is a used key.** The used-key set carries the folder key, so `W_MOCK_UNUSED` does not fire for a folder that answered a reference.
