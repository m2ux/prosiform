**Component:** example/work-planner/SKILL.md

## Overview

Every document in the example tree and every corpus source declares its settings inside a preset, and none declares `group` or `root`. The published bundles are unchanged, which is what proves the migration moved no content.

## Problem

The tree declares flat fields that the epics before this one refuse.

- **Forty-four documents declare `group` and `group-depth` flat.** Each carries the pair as two top-level keys, and [I08:E01](https://github.com/m2ux/prosiform/issues/436) refuses `group` outright.
- **A flat pair stops the tree compiling.** The example is what `make corpus` and `make examples` read, so nothing downstream survives the field rules without this rewrite.
- **The corpus mirrors the tree.** The `usage-example/` family reaches it through symbolic links, so a tree that will not compile takes the corpus with it.
- **The migration is mechanical and must be proved so.** A pair becomes a single-entry mapping inside `default`, and no heading, group name or depth changes, so every published bundle is byte-identical.

## Proposal

**The scene.** A grouped file currently opens with:

```yaml
---
prosiform:
  group: "protocols"
  group-depth: 1
---
```

**The design.**

- **Each pair moves into a `default` preset.** A file declaring a group and a depth becomes:

  ```yaml
  ---
  prosiform:
    default:
      group-depth: [{protocols: 1}]
  ---
  ```

  `default` is what keeps it grouped when it arrives as a dependency, which is how most of the tree is reached.
- **A file declaring nothing keeps an empty `prosiform`.** A document that declares to be included and states no setting keeps the block Declared Inclusion left.
- **No group name and no depth changes.** The migration rewrites a pair's spelling, so the merged groups, the member names and the level shifts are the ones the tree publishes today.
- **The corpus sources follow.** Each fixture source that declares a group moves the same way, and `fixtures/usage-example/`'s expected bundles are unchanged, which is the evidence that nothing moved.
- **The check reading the declaration is rewritten.** `checks/authoring.py`'s root reader went with Declared Inclusion; its group reader follows the same field.
