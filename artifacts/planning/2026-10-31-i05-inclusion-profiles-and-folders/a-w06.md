**Component:** example/work-planner/SKILL.md

## Overview

Every document in the example tree declares `prosiform` and none declares a root. The published example bundles are byte-identical, which is what proves the change moved no content.

## Problem

The example tree states a root in 95 files.

- **Every file declares `root`.** `rg -l 'root:' example` returns 95 documents, 32 of them in `my-skill` and 63 in `work-planner`, each carrying `prosiform.root` beside an optional group.
- **The declaration is load-bearing for the corpus.** The `usage-example/` family reaches the tree through symbolic links, so its bundles follow whatever the tree declares.
- **`checks/authoring.py` reads the declaration.** `DECLARED_ROOT` parses `  root: "..."` and `link_form` refuses a link that resolves from the declared root rather than from the file, so the check holds the tree to a rule this epic deletes.
- **A declared root prefixes a link's spelling.** The [note](../2026-10-24-root-declaration-roles/README.md) records `[Codex](codex.md)` failing where `[Codex](rules/codex.md)` resolves; with no root, both resolve from the file and the walk finds the second alone.

## Proposal

**The scene.** A file currently opens with:

```yaml
---
prosiform:
  root: ".."
  group: "protocols"
  group-depth: 1
---
```

**The design.**

- **The root line is withdrawn and the block is kept.** Each file keeps `prosiform` and its group fields; the `root` line goes. A file that declared the root and nothing else keeps an empty `prosiform` block, which is the declaration.
- **The tree already declares the group fields it needs.** Nothing else about the metadata changes, so the file headings, the merged groups and the level shifts the example publishes are the ones it publishes today.
- **Every link already resolves from its file.** A link carrying a parent segment resolves from the writing document and already did, and a link carrying none resolves from the same document once the root stops prefixing it, so the tree needs no link edited. `make corpus` proves that, since the `usage-example/` family's expected bundles are unchanged.
- **`checks/authoring.py` is rewritten to the derived boundary.** `DECLARED_ROOT` and `declared_root` leave; `link_form` holds a link to the file it is written in, which is the rule that survives, and drops the branch that refused a link resolving from the declared root.
- **The declaration is stated once in the tree.** `example/README.md` and each skill's `SKILL.md` preamble state that documents declare to be included, so a reader of the example learns the rule from the example.
