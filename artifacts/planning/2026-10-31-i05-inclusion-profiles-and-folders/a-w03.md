**Component:** src/prosiform/closure.py

## Overview

The three classification helpers answer from the target's declaration instead of a `covers` test against a root. A `Reference` carries whether its target declares, so discovery, emission and candidate validation read one answer.

## Problem

Classification is a question about directories, asked in five places.

- **`covers(root, path)` is the whole test.** `closure.inside` normalises a link from its writing document, holds the result to `covers(root, path)` and raises `OutsideRoot` where it fails. `resolvable`, `bundled` and `withholding_target` each call it, and `cli.required` calls `inside` directly.
- **The answer needs a read the helper cannot make.** `resolvable` is a pure function of two strings, and its purity is stated as a property: the reference is classified without being opened. A declaration lives in the target, so the answer arrives from outside.
- **A reference carries a root per stage.** `cli.required`, `bundle.target`, `candidate.intended` and `grouping.rewrites` each thread `source.root` through the helpers, and a stage that forgot it would classify a link differently from the stage beside it.

## Proposal

**The scene.** `inside(document, text, root)` returns a `Reference` whose `path` is the normalised identity. `resolvable` filters it by `is_markdown`, `bundled` by the opening's withholding, and `withholding_target` by the inverse.

**The design.**

- **`inside` stops testing the boundary.** It normalises from the writing document and holds the result to the path grammar, so a drive path, an absolute path and one normalising above the working directory are still refused with `OutsideRoot`. It no longer compares the result with a root.
- **A declaration is carried on the `Reference`.** A `declared` field marks a target whose frontmatter declares, set by the caller that probed it. `resolvable` answers a reference whose target declares; one whose target does not is no dependency, and the caller's read of `declared` is the same read at every stage because it rides on the value rather than on a parameter.
- **The helpers stop taking a root.** `inside`, `resolvable`, `bundled` and `withholding_target` lose the `root` parameter and the stages stop threading it. `covers` and `grouping.declared_root`'s reader go with them.
- **The four stages agree by construction.** Because the answer is on the reference the resolution returned, `bundle.target`, `candidate.intended` and `cli.required` cannot disagree with discovery, and a stage cannot forget a parameter it no longer takes.
- **A citation is the same reference.** A link whose target declares nothing is returned by `inside` like any other, and `resolvable` answers it as no dependency — which is what makes a link above the writing document's directory compile when its target declares, the behaviour [AC2](epic-a-declared-inclusion.md) states.
