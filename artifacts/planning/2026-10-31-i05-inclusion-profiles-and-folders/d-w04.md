**Component:** src/prosiform/cli.py

## Overview

A file whose own exclusion removes every region it contributes is refused, so a carve-up cannot publish a bundle the file empties.

## Problem

An exclusion is written independently of what reaches it.

- **The two are stated apart.** A preset's exclusion is written in frontmatter and the selection arrives from a reference, and nothing compares them, so a document excluding every section it holds contributes nothing.
- **An empty contribution composes silently.** Every invariant candidate validation holds is a property of the construction, and a document contributing no region satisfies all of them. The bundle carries the other documents and reports nothing about this one.
- **The case compounds with presets.** A preset carrying an exclusion applies to its own compilation, so a preset may empty the very section it governs while every other compilation is unaffected.
- **A `-c` run is no different.** Check mode reports what a publishing run would publish, so a document emptied by its exclusions is refused there too rather than passing because nothing was written.

## Proposal

**The scene.** `compiled` composes one bundle from its entries and the documents they reach. A document's settled selection is a region set, and the bundle concatenates every contributing document's selected regions.

**The design.**

- **The refusal is decided where a document's contribution is known.** `traverse` holds each document's settled selection, so it is where an emptied contribution is visible. It raises `E_EXCLUDED_ENTRY`, exit status `1`, nothing published.
- **The diagnostic names the document and the exclusions.** It carries the document's identity and each exclusion that removed a region of it, so an author with several exclusions is told which did the removing.
- **A dispatched compilation is held to it too.** A dispatch's target is compiled as its own entry, so a preset emptying it refuses that compilation and the run publishes nothing, exactly as a refused dispatch target does today.
- **One surviving region is enough.** The threshold is emptiness rather than a share, because a share is a judgement the tool cannot make.
- **The refusal precedes publication.** It is raised in the pass that composes the bundle, which runs before the run folder is written, so an earlier set stands untouched.
