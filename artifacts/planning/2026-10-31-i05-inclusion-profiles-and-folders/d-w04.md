**Component:** src/prosiform/metadata.py

## Overview

An exclusion entry may name a heading level beside the section's name, so one of two headings of one name can be removed and the other left with its subsections.

## Problem

A name is not always enough to identify a section.

- **Inclusion refuses the ambiguity.** `source.section` raises `Ambiguous` where two headings produce one fragment, and `selection` reports it as `E_AMBIGUOUS_SOURCE_HEADING`. An exclusion has the same question with no way to answer it.
- **An exclusion cannot fall back to the refusal.** A file that must withhold one of a pair of same-named sections has no spelling for "the level-3 one", so the author would be forced to retitle a heading — the shape of problem the preset model exists for.
- **The level is already known.** `heading.level` is the level each heading opens at, decoded from its token's tag, so a lookup by name and level is a filter over the index rather than a new parse.
- **The level must not change how much is cut.** It tells two headings apart; it is not a depth bound. The whole subtree beneath the heading it selects goes, whatever level that subtree reaches.

## Proposal

**The scene.** `metadata.decode` reads a preset's `exclude` as a list whose entries are strings and single-entry mappings; `selection` narrows a whole-file reference's regions by the resulting pairs.

**The design.**

- **A mapping entry is a name and an integer level.** `{"Tests": 3}` names the level-3 heading whose text is `Tests`, so no suffix has to be parsed back out of a string and no `#` is written.
- **A bare string names the document-level heading.** `"Draft"` is the level that `source.section` would select for a fragment `#Draft`, so the two spellings describe one section.
- **The selected heading goes with everything beneath it.** The level qualifies the heading, never the depth of the cut, so an exclusion names the same shape a selection does.
- **A malformed entry is refused at the metadata key.** A non-integer level, a level outside one through six and a mapping holding two keys each fail with `E_INVALID_CONVERSION_METADATA` naming the entry.
- **Two headings of one name at one level is a miss.** Nothing tells them apart, so the entry is silent for that target rather than ambiguous, which is the rule W01 states for a name the target does not carry.
