## Overview

The clause retiring `-m`, stating a preset's `path-sub` as the only channel, naming its two warnings, and stating that a pair resolves from its declaring file.

## Problem

The contract states two channels for one setting.

- **The CLI contract carries the row.** `-m ORIGINAL=ALTERNATIVE` is an option, and `make invocation` holds its row to the help output.
- **The substitution clause states the option's reach.** It names a positional entry, a referring document and a deferred target as references a mapping redirects, and all of that reach is now a preset's.
- **The path basis differs.** The clause states both sides resolve from the captured invocation working directory; a preset's sides resolve from the declaring file.
- **The clause names the warnings.** It states `W_MOCK_SUBSTITUTED` and `W_MOCK_UNUSED`, and the entry they report is now `path-sub`, so a code would name a word the contract no longer uses.
- **The retirement needs stating.** A reader of an older revision meets the option and would otherwise find a gap.

## Proposal

**The scene.** The CLI contract enumerates each option; the substitution clause states what a mapping redirects and how its sides resolve.

**The design.**

- **The row is withdrawn.** The CLI contract names no `-m`, and the substitution clause states `path-sub` as the only channel.
- **The reach is unchanged and belongs to the preset.** Every reference a mapping redirects stays redirected; what changes is where the mapping comes from.
- **The path basis is stated.** A preset's sides resolve from the file that declares it, and the clause says so where the pair's syntax is stated.
- **The warnings are named for the entry.** `W_PATH_SUB_USED` and `W_PATH_SUB_UNUSED` replace the codes the option's clause names, so a code names the mechanism it reports.
- **The absence is stated as an outcome.** A reference governed by a preset stating no `path-sub` substitutes nothing, which is a fact an author must be able to read rather than infer.
- **This row does not move the pin.** [I08:E00:W00](https://github.com/m2ux/prosiform/issues/434) moves it once for every clause in this initiative, so this amendment lands beside that one.
