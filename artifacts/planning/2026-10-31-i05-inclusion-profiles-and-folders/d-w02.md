**Component:** src/prosiform/cli.py

## Overview

The exclusion is applied where a document's contribution settles, so one seam removes the material and every stage reads one answer. An exclusion touching nothing is silent.

## Problem

Selection is built once per document and read by five stages.

- **`cli.selection` returns the region set.** It resolves each reference a document's fragments name and unions them. It takes the document's tokens and the references naming it, and nothing else, so an exclusion has no parameter to arrive through.
- **Five stages read the result.** `required` follows the dependencies the selected content carries, `withheld` yields its withheld targets, `dispatches` its dispatched ones, `refusals_of_operators` refuses its contradictory marks, and `assemble` emits it. A stage reading its own answer would disagree with the four beside it.
- **A whole-document selection is `None`.** The parent group opens the bundle on its own title because its selection is `None` rather than a region set, so an exclusion has to narrow that case into an explicit region set rather than leave it whole.
- **A silent miss is not an error.** A shared exclusion names sections some document lacks, so an exclusion matching nothing is an ordinary result rather than a fault.

## Proposal

**The scene.** `traverse` computes `chosen = selection(path, parsed[path], selecting, requested)` and passes it to each stage. `contributing` names which references select which document.

**The design.**

- **The settlement narrows in place.** `selection` takes the exclusions and returns the selected regions less the excluded ones. Every stage already receives that value, so no call site changes and none can forget the rule.
- **An exclusion matches a document-level heading only.** A heading a container carries roots no section, so it is no more excludable than it is selectable, and the exclusion simply does not match there.
- **A whole-document selection becomes explicit.** Where a document's selection would be `None` and an exclusion applies to it, the selection becomes every region the document holds less the excluded ones. Where no exclusion applies, `None` stays and the parent still opens the bundle on its own title.
- **A section a document does not carry is skipped.** Matching is per document, so an exclusion that hits nothing in one document is silent there and applies wherever else it matches. No diagnostic is raised, which is the decision the record states.
- **A removal is by region identity.** The excluded heading's own region and every region beneath it are dropped, read by the same rule `source.section` uses to select them, so the two sets are complements.
