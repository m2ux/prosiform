**Component:** src/prosiform/cli.py

## Overview

A link written inside an excluded section is no dependency. The closure shrinks, the document it names is not read through that link, and a document another link reaches still arrives by that link.

## Problem

Exclusion narrows the selection, and discovery reads the selection.

- **Dependencies follow the selected content.** `cli.required` iterates `uses(tokens, selected.regions)`, so a link in a region the selection does not hold is never offered. That is the mechanism already, and it is what makes the closure shrink rather than being filtered afterwards.
- **A second route is a second reference.** A document reached by a link inside an excluded section and by another link elsewhere is reached once, by the link that survives, and `identity` is what the frontier closes over, so it is read once.
- **A withheld target is discovered the same way.** `withheld` and `dispatches` read the same region set, so an operator inside an excluded section withholds nothing and dispatches nothing.
- **The exclusion is not a filter over the output.** Emitting the bundle without the text and still following its links would carry material the consumer was never meant to receive, which is the cosmetic outcome the feature exists to avoid.

## Proposal

**The scene.** `traverse` settles each document's selection, then asks `required`, `withheld`, `dispatches` and `refusals_of_operators` for what that selection carries. The rounds repeat until no new identity appears.

**The design.**

- **Nothing new is added here; a property is stated and pinned.** The exclusion narrows the region set before those four read it, so each already answers for the narrowed content. This row exists because the property is load-bearing and a later change to discovery could remove it silently.
- **A document reached only through an excluded section is absent.** It is not captured, not counted against `-F` or `-I`, and carries no group.
- **A document reached twice arrives once.** The surviving link names it, and the removed one contributes neither a dependency nor a chain.
- **The property is held by a fixture that reads the filesystem.** The excluded section links a document carrying a construct the profile refuses in selected content, so the run publishing proves that document was never read.
- **A dispatch inside an excluded section publishes no bundle.** Its target is not compiled, so the run folder holds the entry's bundle alone.
- **A deferral is not carried across.** An exclusion governs what this run compiles. A deferral the bundle publishes names a path rather than a set of exclusions, so what a later run withholds is that run's business; the clause states it so a later change does not quietly carry one across.
