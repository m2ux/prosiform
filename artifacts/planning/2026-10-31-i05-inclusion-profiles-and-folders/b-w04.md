**Component:** src/prosiform/cli.py

## Overview

A reference is governed by the presets whose names appear as words in the title of the section that writes it, and each document's `default` is in force beneath them.

## Problem

The run holds one set of options and builds each bundle from it.

- **Options are read once.** `main` parses the command line into a `Namespace` and every `compiled` call reads the budgets and the substitution from it, so there is one setting for the whole run.
- **A reference is resolved with its source in hand already.** `traverse` knows the writing document and the link that reached its target, so the section containing that link is available where the choice would be made.
- **A whole-document entry has no containing section.** An entry naming `guide.md` is written in no document, so the file it names supplies the presets and its own title heading supplies the title keywords are matched against.
- **A document may carry several presets.** One run reaching the same target twice, by two sections whose titles name different keywords, may govern the two references differently.

## Proposal

**The scene.** `traverse` resolves each reference from its writing document, `selection` resolves the fragments a reference names, and `compiled` builds one bundle from its entries.

**The design.**

- **The title is the containing section's.** For a link written in a document, the title read is that of the heading the link sits beneath — the whole document's title where it sits in the preamble. The lookup is case-insensitive and whole-word, so `Checks` matches a title `Checks and Draft` and not `Checklist`.
- **Every matching name is selected, and they union.** A title naming two preset names selects both, and the settings they state are combined by W05's rule.
- **`default` is always in force.** The writing document's `default` applies beneath whatever the title selected, so a title matching nothing leaves the reference under `default` alone and one matching a preset adds to it rather than replacing it.
- **`default` is not selectable by keyword.** A heading titled `default` selects nothing by that spelling, so the word has one meaning: what applies when no keyword matched.
- **A command-line entry reads the file it names.** An entry reference is written in no document, so the file it names supplies both the presets and the title — its own title heading for a whole-document entry, the named section's title for a section entry. The file being operated on is the one that states how it is treated.
- **The choice is per reference.** The governing preset is decided where each reference is resolved, so a document reached twice under two titles may be governed twice.
