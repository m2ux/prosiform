**Component:** src/prosiform/cli.py

## Overview

A compilation selects one preset, by the exact heading text of the section its entry reference names, and `default` applies where no name matches. The selected preset governs that compilation alone.

## Problem

The run holds one set of options and builds each bundle from it.

- **Options are read once.** `main` parses the command line into a `Namespace` and every `compiled` call reads the budgets and the substitution from it, so there is one setting for the whole run.
- **A section is resolved per compilation already.** `selection` resolves a fragment against the document's heading index, so the heading a compilation is built for is in hand where the choice would be made.
- **A whole-document entry has no section name.** An entry naming `guide.md` names no heading, so nothing matches — which is exactly the case `default` exists for.
- **A document may carry several presets.** One run reaching the same document twice, by two sections, may select two different ones.

## Proposal

**The scene.** `traverse` computes each document's selection, `selection` resolves the fragment, and `compiled` builds one bundle from its entries.

**The design.**

- **The name is the resolved heading text.** `selection` already resolves the fragment; the same lookup answers the preset's name, so `guide.md#Checks` matches a preset named `Checks` and one named `checks` does not, exactly as `docs/references.md` says `#Run` and `#run` name different sections.
- **`default` is the fallback.** A section matching no preset name, and a whole-document entry, both select it. Where a document declares no `default`, such a compilation runs under the run's own options with no conversion setting.
- **`default` is not selectable by name.** Naming a section headed `default` selects the fallback, which is the same thing; no preset is selected literally by that name, so the word has one meaning.
- **The choice is per compilation.** A document reached twice under two sections may be compiled under two presets, because the choice is a property of the compilation rather than of the document.
- **A preset governs its own compilation's settings.** The groupings, the substitutions and the exclusions it holds apply there and nowhere else.
