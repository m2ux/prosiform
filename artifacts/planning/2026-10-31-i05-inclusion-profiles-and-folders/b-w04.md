**Component:** src/prosiform/diagnostics.py

## Overview

A profile no compilation applied is stated, and a profile a deferral will read is not. The warning names the document, the profile and the sections the run compiled.

## Problem

A profile is invisible in a run's output.

- **A declared profile changes nothing observable.** `W_MOCK_SUBSTITUTED` names a redirected target and `W_MOCK_UNUSED` a key no reference named, so a profile that took effect is already stated by its substitution's own warning. A profile that applied to nothing is stated by neither.
- **A deferral is the case that looks unused and is not.** A document reached only through a `¬` link is captured, parsed and validated but contributes to no bundle, so a profile in it applies to no compilation in this run — and to one in the next, which the deferral names.
- **A merged document's profile is the second such case.** A document selected into another compilation's bundle carries its content under that compilation's options, so its own profile governs nothing here, and a warning that said so would be noise in every run of a grouped tree.

## Proposal

**The scene.** `compiled` returns a `Compiled` holding `leading` and `trailing` diagnostics, and `main` renders them once every bundle is compiled, so a warning that needs the whole run's answer has somewhere to sit.

**The design.**

- **`W_PROFILE_UNUSED`** names the document carrying the profile, the profile's name, and the sections the run compiled. It joins the trailing diagnostics of the run, so it is emitted once after every compilation rather than once per bundle.
- **A profile is used when a compilation matched it.** The set of names matched across every compilation is collected as the run goes, and the warning is raised for each declared name the set does not hold.
- **A deferred-only document is excluded.** The traversal records which sources contributed to no bundle and were reached by a deferral, and a profile on one of those is not warned about, because the run that follows the deferral reads it.
- **A merged document's profile is warned about.** It applied to nothing in this run and no later run reads it through this document, so the warning is the one place a reader learns the declaration had no effect.
- **The code is declared.** `-C` lists it and the design's catalogue carries its row, because `make conformance` compares the codes the build reports against the codes the contract declares.
