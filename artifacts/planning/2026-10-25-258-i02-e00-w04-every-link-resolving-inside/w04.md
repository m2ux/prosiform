**Component:** example/work-planner/

## Overview

A mode's bundle on the merged base carries links whose targets sit inside the example but whose content is absent from the bundle. The cause is that each file's declared root points at its own folder, so the example directory is never one root: a link carrying `..` resolves from the file's folder and lands outside its declared root, and the run drops it silently at exit zero. This row gives the whole tree one effective root and writes each in-root link from it.

## Problem

A document outside a file's declared root is never bundled. It stays a link at every level. That is correct for a citation and wrong for a sibling.

- **The example directory is never one root.**
  A file declaring `root: "."` has its own folder as its source root. A mode in `modes/` therefore names `../artifacts/board.md` outside its root, and the artifact's content is not included.

- **The run exits zero while dropping content.**
  A link to a missing in-root document under the declared root fails. A link outside the root does not: it is treated as a citation. So a wrong root silently produces a smaller bundle rather than an error.

- **The mix of roots splits the tree.**
  W01 set 29 files to `.` and 20 to `..`. Which files reach their siblings depends on which declaration each happens to carry, so no single description of the tree's scope is true.

## Proposal

- **Every declaration resolves to the example directory.**
  A top-level file declares `root: "."` because its own directory is the example; a file one level down declares `root: ".."` because its parent is. Two spellings, one directory.

- **Every in-root link is written as a path from the example directory.**
  A link carrying no `..` resolves from the declared root, so `artifacts/board.md#select-project-board` from a mode reaches inside the example and its content is included.

- **Every out-of-root link stays as authored.**
  `guidelines.md`'s `../guidelines.md` and `modes/revise-mode.md`'s `../../guidelines.md` name documents outside the example. They remain links, and W05's AC8 carries the deferral marker for them.

- **No content changes.**
  Only roots and link destinations change. Every document's text is identical to the base's.
