**Component:** checks/authoring.py

## Overview

A check reads the example and reports every departure from the authoring rules by file and area, which is the findings scan the rollout starts from and, later, the guard that holds the rules.

## Problem

No check reads an operation's Inputs or Outputs line, a Commands section, a command's place or a link's form, so the extent of the change is a hand count and nothing stops a regression.

## Proposal

Run over `example/work-planner/`, the check prints a findings report grouped by area — modes, protocols, artifacts, references and the entry files.

- **Rules read.**
  Inputs and Outputs as one line each of contract links or `None`; no `## Commands` section; a command in an unindented fenced block within a step; a cross-file link file-relative.
- **Size report.**
  Each file over about 20 KB or 8 operations, for a reviewer to read for a second subject.
- **Report and exit.**
  It prints each finding with its file and line, and exits nonzero when any is found; it joins `make check` only once the example passes it.
- **Findings recorded.**
  The first report over the converted example is recorded in the planning record, by area, before any rollout row starts.
