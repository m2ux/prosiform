**Component:** example/work-planner/artifacts

## Overview

Every artifact operation declares its Inputs and Outputs as one line each of links to the contracts defining those values.

## Problem

The artifacts hold 216 prose Inputs lines and no Outputs line, so an operation's boundary is a sentence to interpret rather than a set of values to follow.

## Proposal

Each operation's Inputs and Outputs name boundary values only, each a link to its contract; a value without a contract gains one in the file that owns its subject, and a condition in a shape moves to the step it binds.

## Work Breakdown

| Part | Description |
| --- | --- |
| Analysis | The authoring check's Inputs and Outputs findings for the artifacts, and each value without a contract. |
| Plan | The contract each value links, and the contracts to add. |
| Implementation | The artifacts and the usage-example bundles they reach. |
| Review | Every link names a contract that defines its value. |
| Test | The authoring check over `artifacts/`, `make links`, `make corpus` and `make check`. |
