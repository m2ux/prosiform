**Component:** Makefile

## Overview

The authoring check joins `make check`, so a change to the example that breaks an authoring rule fails the repository's checks.

## Problem

Once the example meets the rules, nothing but review holds them, and the next change can restate a value or detach a command again.

## Proposal

A `make authoring` target runs the check and `make check` runs it; the check's tests include a failing file for each rule.

## Work Breakdown

| Part | Description |
| --- | --- |
| Analysis | The check's report over the epic base, which is empty. |
| Plan | The target, its row in `checks.md`, and the failing cases. |
| Implementation | `Makefile`, `checks.md`, and the failing cases under `checks/tests`. |
| Review | The target is named by a command table, as `make tables` holds. |
| Test | `make authoring`, `make links`, `make corpus` and `make check` on the epic base. |
