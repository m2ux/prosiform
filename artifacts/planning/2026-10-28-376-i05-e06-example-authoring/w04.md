**Component:** example/work-planner/conventions.md

## Overview

How a helper is invoked and how a write is confirmed each have one home in the conventions, and every operation applying one links it.

## Problem

Operations restate how a helper runs and how a write is checked, each in its own words, so the rule a reader meets depends on the operation they read.

## Proposal

The conventions gain the two shared rules; each restatement elsewhere becomes a link.

- **Helper invocation.**
  Where a helper runs from and how it is called.
- **Write confirmation.**
  Only a fresh re-read confirms a write; a failed re-read is uncertainty, never retried as a different write.
