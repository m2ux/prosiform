## Proposal

**The scene.** #414 and its record's `epic.md` each hold a *Supersession* section stating which criteria a later epic voided, and each such criterion carries a note linking to it.

**The design.**

- **AC13 joins the superseded set.**
  It keeps its tick and its number, because the work that delivered it landed and a pull request naming it still resolves, and gains a note linking the Supersession section.
- **The entry names the rule that holds.**
  It links I08:E03 as the removing epic and names its AC2 — a positional `document#fragment` derives its run's name from the document it names — as the rule a section entry now follows.
- **The fixture stays withdrawn.**
  The entry states that `fixtures/mock/a-redirected-referrer-carries-its-entry` is withdrawn rather than rewritten, because no surviving spelling reaches the same behaviour, and the record's fixture inventory marks its row the same way.
