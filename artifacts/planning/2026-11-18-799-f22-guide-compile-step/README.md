# Guide Compile Step — November 2026

> Hot-fix · Created 2026-11-18

## Executive Summary

The guide `pf` prints states its compile step as run on a link in a bundle as written, without saying which links that covers, so an agent can read it as covering a published `⇉` dispatch link. Two sessions of the dispatch-brief run compiled such a link.

The fix adds one short clause excluding `⇉` and `⫽` links from the compile step, in the guide and in `invocation.md`, and changes no other wording.
