# Guide Compile Step — November 2026

> Hot-fix · Created 2026-11-18

## Executive Summary

The guide `pf` prints tells an agent to run `pf` on a link in a bundle as written, without saying which links that covers, so an agent can read it as covering a published `⇉` dispatch link. Two sessions of the dispatch-brief run ran `pf` on such a link.

The guide and `invocation.md` each gain one short clause saying the agent does not run `pf` on a `⇉` or `⫽` link, whose bundle the run has already compiled and the agent hands on. No other wording changes, and neither does what `pf` compiles.
