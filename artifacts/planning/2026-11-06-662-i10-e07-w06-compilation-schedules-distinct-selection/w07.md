## Design

The provenance map retains each occurrence's destination, normalized requested tags and operator. Parallel publication maps every raw request to its effective filename or generated set heading, while equivalent requests share one generated member and retain its first label. Candidate validation reads the original occurrence's tags and checks the file selected by the captured destination metadata.

The joined session delegates `cli.py` and `dispatch.py` to separate component workers. This session owns shared closure, provenance, rendering, composition, candidate and corpus seams; workers commit nothing.
