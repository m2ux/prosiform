**Component:** main:src/prosiform/metadata.py

## Overview

`prosiform` holds presets alone. Every key is a preset name whose value is a mapping, and a key whose value is anything else is refused, so the declaration has one kind of key and a place for every preset the epic goes on to select.

## Problem

`prosiform` admits three flat keys and fails every other.

- **The key set is closed.** `metadata.decode` accepts `group` and `group-depth` and raises `E_INVALID_CONVERSION_METADATA` for anything else, so a preset has nowhere to be written.
- **A key's kind is not knowable from its name.** `path-sub` is a field name and a plausible preset name; `Target` is a preset name and no field. The value decides, which is why the rule is a shape rather than a list.
- **A file-wide setting has no place left.** With the fields moving into presets, any top-level parameter would be a second rule for the same thing, and the one that cannot vary with a selection.

## Proposal

**The scene.** `decode` iterates the `prosiform` mapping's pairs, refuses a key outside a fixed tuple, checks each field's type, and returns a `Conversion` carrying one group and depth per file, which `cli.group_depths`, the member-heading pass and the group arrangement read.

**The design.**

- **One kind of key.** Every `prosiform` key is a preset name, and every value is a mapping. A value that is not a mapping fails with `E_INVALID_CONVERSION_METADATA` at the value, naming the key; a preset field written at the top level also names the preset it belongs in, `prosiform.default.<field>`. `root` stays refused at the top level and within a preset.
- **A preset's fields.** A preset admits `group`, `group-depth`, `exclude` and `path-sub`, and refuses any other field as unknown. `group` and `group-depth` keep their present shapes and pairing, read per preset; `exclude` and `path-sub` must be lists. Their entry shapes, and `group`'s refusal, are later rows of the epic.
- **`Conversion` holds presets.** One immutable value per file: `declared`, and a `Preset` per key in written order, each carrying its name, its group and depth and their locations.
- **`default` is the preset in force.** `Conversion.default` returns the `default` preset, or an empty one where the document declares none. Grouping reads it, so a document whose `default` states no group keeps its individual file group. Keyword selection is a later row; until it lands, no other preset is in force.
- **An empty `prosiform` mapping states nothing.** A file with an empty block declares and carries no preset, and one with `default: {}` carries an empty preset; both compile with no group.
- **Migration.** Every fixture, example and test source that declared `group` and `group-depth` at the top level declares them in its `default` preset, each such fixture citing *Presets — `default` always applies*, and the invocation, the source page and the rendered drawings show the nested form.
