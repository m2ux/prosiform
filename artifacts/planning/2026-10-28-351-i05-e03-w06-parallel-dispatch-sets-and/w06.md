**Component:** src/prosiform/run_set.py

## Overview

The `⫽` links in one section form a set: each target is compiled to a bundle of its own, and every `⫽` link in the section points at one `Dispatch in parallel` sub-section listing those bundles, to be dispatched together. Parallelism becomes a property of the dispatches a section's prose writes, and the run-set target shape is retired with the module that held it.

## Problem

- **A run-set is a target shape.**
  [`run_set.py`](https://github.com/m2ux/prosiform/blob/4fdaf8a2ffb1c46784ef454522e5deb37dfef32a/src/prosiform/run_set.py) holds a `⫽` target to one bulleted list of calls and warns `W_RUN_SET_SHAPE` on anything else; the target is compiled into the bundle carrying the link and the mark is published.
- **Nested items carry an order.**
  A run-set's nesting states which call waits on which, an order a set of parallel dispatches cannot hold.

## Proposal

A review step writes `[⫽ Code Review](review.md#code) and [⫽ Test Review](review.md#tests)`. Both links point at `### Dispatch in parallel`, which lists `review__code.bundle.md` (Code Review) and `review__tests.bundle.md` (Test Review).

- **A `⫽` link is a dispatch.**
  It withholds its target as `⇉` does, and its target compiles, transitively, to a bundle of its own, under the same cycle, depth and self-dispatch analysis.
- **A section's `⫽` links are one set.**
  The set is the `⫽` links in the section's own content, anywhere in its prose; a child section's links form that section's set.
- **One sub-section per set.**
  Headed `Dispatch in parallel`, after the section's own content and its dispatch sub-sections and before its child sections. Its body lists each bundle file once with the first link's text, and carries no protocol link until W08. Every `⫽` link in the section points at it with its mark stripped. [`Placing`](https://github.com/m2ux/prosiform/blob/4fdaf8a2ffb1c46784ef454522e5deb37dfef32a/src/prosiform/dispatch.py#L401) emits it beside the dispatch sub-sections; no second placement path is written.
- **Sets and dispatches are independent.**
  A section carrying `⇉` and `⫽` links has a sub-section for each `⇉` target and one for its set; a link's destination is keyed by its target and whether it is parallel, so one target named by both operators reaches both.
- **A set has no order.**
  `run_set.py`, `W_RUN_SET_SHAPE`, the shape check and the nested-item ordering are removed, with `test_run_set.py`.
- **The contract moves with the build.**
  The design's operator, Dispatched bundles, Dispatch sub-sections, Dispatch depth and Run-set clauses, the diagnostics section, the adversarial fixtures, the declared codes, the manifest schema's catalogues, the pin, `invocation.md` and the glossary state the set.
