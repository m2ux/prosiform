**Component:** main:evals/diagram-following/workflows/declared-inclusion/scenarios.toml

## Overview

A diagram-following workflow whose links are compiled by their targets' `prosiform` declarations, one scenario per permutation, so the live run measures an agent following a bundle that followed one link and left another as text.

## Problem

- **No eval workflow links an undeclared document.**
  Every corpus document declares, so the eval never measures a bundle carrying a link `pf` left as written.
- **The corpus proves the bytes, not the reading.**
  A fixture shows which links `pf` follows; only a session shows an agent following the result.

## Proposal

**The scene.** A delivery workflow: Receive decides on `inputs/supplier.txt` between Inspect and Liaise, Inspect reaches Verify, and both reach Archive.

**The design.**

- **A declared link followed.**
  Verify carries no click; Inspect's section links its document, which declares, so the bundle carries Verify and the link names its section. Scenario `declared-link-followed`.
- **An undeclared link left as text.**
  Liaise links a document under `undeclared/`, which declares nothing, so the bundle keeps the link as written and carries none of the document. Scenario `undeclared-link-as-text`.
- **An undeclared directory.**
  The corpus requires every document to declare, save those under `undeclared/`, which must declare nothing.
- **The diagram form alone.**
  The workflow takes `bundle` and `tree`.
