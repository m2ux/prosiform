**Component:** example/work-planner/protocols

## Overview

Every protocol procedure writes its steps as sub-sections, so the step a mode or another protocol depends on can be linked.

## Problem

The twelve protocols hold 55 numbered steps; `epic-closure.md` names its own steps as `step 4` and `step 6` in prose.

## Proposal

`task-merge.md`'s labelled steps become `###` sub-sections under `## Procedure`, each headed by its label.

- **Labels become headings.**
  Each bold step label becomes its sub-section's heading in title case.
- **Fixtures.**
  Each usage-example fixture whose entry reaches a protocol takes the expected bundle the converted corpus compiles to.

## Work Breakdown

| Part | Description |
| --- | --- |
| Analysis | Each protocol's procedure and heading levels. |
| Plan | Headings for any two labels in one file that read alike. |
| Implementation | The twelve protocols and the regenerated usage-example bundles. |
| Review | Each step's text is unchanged but for its label becoming a heading. |
| Test | `make links`, `make corpus` and `make check`. |
