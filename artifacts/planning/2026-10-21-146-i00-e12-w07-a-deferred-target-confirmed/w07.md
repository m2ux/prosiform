**Component:** `src/prosiform/closure.py`

## Overview

This task makes a deferral followable. The run resolves a deferred reference against the allowed source root, reads the document it names and looks up the heading a fragment names in that document's heading index, and the destination the bundle publishes for that link is the target's path from the root. A deferred reference naming no document, or no heading in the document it resolves to, fails with `E_TARGET_NOT_FOUND` and the run publishes nothing.

It matters because deferral withholds the compilation, and the compilation was what confirmed the target and named its destination. Without this row the bundle hands an agent a link that may name nothing, spelled relative to a source document that agent does not hold, and a run that reaches neither.

## Problem

A deferred reference is passed over before the traversal reads anything, so nothing confirms what it names and nothing rewrites where it points.

- **A deferred reference naming nothing succeeds.**
  `cli.required()` passes over a marked use before it resolves one, so the document is never read and the fragment is never looked up. The same reference unmarked fails with `E_TARGET_NOT_FOUND`, so the run answers for one half of a rule the design states over both.

- **The destination is relative to a document the bundle does not record.**
  `bundle.target()` returns no destination for a deferred link, so the link reaches the bundle with the path its author wrote, which is resolved from the directory of the source carrying it. The agent reading the bundle holds the root and the bundle and has no such directory, so a correct link is unfollowable and `../SKILL.md` names nothing it can reach.

- **The confirmation has nowhere to live.**
  `closure.bundled()` answers one question — does this run compile the link — and returns nothing for a deferred one, a reference leaving the root and a reference naming no Markdown document alike. A caller needing the deferred reference's target cannot tell those three apart.

## Proposal

The run is responsible for every reference under the root, and a deferral says only that this run does not carry it. So the reference is resolved and confirmed like any other, and the destination it is published with names the target from the root.

- **The classifier answers the deferred question too.**
  `closure.deferring()` returns the target one deferred link names, where that link resolves under the root to a Markdown document, and nothing otherwise. It shares `closure.resolvable()` with `closure.bundled()`, so the two answer opposite halves of one rule from one resolution and a mark on a reference position already leaves as text changes nothing.

- **The traversal confirms without carrying.**
  `cli.withheld()` yields the target of each deferred use a selected region carries, and `cli.traverse()` confirms each after the closure reaches its fixed point: the document is read, and a fragment is looked up in `source.index()`, the index of every heading the profile recognizes. The reference contributes no identity to the frontier, so the document is not bundled through it, adds no content, takes no destination of its own and heads no file group. A document another reference carried is confirmed from the tokens that reference already produced.

- **Existence is the question a confirmation asks.**
  A heading the document carries confirms the reference, whether or not it roots a selectable section. Which heading a fragment selects, and whether it can be told from another, is the question the run that compiles the link answers; this run states only that the target is there to be found.

- **The failure is the one a compiled reference raises.**
  A document the root does not carry is refused by the read, and a fragment the index does not hold is refused beside it: `E_TARGET_NOT_FOUND` naming the reference, the resolved path and the route the run followed to the link, and the run publishes nothing.

- **The destination names the target from the root.**
  `closure.rebased()` writes the resolved target's root-relative path, each segment percent-encoded so a path the decoding step reads is the path the filesystem carries, and carries the fragment the author wrote after it. `bundle.target()` and `candidate.intended()` both publish it, so the bundle's bytes and the invariant checked over them agree.

- **The example tree shows a deferral.**
  `example/work-tracker/modes/plan-mode.md` names its routing document in prose, because a link under the root would carry it. It defers that document instead, so the tree carries all three of position's answers and the `usage-example/` fixtures publish a destination rebased from `../SKILL.md` to `SKILL.md`.

- **A rule a later row owns keeps the behaviour the build has.**
  `W08` states the rules in the published documentation and the glossary, and retires `design.md`'s *Validation scope* account of self-reference. This row leaves both alone.
