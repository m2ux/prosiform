**Component:** main:src/prosiform/cli.py

## Overview

One repeatable `--budget NAME=VALUE` replaces the eight lettered budget options, and its value parser resolves each entry to the budget it names, so a run sets a ceiling by a word that says what it bounds.

## Problem

The family is generated from a loop and its validity lives in the grammar.

- **The parser loops over `BUDGETS`.** Eight `add_argument` calls come from one loop, each with its own destination and `type=override`, so the letters are a rendering of the table.
- **`budgets(options)` reads eight attributes.** It builds `Limits` from one attribute per budget, so a collapsed option changes that read to one mapping.
- **`diagnostic_format` walks value-taking short options.** The eight letters sit in its set of options taking a value, and a long option takes its value as the next token, which carries no leading `-`.
- **A diagnostic names a letter.** A crossed budget names `-F` and its remedy says to raise `-F`, a spelling the run no longer accepts.

## Proposal

**The scene.** `parser()` declares each option with a `type=` parser, and `budgets(options)` returns the `Limits` in force.

**The design.**

- **One option, appended.** `--budget NAME=VALUE`, metavar `NAME=VALUE`, with no short form; its destination is a mapping from `Budget` to figure, empty when no entry is given.
- **Each budget carries its name.** `Budget.name` replaces the letter and its destination, and `NAMED` maps each name to its budget, so the parser resolves names from the one table.
- **The value parser splits on the first `=`.** The name is resolved against `NAMED` and the right side read by `override`, whose integer rule is unchanged.
- **The result is a mapping.** `budgets(options)` reads each budget from the parsed entries, and a budget no entry names stands at its default.
- **The help lists the budgets.** A `budgets:` section of the help states each name, its default and what it counts, generated from `BUDGETS`.
- **A crossing names the budget.** `Crossed` reads "crosses the files budget of N", and its remedy names `--budget files`.
