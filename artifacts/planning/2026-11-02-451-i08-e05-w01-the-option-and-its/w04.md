**Component:** main:invocation.md

## Overview

Eight budget rows become one option row, and a budgets table beneath it states each name, its default and what it counts, held to the help output in both directions.

## Problem

The table states the same rule eight times.

- **The option table carries eight budget rows.** Each takes a positive decimal integer and each bounds a different count, so a reader scans eight rows to learn one rule.
- **`make invocation` compares both directions.** The table and the build's help output must name the same options, so eight rows and eight flags go together or the check fails.
- **The names and their rules are the content.** A reader needs the eight names, their defaults and what each counts, and a list nothing compares drifts from the build.
- **Pages name budgets by letter.** `docs/validation.md`, `docs/sources.md`, `docs/dispatch.md` and `docs/output-budget.md` state budgets as `-O`, `-E` and the rest.

## Proposal

**The scene.** The option table's rows are clauses `make invocation` compares against the build's own help.

**The design.**

- **One row states the option.** `--budget NAME=VALUE`, repeatable, reproducing the help text word for word.
- **A budgets table states the names.** A table keyed `Budget` lists each name with its default and what it counts, and `make invocation` compares it with the help's `budgets:` section in both directions, as it compares exit statuses.
- **The refusals are stated once for a reader.** The budgets section names the entries refused as invalid usage, linking no second statement of a counting rule.
- **The prose naming budgets uses names.** Every page stating a budget by letter states it by name.
- **No other row changes.** The invocation rows and the informational rows keep their wording.
