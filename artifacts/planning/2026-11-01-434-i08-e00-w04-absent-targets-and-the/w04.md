**Component:** src/prosiform/cli.py

## Overview

A link naming nothing is text, and the shapes that state responsibility keep failing: an operator naming no document, a fragment naming no heading, and an entry reference naming a document that declares nothing. Responsibility is stated by the mark an author writes and by the entry a caller names, not by whether a path happens to exist.

## Problem

After [W03](https://github.com/m2ux/prosiform/pull/493), absence was still decided by the read.

- **The probe failed on absence.** `cli.probe` let the walk's `Absent` reach `reading`, which raised `E_TARGET_NOT_FOUND` for every link naming a missing Markdown path, marked or not. A misspelled citation failed the run although nothing stated the bundle was answerable for it.
- **The operator refusal could not tell three targets apart.** `refusals_of_operators` asked `resolvable`, which answers a silent target, an absent one and a citation alike as `None`, so a marked link to a missing document was refused as `E_UNSUPPORTED_CONSTRUCT` naming "no Markdown document … under the source root".
- **An entry was never asked.** `traverse` captured every entry whole, so a document declaring nothing was bundled as a procedure.
- **Diagnostic text named a retired boundary.** `missing`, `reading`, `entry` and the operator refusal said "allowed source root".

## Proposal

**The scene.** `compiled` builds one `Declarations` record per bundle over `cli.probe`, and `traverse` reads each entry before discovery; `required`, `refusals_of_operators` and `withheld` classify every link through the record.

**The design.**

- **The probe answers three ways.** `closure.Probed` is `DECLARING`, `SILENT` or `ABSENT`; `Declarations.answer` keeps it by path and `declares` holds for `DECLARING` alone. `cli.probe` returns `ABSENT` where the walk finds no regular file, so `required` treats a missing target as text through the same `declares` test a silent one meets.
- **A substitute naming nothing is refused.** `Reference.redirected` marks a reference the mapping redirected, and the probe re-raises its absence, because the caller who named the substitute stated the run answers for it.
- **An operator reads the answer.** `closure.named` resolves a link to its local Markdown occurrence, and `refusals_of_operators` asks the record: `ABSENT` fails with `E_TARGET_NOT_FOUND` in the operator's diagnostic shape, `SILENT` with `E_UNSUPPORTED_CONSTRUCT` naming the missing declaration, anything else as naming no Markdown document. `resolvable` is `named` plus the declaration.
- **Every entry declares.** `declared_entries` asks the record for each entry — the referring document for a fragment-only one — before `traverse` reads a source, and fails a silent or absent entry with `E_TARGET_NOT_FOUND`. An entry with a non-Markdown suffix is left to the read's suffix refusal.
- **A fragment-only link keeps its refusal.** `selection` already raises `E_TARGET_NOT_FOUND` for a fragment naming no heading; the fixture states it.
- **`read_document` keeps its absence branch.** A `-f` referring document is captured without a probe, so absence there still reaches the read.
- **The trees declare their entries (folded, blocking).** Every corpus entry and every unit-test entry declares `prosiform`; a malformed opener carrying a key now declares nothing and its entry is refused.
