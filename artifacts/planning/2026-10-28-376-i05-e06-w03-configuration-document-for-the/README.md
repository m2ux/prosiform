## Executive Summary

This record holds the delivery of I05:E06 W03. It creates `example/work-planner/configuration.md`, which states each of the example's deployment and run values once, with its meaning and allowed values. These values are the repository, labels, board fields and limits. `SKILL.md` and the guidelines' Bindings rule link the new document, and every other occurrence of a binding becomes a link to it.

Board fields, labels and limits are written in more than one file, so changing a value in one place leaves a stale copy in another. With one home, each value has a single place to change.
