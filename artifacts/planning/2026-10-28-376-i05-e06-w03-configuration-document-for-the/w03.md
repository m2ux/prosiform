**Component:** example/work-planner/configuration.md

## Overview

The example's deployment and run values — labels, board titles and fields, the engineering branch and the standup limits — are stated once in `example/work-planner/configuration.md`, which `SKILL.md` and the guidelines' Bindings rule link. Every other occurrence links its entry, so a deployment changes each value in one place.

## Problem

- **Labels are restated.**
  The kind labels sit in each body artifact's Titles, the theme labels in the board's Themes table and two Titles sections, and the priority label's colour and description in the board queue's Priority Sets.
- **Board names sit in commands.**
  The `Proposals` title, the two template titles and the `Status` field name are literals inside steps and command templates in `artifacts/board.md`.
- **The engineering branch is a literal.**
  `artifacts/planning-record.md` matches `[engineering]` and lists `artifacts/planning/` inside its commands.
- **Report limits are prose.**
  The standup window's week and its five Ready items are stated in two places in `artifacts/standup-report.md`.

## Proposal

A reader looking for the value a deployment sets opens one file. Each entry names the value, what it means and the values it allows. Each other file links the entry it uses, and a command template takes the value as a parameter its step fills from that entry.

- **Home.**
  `example/work-planner/configuration.md`, beside `conventions.md`, linked from `SKILL.md` and from the Bindings rule in `guidelines.md`. Bindings are values and conventions are rules, so each file keeps one subject.
- **What a binding is.**
  A literal a deployment or a run sets and the skill writes or matches: a label name, colour or description, a board or template title, a field or option name, a branch or folder name, a count or a window.
- **What it is not.**
  - A state name used as a word, such as "an epic In Progress", is the scheme's vocabulary. The binding is the option set the board carries.
  - A labelled example illustrates a value's shape and supplies none, as the guidelines' Concrete examples rule states. The conventions' Example values list is such an illustration and stays with Conventions.
  - A placeholder such as `<owner>` or `<repo>` is a run input the step fills.
  - `per_page=100` is the GitHub REST maximum page size, the same for every deployment. Word counts and line limits in Titles and Fields are format rules of the scheme.
- **Limits.**
  The standup's window and Ready count are configured values that the report's fields name by link. The `--since` argument carries the window start.
