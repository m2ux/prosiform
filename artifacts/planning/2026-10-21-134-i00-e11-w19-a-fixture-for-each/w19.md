**Component:** [`checks/runner.py`](https://github.com/m2ux/prosiform/blob/main/checks/runner.py)

## Overview

A manifest declares the whole of its invocation, the allowed source root included, so every command-line fault the contract names is a fixture the corpus runs against any build.

## Problem

`E_INVALID_USAGE` names six faults, and the corpus states three of them.

- **Three faults are stated by fixtures.**
  An option value outside the set its row names, a fragment-only reference with no referring document, and an output path naming an input source. Each declares the run's own data its message must carry, so a build reporting another fault under that code fails the fixture.

- **Three faults are stated by nothing the corpus reads.**
  An option the contract does not declare, a command line naming no entry reference, and a command line naming no allowed source root. Each is held by one build's own tests, which bind that build rather than the contract.

- **One of the three cannot be written at all.**
  The runner prepends `--root` and the fixture's resolved source tree to every invocation, so no manifest can describe a run supplied no allowed source root, however the rest of it is written.

- **A reader of the catalogue cannot tell cover from gap.**
  The catalogue names one code and the corpus carries fixtures under it, and nothing says which of the faults that code names are stated.

## Proposal

The invocation a manifest declares becomes the whole invocation: the runner supplies the allowed source root where the manifest names one and supplies nothing where it does not.

- **`invocation.root` is optional.**
  A manifest naming it declares the tree the run is confined to, as every manifest does today. A manifest omitting it declares a run with no allowed source root, which is the command line the contract refuses for naming none. Nothing else changes about the run: the diagnostic format is still the runner's, and the working directory is still the fixture's.

- **Each of the three unstated faults becomes a fixture.**
  Each declares severity `error`, code `E_INVALID_USAGE`, exit status 2 and the text its message carries — the option spelling the grammar does not admit, the contract's name for the thing the command line supplies none of, and `--root`. A build reporting another fault under the code fails the fixture.

- **The corpus guide names what the code's fixtures cover.**
  The guide carries the six faults the code names and the fixture stating each, so coverage is read from the corpus rather than assumed from the code.
