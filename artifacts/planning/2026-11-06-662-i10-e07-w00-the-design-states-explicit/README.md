# Explicit Preset Selection Design — November 2026

> I10 E07 W00 delivery · Created 2026-11-06

## Executive Summary

The design defines a Markdown link title as its explicit tag selection, and defines the command an agent supplies to compile that selection. One invocation compiles one entry and its dispatched bundle set.

The contract supplies the selection and variant identities that later source, CLI and dispatch work consume. This unit changes the design document; it does not claim that the compiler implements the new behavior.
