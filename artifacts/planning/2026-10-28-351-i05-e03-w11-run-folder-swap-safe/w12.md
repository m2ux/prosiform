**Component:** src/prosiform/cli.py

## Overview

Every refusal publication can meet is decided before any write, and decided the same way under `-c`: two bundles deriving one name, an output folder that does not exist, and a source the run read with different bytes for two of its bundles.

## Problem

- **A derived-name collision is found by the write.**
  `a/b.md` and `a_b.md` derive one name; only the exclusive open in the staging folder finds it, so `-c` exits `0` while the run exits `3`, naming a hidden staging path with a remedy about the output folder.
- **`-c` never looks at the output folder.**
  `pf -c -o /nonexistent ref.md` exits `0`; the same run without `-c` exits `3`.
- **Captures are merged last-wins.**
  Each bundle captures the sources it reads, and the merge keeps the last capture of a path, so a source edited between two bundles' reads passes the recheck and publishes a mixed set.

## Proposal

The scene: one run, its entry and its dispatched targets each compiled, then published.

- **Names are checked with the budgets.**
  `publication` refuses a second bundle taking a name an earlier one took, naming both targets, before the `-c` branch, under `E_PUBLICATION_FAILED`.
- **The output folder is checked with them.**
  An output folder that is not an existing folder is refused there too, under `E_PUBLICATION_FAILED`, naming it.
- **Captures must agree.**
  Merging the bundles' captures refuses a path whose digest or file identity differs between two, under `E_SOURCE_CHANGED`.
