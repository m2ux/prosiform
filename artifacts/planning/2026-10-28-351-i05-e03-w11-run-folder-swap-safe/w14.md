**Component:** src/prosiform/dispatch.py

## Overview

A dispatching link's text becomes a well-formed heading and listing item, a link with no text is refused as an input defect, and only the headings pf emits in a bundle are reserved in it. The dispatched links a source writes are read by one reader, so the hops a run follows and the sub-sections it places cannot disagree.

## Problem

- **Link text enters a heading as written.**
  A wrapped link, a hard break, a trailing space or empty text gives a `Dispatch <link text>` heading candidate validation rejects, so the run exits `4` and publishes nothing.
- **Two headings are reserved in every bundle.**
  `collisions` adds `Prosiform` and `Dispatch in parallel` to the emitted set whether or not the bundle emits them, so a bundle dispatching nothing cannot carry an authored `## Prosiform`.
- **Dispatched links are read twice.**
  `cli.dispatches` reads them through `uses`, `written_in` through `inlines`; a disagreement surfaces as a bare `KeyError` when a link is rewritten.
- **Deduplication is repeated.**
  `Graph.beyond` and `distinct` deduplicate hops the traversal already keyed by target.
- **A refusal names deferral for a dispatch.**
  `confirm` reports a missing heading as one "of the document it defers" for dispatched links too.

## Proposal

The scene: `[⇉ plan\nmore](plan.md)`, `[⇉ ](plan.md)` and an authored `## Prosiform` in a bundle with no dispatch.

- **Text is collapsed.**
  `written_in` writes the link text with each run of whitespace as one space, for the heading and the parallel listing alike.
- **Empty text is refused.**
  A dispatching link with no text after its mark is refused under `E_UNSUPPORTED_CONSTRUCT`, naming the link, during traversal.
- **Only emitted headings are reserved.**
  `collisions` reads the emitted set from the generated headings alone.
- **One reader.**
  The traversal's hops come from `written_in` over the selected regions; `Graph` and `distinct` go.
- **Wording.**
  `confirm`'s message names the document the link withholds.
