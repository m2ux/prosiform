**Component:** src/prosiform/cli.py

## Overview

The hidden folders a run stages its set in, and moves the earlier set aside to, take short names of their own, so any run folder name the filesystem accepts can be published.

## Problem

- **Staging names grow with the run's name.**
  `sibling` names the staging and aside folders `.<run folder>.<role>.<32 hex>`, 38 characters longer than the run folder, so a run folder name of 218 to 255 characters fails with `ENAMETOOLONG` though the folder itself could be written.

## Proposal

The scene: an entry whose derived name is 240 characters.

- **A fixed-length hidden name.**
  The staging and aside folders are `.pf.<role>.<32 hex>` beside the run folder, whatever its name.
