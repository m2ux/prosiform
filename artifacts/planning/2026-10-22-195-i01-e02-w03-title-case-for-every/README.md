# Title Case for Every Generated Heading — October 2026

> Delivery · Created 2026-10-22

## Executive Summary

The compiler writes headings of its own: the heading a merged group carries, and the heading a document arrangement derives from a path. The first is title-cased and the second is not, so one run emits `# Rules` beside `# procedure` and `# rules/codex`, and the diagrams rendered from those runs carry both spellings as though both were intended. This unit makes the casing the group construction already applies the convention every generated heading takes, path structure preserved.

A heading an author wrote and a filesystem path a run names are not the compiler's to respell, so the convention has a boundary as well as a reach. Holding that boundary is what keeps the change a presentation rule rather than a rewrite of content the source owns.
