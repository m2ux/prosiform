**Component:** main:src/prosiform/cli.py

## Overview

A composition failure ends the run before publication, so no bundle reaches the working directory, a named output folder or standard output, under `-c` as without it. A dispatch mark written against a composition directive's label is refused (folded work).

## Problem

- **The Failure clause had no fixture.**
  *Section composition — Failure* states that every composition failure publishes nothing, and no fixture showed it for a failure arising after the entry composed cleanly.
- **A dispatch mark against a directive's label read as text.**
  `[⇉→]` dispatches to a sub-agent and places inline at once. W06 left it an ordinary link of two characters (user, 2026-11-02).

## Proposal

**The scene.** `execute` in `cli.py` compiles the entry and every dispatched bundle, each raising its composition failure as a `Failure`, before `publication` makes the output folder or writes a bundle.

- **Nothing published.**
  The guard holds already; fixtures pin it for a failure in a dispatched bundle, on the default output, a named output folder and a check run.
- **The contradicting mark.**
  `contradicting()` in `closure.py` reads a plain-text label of operator marks, a dispatch or parallel mark among them, written against one qualifying scalar. `refusals_of_operators` refuses it under `E_UNSUPPORTED_CONSTRUCT`, naming the link. *Operators that combine* states the rule; *Operator marks* links it.
