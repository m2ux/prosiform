## Overview

A `staged` workflow whose sources hold a footnote-style `[†]` link beside an arrow `[→]` directive, and a section composed from its own document, so the eval measures an agent reading each as its bundle publishes it.

## Problem

- **Only an arrow composes.**
  A single footnote mark is an ordinary link, which the agent must open rather than read in place.
- **Self-composition publishes with a warning.**
  The bundle is followed all the same, and nothing shows a session doing so.

## Proposal

**The scene.** A workflow is a directory under `workflows/`, its forms beside a `scenarios.toml` naming each scenario's inputs, the path a correct session walks, the sub-agents it starts and the `pf` runs it makes. A `staged` session receives the compiled bundle set with the build under test as `pf` on its path; the scenario passes when the session's path is the one its bundle states.

- **Footnote and arrow.**
  `Compose` writes `[→](../reference/style.md#rules)`, placed beneath its step, and `[†](vet.md#vet)`, which publishes `Vet` as a document of its own. The diagram clicks no `Vet`, so `footnote-opened`, reading `review`, walks `Compose`, `Vet`, `Issue` through the footnote.
- **Self-composed.**
  `Issue`'s `Release` step writes `[→](#summary)`, composing the `Summary` section of its own document; the run warns `W_COMPOSE_SELF`, which the workflow declares, and `self-composed`, reading `direct`, walks `Compose`, `Issue`.
