**Component:** main:evals/diagram-following/workflow.py

## Overview

A scenario states the `pf` runs a correct session and each of its sub-agents makes, and the corpus declares the `staged` form, so a scenario can say when an agent compiles deferred material.

## Problem

- **A scenario states no compile.**
  `scenarios.toml` names inputs, a path and a dispatch trace; the only compile the eval observes is whether a `bootstrap` session ran `pf` at all.
- **No form hands a session a bundle and the build together.**
  The `compiled` form gives a bundle set with no shell, and `bootstrap` gives sources to compile, so a bundle carrying a `↳` line has no form to run in.

## Proposal

**The scene.** A workflow is a directory under `workflows/`, its forms beside a `scenarios.toml` naming each scenario's inputs, the path a correct session walks, the sub-agents it starts and the `pf` runs it makes. A `staged` session receives the compiled bundle set with the build under test as `pf` on its path; the scenario passes when the session's path is the one its bundle states.

- **Each run is a stated entry.**
  A `[[scenario.compile]]` table names who runs `pf` and the references it names, in the order a correct walk makes them: `by`, the section a sub-agent follows as `<document>#<heading>`, absent for the session's own run; and `args`, each `<document>[#<fragment>]` the run compiles, empty for bare `pf`. Options such as `-o` are the agent's to choose and are not stated.
- **A stated run names a real document.**
  A run's references resolve from the directory a shell form runs `pf` in: the skill's directory for `bootstrap`, the form's tree for `staged`. The corpus test refuses a reference naming no document there, a `by` naming no section of the scenario's trace, and a run stated by a workflow written in no shell form.
- **`staged` is a shell form.**
  It joins `SHELL_FORMS` beside `bootstrap`, is written with dispatch marks as `compiled` is, and draws the workflow in its entry. `dispatch-set` is written in it, a scenario whose bundle carries nothing to compile and states no run.
- **`bootstrap-audit` states its runs.**
  Its skill says to run `pf`, then compiles the `↳` link, so each scenario states bare `pf` then `pf sources/workflow.md`.
