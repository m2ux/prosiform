## Overview

User ruling: "Operations are applied and procedures are followed." Each verb that governs a link to an operation or a procedure is chosen by opening the link's target, not by reading the link text.

## Problem

- **Steps use Run and Call on every kind of target.**
  A step said "Run", "Call" or "Follow" before an artifact operation, a mode, a protocol or a command spec alike. The verb did not tell the reader what kind of target the link led to.
- **The guidelines prescribed the mixed verbs.**
  Modes "Other modes" said to invoke another mode with Run or Follow. The Prose API, Layers and Execution rules said operations and protocols are called or run.

## Proposal

- **Apply for operations.**
  A link to a subsection under an artifact's Operations is applied.
- **Follow for procedures.**
  A link to a mode, a protocol, or a mode's or protocol's Procedure subsection is followed.
- **Run for commands.**
  A command specification under an artifact's Commands, or under a mode's Operations, keeps Run.
- **One rule.**
  The guidelines' Procedure section carries a Step verbs rule. The other rules use its verbs.

## Implementation Findings

- **A mode's Operations section holds command specs.**
  revise-mode's Run Tests and Check Skill Files are bash command specifications, so the verb stays Run.
- **Some steps named operations in plain words.**
  plan-mode named Populate Epic Issue Body and Report Review Finding without a link. Both are applied.
- **sync-mode's Issue Closure step had no verb.**
  It now reads "Follow [Issue Closure] for each epic".
