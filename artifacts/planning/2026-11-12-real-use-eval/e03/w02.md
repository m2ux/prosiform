## Overview

A Work Planner session is scored on the context its request requires: it passes when its recorded reads cover every file and section its request's context contract names.

## Problem

- **The scorer holds a session to a path of states.**
  Work Planner states no state diagram and writes no `trace.log`, so the path scorer has nothing to read.
- **A required section missed leaves no mark.**
  A session that skips a prerequisite and one that never needed it finish alike.

## Proposal

**The scene.** `subagents.json` records each file a session read and each command it ran, and the skill's reading-route harness states a context contract per captured request at each revision.

- **The contract is the revision's own.**
  Each variant is held to the contract its revision's harness states for the request.
- **A section is read from a source or a bundle.**
  A read of a source file covers its sections; a read of a bundle `pf` wrote covers each section that bundle carries.
- **Failure classes name what was missed.**
  A session lacking required context fails as missing context, naming each file or section, beside the existing errored class.
- **`read_source` holds.**
  A `compiled` session that opens a source beside its bundle fails as it does in every workflow.
