## Overview

The field-scale run is made as the runbook states, triaged, and committed as the eval's record of one skill of real size compiled against plain.

## Problem

- **No record compares a skill of real size compiled against plain.**
  Every committed run is of workflows a session reads whole.

## Proposal

**The scene.** The runbook's field-scale section fixes the run's arguments and caps.

- **The run.**
  The section's command on the harness and model the user named, held to its stop rules.
- **The record.**
  Every failing session triaged into `dispositions.json`; the run's report as `field-scale.json` and `field-scale.md`; the run's measured cost and its variant comparison in the README.

## Work Breakdown

| Part | Description |
| --- | --- |
| Analysis | The section's caps and the user's approval of the cost cap |
| Plan | None beyond the runbook |
| Implementation | The run, its triage and the committed record |
| Review | No `untriaged`, `defect` or `unclear` disposition |
| Test | The report's Failing Sessions and variant comparison, and `make eval-harness` reading the committed record |
