## Overview

The four dispatch workflows become a product skill and an `authored` control skill each, so the eval still measures what compiling the dispatch protocol adds.

## Problem

- **The dispatch workflows hand over a bundle set.**
  Their `compiled` form gives a session the bundles `pf` already wrote, and `authored` gives its one bundle by name.

## Proposal

**The scene.** Each workflow holds `compiled/` and `authored/` trees and a dispatch trace per scenario.

- **Two skills per workflow.**
  `compiled` runs `pf` and links `compiled/`'s entry with `↳`, so the session compiles the dispatch set itself; `authored` links `authored/`'s entry as plain Markdown.
- **Traces name what the skill compiles.**
  Each trace's `dispatch` names the section as the skill's compile publishes it.
