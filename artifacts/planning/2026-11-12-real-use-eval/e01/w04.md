## Overview

The composition workflows and the two nested-dispatch workflows become product skills, so labels and deep dispatch are followed from a discovered skill.

## Problem

- **These workflows start from a compiled bundle.**
  `conditional-composition`, `directive-labels`, `dispatch-depth` and `subagent-first-run` hand a session the bundle set `pf` wrote.

## Proposal

**The scene.** Each is written in `compiled/` alone, and the nested ones state sub-agents' runs.

- **One skill per workflow.**
  `compiled` runs `pf` and links `compiled/`'s entry with `↳`.
- **Sub-agents' runs resolve from the skill.**
  A run stated `by` a section names its reference from the skill's directory.
