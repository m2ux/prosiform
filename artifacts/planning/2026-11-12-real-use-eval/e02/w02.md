## Overview

The runbook states how the real-use baseline is run, and its shakedown sets the run's caps, so the run makes no design judgement of its own.

## Problem

- **No runbook section covers the skill-entry eval.**
  The baseline section's caps came from a bare-prompt shakedown.

## Proposal

**The scene.** The runbook's rubric and stop rules bind every run; a run section states its arguments, caps and committed files.

- **A real-use baseline section.**
  Harness and model asked at the start of the run; the default matrix; five repetitions; caps by the shakedown's rule.
- **Its shakedown.**
  One repetition of every cell on the harness and model the user names, its spending cap set before it starts, its runs and measured figures recorded in the section.

## Work Breakdown

| Part | Description |
| --- | --- |
| Analysis | The default matrix's cells on the chosen harness |
| Plan | The shakedown's spending cap, put to the user |
| Implementation | The section, the shakedown run, each attempt recorded with its triage |
| Review | Every cap traces to a recorded shakedown figure |
| Test | The runbook test, and the shakedown's committed record of its attempts |
