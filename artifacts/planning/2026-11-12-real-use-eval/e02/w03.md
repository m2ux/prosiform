## Overview

The shakedown the runbook's real-use baseline section states is run, and its measured figures set the section's caps.

## Problem

- **The section's caps have no figures.**
  The rule derives each cap from a shakedown on the skill-entry eval, and none has run.

## Proposal

**The scene.** The runbook's real-use baseline section states the shakedown and the rule deriving each cap.

- **The shakedown.**
  One repetition of every cell on the harness and model the user names, held to the spending cap set before it starts and to the stop rules.
- **The recorded caps.**
  Each attempt, its triage and its measured figures are recorded in the section, with the session cap, token budget and cost cap the rule derives.

## Work Breakdown

| Part | Description |
| --- | --- |
| Analysis | The default matrix's cells on the chosen harness |
| Plan | The shakedown's spending cap, put to the user |
| Implementation | The shakedown run, each attempt recorded with its triage, the derived caps |
| Review | Every cap traces to a recorded shakedown figure |
| Test | The runbook test, and the shakedown's committed record of its attempts |
