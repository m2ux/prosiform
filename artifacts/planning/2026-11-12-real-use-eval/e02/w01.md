The eval's committed records and the sections describing them leave, since each was taken from a bare prompt the eval no longer gives.

## Problem

- **Every committed record is a bare-prompt run.**
  `baseline.json` with `report.md`, `mvp-proof.json` with `mvp-proof.md`, and `agent-pick.json` with `agent-pick.md`.
- **Tests and sections read them.**

## Proposal

**The scene.** Once every family is a skill, no record describes a session the eval can give.

- **The records and sections leave.**
  The six record files, the README's sections and default-matrix figures that cite them, the runbook's four run sections, and the tests reading them.
- **The baseline and edge split leaves.**
  `EDGE_WORKFLOWS` and the default matrix's exclusion of it are removed, so the default matrix holds every workflow.
- **The rubric and stop rules stay.**
  The triage rubric, dispositions file and stop rules bind every run, so they stay as they are.
