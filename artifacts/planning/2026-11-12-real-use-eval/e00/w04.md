## Overview

The bare-prompt path leaves the eval: no instruction file, no entry-file prompt, and no session for a workflow not yet written as a skill. The runner then runs what it can run as real use, and each family joins it as it converts.

## Problem

- **Three instruction files drive the bare prompt.**
  `instruction.md`, `instruction-compiled.md` and `instruction-bootstrap.md` and the `ENTRY` placeholder, `entry_named()` and the per-form instruction table carry it.
- **Every form still runs.**
  The default `--forms` lists `bundle`, `tree`, `prose`, `linked`, `compiled`, `authored` and `bootstrap`, each started from an instruction.

## Proposal

**The scene.** Once the prompt is a task and the session's material is a placed skill, the instruction files and the entry wiring are unused.

- **The files and wiring leave.**
  The three instruction files, `ENTRY_PLACEHOLDER`, `entry_named()` and the bundled forms' workspace layouts are removed, with the tests that held them.
- **The matrix holds skills alone.**
  `--forms` becomes `--variants`, and a workflow with no `skills/` text gives no session.
- **The README states the eval as it is.**
  The Forms section describes variants, and every sentence about an instruction or entry document leaves.
