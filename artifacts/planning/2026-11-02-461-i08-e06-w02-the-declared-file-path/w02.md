**Component:** main:src/prosiform/closure.py

## Overview

A preset's `subst` pair resolves from the file that declares it, so one declaration reads the same wherever the run starts. The corpus holds that as a fixture run from a directory other than the declaring file's.

## Problem

The pair's sides are references, and a reference has a base.

- **The basis is delivered and unwitnessed.** `cli.subst_identity` and `cli.subst_reference` read each side from the declaring document's directory, and the substitute `closure.Substitution.writing` returns for a link opens through that same walk. No fixture runs a declaration from a working directory other than the declaring file's, so a regression to the working-directory basis would pass the corpus.
- **A parent segment is the common case.** A mode in `modes/` names the skill root's `../rules.md`, so the basis must hold for a side that leaves the declaring directory.

## Proposal

**The scene.** `governing` builds each carried document's pairs with `subst_identity` for the key and `subst_reference` for the substitute, both from `posixpath.dirname` of the declaring document's path.

**The design.**

- **The base is the declaring file's directory.** `rules.md=stub.md` in `modes/plan.md` names `modes/rules.md` and `modes/stub.md`; `../rules.md` names the directory above.
- **The grammar is the reference grammar.** Percent decoding, control-character refusal and `..` normalisation are the ones a link meets, because the call is the one a link makes.
- **The working directory plays no part.** The same tree run from `source/` naming `modes/plan.md`, and from `source/modes/` naming `plan.md`, compiles the same substitute.
