## Overview

The triage rubric decides each class the scorer gives a session's `pf` runs, so a live run meeting one has a disposition to give it.

## Problem

- **The run classes have no rubric entry.**
  W03 adds `uncompiled`, `overcompiled` and `misordered_compile` to the scorer, and `RUNBOOK.md`, whose rubric decides every class, arrives with I10:E05 W00 on a base W03 did not hold. Once both meet on the epic base, the runbook test holding the rubric to the scorer fails.
- **The rubric decides a class the scorer does not give.**
  W05 retires `unbootstrapped` from the scorer, and the By Class table still holds its row.

## Proposal

**The scene.** `RUNBOOK.md` holds the triage rubric and a runbook per live run; a run row follows its runbook and escalates what the rubric marks a defect.

- **One row per run class.**
  Each of the three classes gets its `miss`, `defect` and `unclear` reading in the rubric's By Class table, read against `subagents.json`'s `commands` for the session and each start, the transcript's shell calls, the session's form and the scenario's `[[scenario.compile]]` tables.
  - `uncompiled`: a miss where the form states the line, link or guide run on the path and no record makes it; a defect where the transcript makes it and the record omits or misattributes it, or the form states no such run.
  - `overcompiled`: a miss where the agent compiles a reference the path does not reach; a defect where the form states it and the tables omit it, the spelling escapes the scorer's match, or the harness ran the command.
  - `misordered_compile`: a miss where the transcript makes the stated runs in the recorded order and the form reaches them in the tables' order; a defect where the record or the tables disagree with the transcript or the form; unclear where one message holds several runs.
- **No row for a retired class.** (User, 2026-11-03.)
  The By Class table holds only classes the scorer gives.
- **The rubric test holds it.**
  `test_the_rubric_decides_every_class_the_scorer_gives` passes on a base carrying both W03 and E05 W00.
