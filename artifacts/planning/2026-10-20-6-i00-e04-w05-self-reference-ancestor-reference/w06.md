## Overview

Resource budgets that fail at the first boundary crossed.

## Problem

Without enforced budgets, a pathological source tree is discovered by exhausting memory rather than by a diagnostic.

## Proposal

Each limit the profile names is counted as the design states: distinct source identities opened, raw bytes per source, summed raw bytes, complete bundle bytes, distinct targets discovered, authored link occurrences in selected content, and syntactic container nesting. Crossing one fails the compilation with no output and no truncation. A positive decimal override is accepted and zero is refused. Nesting is enforced as an explicit failure rather than left to a parser option.

## The Code a Crossed Budget Reports

The contract declares eight budgets and holds that crossing one fails rather than truncates, and it named no code for that failure. [D41](https://github.com/m2ux/prosiform/blob/engineering/artifacts/planning/2026-10-17-prosiform-v1/decisions.md) settles it: `E_RESOURCE_LIMIT` covers all eight, and the diagnostic names the budget crossed and what it counted.

Adding it means the clause in `design.md` on `engineering` and the entry in `fixtures/manifest.schema.json` on this branch, which `checks/tests/test_catalogue.py` holds equal while reading the design from `origin/engineering`. Either side alone turns CI red on every branch of the repository. This unit also adds `E_MARKED_RESOURCE` for W05's AC17, so **land both codes and both clauses in one window** rather than two, and say so when reporting.

## What the Measurement Found

No budget existed on the base: every one of the eight options was refused as an undeclared argument, so nothing counted and nothing could cross. Both criteria need the counters, their placement and the overrides in full.

The nesting budget needed one thing the design implies rather than states. A parser carries a nesting ceiling of its own, and reaching it makes the parser read the rest of a construct as text, which is the silent reinterpretation the design forbids. The ceiling therefore sits above the declared budget with enough headroom that ordinary inline structure is unaffected, so a source nested past the boundary is always counted past it and refused explicitly.

The expansion depth is the round a traversal discovers a reference in. A selection only grows, so the round a reference first appears in is the shortest path in link hops from the nearest entry reference, which is what the budget is declared over.
