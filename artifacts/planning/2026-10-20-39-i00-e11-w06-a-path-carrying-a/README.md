# I00:E11:W06 A Path Carrying a Number Sign, Named or Ruled Out - October 2026

> Task Plan - Created 2026-10-20

## Executive Summary

This record holds the local plan for the row that settles what happens to a source path carrying a number sign. Either the path is nameable by an entry reference and reaches its file heading with that character intact, or it is refused with the code the contract names, and the fixtures state whichever the contract settles on.

It matters because a reference splits at the first number sign and reads the remainder as a fragment, so such a path can be written on disk and named by nothing. The file heading escapes the character today, held by one build's own tests and by no fixture, which leaves the behaviour undeclared either way.
