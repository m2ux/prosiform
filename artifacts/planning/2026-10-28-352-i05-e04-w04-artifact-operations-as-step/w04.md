**Component:** example/work-planner/artifacts

## Overview

Every artifact operation writes its steps as sub-sections, each headed by its number and an action, so a mode or protocol can link the one step of an operation it means.

## Problem

- **An artifact step roots no anchor.**
  The 31 artifacts hold 423 numbered steps across 118 operations, the bulk of the corpus, from 2 in `work-item.md` to 54 in `pull-request.md`. No operation has a single step and no step list nests another. A link can name an operation but not one of its steps.
- **No label to promote.**
  Artifact steps carry no bold label, since the guidelines' Operation steps rule forbids one, so each step needs an action written for it.

## Proposal

In `issue.md`, Save Tracker Issue's `3. For a new issue, run Create Tracker Issue …` becomes `#### 3. Create New Issue` under `### *Save* Tracker Issue`.

- **An action per step.**
  Each step gains a short action after its number, written from its leading instruction: title case, small words lower case mid-heading, each part of a hyphenated word capitalised, articles kept. Each action names its operation's subject, so every `N. Action` pair is unique across the corpus and no step anchor takes an ordinal suffix in a bundle.
- **Text unchanged.**
  Each step's text stays as written, its instruction opening the sub-section and its bullets beneath. Prose step references such as `step 2` stay for W05.
- **Existing sub-sections.**
  `issue-body.md` Verifiable and `delivery-evidence.md`'s board-reads section keep their place after the operation's steps.
- **Run Board Reads.**
  `#### Board Reads` takes the three-word title `#### Run Board Reads` the Child section titles rule asks for, with its linking step, the README excerpt and the fixture description. The fixture name `a-mode-and-the-board-reads-it-steps-through` still describes it and stays.
- **Fixtures.**
  Each usage-example fixture whose entry reaches an artifact takes the expected bundle the converted corpus compiles to, and `example/README.md`'s Read in steps excerpt quotes the converted text.
