**Component:** evals/diagram-following/baseline.json

## Overview

The dispatch scenarios' first baseline: one run of the default matrix in both forms, reviewed and committed as the reference later runs compare against.

## Problem

Until a dispatch scenario has been run, the report states no pass rate for either form and no comparison between them.

## Proposal

The scenarios and the scorer's dispatch checks are on the branch this task extends, and the eval's login is the one the diagram-following baseline already uses.

- **Cost first.**
  The run's estimate is put to the user before it starts, as the diagram-following baseline's was, and the run starts only on their approval.
- **The run.**
  `make eval-diagrams` over the dispatch scenarios, both forms, the default models and five repetitions.
- **Review.**
  Every failing session is read: a failure caused by an ambiguous scenario or an unclear protocol is a corpus defect, fixed and the affected cells re-run before the baseline is taken.
- **Record.**
  The baseline file and the run's report are committed, and the eval's README states the dispatch scenarios' measured cost.

| Part | Description |
