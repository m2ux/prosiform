**Component:** evals/diagram-following/score.py

## Overview

The scorer's dispatch checks: whether every bundle reached a sub-agent, whether a set's bundles started together, whether a question a sub-agent returned was relayed rather than answered, and whether the run completed.

## Problem

The scorer holds seven classes for a walk that departs from a scenario's path, and reads a trace of states entered. A dispatch trace records sub-agent starts and questions, which no class observes; a bundle set handed to an agent is scored as an unfinished walk.

## Proposal

The dispatch checks read the session transcript beside the trace the scorer already reads, and each has a class of its own.

- **Sub-agent record.**
  The session transcript is read for each sub-agent start and its position in the run, written beside the trace and the session's cost so the scorer needs no second read.
- **Checks.**
  Every bundle reached a sub-agent; a set's bundles started together; every question a sub-agent returned was put to the user rather than answered; the run completed.
- **Classification.**
  A failing trace takes the first check it fails, so the report's failure kinds distinguish a bundle left undispatched from a set run in sequence and from a question answered in the sub-agent's place.
- **Stub agent.**
  The stub writes the sub-agent starts and the traces the tests assert on, so `make check` runs the checks without a paid session.
