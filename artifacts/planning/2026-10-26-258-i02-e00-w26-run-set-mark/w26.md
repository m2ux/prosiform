## Overview

`⫽ ` marks a link whose compiled target is a run-set: a bulleted list of calls to run concurrently. pf checks the target's shape and warns when it is not one.

## Problem

- **No concurrency mark.** An author could not say that the calls a section holds run together. Nothing checked that such a section holds only calls.

## Proposal

- **Recognition.** `closure.RUN_SET_MARK = "⫽"` joins `OPERATORS`, so `opens`, `operators` and `conflicting` read it under the W25 spacing rule. `run_set(opening)` holds where `⫽` is among the operators. `withholding` is `deferred or dispatched`, so a run-set link is a dependency: `bundled` compiles it and the bundle rewrites its destination. `unmarked` strips only a deferral, so `⫽ ` is published.
- **Refusals.** `refusals_of_operators` refuses text opening with two distinct operators, naming each. It also refuses any operator, `⫽` included, whose destination `resolvable` does not resolve to a Markdown document or section under the root, and any image carrying an operator.
- **Shape rule** (`run_set.stray`), over the target's selected regions: the whole document, or the section with its subsections.
  1. A heading opening the regions is the target's own and is skipped.
  2. No regions left: `no bulleted list`.
  3. The first region must be `bullet_list_open`; otherwise the construct is named.
  4. Any further region is named, for example `a further bulleted list` or `a heading`.
  5. Inside the list, every token must be a bulleted list, list item, paragraph or inline token. Anything else is named: `a numbered list`, `a code block`, `a block quote`, and so on.
  6. Every list item, nested ones included, must carry in its own inline text (not counting nested items) a `link_open` whose destination `resolvable` resolves from the target's document within that document's root. Images do not count. An item without one is `a list item that links no Markdown document or section under the root`.
- **Reporting.** `traverse` collects run-set links per round, each target once at the first link naming it, and returns them after the hops. `cli.misshaped` emits one `W_RUN_SET_SHAPE` per target after the dispatch warnings. A target whose section is ambiguous or nested raises nothing here, since the compilation refuses it first.
- **Dispatch hops.** A run-set target is compiled, so `dispatches` reads its `⇉` links in the selection that compiles it. Those links are the bundle's first hops, and in `onward` closures they are hops of that closure. No analysis change was needed. Tests cover a depth warning and a non-procedural warning raised through a run-set item.

## Warning

Text:

```text
W_RUN_SET_SHAPE: the run-set link '⫽ the reviews' names 'plan.md#reviews', which is no run-set: it holds a paragraph, where a run-set holds only one bulleted list of calls
  reference: plan.md#reviews
  resolved: plan.md#reviews
  chain: guide.md → plan.md#reviews
  remedy: link a section that holds only a bulleted list of calls, or remove the run-set mark
  location: guide.md:3:1
  related: plan.md:5:1: holds a paragraph
```

## Implementation Findings

- **Fixtures added** (`fixtures/run-set/`):
  - `a-run-set-is-compiled-with-its-mark`: clean, no diagnostic.
  - `nested-run-set-items-each-carrying-a-call`: clean, no diagnostic.
  - `a-run-set-target-holding-a-paragraph-warns`: warns.
  - `a-run-set-target-holding-a-numbered-list-warns`: warns.
  - `a-run-set-item-linking-no-document-warns`: warns.
  - `a-link-carrying-the-run-set-mark-and-the-dispatch-operator`: refused with `E_UNSUPPORTED_CONSTRUCT`.
  - `a-run-set-link-naming-a-remote-address`: refused with `E_UNSUPPORTED_CONSTRUCT`.
  - `a-run-set-mark-with-no-space-after-it-opens-an-ordinary-link`: compiled with no diagnostic.
- **Independence.** The design's one-operator clause no longer says "wait". `dispatch/a-link-carrying-both-operators` used that word in its description, so the description was reworded.
- **Refusal text.** The conflicting-operator message names each operator, for example `opens with the run-set mark '⫽' and the dispatch mark '⇉', which state different things for one compilation`. The operator-target message ends `so the operator states no compilation the run can carry out`.
