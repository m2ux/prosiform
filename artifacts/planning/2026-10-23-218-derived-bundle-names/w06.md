## Overview

The normative contract defines deterministic output names for whole-file and section entries.

## Problem

Output destinations are supplied manually and the contract defines stdout as the default.

## Proposal

Specify the confirmed basename transformation, normalized selection identity, explicit destination for combined selections and authoring naming guidance. Specify automatic file publication with only the root option and the positional entry required. Preserve root confinement and publication guarantees.
