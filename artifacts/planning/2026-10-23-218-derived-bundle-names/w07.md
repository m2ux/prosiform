**Component:** src/prosiform/metadata.py

## Overview

Captured metadata exposes an immutable root declaration and its original location.

## Problem

The reserved metadata schema carries group/depth but no compilation root.

## Proposal

Keep the Agent Skills string-valued metadata schema and test rejection of nested prosiform mappings. Accept an optional nonempty relative prosiform-root string independently of group/depth. Preserve its raw value and source location; reject unsupported path forms and types through bounded decoding. Preserve absence in the captured value; traversal supplies the parent root. Explicit declarations resolve from the declaring file directory. Update source-model tests and the immediately affected schema contract.
