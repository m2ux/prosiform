**Component:** src/prosiform/metadata.py

## Overview

Captured metadata exposes the top-level prosiform mapping and an immutable root declaration with its original location.

## Problem

The reserved metadata schema carries group/depth but no compilation root.

## Proposal

Decode the top-level prosiform mapping with full root, group and group-depth keys. Accept string root/group values and an integer depth from 1 through 6, paired with group. Accept an optional nonempty relative root independently of group/depth. Preserve its raw value and source location; reject unsupported path forms and types through bounded decoding. Preserve absence in the captured value; resolution uses the invocation working directory. Explicit declarations resolve from the declaring file directory. Remove obsolete prefixed metadata-field handling. Update source-model tests, existing metadata fixtures and directly affected consumers in this unit.
