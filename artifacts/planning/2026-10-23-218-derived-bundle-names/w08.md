**Component:** src/prosiform/cli.py

## Overview

The command compiles a positional file while each source supplies the root for its own links.

## Problem

Source traversal uses a caller-supplied shared root and file-relative links.

## Proposal

Capture the entry under existing limits and no-follow access. Resolve each source's optional prosiform-root relative to its file directory; absence inherits the linking parent's effective root; a direct entry defaults to its containing directory. Resolve path-bearing Markdown links from the declaring source's effective root, and apply the target's own metadata to its outgoing links. Capture bytes by canonical physical identity. Keep the effective root in traversal context so a shared file reached under different inherited roots resolves each context correctly. Preserve cycle detection and deterministic deduplication under the normative contract. Preserve fragment-only self references, deferred validation, limits, original locations, source rechecks and per-source rooted access. Different valid roots are permitted. Remove -r. Update source identities, diagnostics, active fixtures, -f semantics, installed-wheel smoke and directly affected consumers in this same unit.
