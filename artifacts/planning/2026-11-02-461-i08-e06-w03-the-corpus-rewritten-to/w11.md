**Component:** main:src/prosiform/cli.py

## Overview

`-m` is not an option the build declares, so a preset's `subst` is the only way a run substitutes a reference.

## Problem

- **The option still parses.** `cli.parser()` declares `-m, --mock`, `cli.mock` reads its pair, and `cli.substitution` holds four command-line refusals.
- **The run-wide mapping outlives it.** `closure.Substitution` holds run keys, their spellings and the unused-key report beside each document's pairs, and an entry reference is redirected through those keys.

## Proposal

**The scene.** `execute` builds the run's `Substitution`, `compiled` lays each document's governing pairs over it, and `inside` resolves a link through the writing document's pairs.

**The design.**

- **The grammar declares no `-m`.** The option, its parser, its refusals and its diagnostic-format lookahead are removed.
- **A mapping is each document's pairs and the run's record.** `Substitution` holds `documents`, `redirects` and the `writer`; a mapping naming no writer redirects nothing, so a run key, its spelling and the unused-key report have no subject and are removed.
- **An entry reference is compiled as named.** `entry` takes no mapping.
- **Retired, not refused.** No refusal or fixture asserts the option's absence.
