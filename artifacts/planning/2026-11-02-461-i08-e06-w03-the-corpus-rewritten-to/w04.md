**Component:** main:invocation.md

## Overview

The option table names no `-m`, and no page, help string or fixture names it, so the invocation documents substitution only as the `subst` entry.

## Problem

- **The table carries the row.** `invocation.md` states `-m, --mock ORIGINAL=ALTERNATIVE` with its effect, reach and repeatability.
- **Other pages describe the option.** The glossary's *substitution mapping*, the references page's mapping section and its figure describe a command-line parameter read from the working directory.

## Proposal

**The scene.** The option table's rows are clauses `make invocation` compares, in both directions, against the build's help output.

**The design.**

- **The row is removed.** The table names no channel for a substitution.
- **Every page describes the preset.** The glossary entry, the references page's section and its figure state the `subst` pair of the writing document, resolved from that document.
- **The search proves the rest.** No file outside the git history names `-m` or `--mock`.
