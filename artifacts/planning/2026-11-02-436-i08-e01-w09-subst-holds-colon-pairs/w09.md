**Component:** main:src/prosiform/metadata.py

## Overview

A preset's substitution entry is named `subst` and writes each pair as a single-entry mapping from an original reference to its alternative, `subst: [{rules.md: stub.md}]`, read by the same single-entry-mapping reader `group-depth` and `exclude` use. A side holding a colon followed by a space is quoted the YAML way. An entry of any other shape is refused naming it.

## Problem

The preset entry is spelled and shaped apart from its siblings.

- **The pair is a string.** `metadata._path_sub` splits an `ORIGINAL=ALTERNATIVE` string at its first `=`, while `group-depth` and `exclude` write their pairs as single-entry mappings read by `metadata._pair`.
- **The design's reason for the string is wrong.** Design clause *path-sub holds pairs written as strings* says a reference in a mapping key would collide with a path's colons. YAML splits a key only at a colon followed by a space, and a quoted key carries one.
- **The name is long.** The entry is `path-sub`, against the one-word `exclude`; `PathSub`, `Preset.path_subs`, `cli.path_subs`, two corpus fixtures, the source page and the design name it.
- **`SUBSTITUTION` lives in `metadata`.** The `=` separator is read by `-m` alone once the preset entry is a mapping.

## Proposal

**The scene.** `metadata._preset` reads each preset field's entries; `cli.substs` holds each side to the reference grammar when a document is opened; `cli.mock` reads `-m ORIGINAL=ALTERNATIVE`.

**The design.**

- **The field is `subst`.** `metadata.SUBST` names it in `FIELDS`; `Subst` holds one entry's original, alternative and location; `Preset.substs` holds them in written order.
- **An entry is a colon pair.** `metadata._subst` reads the entry through `_pair`, then requires the value to be a string and neither side empty. A mapping holding two keys, a non-string key, a non-string value, an empty side and an entry of any other shape fail with `E_INVALID_CONVERSION_METADATA` naming `prosiform.<preset>.subst[n]`.
- **Each side is read by the reference grammar.** `cli.substs` resolves both sides as before and names `subst` in its refusal.
- **`-m` keeps its own separator.** `SUBSTITUTION` moves to `cli`, its one reader.
- **The design states the colon pair.** The clause becomes *subst holds colon pairs*, stating the single-entry mapping and the YAML quoting of a side holding `: `; every other `path-sub` mention in the design reads `subst`, and the README design pin moves to that revision.
- **Every mention is renamed.** Code, tests, fixtures and the source page name `subst`.
