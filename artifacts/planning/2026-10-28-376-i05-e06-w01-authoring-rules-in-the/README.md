## Executive Summary

This record holds the delivery of I05:E06 W01. The work-planner example's guidelines gain the authoring rules the epic applies:

- **Bindings:** each binding is stated once, in a configuration document.
- **Inputs and Outputs:** each is one line of contract links.
- **Commands:** commands sit inline in the steps that run them.
- **Homes:** each convention and rule has one home, and links are file-relative.
- **Subjects:** each file holds one subject.
- **Steps:** steps stay `N. Action` sub-sections.
- **Headings:** a file's H1 is its heading in the bundle.

Every later row of the epic changes the example to meet these rules. Stating them first gives each change one written rule to meet and gives a reviewer one place to check it. Today the guidelines describe the shape the epic replaces.
