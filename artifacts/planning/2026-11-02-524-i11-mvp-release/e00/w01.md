## Overview

The release record states the `contract/v0.15.0` corpus's result against the release build and the version it selects.

## Problem

- **The bump is read, not chosen.**
  `docs/versioning.md` settles it by running the previous revision's corpus against the new build.
- **The tag messages cite the result.**
  The `contract/` tag states the previous corpus's result, so the run is recorded before the tags.

## Proposal

**The scene.** `contract/v0.15.0`'s corpus is the fixtures at that tag; `make corpus` runs a corpus against the build `PROSIFORM_BUILD` names.

**The design.**

- **The previous corpus against the release build.**
  Run the `contract/v0.15.0` fixtures against the build at `main`'s release commit and record each failure.
- **The version follows the rule.**
  Any failure is incompatible, which below 1.0 bumps the minor; the record states the version selected.
