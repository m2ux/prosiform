**Component:** main:src/pyproject.toml

## Overview

A `release/vX.Y.Z` branch from `main` holds one commit setting the selected version.

## Problem

- **The package reports the last release's version.**
  `src/pyproject.toml` and `src/uv.lock` name `0.15.0`.

## Proposal

**The scene.** The release branch carries the commit both tags name.

**The design.**

- **One commit.**
  It sets the version in `src/pyproject.toml` and the prosiform entry in `src/uv.lock`, and nothing else.

## Work Breakdown

| Part | Description |
| --- | --- |
| Analysis | Read the selected version from the release record. |
| Plan | Settle the branch name from it. |
| Implementation | Cut the branch from `main` and commit the bump. |
| Review | Confirm the commit changes the two files alone. |
| Test | `make lock-check` and `make check`. |
