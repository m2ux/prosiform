**Component:** main:README.md

## Overview

`README.md` states what the repository holds and how a caller runs it as the merged build and the pinned design have it.

## Problem

- **The page was written epic by epic.**
  Each epic amended the parts it touched, so the page as a whole was never read against the merged build.
- **A stale claim reads as current fact.**
  A reader of the MVP takes the page as the contract.

## Proposal

**The scene.** `README.md` documents what the repository holds and how a caller runs it.

**The design.**

- **The page is read whole against the build.**
  Each claim is checked against the build's help output and the corpus, and each behaviour of its subject the build has is stated.
- **The evidence is recorded.**
  The pull request lists each claim corrected or added and what showed it.

## Work Breakdown

| Part | Description |
| --- | --- |
| Analysis | Read the page against the build's help output and the corpus. |
| Plan | List each claim to correct, add or remove. |
| Implementation | Amend the page. |
| Review | Re-read the page whole against the build. |
| Test | A read of the page whole against `pf -h`, the guide `pf` prints, `pf -C` and the corpus fixtures it cites, recorded in the planning record; `make harness` for its worked commands; `make links`, `make tables` and `make vocabulary`. |
