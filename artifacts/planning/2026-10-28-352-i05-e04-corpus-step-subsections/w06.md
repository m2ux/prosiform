**Component:** checks/steps.py

## Overview

A guard `make check` runs fails when a procedure in the example corpus writes its steps as a numbered list, so the convention holds after this epic as it does at its close.

## Problem

Nothing observes the step convention: a numbered list added to a procedure reads as valid Markdown, publishes, and loses the anchor a link needs, and `pf` states no rule on a target's shape.

## Proposal

A contributor adds `1. Fetch the issue.` to an artifact operation; `make check` fails naming the file and line.

- **What it reads.**
  Every tracked Markdown file under `example/`, its fenced and indented blocks blanked as the other checks blank them.
- **What fails.**
  A line opening a numbered list item at column 0 outside a code block.
- **One target.**
  `make steps`, in the set `make check` runs, named by the command table `make tables` reads.
