**Component:** example/work-planner

## Overview

Every reference the corpus makes to one step of a procedure is a link to that step's sub-section, so the precision the sub-sections give is used where the corpus names a step.

## Problem

About 50 prose references name a step by number or role, such as `step 4` in `plan-mode.md` and `epic-closure.md` or `the report step` in `propose-mode.md`, and none links anything.

## Proposal

Plan mode's "record its result as step 4 does" becomes "record its result as [4. Populate the Epics](#4-populate-the-epics) does".

- **By name, not number.**
  A reference names the step's heading and links its anchor; a later insertion that renumbers it is caught by `pf`'s unresolved-link check.
- **Every tree.**
  Modes, protocols, artifacts and the guidelines' own examples.

## Work Breakdown

| Part | Description |
| --- | --- |
| Analysis | Every prose reference to a step by number or role. |
| Plan | The link text for each, where a role differs from the heading. |
| Implementation | The links and the regenerated usage-example bundles. |
| Review | A search for `step <n>` and `the <word> step` outside code finds none naming a single step. |
| Test | `make links`, `make corpus` and `make check`. |
