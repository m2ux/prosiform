**Component:** main:checks/vocabulary.py, main:checks/tests/test_vocabulary.py, main:docs/composition.md

## Overview

The vocabulary check reads every page under `docs/` for terms the glossary names as deliberately not used, and each page stating one is reworded.

## Problem

- **The documentation is read for nothing.**
  The avoided-term rule reads the design and the corpus, and pages under `docs/` state such terms, "includes" in `docs/composition.md` among them.
- **The documentation is what a user reads.**
  The glossary's reasons hold for it as much as for a fixture description.

## Proposal

A page explains what a contribution does to the section it joins.

- **The vocabulary check reads `docs/`.**
  Each page is read with code blanked through the shared reading, and an avoided term outside the glossary's own table is reported with the table's reason.
- **Offending pages are reworded.**
  Each uses the word the glossary's reason points to; the Component line names the page the epic records, and the pull request lists every page reworded.
