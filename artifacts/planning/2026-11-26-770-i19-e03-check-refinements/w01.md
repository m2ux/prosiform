**Component:** main:checks/vocabulary.py, main:checks/conformance.py, main:checks/tests/test_vocabulary.py, main:checks/tests/test_conformance.py

## Overview

The vocabulary check and the conformance report blank code blocks through the shared reading, so an indented fence in the design is passed over as the link and table checks pass over one.

## Problem

- **Each keeps a left-margin fence pattern.**
  `vocabulary.strip_code` and the conformance report's clause and section readers toggle on a fence at the margin, so a fence under a bullet is read for marked terms and clauses.
- **Three readings decide one question.**
  The shared reading, the vocabulary check and the conformance report can each disagree on what in one document is code.

## Proposal

The design shows a Markdown example in a fence indented under a list item.

- **One reading.**
  Both call `documents.strip_code_blocks`; their fence patterns and the code that toggled on them go.
- **Code spans stay as each check reads them.**
  The vocabulary check still blanks inline code spans before reading marked terms; only block detection moves.
- **Nothing the design states moves.**
  The marked terms and the clause list are compared before and after.
