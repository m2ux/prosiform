## Overview

A stub's `subst` pair stands in for material under test and warns `W_SUBST_USED`; every other pair routes where its author declared and raises nothing where a link used it, so a live workflow compiles without warnings and the warning names a trial stand-in alone.

## Problem

- **A routing pair warns on every live run.**
  A pair `default` or an ordinary preset states warned `W_SUBST_USED` wherever a link used it, so a stage routing on two axes warned on every live run, and a trial's stand-in warnings sat among them.

## Proposal

- **`routing` is set by the preset, not by agreement.**
  `Governed.routing` holds for every pair but a stub's: `layer` sets it from `preset.stub is None` and `defaults` marks `default`'s pairs routing. The `standing` argument `layer` took to compare an alternative's pair against `default`'s goes.
- **The warnings follow `routing` unchanged.**
  `substituted` warns for a non-routing pair a reference used and `unused_pairs` weighs a routing pair against its document's links, as before; only which pairs are routing changes. `routes` keeps a stub's pair a stand-in where it names the same document, key and substitute as a route.
- **The tests and fixtures stating a warning for a route move.**
  A test or fixture about a warning's shape declares its pair in an entry stub; one about a route expects silence, and a fixture whose name stated the old rule is renamed.
- **The documents state it once.**
  `docs/selection.md` owns the rule; the glossary, validation catalogue, fixtures README and the design name it, and the docs pin the design at `d6b825c39`.
