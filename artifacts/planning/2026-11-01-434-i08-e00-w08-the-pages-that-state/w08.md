**Component:** docs

## Overview

Every page that states a root as a property of a source describes inclusion by declaration instead: a link is compiled when the document it names declares `prosiform`, wherever that document sits, and the invocation working directory bounds only entry references and the paths diagnostics name. The drawings whose cases declared a root are re-rendered from cases that declare, so `make examples` draws what the build now does.

## Problem

[W01](https://github.com/m2ux/prosiform/pull/487) to [W07](https://github.com/m2ux/prosiform/pull/502) made the build, the example tree and the corpus run the declaration rule. The pages a reader learns the tool from still state the old one.

- **The pages teach a root.** `docs/sources.md` has a section titled *The root* and lists `root` as a `prosiform` key; the architecture, reference, selection, hierarchy, validation, destinations and bundles pages, the glossary, the docs index and `invocation.md` say a link is followed when it lands under its author's root.
- **Worked examples of confinement name a root.** The two figures on the source and architecture pages draw a root deciding what a source may reach, and the output-budget page explains its working directory as "the root below".
- **The drawings fail to render.** Every case in `scripts/examples.json` has an entry that declares nothing, and five carry `root:`, so `make examples` exits nonzero on each; the published `source`, `references`, `dispatch`, `parallel` and `run` drawings show `root:` panels.
- **Held sentences and rows state the old rule.** `checks/tests/test_authoring.py` holds `docs/sources.md` to three root sentences, the `make smoke` row in `checks.md` says it bundles "from a source root", and the readme says missing dependencies fail a run, where a link naming no document is now text.

## Proposal

**The scene.** A source is a Markdown file the run opens. A link inside it resolves from the file that writes it. The target's leading frontmatter either carries a `prosiform` mapping, an empty one included, or carries none. The run is invoked from a working directory, captured once.

**The design.**

- **The declaration decides, and position does not.** Each page states that a link is a dependency when its target declares `prosiform`, that a target declaring nothing or naming no document is text, and that a link may name a declaring document anywhere, above the working directory included. The last is the rule [#503](https://github.com/m2ux/prosiform/issues/503) delivers in the build; the pages state the rule rather than the current refusal.
- **The working directory bounds entries and diagnostics.** Pages that said a root confines a source say that the invocation working directory is what an entry reference resolves from and every diagnostic path is written from, and that an entry must name a declaring document.
- **The boundary replaces the root as the worked example.** The source page's *The root* section becomes *The declaration* and *The boundary*; its figure and the architecture page's figure draw a target's declaration deciding, and the boundary example names a document whose links reach the directory above and derives that directory. The output-budget page explains its working directory by the document that cites the directory above, and its re-taking recipe adds the declaration the measured commit predates.
- **`root` is named as refused.** The `prosiform` key table lists `group` and `group-depth`, and the page states that `root` fails with `E_INVALID_CONVERSION_METADATA`. The glossary drops **root**; **boundary** already carries the derived definition.
- **Every drawing case declares.** Each file in `scripts/examples.json` opens with a `prosiform` declaration and none names a root. The references case shows its fourth link naming a document present in the tree that declares nothing, so the drawing shows the rule rather than a missing file. The drawings are re-rendered with `make examples`.
- **Held sentences follow the page.** `checks/tests/test_authoring.py` holds the source page to the declaration and key sentences it now states, and the smoke row says it bundles a declaring reference.
