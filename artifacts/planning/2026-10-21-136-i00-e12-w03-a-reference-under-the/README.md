# I00:E12:W03 A Reference Under the Root That Resolves Nowhere — October 2026

> Task Plan · Created 2026-10-21

## Executive Summary

This record holds the local plan for the row that makes the run answer for every reference it is responsible for. A reference under the allowed source root naming no document, or naming no heading in the document it resolves to, fails with `E_TARGET_NOT_FOUND` and publishes nothing, whether the run compiles that reference or defers it.

It matters because position now decides what the bundle carries, so a broken reference under the root is a broken bundle rather than an author's mention. A deferred link is held to the same standard: an agent given a mark it cannot follow is given nothing.
