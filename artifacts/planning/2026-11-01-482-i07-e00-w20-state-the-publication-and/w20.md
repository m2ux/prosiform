**Component:** artifacts/planning/2026-10-17-prosiform-v1/design.md

## Overview

Brings the design's Publication and Dispatch sub-sections clauses to the refusals the build performs and the pages state. The corpus cites the design's clauses as the contract, so a clause that contradicts the build misstates what a second build is held to.

## Problem

The Publication clause says whatever stands at the run folder's path is renamed aside and removed once the new folder stands. The build refuses a regular file there with `E_PUBLICATION_FAILED` and leaves it in place, and `docs/bundles.md` and the fixture `publication/a-file-at-the-run-folder-s-path-is-refused` say so. The Dispatch sub-sections clause names only the refusal of a link with no text, not the refusal of a dispatch in a heading the bundle emits as text alone, which `docs/dispatch.md` and two dispatch fixtures state.

## Proposal

A reader of the design's Publication clause learns which entries at the run folder's path a run replaces and which it refuses; a reader of Dispatch sub-sections learns which headings cannot carry a dispatch.

- **Publication.** An earlier set at the run folder's path is renamed aside and removed once the new folder stands; a symbolic link is replaced as the link it is; anything else, a regular file among them, is refused with `E_PUBLICATION_FAILED` and left where it stands, under `-c` as without it.
- **Dispatch sub-sections.** A dispatch in a heading the bundle emits as text alone — a referenced document's title its file heading absorbs, a merged group member's title its subsection absorbs, or a title above the selection — has no section to stand beneath, so the run publishes nothing and fails with `E_UNSUPPORTED_CONSTRUCT`, naming the link. The entry's own title heads its bundle, so a dispatch there publishes.
- **Design pin.** The README's Design link names the engineering commit carrying both clauses, so the conformance and vocabulary checks read them.

Clause names stay as they are, so every fixture citing either clause still resolves.
