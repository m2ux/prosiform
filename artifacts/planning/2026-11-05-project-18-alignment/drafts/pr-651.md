Every composition is `[↳ Title]` or `[¬↳ Title]`; the two deferred dispatches become deferred compositions of a section that dispatches; and the corpus test holds each dispatched bundle a scenario follows to the run-pf line and to the files its `⇉` links and `In parallel` items name. The scenarios written only in `staged` already run in `compiled`, folded in when `main` was merged into the epic base (`7ab77824`); this pull request fixes every test that merge left failing.

## Changes

The epic base's merge of I10:E06 left the edge sources writing marks `pf` now refuses and the corpus test reading a section `pf` no longer emits.

### Edge Workflows

- **Compose with the composition mark.**
  `conditional-composition`, `deferred-composition`, `directive-labels`, `preset-deferral` and `subagent-first-run` write `[↳ Title]` and `[¬↳ Title]`, titled as the target section is headed.
- **Reach a dispatch through a deferred composition.**
  `deferred-dispatch`'s `Pack` and `subagent-first-run`'s review defer the section that dispatches with `¬↳`, so the run on the line writes the bundle linking its targets.

### Corpus Reader

- **Enters a state by the heading a link names.**
  A link leads into a state where the heading it links is titled as the state, so a `↳` title reaches the section composed under it.
- **Reaches a deferred line through its sub-section.**
  A step reaches the `↳` lines under each heading its links name, and a source's reached `¬↳` is followed for the dispatches its material makes.
- **Matches a source heading by its slug.**
  A fragment such as `#read-mirror` names the `Read mirror` heading.

### Corpus Test

- **Holds each dispatched bundle to the run-pf line and its links.**
  Each bundle a scenario follows opens with the run-pf line, each `⇉` link names a file its run wrote, and each followed bundle is one a `⇉` link names.
- **Refuses a retired mark in any source.**
  No workflow source writes `¬⇉`, `¬⫽` or an arrow-labelled link.

### Eval Prose

- **States the composition mark and the run-pf line.**
  The README's dispatch, stated-run, sub-agent-run, deferral and composition sections and the scenario comments name `↳`, `¬↳`, inline `⇉` links and the run-pf line.
