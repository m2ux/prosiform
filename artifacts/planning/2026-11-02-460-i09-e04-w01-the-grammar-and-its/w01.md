**Component:** main:src/prosiform/composition.py

## Overview

A link whose plain-text label is exactly one Unicode scalar above U+007F is recognised as a composition directive, after the deferral mark is set aside, so deferral and placement are read independently. A directive written in a preamble has no destination scope and is refused, which is the run's first observable answer to recognition and lets lexical fixtures tell a directive from an ordinary link before composition places anything.

## Problem

- **No link requests placement.**
  Every link is a reference, deferred or not, and none asks that its target sit beneath the section naming it.
- **Recognition alone shows nothing.**
  A recognised directive in a section bundles as the ordinary reference it is until composition lands, so no fixture can tell one label from another without a behaviour that answers recognition.

## Proposal

**The scene.** The closure reads each use's opening for its operators, and a use carries the section title holding it, absent in a preamble.

- **The label.**
  The source reader records each link's label where it is plain text: text events alone between the link's opening and closing, entities already decoded. An image, an autolink, a diagram link and a label carrying emphasis, code, strikethrough, a line break or raw HTML carry none.
- **The predicate.**
  The composition module decides a directive from that label alone. A deferral mark written against the label is set aside; any other operator leaves no directive. What remains is one scalar above U+007F that is none of `¬`, `⇉`, `⫽` or `↳`. Nothing is trimmed or normalised.
- **Deferral stays independent.**
  Deferral is read from the opening, so `[¬→]` is a deferred directive and `[¬ guide]` an ordinary deferral, while `[¬ →]` and `[⇉ →]` write a blank between two symbols and are refused, as the design's *Operators that combine* states.
- **No scope, no directive.**
  A directive in a preamble is refused with `E_UNSUPPORTED_CONSTRUCT`, naming the link and its source location. The other scopeless case, a heading emitted as text alone, stays with the diagnostics task.
