**Component:** main:src/prosiform/cli.py

## Overview

Narrows a composition directive's label to one Unicode arrow, warns when a directive composes a section of the document that writes it, and opens a dispatched bundle that needs `pf` with a Prosiform section carrying the command its sub-agent runs first.

## Problem

- **Any single non-ASCII scalar placed content.**
  A footnote mark (`†`), a superscript (`¹`) or a letter (`é`) written as a link's whole label composed its target, so ordinary prose links changed meaning.
- **Composing one's own document passed silently.**
  `[→](#s)` and `[→](guide.md#s)` in `guide.md` place material the document already carries, while the equivalent dispatch warns with `W_DISPATCH_SELF`.
- **A sub-agent met links it could not compile.**
  A dispatched bundle carrying a deferred dispatch or a generated `[↳ …]` line is followed by a sub-agent that never ran bare `pf`, so it has no guide telling it how to compile them.

## Proposal

**The scene.** `placing` in `closure.py` decides a directive's label; `refusals_of_directives` and `traverse` in `cli.py` read each directive per round; `Placing` in `dispatch.py` emits the Prosiform section for a bundle that dispatches; `dispatched_set` compiles each dispatched bundle through `compiled`.

- **Arrows only.**
  `arrow` accepts an assigned scalar of the four Arrows blocks, or a Dingbats or Miscellaneous Symbols and Arrows scalar whose name holds the word `ARROW`; `placing` keeps `⇉` and `↳` out. `¬` and `⫽` are no arrows, so their exclusion goes.
- **Self-composition warns.**
  `composing_itself` yields `W_COMPOSE_SELF` for each immediate directive in a section whose target resolves to its own document; `traverse` keeps one per link and `compiled` publishes them after the dispatch warnings. A cycle still fails in composition, so the warning never accompanies it.
- **A first run for a dispatched bundle.**
  `compiled` marks a dispatched bundle; `first_run` reads whether it carries a deferred dispatch or an activation line. `Placing.open` then emits `Before following this bundle, [run pf first](#run-pf-first).` above `# Prosiform` and `## Run pf first` with ``Run `pf` first, with no arguments, and follow the guide it prints.`` ahead of any protocol.
- **Design.**
  *Recognition*, *Operator marks*, a new *Composing its own document*, *The Prosiform section*, *Clean Markdown*, the exit-status codes and the fixture lists. The README pin, the glossary, the dispatch page, the fixtures README and the schema follow.
