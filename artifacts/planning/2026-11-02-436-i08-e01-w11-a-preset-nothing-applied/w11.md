**Component:** main:src/prosiform/cli.py

## Overview

A preset no reference of the run selected is stated by `W_PRESET_UNUSED`, naming the document and the preset, beside a published bundle and exit status `0`. A preset on a document reached only through a deferral raises none, because the run that follows the deferral compiles the document and reads the preset then.

## Problem

The design's *A preset nothing selected warns* clause is stated without a code, and the build states nothing.

- **A preset no title selects is silent.** `cli.joined` reads, for each reference reaching a document, the presets its title selects, and a declared preset no title names governs nothing and is reported by nothing, so a misspelt keyword and a preset that took effect publish the same output.
- **The clause names no code.** The catalogue test requires every `W_` code the design names to sit in the warning catalogue, to be reported by `-C` and to be declared by a fixture, so W00 stated the warning by its effect and left the code to this row.
- **A deferred-only document looks unused and is not.** A document reached only through a `¬` link contributes no content to any bundle, so no reference of this run selects any of its presets; the run the deferral names compiles it.
- **Existing fixtures carry unselected presets.** `fixtures/inclusion/a-preset-key-holds-a-mapping` declares a `Target` preset nothing selects, and other preset fixtures leave a keyword preset unselected to show what a title does not select; each now warns.

## Proposal

**The scene.** `cli.compiled` traverses one bundle's closure and composes it, `cli.contributing` names each document the bundle carries with the references reaching it, `cli.keywords` returns the presets one title selects, and `cli.execute` hands `cli.publication` the warnings that are facts about the run rather than about one bundle.

**The design.**

- **A bundle records what it left unselected.** `cli.unselected` returns, for each document the bundle carries, the presets of that document no reference reaching it selected, in declared order, with `default` never among them. `Compiled.unselected` holds it.
- **The title a reference selects by is read once.** `cli.selecting_title` returns the title an entry's own document supplies or the title of the section holding the reference, and `cli.joined` and `cli.unselected` both read it, so the presets a reference governs with are the presets it counts as selecting.
- **The run unions what its bundles selected.** `cli.unused_presets` keeps, for each document, the presets every bundle carrying it left unselected, and raises one `W_PRESET_UNUSED` per preset, in path order and then declared order, naming the document as `source` and the preset in the message, with a remedy.
- **A deferred-only document is weighed by no bundle.** Only a document a bundle carries is recorded, and a deferral contributes no content, so a document reached only through one raises nothing.
- **The code is declared.** `PRESET_UNUSED` joins `CODES`, the design's *Presets* clause names `W_PRESET_UNUSED`, and the warning catalogue and the corpus README's catalogue carry it.
