**Component:** main:invocation.md

## Overview

The invocation and the source page state `prosiform` as presets: what a preset holds, how a keyword selects one, what `default` does, what a selection governs, what is refused, and that a preset nothing selected warns. The glossary defines *preset* beside the grammar *profile*.

## Problem

Earlier E01 rows stated presets on the pages as each rule landed, and three statements are still missing.

- **The invocation states placement alone.** Its *Conversion metadata* section states keyword selection and `default`, and its example and prose speak only of `group-depth`; what a selection governs beyond placement, `subst`, is stated on no page a caller reads first.
- **The refused fields are stated as a rule, not a list.** `docs/sources.md` states that a key outside the three fails, and not that budgets and the caller's options are among the refused keys, nor why.
- **The glossary has no *preset*.** It defines *profile* as the grammar a run declares and *grouping rule* as a preset's `group-depth` entry, and nothing defines the preset itself or tells it from the profile.
- **Nothing states the warning.** A preset nothing selected warns, and neither page says so.

## Proposal

**The scene.** `invocation.md` holds a *Conversion metadata* section with one example, `docs/sources.md` holds a *Frontmatter* section with the key table, and `docs/glossary.md` holds the *Sources* table.

**The design.**

- **The invocation shows a preset governing both settings.** The example gains a keyword preset beside `default`, holding a placement and a `subst` pair, and the prose states what the presets in force decide: the groups and where each reference the document writes resolves. `exclude` is retired by [W14](https://github.com/m2ux/prosiform/issues/436), so no page this row writes names it.
- **The source page lists the refused keys.** A budget, the output folder, the diagnostics format, check mode, the version and the help are the caller's, so a preset key naming one fails as unknown.
- **Both pages state the warning.** A preset no reference of the run selected warns, naming the document and the preset, and the run publishes; a document reached only through a deferral raises none.
- **The glossary defines the term.** *preset* joins the *Sources* table, distinguished from the profile, and the design marks it where it first uses it.
- **No option row is added.** A preset supplies values a resolution rule already reads, so the option table and `make invocation`'s comparison are unchanged.
