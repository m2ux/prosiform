**Component:** evals/diagram-following/report.py

## Overview

The report a run produces, its comparison with the committed baseline, and the command a reader runs.

## Problem

A directory of verdicts does not answer how well each model follows each form, or whether a change moved that.

## Proposal

- **Report.**
  `report.md` and `report.json` under the run: per model, form and scenario, the pass rate, the count of each failure class, mean tokens and cost; and per model and form across scenarios.
- **Baseline comparison.**
  With `evals/diagram-following/baseline.json` present, each cell carries its difference from the baseline.
- **Command.**
  `make eval-diagrams` runs the default matrix with a default spending cap; options pass through. It is not a prerequisite of `check`.
- **Documentation.**
  `evals/diagram-following/README.md` states what the eval measures, the forms, the scoring, the command, the default matrix and the measured cost of a default run; `checks.md` notes that the eval is outside `make check`.
