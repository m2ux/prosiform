**Component:** evals/diagram-following/workflows/*/linked, evals/diagram-following/workflow.py

## Overview

A fourth form whose decisions name the rule document stating the branch's label, so the edge a branch takes is reachable only by following the link, and the label is still held to the edges the diagram draws.

## Problem

The diagram form states a branch's label in the decision section, and the prose form names the next state, so neither needs a link to choose a branch. The `tree` form hands every session a recursive listing that names each state document, and the bundled forms put every section in one buffer, so no session in the committed baseline depends on a link. A 5/5 baseline cannot tell an agent that read a listing from one that followed a link.

## Proposal

- **A linked form**, `workflows/<name>/linked/`, with a Mermaid flowchart as the diagram form has and decisions phrased `take the transition labelled in [the escalation rule](../rules/escalation.md)`. Each rule document states exactly one label.
- **Both branches link**, `escalation.md` stating `high` and `queue.md` stating `low` for `branching`, so a first-link-first-label reading fails one scenario. `looping` links `rework.md` (`revise`) and `release.md` (`approve`).
- **The reader resolves through the document.** `parse_transition` takes the section's directory, reads the linked document, and returns the label it states. A document stating no label, or more than one, is a corpus error. The link resolves from `states/`, which is the writing document's directory.
- **The label stays held.** `transition_faults` checks the linked form's stated labels are the edges leaving the state, so a rule naming an absent edge is a fault.
- **Bundling is proven, not assumed.** `pf` inlines each rule document and rewrites the link to the document's anchor, so a bundle carries the same conditional semantics. The forms test bundles every form, so the linked form is held to that at exit 0.

## Findings

- **Every baseline cell passes.** All 150 sessions of `20261028T165414Z` pass, in every model, form and scenario, so the baseline separates no model from another and no form from another.
- **The links carried nothing.** In `tree`, all 50 sessions issued `Glob **/*` before their first state read and the listing named every `states/*.md`. In `bundle` and `prose`, no session read a state document at all. `Check` is the one state with no click line, reached by the `Revise → Check` edge.
- **The conditional semantics were resolved, the link was not.** 120 of 150 sessions sit on a decision path and all 120 passed, taking both edges of both decisions, so the annotated transition conditions work. Resolving a branch *through a link* is what the committed baseline cannot show.
- **The loop re-evaluates.** All 30 `two-rounds` sessions took `Revise, Revise, Publish`; all 30 `no-rework` sessions took `Publish` on their first `Review` visit.
