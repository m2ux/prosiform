**Component:** evals/diagram-following/baseline.json

## Overview

The first full run of the default matrix, reviewed and committed as the baseline later runs compare against, and the answer to how well agents follow a bundled diagram.

## Problem

Until one full run is recorded, the eval has no reference point and its first finding is unknown.

## Proposal

The runner (W03), report and `make eval-diagrams` (W04) are on `i05/e01/main`. Sessions run on the claude.ai team login held in the eval's own config directory.

- **The eval login.**
  The user logs in once: `CLAUDE_CONFIG_DIR=~/projects/eval/prosiform/config claude`, then `/login` with the team account. The runner refuses to start until `~/projects/eval/prosiform/config/.credentials.json` exists; the session reads its presence only, never its content.
- **Calibration.**
  One session — `claude-haiku-5-5`, `linear`, `bundle`, one repetition, `--session-budget-usd 0.50` — run from a plain shell, not from inside Claude Code: `uv run --project src --frozen python evals/diagram-following/run.py --models claude-haiku-5-5 --workflows linear --forms bundle --repetitions 1 --budget-usd 0.50`. It confirms the stream-json `result` fields the runner reads (`total_cost_usd`, `usage`), and gives the measured per-session cost and duration. W03 could not run it: `--bare` accepts only an API key, and the team login was chosen in its place. A run is refused unless `--budget-usd` covers its sessions × `--session-budget-usd`: this one session fits at USD 0.50, and a wider check names a lower `--session-budget-usd`, such as 0.05 for nine Haiku sessions.
- **Cost first.**
  The full run's estimate, from the calibration session, is put to the user before it starts; the run starts only on their approval. The unmeasured estimate is roughly USD 15–25 (Haiku about a cent a session, Sonnet about USD 0.15–0.30), within the USD 75 default cap, drawn against the team subscription.
- **The run.**
  `make eval-diagrams` with `claude-haiku-5-5` and `claude-sonnet-5-5`, every workflow, form and scenario, five repetitions — 150 sessions.
- **Review.**
  Failing sessions are read: a failure caused by an ambiguous section or scenario is a corpus defect, fixed and the affected cells re-run before the baseline is taken.
- **Record.**
  `report.py --write-baseline` writes `baseline.json`; it and the run's `report.md` are committed. The README's cost section states the measured cost of a default run in place of the USD 75 bound (AC10). The planning record holds the findings — which forms and models follow which workflows, and the dominant failure classes.
- **Carried from W03 and W04.**
  - A `CLAUDE.md` in `~/projects/eval/`, `~/projects/` or `~` would reach every session, since sessions run without `--bare`; none exists. Check before the run.
  - `--max-budget-usd` is checked between API calls, so a run's recorded cost can pass its budget by part of one session.
  - With a baseline committed, the stub-agent runner tests write their reports against it; harmless, as they assert nothing about the comparison.
