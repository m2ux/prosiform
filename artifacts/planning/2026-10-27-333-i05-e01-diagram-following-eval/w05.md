**Component:** evals/diagram-following/baseline.json

## Overview

The first full run of the default matrix, reviewed and committed as the baseline later runs compare against, and the answer to how well agents follow a bundled diagram.

## Problem

Until one full run is recorded, the eval has no reference point and its first finding is unknown.

## Proposal

- **Cost first.**
  The run's estimated cost, from W03's live session, is put to the user before it starts; the run starts only on their approval.
- **The run.**
  `make eval-diagrams` with `claude-haiku-5-5` and `claude-sonnet-5-5`, every workflow, form and scenario, five repetitions.
- **Review.**
  Failing sessions are read: a failure caused by an ambiguous section or scenario is a corpus defect, fixed and the affected cells re-run before the baseline is taken.
- **Record.**
  `baseline.json` and the run's `report.md` are committed; the planning record holds the findings — which forms and models follow which workflows, and the dominant failure classes.

## Work Breakdown

| Part | Description |
| --- | --- |
| Analysis | Estimate the run's cost from the recorded live session. |
| Plan | The user's approval of the run and its cap. |
| Implementation | The run, the review of failures, and the baseline. |
| Review | Every failure in the baseline is the agent's, not the corpus's. |
| Test | The report against the committed baseline shows no difference; `make check`. |
