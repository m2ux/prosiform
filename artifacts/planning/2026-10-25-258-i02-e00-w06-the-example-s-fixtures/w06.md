**Component:** fixtures/usage-example/

## Overview

Five usage-example fixtures symlink their source to `example/work-tracker`, the four-file tree the migration replaced. AC9 asks that every fixture whose source is the example passes, and the example is now `example/work-planner`. This row repoints those five and re-records the bundles each invocation emits from the new tree.

## Problem

The corpus passes, and it passes against a tree the epic replaced.

- **Five fixtures source the superseded tree.**
  `a-bare-fragment-and-its-referring-document`, `a-procedure-and-everything-it-reaches`, `every-document-under-a-directory-merged`, `two-selected-sections` and `validation-without-publication` each link `../../../example/work-tracker`. Nothing in the corpus reads `example/work-planner`.

- **Their expected bundles record the four-file tree's output.**
  A fixture's expected bytes are the bundle that tree produces, so a green corpus says the old tree still bundles rather than that the new one does.

- **The invocations already resolve against the new tree.**
  Tested on the merged base with the source repointed: four of the five compile with exit 0 and one warning; `two-selected-sections` declares no entry argument and fails as invalid usage, so its manifest needs the same arguments its sibling carries.

## Proposal

- **Each of the five source links points at `example/work-planner`.**
  The link target is `../../../example/work-planner`, keeping the fixture self-contained and keeping the one tree the design and the corpus both name.

- **Each expected bundle is re-recorded from the build that exists.**
  The expected bytes are what the invocation now emits, so the fixture records the current contract rather than a superseded tree.

- **A manifest whose invocation is incomplete is completed.**
  `two-selected-sections` selects two sections of one document and declares no arguments; it takes the arguments its invocation names.

- **`make links` proves the prose direction.**
  A symlink the repository tracks is not a document reference, so this row changes the fixture sources and their expectations, and W07 carries the prose that names the example.
