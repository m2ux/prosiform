## Overview

The design clause stating a preset's `subst` as the only substitution channel, resolved from the declaring file and reaching only the links that file writes, with `-m` retired and the two warnings renamed, and the README pin moved to the revision carrying it, so every later row of the epic cites a clause the pinned design holds.

## Problem

The contract states two channels for one setting.

- **The CLI contract carries the option.** `-m ORIGINAL=ALTERNATIVE` is a row of the CLI contract table, and ten fixtures declare that row as a clause.
- **The substitution clause states the option's reach.** It names a positional entry, every compiled, deferred and dispatched target, and a substitute's own links as references the run's one mapping redirects, all of which is now a preset's to state per document.
- **The path basis differs.** The clause resolves both sides from the captured invocation working directory; a preset's sides resolve from the declaring file.
- **The warnings carry the retired word.** `W_MOCK_SUBSTITUTED` and `W_MOCK_UNUSED` name the option's word, and the build, its tests, the fixture schema and eighteen fixtures carry them.
- **The epic's later behaviour has no clause.** A reference under no `subst`, an entry reference, a substitute's fragment-only link, a folder side and a pair reached only outside the selection are each stated nowhere, so the fixtures W01 to W11 add would name no clause.

## Proposal

**The scene.** The CLI contract enumerates each option; the substitution mapping bullet under Link classification and resource handling states what a mapping redirects and how its sides resolve; Conversion metadata and Presets state the `subst` entry's grammar and refusals; Exit status and JSON diagnostics names the warnings. The README badge pins the revision `make conformance`, `make vocabulary` and `make independence` read.

**The design.**

- **The row is withdrawn and the retirement stated.** The CLI contract names no `-m` row, and a `-m` is retired bullet states that a command line carrying it names an undeclared option, `E_INVALID_USAGE`, exit status 2.
- **The mapping is the writing document's.** The substitution mapping bullet states the union of the `subst` pairs the presets governing the writing document state as the one channel, reaching only that document's links; the document it links, the document linking it, a substitute and a dispatched target are each governed by their own presets.
- **The path basis is the declaring file.** Each side resolves from the declaring document's directory, so one declaration reads the same from any working directory.
- **The absences are outcomes.** A link written under no `subst` is compiled as authored; an entry reference is written by no document and compiled as named; a pair reached only in a heading outside the selection is unused.
- **The folder side is refused.** The `subst` bullet under Conversion metadata refuses a side ending in a path separator with `E_INVALID_CONVERSION_METADATA` naming the entry; Presets lists a value naming no Markdown document among a preset's refused pairs.
- **The warnings are named for the entry.** `W_SUBST_USED` and `W_SUBST_UNUSED` replace the two codes in the design, the build's code catalogue, its tests, the fixture schema, the fixtures README and every manifest declaring one.
- **Declarations follow the rows.** Each manifest naming the retired `-m` row names the substitution mapping clause; its invocation stays for W03 and W11.
- **The pin moves.** The README badge names the engineering commit carrying the clause.
