**Component:** main:src/prosiform/composition.py

## Overview

A directive a contribution carries composes beneath the heading holding it, a composition reaching a section that holds a directive on its own chain is refused with that chain, and every composed byte counts against the declared budgets as it is emitted.

## Problem

- **Nested directives were read as ordinary links.**
  A directive inside a contribution composed nothing: placement turned it into an inclusion of its target, so the target stood in a file group and the link pointed there. That branch was a stopgap kept from W08 to avoid an internal `KeyError`.
- **Nothing bounded recursion.**
  Composing a nested directive whose target holds a directive on the chain that reached it would expand without end.
- **Materialised content was counted only once whole.**
  `output-bytes` was held against the finished bundle, so a multiplying composition was built whole before the run failed.

## Proposal

**The scene.** W02 to W04 compose each authored directive beneath its scope, with structural refusals; W08 bundles inline-only targets in their contributions. The traversal already counts each directive as a hop.

- **Nested directives.**
  A contribution reads the directives each of its regions writes and composes them beneath the heading holding them: the contribution heading for the target's own body, a carried subsection heading for a subsection. Destination sections follow that heading's content, ahead of the next subsection.
- **Placing.**
  A source link stands in every copy of its contribution, so each composition is keyed by its *placing*: the directives whose compositions reached it, outermost first. The composing map, each range's provenance and candidate validation all read links by placing.
- **Cycles.**
  A directive whose target section holds it, or holds a directive on its placing, fails with `E_UNSUPPORTED_CONSTRUCT`: `location` the closing directive, `related` each earlier one, `chain` the entry chain then each composed section.
- **Budgets.**
  Composition holds `output-bytes` at each emission. The mapped pass counts every emitted byte; the unmapped pass, where a link's published destination is unknown, counts only the generated headings both passes emit alike, so its figure never exceeds the published bundle's. `depth` already counts each directive as a hop; a fixture pins it.
- **Stopgap removed.**
  Placement reads a nested directive's section where it is composed; the two `test_cli.py` cases W08 added for the stopgap go with it.
