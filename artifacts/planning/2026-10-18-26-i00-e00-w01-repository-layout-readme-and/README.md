## Executive Summary

This record holds the local plan for one unit of work: the first task of [I00:E00] Project Foundation. The task creates the three trees this stage needs - one for the language-neutral fixture corpus, one for the Python build, one for the documentation the repository owns - writes the README that states what the tool is, how it is installed and how it is invoked, and publishes the glossary that defines every term the contract uses. It carries the layout check, the link check and the vocabulary check that assert those three things hold.

It matters because every later task of the initiative lands in the structure this one creates, and because the contract's vocabulary has no published home. A reader meets a closure, a region, a structural ancestor and a variant in the tool's diagnostics with no definition to hand, and a later author has nothing to keep the usage from drifting. The task covers AC1, AC5 and AC6 of the epic.
