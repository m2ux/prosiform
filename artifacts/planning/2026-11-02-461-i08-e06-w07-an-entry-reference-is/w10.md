**Component:** main:src/prosiform/bundle.py

## Overview

A substitution is recorded only for a reference in content the run selected, so a key whose only reference sits in a heading outside the selection warns as unused.

## Problem

Reading a heading's visible text resolves every withheld link in the document, and records it.

- **`emitted_visible` reads every heading.** `bundle.shown_text`, `file_heading`, `grouping` and candidate validation call it, and it calls `withholding_target` with the run's mapping for every heading the document holds, selected or not.
- **The lookup records what it resolves.** `Substitution.redirect` marks the key served and writes a record with no location.
- **The run reports a substitution it never made.** With `guide.md` holding `## Keep` and `## [¬ Rules](rules.md)` and a `default` pair `rules.md: stub.md`, `pf 'guide.md#keep'` exits `0` with `W_SUBST_USED` and no location, and raises no `W_SUBST_UNUSED`.

## Proposal

**The scene.** Discovery records a substitution with the link's position, and emission and validation resolve the same links again.

**The design.**

- **Text reading records nothing.** `emitted_visible` resolves through `Substitution.unrecorded()`, the same keys with a record of its own, so it decides what a heading shows and nothing about what the run substituted.
- **The record is discovery's.** A key is served by a reference discovery reached in selected content, which is where the position is known; a withheld link in a selected heading is still recorded there, with its location.
