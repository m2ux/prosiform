# W01 Put Rule Guards Ahead of the Corpus

> Work item · Delivered 2026-10-31

## Overview

The order the repository checks run in, so a broken rule reports the rule rather than a downstream symptom.

## Problem

Two orderings defeat the checks they precede. `make steps` runs last, so a broken corpus reports moved bundle bytes from `corpus` instead of the rule from `steps`. `make test` precedes `authoring`, so a file-relative link break reports a target-not-found code instead of naming the file and the rule.

The finding is recorded as findings 3 and 11 in the [merged-epic review](../../2026-10-31-merged-epic-review/findings.md), with its site and the case that failed.

## Proposal

**The scene.** Each defect above was found by the review of fifteen merged epics, and each has a case that reproduces it. The task repairs one scope area and carries that case, so the defect cannot return unnoticed.

**The design.**

- **The repair follows the finding.** Move `steps` and `authoring` ahead of the targets whose failures they mask, and record the order the `Makefile` now states.
- **The case ships with the fix.** The failing case the finding records becomes a check the repository runs, so a regression fails a target rather than waiting for another review.
- **No other task's area is touched.** Each task repairs one scope and carries its own failing case, so the faults land as separate pull requests.

## Which targets mask which guard

Two kinds of target read the work-planner example, and the order puts every guard ahead of every one of them.

| Target | Reads the example by | Guard it masks | Order |
| --- | --- | --- | --- |
| `steps` | `checks/steps.py`, alone, no build | — | ahead |
| `authoring` | `checks/authoring.py`, alone, no build | — | ahead |
| `test` | `src/tests/test_handoff_round_trip.py` copies the tree and compiles each mode | `steps`, `authoring` | after both |
| `corpus` | the usage-example fixtures bundle the tree through the build | `steps`, `authoring` | after both |

`harness` carries `checks/tests`, which reads the example only through test-written copies, so it is no bundling target and keeps its place after `test`.
