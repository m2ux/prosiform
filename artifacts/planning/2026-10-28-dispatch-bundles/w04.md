**Component:** src/prosiform/run_set.py

## Overview

The `⫽` links in one section form a set: each target is compiled to its bundle, and every `⫽` link in the section points at one `Dispatch in parallel` sub-section listing those bundles to be dispatched together. Parallelism becomes a property of the dispatches a section's prose writes, and the run-set target shape is retired.

## Problem

- **A run-set is a target shape.**
  [`run_set.py`](https://github.com/m2ux/prosiform/blob/9851615028ea489c48f6b3fa5ddbe0d917438cf2/src/prosiform/run_set.py) holds a `⫽` target to one bulleted list of calls and warns `W_RUN_SET_SHAPE` on anything else; the target is compiled into the bundle and the mark published.
- **Nested items carry an order.**
  The example's [Board Reads](https://github.com/m2ux/prosiform/blob/9851615028ea489c48f6b3fa5ddbe0d917438cf2/example/work-planner/artifacts/delivery-evidence.md) nests a read under the one whose result it takes, an order the set itself has to state.

## Proposal

A review step writes `[⫽ Code Review](review.md#code) and [⫽ Test Review](review.md#tests)`. Both links point at `### Dispatch in Parallel`, which lists `review__code.bundle.md` (Code Review) and `review__tests.bundle.md` (Test Review).

- **A section's `⫽` links are one set.**
  The set is the `⫽` links in the section's own content, anywhere in its prose; a child section's links form that section's set.
- **One sub-section per set.**
  Headed `Dispatch in parallel`, listing each bundle file with its link text once, placed as a dispatch sub-section is; every `⫽` link in the section points at it, its mark stripped.
- **Sets and dispatches are independent.**
  A section with `⇉` and `⫽` links has a sub-section for each `⇉` target and one for its set.
- **A set has no order.**
  The run-set shape rule, `W_RUN_SET_SHAPE` and the nested-item ordering are removed.
- **Board Reads as steps.**
  The example's Board Reads is rewritten as sequential step sub-sections in the corpus's step form, since its reads depend on one another and a set has no order.
- **The contract moves with the build.**
  The design's Run-set clauses, declared codes, pin and `invocation.md` state the set.
