## Overview

A deferred link to a document with alternatives states its pick: it names exactly one alternative or carries `?`, never both, and `?` names a target that declares alternatives. Every other form is refused before a bundle is published, since the later run would fail.

## Problem

- **A deferral is checked for its target alone.**
  The run publishing a deferral checks that its target exists and names its heading, so a deferred link that names no alternative of a router publishes a command that can only fail.

## Proposal

**The scene.** The run reads every withheld target after the traversal's fixed point, `subst` redirects included, and confirms its heading there, so the target's declared alternatives are already at hand.

- **A withheld reference states that it defers.**
  `Reference.defers` in `closure.py` marks a target a `¬` or `¬↳` link withholds, so a dispatch's target is held to the alternatives rule its own bundle applies.
- **One pick, or `?`.**
  `stated_pick` in `cli.py` refuses a deferred link to a document with alternatives whose title names none, names two, or names one beside `?`.
- **`?` needs alternatives.**
  It refuses a `?` link whose target declares no alternative.
- **The refusal names the alternatives.**
  Each refusal is `E_UNSUPPORTED_CONSTRUCT`, naming the link, its source location, the target and its alternatives.
