## Overview

A `?` token in a link title requests the agent's pick. It is accepted on a deferred link and published with the deferral's title, and refused on every link the run compiles itself.

## Problem

- **Every title token names a preset.**
  The tag reader returns each trimmed, case-folded name, and a name the target does not declare selects nothing, so `?` reads as one more unknown name.
- **Nothing ties a tag to an operator.**
  Operators decide how a target is compiled and titles decide its presets, so no rule refuses a tag a compiled link cannot honour.

## Proposal

**The scene.** `closure.py` holds the predicates that read each link's operator marks, and `cli.py` refuses, per selected region, the combinations no run can carry out, as `¬⇉` is refused; a deferral publishes its destination from the working directory with its title as authored.

- **`?` is the pick token.**
  `tags.py` is the token's one home: `PICK` and `picks` mark it apart from the preset names, and `metadata.py` reads `PICK` from there when it refuses a preset named `?`. No preset carries the name, so it selects none.
- **A deferred link carries it.**
  `?` is accepted on a `¬` or `¬↳` link, and the deferral publishes the title unchanged.
- **A compiled link refuses it.**
  `compiled_pick` in `closure.py` answers whether a link carries `?` without the deferral mark. `refusals_of_picks` in `cli.py` refuses such a link naming a declaring document with `E_UNSUPPORTED_CONSTRUCT`, naming the link and its source location; a link naming anything else compiles nothing, so its title stays the author's text.
