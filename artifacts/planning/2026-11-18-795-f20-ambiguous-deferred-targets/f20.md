## Overview

Two input failures reach the author as something other than a fix the run accepts. A deferred composition directive whose fragment roots no one section of its target ends the run with an internal error, and the unresolved-alternative remedy names `--pick` beside entries the run refuses it for. This hot-fix reports each as the input failure it is, with a remedy the run accepts.

## Problem

- **A deferred directive's target is read as a withheld link's.**
  The run checks only that the document carries the heading. Composition then asks for the section that heading roots, to name the contribution, and the refusal `section` raises for a shared fragment or a container-carried heading escapes as `E_UNEXPECTED_INTERNAL_ERROR`.
- **The remedy names one pick for every case.**
  `E_ALTERNATIVE_UNRESOLVED` always suggests a rerun with `--pick`, which is invalid usage beside an entry carrying no `?`, a plain path among them.

## Proposal

The run publishing a deferred directive already reads its target, and the selection step already reports a fragment that roots no one section.

- **One step reports a fragment rooting no one section.**
  `rooted` in `cli.py` wraps `section` and maps `Ambiguous` to `E_AMBIGUOUS_SOURCE_HEADING` and `Nested` to `E_NESTED_SECTION_TARGET`, naming the reference, the document it resolved to and the chain. `selection` and `confirm` both call it.
- **A deferred directive's target roots one section here.**
  `confirm` holds a composing withheld reference to `rooted`, since this run names its contribution by the heading its target opens with. A deferred link keeps the existence check, its section left to the later run.
- **The remedy follows the entry.**
  `unresolved` names a rerun with `--pick` where none is in force and the entry reaching the document carries `?`, and otherwise the alternative named in the title or tooltip of each link reaching the document. The `--pick` usage rule is unchanged.
