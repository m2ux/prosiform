## Overview

An alternative's `subst` pairs route its document's links without the warnings a stand-in raises: a used pair raises no `W_SUBST_USED`, and `W_SUBST_UNUSED` fires only for a key no link of the document names.

## Problem

- **Every routed link warns.**
  A pair a link used warns `W_SUBST_USED` once, so each compile of a router warns for the route it took.
- **Every route outside the selection warns.**
  `unused_pairs` warns for each pair in force that no reference of the run resolved, so compiling one section of a router warns for every other section's route.
- **A record names no pair.**
  A substitution record holds the substitute, the identity and the link, but not the pair that served it, so the warning stage cannot tell a route from a stand-in. `closure.py` gives the record its pair.

## Proposal

**The scene.** `subst` was built so a bundle could be compiled against stand-in material, and its two warnings mark a bundle built that way.

- **An alternative's pair is routing.**
  A pair declared by an alternative raises no `W_SUBST_USED`.
- **A stale route still warns.**
  A routing pair warns `W_SUBST_UNUSED` only when no link anywhere in its declaring document resolves to its key, whatever the run selected.
- **A stand-in still warns.**
  A pair of an ordinary preset keeps both warnings as before.
