**Component:** fixtures/

## Overview

States the numeric scalar ceiling in the `E_RESOURCE_LIMIT` catalogue entry, so the catalogue names every case the code covers.

## Problem

`docs/validation.md` states that one numeric scalar carries at most 65,536 characters and that a longer one fails with `E_RESOURCE_LIMIT`. The catalogue in `fixtures/README.md` names only a declared budget the run crossed, so a reader of the catalogue meets a refusal it does not list.

## Proposal

A reader of the catalogue looks up `E_RESOURCE_LIMIT` and finds both the declared budgets and the scalar ceiling, with the figure `docs/validation.md` states.

- **Catalogue row.** The row names a numeric scalar longer than the 65,536 characters a byte budget admits, beside the declared budgets.
