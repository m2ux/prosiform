**Component:** checks/authoring.py

## Overview

`make authoring` holds every document of the example tree to a `prosiform` declaration naming no root, and the example's own pages state that rule. The tree already declares; the check and the prose still read a root.

## Problem

[W01](https://github.com/m2ux/prosiform/pull/487) withdrew `root` from every example document, so the tree declares and none names a root. Three readers of the tree still describe the retired rule.

- **The authoring check reads a root nothing declares.** `DECLARED_ROOT` parses `  root: "..."` and `link_form` refuses a link resolving from that root. It matches no document, and nothing in `make authoring` observes that a document declares at all.
- **The worked examples teach a root.** `example/README.md` defines `prosiform.root`, speaks of links "under the root" and "outside the root", and quotes an epic frontmatter carrying `root: ".."` that the file no longer holds.
- **The shared guidelines forbid the declaration.** `example/guidelines.md` allows `name`, `description` and `hooks` and "no other field", while every SKILL.md in the tree declares `prosiform`.

## Proposal

**The scene.** Every example document opens with `prosiform: {}` or a `prosiform` block holding `group` and `group-depth`. `checks/authoring.py` reads every Markdown document under `example/work-planner/` with the standard library alone and reports each finding by file, line, area and kind.

**The design.**

- **A Declaration kind.** `authoring.declaration(name, text)` reports a document with no front matter, front matter with no `prosiform` key, and each `root` key in the `prosiform` block, block or flow form, at its line. A `root` key outside that block is not the declaration's and is not read.
- **The root reader leaves.** `DECLARED_ROOT` and `declared_root` go, `link_form` keeps the absolute-path and repository-URL rules, and `report` takes the name and text alone since no rule reads the file's place on disk.
- **The rule is stated where skill files are written.** `example/guidelines.md` adds `prosiform` to the frontmatter fields and states the declaration: every file declares, a bare file writes `prosiform: {}`, no root. The SKILL.md preambles stay as they are, since each skill's opening is one sentence and a list by that same guideline.
- **The worked examples describe declaration.** `example/README.md` states that every document declares and none names a root, says "working directory" where it said "root", and quotes the epic's frontmatter as the file holds it.
- **One check, two readers of it.** `checks.md` lists five authoring rules and `checks/README.md` names the Declaration kind.
