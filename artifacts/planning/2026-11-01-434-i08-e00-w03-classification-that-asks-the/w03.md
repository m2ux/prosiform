**Component:** src/prosiform/closure.py

## Overview

A link naming a Markdown document is a dependency when, and only when, that document declares `prosiform`. The traversal asks the frontmatter probe once per path, keeps each answer in one record, and every stage that classifies a link reads that record, so a silent target is text at every stage.

## Problem

Classification asked a directory question, and the trees did not state the new one.

- **`covers(root, path)` was the whole test.** `closure.inside` held each link to a root, and `resolvable`, `bundled` and `withholding_target` answered every Markdown path under it as a dependency. `Source.root` was always empty once [W01](https://github.com/m2ux/prosiform/pull/487) refused `root`, so the parameter every stage threaded decided nothing but the working-directory bound.
- **The probe had no caller.** [#492](https://github.com/m2ux/prosiform/pull/492) added `cli.probe`, and `fixtures/inclusion/an-oversized-silent-target-is-text` and `fixtures/inclusion/no-block-does-not-declare` awaited a classification that read it.
- **No tree declared its targets.** 151 corpus fixtures, the diagram-following eval workflows and about 140 unit tests link documents carrying no `prosiform` block, so asking the target turns every such link into text.

## Proposal

**The design.**

- **`Declarations` is the one answer.** `closure.Declarations` wraps a probe and keeps each answer by path, so a second link to one target costs no read. `cli.compiled` builds one per bundle over `cli.probe`, and passes it wherever the `root` parameter went: discovery, the operator refusals, the withheld targets, the dispatch reader, emission, grouping and candidate validation.
- **`resolvable` asks the record last.** After the reference resolves to a local Markdown path, `resolvable` asks the record; a citation naming no Markdown document is never opened. `cli.required` asks it for each unwithheld link. The record is handed the occurrence — origin and chain — so a refusal the probe meets (an absent target, a link, an invalid declaration) names the link that asked, as the capture named it before.
- **The helpers take no root.** `inside`, `bundled`, `withholding_target` and `resolvable` lose `root`; `covers` and `Source.root` retire. `inside` keeps the path-grammar refusals and refuses a path normalizing above the working directory with `OutsideRoot`, after the substitution mapping is consulted.
- **`Reference.declared` is not added.** The record answers by path for every stage, so the answer rides on one shared value rather than on a field set by whichever caller probed; a reference never probed is probed on first ask.
- **A marked link to a silent target is refused.** `withholding_target` answers it as no withheld target, so `refusals_of_operators` refuses it with `E_UNSUPPORTED_CONSTRUCT`, the reading [W04](epic-a-declared-inclusion.md) keeps.
- **Every tree declares (folded, blocking).** Each failing corpus fixture declares `prosiform` in its sources, diagnostic lines shifted by the block; `parser-limit/a-nesting-ceiling-the-last-valid-reference-reaches` and its declining pair move to `-N 2` with one more bracket, since a declaration is YAML depth 2. The eval workflows declare and the eval reader strips the block. Unit-test trees declare the documents they expect compiled.
