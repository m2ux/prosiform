# I00:E11 Outstanding Row Joins — October 2026

> Epic Plan · Created 2026-10-21

## Executive Summary

This record holds the join analysis across the deferred-debt epic's outstanding rows, W24 through W29. Each was raised by a session delivering one of W16 through W23, from debt its own validation found, so the rows arrived one at a time rather than being planned together. The analysis settles which of them share a pull request and which keep their own, before any of them is delivered.

It matters because a row whose implementation is a single reference in a document is close to an empty pull request, while a row carrying its own contract decision is a review of its own. The Joins cells say which is which, and the pairs that do not share are named here with the reason, so the next session reads the answer rather than re-deriving it.
