**Component:** fixtures/dispatch

## Overview

The corpus proves the bundle set end to end for every layout a source tree can give it: each fixture compiles a source tree to its expected set of bundles under `make check`.

## Problem

The earlier tasks each prove the rule they add; nothing proves the rules together across the shapes a source tree takes, where a sub-section's placement, a shared target and a set beside a dispatch interact.

## Proposal

Each permutation is a fixture whose `expected/` holds every bundle the run writes, by derived name.

- **Dispatch placement.**
  A dispatch in a section, in a nested section and in the preamble.
- **Shared targets.**
  One target dispatched from two sections, and one target named twice in a set.
- **Chains.**
  Depth one, two and three with no warning; past the limit with the warning; a refused cycle; a refused level-6 dispatch.
- **Parallel sets.**
  A set in one section, sets in sibling and nested sections, and a set beside a `⇉` link.
- **Entries.**
  Several joined entries, each dispatching.
- **Clauses.**
  Each fixture names the design clause it exercises, so `make conformance` reports the clauses covered.
