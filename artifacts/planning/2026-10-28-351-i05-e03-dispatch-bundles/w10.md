**Component:** evals/diagram-following/workflows

## Overview

Agents are measured following dispatch and parallel-dispatch bundle sets: a scenario set in the diagram-following eval, scored for sub-agent dispatch, sets dispatched together, questions relayed and completion, and compared against the bootstrap-driven form the corpus used before. The first baseline answers whether compiled protocols improve on authored ones.

## Problem

The eval's runner and scorer measure an agent walking one bundled diagram. Nothing observes whether an agent given a bundle set hands each dispatched bundle to a sub-agent, starts a set's bundles together, or relays a sub-agent's questions rather than asking them.

## Proposal

A scenario hands the runner a bundle set and the guide a bare `pf` prints; the trace shows which bundles reached a sub-agent, when, and what was asked.

- **Scenarios.**
  A dispatch chain, a parallel set, a set beside a dispatch, and a dispatched target returning a question; each names its inputs and the dispatch trace a correct agent produces.
- **Two forms.**
  The compiled form (bundle set and the bare `pf` guide) and the bootstrap-driven form (source tree with the retired bootstrap's symbol table), so the report compares them.
- **Scorer checks.**
  Each bundle dispatched to a sub-agent; a set's bundles dispatched together; questions relayed, not asked; the run completing. A failing trace is classified.
- **Sub-agent observation.**
  The runner records sub-agent starts and their timing from the session transcript.
- **Baseline.**
  The default matrix runs once with its cost estimated first and approved by the user, as the eval's first baseline was; the reviewed result joins the committed baseline.

## Work Breakdown
