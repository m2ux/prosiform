**Component:** src/prosiform/bundle.py

## Overview

A bundle that dispatches opens with a `# Prosiform` section stating the protocols its sub-sections invoke, in wording the profile fixes, so an agent reading top-down meets each protocol before the step that uses it. The changed output is the `skill-markdown-v4` profile.

## Problem

The protocols an agent needs to follow a dispatch live in the corpus's own [bootstrap symbol table](https://github.com/m2ux/prosiform/blob/9851615028ea489c48f6b3fa5ddbe0d917438cf2/example/work-planner/bootstrap.md#symbols), outside the bundle, in wording each corpus writes for itself; and `pf -v` reports [`skill-markdown-v3`](https://github.com/m2ux/prosiform/blob/9851615028ea489c48f6b3fa5ddbe0d917438cf2/src/prosiform/__init__.py#L8) though the same source now bundles differently.

## Proposal

The advance-mode bundle opens with `# Prosiform` and `## Dispatch`; a review procedure that also dispatches its reviews in parallel carries `## Dispatch` and `## Parallel dispatch`; a bundle using neither has no Prosiform section.

- **Placement.**
  The section precedes the first authored section, and holds `## Dispatch` and `## Parallel dispatch` each only when the bundle uses that operator.
- **Dispatch protocol.**
  Hand the named bundle to one sub-agent with the inputs the invoking step names, to follow from its start, and continue with its result; a dispatched run returns its questions unanswered, and the dispatching session puts them to the user or returns them in turn, then dispatches again with the answers.
- **Parallel dispatch protocol.**
  Dispatch every listed bundle at once, one sub-agent each, once per value for a "for each" item; continue when all return; a failure cancels nothing, and failures and questions return together.
- **The text is pf's.**
  The wording is a constant of the profile, identical in every bundle.
- **Profile v4.**
  `PROFILE` becomes `skill-markdown-v4`, with the profile docstring, the design's profile clause and the pin.
