**Component:** src/prosiform/limits.py

## Overview

The declared resource bound and the diagnostic that reports it, so the bound bounds work and the remedy is readable.

## Problem

The declared byte bound does not bound decoder work: a base-prefixed integer costs quadratic time inside the bound. A root-not-found diagnostic reports a bare path segment, with no reference and no remedy.

The finding is recorded as findings 35 and 36 in the [merged-epic review](../../2026-10-31-merged-epic-review/findings.md), with its site and the case that failed.

## Proposal

**The scene.** Each defect above was found by the review of fifteen merged epics, and each has a case that reproduces it. The task repairs one scope area and carries that case, so the defect cannot return unnoticed.

**The design.**

- **The repair follows the finding.** Bound the work behind the byte budget as well as the bytes, and name the reference that declared the root and the root it named, with a remedy.
- **The case ships with the fix.** The failing case the finding records becomes a check the repository runs, so a regression fails a target rather than waiting for another review.
- **No other task's area is touched.** Each task repairs one scope and carries its own failing case, so the faults land as separate pull requests.
