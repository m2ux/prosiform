**Component:** evals/diagram-following/harness

## Overview

The Cursor harness, which crashes on every default run and discards the traces it keeps.

## Problem

`--harness cursor` crashes on every default run: `sections_of` receives a run form where `TRANSITION` is keyed by corpus form, raising `KeyError`. A sub-agent's trace is discarded, because `keep()` globs `trace*` while the instruction tells the sub-agent to write `trace-<section>.log`.

The finding is recorded as findings 1 and 8, one defect from two directions in the [merged-epic review](../../2026-10-31-merged-epic-review/findings.md), with its site and the case that failed.

## Proposal

**The scene.** Each defect above was found by the review of fifteen merged epics, and each has a case that reproduces it. The task repairs one scope area and carries that case, so the defect cannot return unnoticed.

**The design.**

- **The repair follows the finding.** Key the transition lookup by the form it receives, and keep the trace name the instruction states.
- **The case ships with the fix.** The failing case the finding records becomes a check the repository runs, so a regression fails a target rather than waiting for another review.
- **No other task's area is touched.** Each task repairs one scope and carries its own failing case, so the faults land as separate pull requests.
