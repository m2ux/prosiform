**Component:** example/work-planner

## Overview

Three example faults where a step names its neighbour by role, a retired rule survives on the page readers land on, and a step omits an input its operation requires.

## Problem

`plan-mode.md` names a step by role rather than by link. `docs/hierarchy.md` states the retired group-heading rule on the page a reader lands on for groups. A step that calls an operation omits an input that operation requires.

The finding is recorded as findings 17, 29 and 81 in the [merged-epic review](../../2026-10-31-merged-epic-review/findings.md), with its site and the case that failed.

## Proposal

**The scene.** Each defect above was found by the review of fifteen merged epics, and each has a case that reproduces it. The task repairs one scope area and carries that case, so the defect cannot return unnoticed.

**The design.**

- **The repair follows the finding.** Link the named step, state the heading rule the build emits, and declare each input the called operation requires.
- **The case ships with the fix.** The failing case the finding records becomes a check the repository runs, so a regression fails a target rather than waiting for another review.
- **No other task's area is touched.** Each task repairs one scope and carries its own failing case, so the faults land as separate pull requests.

## Work Breakdown

| Part | Description |
| --- | --- |
| Analysis | Read the finding and the site it names, and reproduce the case it records before changing anything. |
| Plan | Settle the repair against the surrounding code, and whether the case belongs in the corpus, the checks or the example, per the scope the disposition table names. |
| Implementation | Link the named step, state the heading rule the build emits, and declare each input the called operation requires. |
| Review | Confirm the case fails before the change and passes after, and that no neighbouring behaviour moved. |
| Test | The reference sweep shows the link; a comparison of the page against a bundle shows the emitted rule; the authoring check's run over the example shows every input declared. |
