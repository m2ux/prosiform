**Component:** src/prosiform/diagram.py

## Overview

Three diagram faults where a link Mermaid renders is bundled as nothing, or rewritten where it should be carried.

## Problem

A `links` array renders live anchors but decodes to a list, so neither document is bundled and the run exits 0. Any `<a href>` on a fence line is refused as a node label, including a `click` tooltip and a pie or sequence label. A line carrying a second `click` matches neither, so both destinations escape rewriting.

The finding is recorded as findings 19, 20 and 25 in the [merged-epic review](../../2026-10-31-merged-epic-review/findings.md), with its site and the case that failed.

## Proposal

**The scene.** Each defect above was found by the review of fifteen merged epics, and each has a case that reproduces it. The task repairs one scope area and carries that case, so the defect cannot return unnoticed.

**The design.**

- **The repair follows the finding.** Read a `links` value as a destination set, refuse an anchor only where the renderer draws one, and follow every `click` on a line.
- **The case ships with the fix.** The failing case the finding records becomes a check the repository runs, so a regression fails a target rather than waiting for another review.
- **No other task's area is touched.** Each task repairs one scope and carries its own failing case, so the faults land as separate pull requests.
