**Component:** docs/bundles.md

## Overview

The pages and the docstring that still state `-o` names an existing folder, although the build creates a missing one.

## Problem

`-o DIR` makes the folder when it is absent and swaps the run folder in whole, as `pf -h` and `invocation.md` state. `README.md` says "the existing folder `-o` names", `docs/bundles.md` says "`-o DIR` names an existing folder", and the `publication()` docstring in `src/prosiform/cli.py` says the output folder is held to existing and that a check run writes nothing.

The finding was raised by the agent review of the I08:E07 integration pull request, against main's revision of `-o`.

## Proposal

**The scene.** A reader sets `-o` to a folder that does not exist yet. Every page they read says it is made.

**The design.**

- **The pages agree with the help output.** `README.md` and `docs/bundles.md` state that `-o` makes its folder when absent.
- **The docstring states the code.** `publication()` describes the folder it creates and what a check run writes.
