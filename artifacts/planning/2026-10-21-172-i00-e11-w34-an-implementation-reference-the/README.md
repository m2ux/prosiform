# An Implementation Reference the Inventory Does Not Name — October 2026

> Delivery · Created 2026-10-21

## Executive Summary

The independence check refuses an implementation reference by naming the terms that are one: an inventory of 60 languages, runtimes, module and packaging machinery, and the wording a build gives its own fault. A reference spelled in a word the list does not carry passes, so the check establishes that no named implementation term is bound rather than that no implementation is.

It matters because the bound that exists runs the wrong way, and no list can be completed. The contract already states its own vocabulary — the design italicises each term where it first uses it and the shipped glossary defines it — so a declaration can be read against the words it is entitled to use rather than against a list of words refused. A rule stated that way cannot be reached by spelling a term differently, and the refused inventory retires with it.
