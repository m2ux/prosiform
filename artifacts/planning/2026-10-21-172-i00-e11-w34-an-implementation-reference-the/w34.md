**Component:** `checks/independence.py`

## Overview

The independence check reads every claim the corpus and its conformance report make against the vocabulary the contract states, and reports each word none of the contract's sources holds. The inventory of 60 refused terms retires with it, so one rule holds the corpus to the behaviour rather than two holding it to a list.

## Problem

The check carries an inventory of three kinds of term — implementation languages and runtimes, the machinery of modules and packaging, and the wording a build gives its own fault. A declaration naming one of them fails.

- **A list is reached by naming a term it does not hold.** A build's own function name, a library the design never mentions, a flag one implementation invented are each an implementation reference and none is on the list. The check establishes that no *named* implementation term is bound, not that no implementation is.
- **The one bound that exists runs the other way.** The check scans the contract's declared names against the inventory, so an interface term can never be refused and nothing bounds the first direction.
- **The contract already carries its own vocabulary.** The design states the contract's words, `docs/glossary.md` defines each term the design marks, and `make vocabulary` holds the two to each other.

## Proposal

A fixture's description, the clauses it declares, the text its outputs must carry, its own identity and every line of the conformance report are claims about the contract. The bound is the vocabulary those claims are entitled to state.

- **Four sources state the vocabulary.** The design's prose and the names it gives its own clauses; the terms `docs/glossary.md` defines; the interface the manifest schema and the documented invocation declare by name — the error codes, the warning codes, the severities, the exit statuses and the options; and `docs/corpus-vocabulary.md`, a register of the words the corpus's own declarations and the report's entries add.
- **A word outside all four is reported.** Nothing is refused by name, so a term is not reached by spelling it differently: a word the vocabulary does not hold is reported whatever it names.
- **The tree a declaration names is the run's input.** Paths, reference texts and arguments name the fixture's own documents, which `manifests.py` already holds to the files the fixture carries, so they are read as the tree they name rather than as words.
- **A word is read as the contract states it rather than as a sentence inflects it.** A plural, a past tense, a present participle and an adverb resolve to the word they are formed from; a hyphenated compound is its parts; case is folded on the reading side and not on the stating side, so a word the design writes only capitalised names a product rather than stating a term.
- **The inventory retires.** Two rules doing one job is the condition this work ends.
