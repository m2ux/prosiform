**Components:** src/prosiform, src/tests, checks, fixtures, README.md, design.md

## Overview

`pf` reports nothing about an entry reference on success. The bundle's entry line links each entry reference to the destination it resolved to, and that line is what reaches the agent.

## Problem

- **Every successful run warned.**
  One `W_ENTRY_DESTINATION` per entry reference reached the diagnostic stream, so a clean run never had a clean stream and a caller had to filter a warning that signals nothing wrong.

- **The warning restated the entry line.**
  The pair it reported is the pair the bundle's opening line links.

## Proposal

- **Remove the emission and the code.**
  `compose` returns the bundle alone; `ENTRY_DESTINATION` leaves `cli.py` and the `-C` listing.
- **Remove the design clause.**
  Agent delivery contract — Entry destinations leaves `design.md` (`698a75e0`); `README.md`'s design link is repinned to it.
- **Remove every expectation and description of it.**
  Schema warning catalogue, `fixtures/README.md`, manifests, unit and check tests, the smoke step.

## Implementation Findings

- **184 manifests carried the warning; 175 now declare `diagnostics = []`.**
  The other nine keep `W_RESOURCE_PORTABILITY` or an error. No expected stdout changes.
- **No fixture is removed.**
  Each fixture that observed the warning also observes the bundle.
  - `delivery/an-entry-destination-is-reported` → `delivery/a-successful-run-writes-only-the-bundle`: the clean stream and the entry line's order.
  - `delivery/an-entry-destination-under-a-grouping-rule` → `delivery/an-entry-line-under-a-grouping-rule`: whole-document entries linked to member subsections.
  - `cli/validation-only-run` and `grouping/one-entry-bundled-by-document`: descriptions drop the report.
- **`diagnostics/one-json-object-per-diagnostic-line` now observes one line.**
  Its only remaining diagnostic is `W_RESOURCE_PORTABILITY`, which a run emits at most once.
- **`resolved` is always a source path.**
  The warning was the only diagnostic whose `resolved` was a bundle destination; the schema and `diagnostics.py` say so.
- **`decisions.md` still names the warning.** Left to the orchestrator.
