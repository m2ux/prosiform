**Component:** main:invocation.md

## Overview

The option table loses the `-x` row, the help output loses the flag with it, and the page points a reader at the design's Conformance faults section.

## Problem

The fault is presented to a caller as part of the contract.

- **The table carries a row.** `invocation.md` states `-x {source-changed,internal,cleanup-refused}` beside `-o` and `-c`.
- **`make invocation` holds the two together.** The table and the build's help output name the same options in both directions, so the row and the flag go together.
- **The mechanism must stay stated.** Removing the row must not leave it unstated; the design's own section carries it.

## Proposal

**The scene.** The option table's rows are statements `make invocation` compares with the build's help.

**The design.**

- **The row is removed.** The table names nothing a caller has reason to ask for.
- **The help string goes with it.** `cli.parser` declares no `-x` (W01), so the comparison holds in both directions.
- **One sentence points at the design.** The options prose says a conformance run's fault is read from the environment, linking the design's Conformance faults section, which owns the rule.
- **The guide names no fault.** `GUIDE` carries none already.
- **`checks/tests/test_authoring.py`'s set of value-taking options drops `-x`.**
