**Component:** main:checks/runner.py

## Overview

The corpus runner passes a manifest's `fault` to the build as `PROSIFORM_FAULT` in the child's environment, and adds no argument for it.

## Problem

The runner translates a manifest field into an invocation, and that translation is the seam.

- **The field is already abstract.** A manifest declares `fault = "internal"` and the runner appended `-x internal`, so how the build receives it lives in one function.
- **The environment travels with the process.** `run_fixture` already sets the child's working directory and argument list, so the environment is set by the same call.
- **An ambient variable could leak.** A corpus started from a shell carrying `PROSIFORM_FAULT` would otherwise hand it to every fixture.
- **The bare command was tied to the fault.** A manifest with no argument ran bare only when it also named no fault, because the fault was an argument.

## Proposal

**The scene.** `run_fixture` builds `subprocess.run`'s arguments from `invocation.cwd` and `invocation.arguments`, and compares the result with `expected`.

**The design.**

- **The field passes through the environment.** `environment(fault)` returns this process's environment with `PROSIFORM_FAULT` set to the declared fault, and `subprocess.run` takes it as `env`.
- **A manifest with no fault sets nothing.** The variable is removed from the child's environment, so a build sees no fault rather than an inherited one.
- **The bare command depends on arguments alone.** A manifest declaring no argument runs the bare command.
- **The fault is copied into a scratch tree as before.** `worked` is unchanged.
