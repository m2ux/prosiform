**Component:** main:docs/patterns/README.md

## Overview

The flow, concurrency and staging section of the catalogue index lists each of its pattern pages with the paradigm it realises and the SOLID principles it serves.

## Problem

- **A page no index lists is found by browsing.**
  The family's pages exist, but the index section holds only its intent.

## Proposal

**The scene.** Every flow, concurrency and staging page has landed.

**The design.**

- **One table, in the family's own section.**
  Columns `Pattern`, `Paradigm` and `Principles`; one row per page, linked. The `Principles` column is where a reader finds which pages serve each SOLID principle.
- **No other section changes.**
  The SOLID map and the other families' sections stay as they are, so the four families' index rows write disjoint regions of the index.

## Work Breakdown

| Part | Description |
| --- | --- |
| Analysis | Read each page's `Paradigm` and `Related`. |
| Plan | Order the rows as the pages' dependencies read. |
| Implementation | Write the table and the principle lines. |
| Review | Every page of the family has one row; every row's principles match its page. |
| Test | `make links`; `make pattern-bundles`. |
