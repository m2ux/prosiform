**Component:** main:checks/pattern-pages.py

## Overview

The check that holds every pattern page to the catalogue's template, so a page that drops a section, cites no paradigm or states a limit with no issue fails `make check`.

## Problem

- **Nothing reads a usage page's shape.**
  `make links` resolves links and `make vocabulary` holds the glossary, but no check reads a documentation page's sections.
- **A template nothing enforces drifts.**
  Every later page would be held to the template by review alone, so the first page to omit a section passes.

## Proposal

**The scene.** Pattern pages sit under `docs/patterns/`, one per pattern, beside an index; each declares `prosiform`.

**The design.**

- **The template is the check's own definition.**
  `Intent`, `Paradigm`, `Grammar`, `Structure`, `Specimen`, `Consequences` and `Related` as `##` sections in that order, after the page title.
- **Each section carries its minimum.**
  `Paradigm` links at least one external source; `Grammar` links at least one section of a page under `docs/`; `Structure` holds a `mermaid` fence; `Specimen` links the specimen's entry with a deferral.
- **A stated limit names its issue.**
  Each item of a `### Limits` subsection of `Consequences` links an issue of this repository.
- **The index is not a pattern page.**
  `docs/patterns/README.md` is skipped; every other `.md` directly under `docs/patterns/` is checked.
- **One target.**
  `make pattern-pages` runs it, `make check` runs that, and `checks.md` documents it so `make tables` passes.
