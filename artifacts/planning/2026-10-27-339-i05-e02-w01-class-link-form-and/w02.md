**Component:** src/prosiform/source.py

## Overview

A sequence diagram's participant menu, written `link` or `links`, is read as diagram uses, so each document a menu entry names is bundled and the entry points at its group.

## Problem

A sequence diagram links a participant to documents through a menu. [`clicks`](https://github.com/m2ux/prosiform/blob/ad2e7338c65259e546a97be83b0964e705d64bc5/src/prosiform/source.py#L564-L581) reads one quoted destination per `click` line, so a menu entry opens nothing and keeps its source path in the bundle.

## Proposal

A participant menu is written one entry per line, `link Alice: Spec @ docs/spec.md`, or several on one line, `links Alice: {"Spec": "docs/spec.md", "Notes": "docs/notes.md"}`. Mermaid splits the first at its first `@` and parses the second as a JSON object.

- **The single entry.**
  After `link <actor>:`, the destination is the text after the first `@`, trimmed; its offset is where that text starts on the line.
- **The JSON menu.**
  After `links <actor>:`, the rest of the line is parsed as a JSON object. Each string value is one destination, located at its quoted span, in written order. A line that is not a JSON object yields nothing.
- **A value holding an escape.**
  A value whose source text differs from its decoded string, such as one with `\/`, yields nothing, since the bytes to rewrite are not the destination's characters.
- **The rewritten destination.**
  The destination becomes the group's anchor, `#<slug>`. Mermaid 11.16.0's sequence lexer reads `#` to the end of the line as a comment, so a renderer drawing the bundle's diagram drops the rewritten entry's destination and fails to parse a rewritten `links` object. A reader of the bundle's text reads the anchor.
- **Several on one line.**
  Each destination carries its own offset. [`clicked`](https://github.com/m2ux/prosiform/blob/ad2e7338c65259e546a97be83b0964e705d64bc5/src/prosiform/bundle.py#L416-L428) locates a destination from the line's end, so the rewrite runs once per destination, left to right, on the line as each previous rewrite left it.
