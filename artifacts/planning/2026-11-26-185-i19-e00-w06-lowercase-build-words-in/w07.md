## Overview

The independence check reports a fixture description stating a term `docs/glossary.md` names as deliberately not used, with the reason that table gives, and the corpus's descriptions are reworded to pass it.

## Problem

- **An avoided term reaches a declaration through the design's ordinary prose.** The design writes `include` and `branches` in their ordinary senses, so nothing refused either in a description.
- **The table states the reason, and nothing read it.** A description is the text a second implementor reads for what the contract means, which is the text the avoidance was written for.

## Proposal

The glossary's "Terms deliberately not used" table is read by its `Avoided` and `Why` columns.

- **A description stating an avoided term is reported.** Every inflection counts, whatever the design's prose states, and the report carries the table's reason.
- **Names are held to the design's words.** A clause the design names, the bytes a build writes and a fixture's identity are names rather than statements, so the avoided rule reads the description alone.
- **The corpus is reworded.** Twenty-six descriptions stating `include`, `anchor` or `branch` in any form use the glossary's own words: bundles, reaches, selects, link, destination, subtree.
