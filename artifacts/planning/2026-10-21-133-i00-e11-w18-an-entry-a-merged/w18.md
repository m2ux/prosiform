**Component:** `src/prosiform/grouping.py`

## Overview

Every reference the run resolves into a merged group names a destination the bundle carries, so a bundle is written from a map that holds every target it was asked about.

## Problem

A merged group's arrangement decides which headings it emits, and a member can contribute none of them. The destinations such a member owns are then assigned nowhere, and the two readers of the destination map reach for them regardless.

- **A member whose whole content the arrangement drops answers nothing.**
  A document carrying one H1 its overview subsection heading absorbs, and nothing above or at the grouping depth, contributes no region to the group: it takes no overview subsection and no merged section. Neither the document itself nor the title its heading carries is answered by any emitted heading.

- **An entry reference naming such a member ends the run as a fault in the tool.**
  The entry line is written from the destinations the entry references resolved to, and it reads the last of them without asking whether there is one. An empty list raises, and the run returns `E_UNEXPECTED_INTERNAL_ERROR` — the status the contract reserves for a defect no author can reach — from a source tree and a command line alone.

- **A compiled reference into such a member ends the run the same way.**
  A rewrite reads each resolved target out of the destination map by its identity, so a link from another document into a member the arrangement drops raises on a key the map never held.

- **Nothing states the outcome.**
  No fixture declares a run over a merged group that emits no heading for one of its members, so the construction's assumption that every resolved target is answered is unwritten.

## Proposal

The group's own heading carries every member, including one the arrangement emits nothing else from, so it is a destination the bundle has for whatever the member owns.

- **A member the group emits no heading of its own for is answered by the group's heading.**
  The fallback already written for a member with no overview subsection — its first contributed heading answers the document — gains the group heading as the answer where there is no contribution, and covers the title the member's own heading carries as well as the document itself. Both destinations are then assigned under every arrangement.

- **The entry line rests on a map that answers every target.**
  With the arrangement answering what it carries, the entry line is written from a list that holds one destination per entry reference, and the candidate's entry-line invariant — each entry reference names a target a destination was assigned to — is what reports a disagreement, as an invariant of the construction rather than an index error.

- **The corpus declares both readings.**
  One fixture states where an entry reference naming such a member lands, and one states what a compiled reference into it is rewritten to, so the arrangement rather than one build's tests says where such a reference resolves.
