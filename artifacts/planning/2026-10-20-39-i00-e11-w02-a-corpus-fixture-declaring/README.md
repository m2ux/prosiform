# I00:E11:W02 A Corpus Fixture Declaring Each Warning - October 2026

> Task Plan - Created 2026-10-20

## Executive Summary

This record holds the local plan for the row that gives every warning the design declares a corpus fixture that carries it. A warning code the contract names and no fixture states is a claim about the build rather than a conformance the corpus can check, and the corpus run is where that gap closes.

It matters because the corpus is the contract in executable form. A declared code that no fixture reaches leaves the behaviour to one implementation's own tests, and the next build meets it for the first time in use.
