**Component:** main:fixtures/inclusion/every-stage-reads-one-selection

## Overview

A corpus fixture holds the property that every stage of a run reads the one region set the run settled for a document. The property follows from the call graph today; the fixture makes it a check, so a stage that later reads a document whole fails the corpus.

## Problem

Discovery (`required`), the operator refusals (`refusals_of_operators`), the withheld-target check (`withheld`), dispatch placement (`dispatches`), candidate validation (`refusals` over the selected regions) and emission (`group`) each receive the selection `traverse` settled. That agreement is a property of where the code sits, and nothing reports a stage that reads the document for itself. An author cannot construct a tree where the stages disagree, so no refusal exists for it; it can only be held by observing the outcome over a tree chosen to expose each reader.

## Proposal

**The scene.** `traverse` computes `chosen` once per document and round, and passes it to each reader. Emission computes the same selection from the settled entries.

**The design.**

- `guide.md` holds `## Keep`, which links a declaring `rules.md`, and `## Draft`, which no reference selects. The entry is `guide.md#keep`.
- `Draft` carries one construct per reader, each of which fails or changes the run when that reader reads the document whole:
  - a link to a declaring `outside.md` — discovery would compile it;
  - a dispatch of a declaring `helper.md` — dispatch placement would write a second bundle;
  - a deferral of `archive.md#missing`, a declaring document with no such heading — the withheld-target check would refuse it;
  - a deferral of `ledger.md`, which does not exist — the operator refusal would refuse it;
  - raw HTML — candidate validation would refuse it.
- Expected: exit `0`, the run folder holding `guide__keep.bundle.md` alone with `Keep` and `Rules`, and no diagnostic.
- No code, refusal or diagnostic is added: the property is an invariant held by a check.
