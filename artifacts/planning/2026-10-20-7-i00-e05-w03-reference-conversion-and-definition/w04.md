## Overview

The destination a reference reaches when it names a heading the file heading absorbed.

## Problem

A document opening `# Repository Labels` and carrying `[Repository Labels](#repository-labels)` has that heading absorbed, because the file heading already names it. The reference resolves against a destination the bundle assigns to nothing, so the published bundle carries a link to a fragment no heading generates and the run reports nothing.

## Proposal

An absorbed title's slug maps to the destination of the file heading that absorbed it. The reference reaches the heading a reader sees carrying that text, the bundle holds no dead fragment, and the destination check has one target to find rather than none.

| Part | Description |
