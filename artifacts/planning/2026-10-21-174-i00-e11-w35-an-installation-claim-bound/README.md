# An Installation Claim Bound to the Run That Would Observe It — October 2026

> Delivery · Created 2026-10-21

## Executive Summary

The conformance report's declared-surface listing carries three installation claims no run of the corpus observes, each with the reason it is unreachable and what a run would have to do to observe it. The claims are declared beside the surface the report renders and nothing ties them to the smoke run, so a claim can outlive what made it true: the day the smoke run executes the documented command line, that claim's entry still stands until someone deletes it.

It matters because a stale entry reads as a current limit of the corpus, which is the condition the listing exists to end. A claim declared against the smoke-run property that would observe it is read from one declaration by both, and a run that comes to observe one fails the check rather than printing a line that is now wrong.
