## Overview

The link check passes over an indented code block written inside a list item, and reads that item's own content, a nested bullet included. The shared reading in `checks/documents.py` finds indented code blocks with the CommonMark parser the build already locks, so the check reads a document's block structure the way the product does.

## Problem

- **A list is read by its markers, not by its content column.**
  `strip_indented_blocks()` holds every line under an open list to be content however far it is indented. A code block indented past an item's content column is therefore read as content, and a link form written there as an example is resolved as a reference.

- **A guide's bullets are where such a block is written.**
  A bullet explaining an invocation, with the command or the Markdown it produces indented beneath it, is the shape this repository's own guides take.

## Proposal

A bullet in a guide holds an indented example of a link form. The link check reads the example as a reference and reports its target missing, so the author fences the block or drops the example.

- **The parser finds the code blocks.**
  `markdown-it-py`, which `src/uv.lock` already pins for the build, parses the document under the CommonMark preset. Each `code_block` token's line range is blanked; every other line is kept. A list item's content column decides whether an indented line is the item's code block or its content, because that is the rule the parser applies.

- **The checks reading documents run from the locked environment.**
  `make links` and `make tables` import the shared reading, so they run under `uv run --project src --frozen` beside the other checks that read the locked group. `checks.md`, `checks/README.md` and the Makefile's header state the environment each check runs in.

- **The shared reading's tests state the rule.**
  `checks/tests/test_documents.py` adds a code block inside a bullet, a nested bullet beneath that bullet carrying a link, a code block beneath a list item's paragraph and one beneath a paragraph at the left margin.
