**Component:** `src/prosiform/rewrite.py`

## Overview

An ordinary CommonMark autolink in selected content is a use the emission carries unchanged, so a document carrying one bundles like any other and the autolink reaches the bundle as the author wrote it.

## Problem

- **The reading and the emission disagree over an autolink.**
  The parser reads an autolink as a link use and the scan over the physical text reads none, because the scan reads brackets and an autolink is written between angle brackets. The counts are cross-checked and the run ends with `E_UNEXPECTED_INTERNAL_ERROR` at exit 4.

- **Both spellings do it.**
  `<https://example.com/profile>` and `<someone@example.com>` each end the run, although the profile names ordinary CommonMark autolinks as core syntax the build supports.

- **No fixture carries one.**
  The corpus holds no source with an autolink in it, so a bare URL written as text passes while the spelling the profile names does not, and the fault reaches the build under test through nothing the corpus runs.

## Proposal

The cross-check establishes that the emission can account for every use the parser read. An autolink is a use it accounts for by carrying it, not one it fails to find.

- **The scan reads an autolink as the use it is.**
  An autolink opens at an unescaped angle bracket outside a code span and closes at the next one, carrying an absolute URI or an email address as CommonMark spells them. The scan reads it where it sits, in written order among the bracketed uses, so the reading and the parser agree on both the count and the order.

- **The emission carries it as authored.**
  An autolink's destination is its own text and carries a scheme or an authority, so the classification emits it as authored and the emission edits no span of it. Every byte between the angle brackets, and the brackets themselves, are the bytes the source wrote.

- **The corpus states it.**
  The fixture carrying the constructs the profile supports declares the run that succeeds, in both spellings, and the marker naming this work is lifted by the change that makes the fixture meet its manifest.
