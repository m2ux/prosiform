**Component:** src/prosiform/metadata.py

## Overview

A dedicated decoder produces a typed conversion value from a frontmatter block.

## Problem

The runtime has no YAML parser or source-metadata schema.

## Proposal

Add the metadata component with immutable settings and field source marks. Verify official library documentation and types before selecting and pinning a safe YAML parser in the package and lockfile. Reject malformed mappings, duplicate keys, custom tags, aliases, merge keys, unknown reserved fields and incomplete group/depth pairs. Enforce the stated byte and nesting bounds before unbounded construction. Keep unrelated skill fields outside the conversion schema. Unit tests are delivered with the decoder.

## Implementation decisions

- Pin ruamel.yaml 0.18.16 and use its pure safe event parser. No existing dependency parses YAML. The official [API documentation](https://yaml.dev/doc/ruamel.yaml/api/) documents safe mode and configurable stages; installed events and scanner types were inspected.
- Apply exact [YAML 1.2 Core resolution](https://yaml.org/spec/1.2.2/#103-core-schema); the library resolver also recognizes timestamp and numeric extensions outside Core.
- Intern tag-aware node identities. Mapping identity ignores pair order; sequences preserve order. Boolean, integer and float keys remain distinct. Decimal integers and symbolic finite-float normalization avoid magnitude or precision loss.
- Bound raw source length before decoding and collection depth before node allocation. Aliases and custom tags never reach object construction.
- Expose decode(raw, file, span, max_bytes, max_depth). The half-open byte span excludes delimiter lines. W03 supplies it from captured bytes and wires diagnostics to runtime errors and code inventory.
- Return frozen Conversion and Location values. InvalidMetadata carries original physical coordinates and duplicate related locations. A narrow scanner override preserves out-of-range Unicode escape marks before library cleanup.
- Source reading, grouping and CLI behavior are outside W02.
