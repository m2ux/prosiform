# I00:E12:W02 A Deferred Link Carried with Its Mark — October 2026

> Task Plan · Created 2026-10-21

## Executive Summary

This record holds the local plan for the row that gives the mark its new meaning. A marked link is not compiled: its target is not bundled, and the bundle carries the link's text with the mark exactly as the author wrote it, so an agent reading the bundle can compile that link in a run of its own.

It matters because the mark is the only way an author states that material belongs to the bundle's context without belonging to its body. Without it a bundle is all of its context or none of it, and nested compilation has nothing to act on.
