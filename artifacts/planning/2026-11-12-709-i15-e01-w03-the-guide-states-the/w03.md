## Overview

The guide's symbol grammar tells the agent how to resolve `?`, and a router fixture proves the flow end to end: the published `?` link, the listing its command draws, and each pick's bundle.

## Problem

- **The guide states three symbols.**
  `GUIDE` states `↳`, `⇉` and `⫽`, and nothing about a title tag the agent must resolve before compiling.
- **No fixture follows a pick.**
  Each rule has its own fixture, and none compiles a router from the command a published `?` link carries.

## Proposal

**The scene.** Bare `pf` prints `GUIDE`, whose Compiling a link block already tells the agent to pass a title as `--presets`, also for deferred links.

- **One entry.**
  The symbol grammar gains `?`: pass the title as `--presets` as usual, read the alternatives `pf` lists, and rerun with `?` replaced by the one that fits. The guide response fixture states the entry beside the other three symbols.
- **A router fixture per step.**
  One kind router, `work-kind.md`, declares `initiative`, `epic` and `task`, each with a routing pair standing its own body in for `body.md`; a mode in `modes/` defers its `Populate Body` section with `"?"`. The `deferral/` family carries the mode's bundle, the listing the published command `work-kind.md#populate-body --presets '?'` draws, and one bundle per pick, each with no warning.
