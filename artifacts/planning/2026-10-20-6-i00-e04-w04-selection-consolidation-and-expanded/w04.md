## Overview

Consolidation of overlapping selections into the region that contains them.

## Problem

A section selected directly and again inside a whole-document inclusion is one region, and emitting it twice makes the bundle disagree with its sources.

## Proposal

A selection contained within a larger selection is replaced by the larger region, and the larger region's own references are traversed before compilation completes. Parsed-file caching is kept separate from included-region tracking, and the mapping from every selected target to its consolidated destination is retained so an entry target stays identifiable when its content is subsumed.

## The Output Check the Closure Completes

A run can write its bundle over a source it bundled. The check refusing an `--output` that names an input source runs over the entry references, before traversal, so a document reached as a dependency is not covered. Nothing is corrupted — every source is read whole before anything is published — but the file is overwritten and lost.

The check belongs here because this row walks the completed closure, which is the first point at which the full set of paths a run read is known. It moves from the entry references to that set.

It was found while delivering [W03](https://github.com/m2ux/prosiform/pull/77) and left there deliberately: completing it needs the read paths resolved after the closure, and W03 was the row that must not reintroduce a path resolution, the symlink hole [W02](https://github.com/m2ux/prosiform/pull/71) had just closed. Whatever this row uses to compare an output path against a source must not resolve a source path through a link.
