**Component:** main:src/prosiform/cli.py

## Overview

A document two sections link is bundled under the presets each section's title selects, so one run reaching it twice may put two of its presets in force. Until now the traversal kept only the first reference to each document and section, so a second link from a differently titled section selected nothing.

## Problem

Selection is per reference, and the traversal keeps one reference per target.

- **A second link is dropped.** `cli.traverse` adds a dependency to the references it carries only when its document and section are new to `seen`, so `## Draft` linking `rules.md` after `## Checks` linked it adds no reference.
- **`joined` reads the references it is given.** `cli.joined` already selects presets for every reference reaching a document and unions their pairs, so the dropped link is the whole gap.
- **A target is not a selection.** The target budget `-T` and the expansion depth count documents and sections reached; a second title reaching one target adds a selection and no target.

## Proposal

**The scene.** `traverse` reads each round's selected content with `required`, `contributing` groups the carried references by document, and `joined` reads each reference's title to put that document's presets in force.

**The design.**

- **A reference is carried once per target and title.** `traverse` keys the dependencies it carries by document, section and the title of the section holding the link, so the same link read again in a later round adds nothing and a link from a new title is carried.
- **A new title adds no target.** A dependency whose document and section are already carried joins the carried references and not the frontier, and counts against neither `-T` nor the expansion depth, since the content it selects is content the run already reads.
- **Disagreement stays a cross-reference conflict.** Two references selecting presets that pair one group with two depths meet in `group_depths` as `E_GROUP_DEPTH_CONFLICT`, exit `1`, as the design's *Selected presets union* clause and W10 left it.
- **The source page states it.** `docs/sources.md` states that each link selects for itself.
