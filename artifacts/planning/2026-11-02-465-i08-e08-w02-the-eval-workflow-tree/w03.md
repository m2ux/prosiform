**Component:** main:checks/independence.py

## Overview

The checks that read or write a declaration state the preset shape, and none names a retired field or option.

## Problem

A check describing a retired field reads as current fact.

- **`checks/smoke.py` already declares without a setting.**
  Its source carries `prosiform: {}` and its root-option assertion is gone (`05913b93`, `8160992c`).
- **Three check sources still describe the retired surface.**
  The independence scanner names `prosiform.group` as its dotted-term example, the link check's resolution test declares `root`, and a manifest-schema test expects a diagnostic naming the retired `-r` option.

## Proposal

**The scene.** The checks read frontmatter where they hold a document to a rule, and their tests write declarations to drive them.

**The design.**

- **The scanner's example is a preset key.**
  `checks/independence.py` and its tests name `prosiform.default.group`.
- **The link test declares no setting.**
  `test_a_link_resolves_from_the_file_that_writes_it` declares `prosiform: {}`.
- **The manifest test follows the schema.**
  A manifest naming no working directory validates, with no diagnostic naming a retired option.
- **The corpus run's refusal list stays.**
  `checks/corpus.py` names `group`, `subst` and `root` to fail a fixture declaring them outside a preset; it reads the preset shape and fails what lies outside it.
