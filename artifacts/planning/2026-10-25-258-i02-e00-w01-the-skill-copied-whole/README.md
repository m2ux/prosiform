# The Skill Copied Whole as the Example — October 2026

> Delivery Record · Created 2026-10-25

## Executive Summary

The first row of the example migration copies the work-planner skill into `example/work-planner` under the name it carries, so the example states a tree the size its users write rather than the four-file reduction it holds now. The copy carries every Markdown file the skill holds and nothing else, and later rows remove the Prerequisites sections, declare a group per folder, and re-record the fixtures the new tree produces.

The row exists because a four-file tree cannot show a protocol, a grouped folder, or a mode that runs another mode, which is what the demonstration must display. The copy is the ground those rows stand on, so it is delivered alone and the six rows behind it wait on it.
