**Component:** `example/work-planner/artifacts/epic-issue-body.md`

## Overview

Release Task Rows ends with the saved body, and the hold and audit-unit rules sit in the fields they constrain. Record Task Delivery returns the comment its delivery calls for. Matching a pull request to its tasks is one operation. An unplaced task issue gets its row through one operation.

## Problem

- Deliver saves released rows itself (deliver-mode.md:51-53), states the hold invariants inline (deliver-mode.md:66-67) and the audit-unit rule inline (deliver-mode.md:69-70).
- Sync composes the `Delivered by #N` comment inline (sync-mode.md:52), and Issue Delivery records the same delivery without it.
- Sync states the matching rule inline and reuses it three times (sync-mode.md:42-47, 60-63, 75).
- Placing an unplaced task row is written inline at align-mode.md:260-266, sync-mode.md:76-83 and plan-mode.md:90-93, and Issue Delivery uses Populate Epic Issue Body for it.

## Proposal

- Release Task Rows applies Save Tracker Issue. Task Delivery holds the hold invariants; Corpus Audit holds the audit-unit rule.
- Record Task Delivery writes the delivered-by comment file and returns it with the body.
- Match Delivery to Tasks names one task, or tasks naming each other in Joins, puts unclear matches to the user and returns confirmed matches.
- Place Unplaced Task Row drafts the row, applies Revise Epic Rows and Save Tracker Issue, and repeats Record Epic Delivery.
