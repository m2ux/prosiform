## Overview

Placing an orphan issue is one protocol. Publishing a reviewed initiative and its epics is one protocol.

## Problem

## Proposal

- Issue Placement applies the destination body operations, Save Tracker Issue and Check Dependencies and Numbering, then Rewrite Orphan Issue or Close Transferred Work.
- Initiative Publication applies Select Tracker Number, Save Tracker Issue for the initiative and each epic in dependency order, Resolve Placeholder Links, Repair Issue Format and Populate Planning Record.
