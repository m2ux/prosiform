## Overview

Save Tracker Issue makes the labels it assigns exist, and Close Tracker Issue leaves the auto-close rule to its field. Repair Issue Format repairs a set of bodies of any kind through that kind's validator. One operation routes a completion check to the kind's check. Resolving Open Questions is one operation returning what stays open.

## Problem

- Save Tracker Issue returns a missing-label result, so Propose (propose-mode.md:32), Plan (plan-mode.md:48) and Advance (advance-mode.md:47) each ensure labels before saving. Close Tracker Issue step 2 restates the Auto-Close Setting rule inline.
- The validate, fix, ask, correct, save and re-validate loop is written by hand in Align (align-mode.md:171-199), Hoist (hoist-mode.md:34-42) and Plan (plan-mode.md:55-58), and Sync re-validates after a repair that already re-validates (sync-mode.md:23-27).
- Issue Closure step 3 branches by task, epic and initiative itself.
- Open Questions are resolved inline at sync-mode.md:17-22 and plan-mode.md:31, 77-80.

## Proposal

- Save Tracker Issue applies Ensure Repository Labels for any label it assigns. Close Tracker Issue links Auto-Close Setting for the condition.
- Repair Issue Format accepts Validate Epic Body, Validate Initiative Body, Validate Proposal Body or Validate Issue Body with the kind's extra inputs, and a set of bodies.
- Check Issue Completion takes the kind and applies Check Epic Completion or Check Initiative Completion, or retains a task's delivery result.
- Resolve Open Questions puts each question to the user, applies corrections, saves, re-reads and returns the questions still open.
