**Component:** `example/work-planner/artifacts/placement.md`

## Overview

The order of placement options is a field condition. Check Dependencies and Numbering finds the work items it measures contention from. Check, record or hold, and interview is one operation. Check Dependencies and Numbering settles through the plan-change operation and returns what to record.

## Problem

- Hoist orders the options itself (hoist-mode.md:21).
- Align reads each row's work-item file before applying the check (align-mode.md:212), and every other caller must do the same.
- The autonomy check followed by record or held settlement is repeated at advance-mode.md:38-41, hoist-mode.md:23-29, 37, sync-mode.md:78-80 and deliver-mode.md:56, 136, 141.
- The operation settles plan changes inline and writes the planning record (steps 2-3).

## Proposal

- Placement Record holds the order; Draft Issue Placement returns options in it.
- The operation takes the planning record and reads each row's work-item file itself.
- Settle Plan Change returns the applied option, held, or the user's answer, with the updated change list.
- Step 2 applies Settle Plan Change; step 3 returns chains and pairs.
