## Overview

Repair Issue Format repairs a set of bodies of any kind through that kind's validator.

## Problem

## Proposal

Repair Issue Format accepts Validate Epic Body, Validate Initiative Body, Validate Proposal Body or Validate Issue Body with the kind's extra inputs, and a set of bodies.
