What this session changed beyond the delivery itself, and what it left for the user.

## Applied

- **The open decision in the row's Proposal is settled: `source.owner` keeps no caller.**
  Under position-states-a-dependency a reference resolves to the destination its target was assigned, read from the map `cli.destination_map` builds from the identity each emitted heading answers to. That key carries neither a link's position nor the region a run consolidated it into, so ownership has nothing left to decide and no later row needs it. The function and its five tests are removed.

- **A second definition is folded into this row.** `limits.defaults` assembled every budget at its declared default and no module and no test named it. It is the same fault in another module, needs no work item, and goes with `source.owner`.

- **The contract's clauses are restated.** The design's **Link ownership** and **Preamble ownership** become **Link position** and **Preamble content**, the post-compilation invariant **Ownership stability** becomes **Destination stability**, the source model derives link positions, and step 3 of the compile indexes no ownership. The initiative's coverage map names the clauses as the design now names them. The two remaining uses of the word in the design are the outline sense — retaining original source ownership independently of output heading levels — describe behaviour the build has, and are left.

- **A new row and criterion are placed on #39.** [#160](https://github.com/m2ux/prosiform/issues/160) is row W26, covering AC27: every function and method the package defines is named by the package itself or by a stated reason it is reached from outside it, as a repository check shows. It carries the delivery wrapper's standing with it, which is the one definition this row found that is a question rather than a fault.
