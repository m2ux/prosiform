## Executive Summary

This record holds the delivery of I05:E03 W09. Running `pf` with no arguments prints what an agent needs before it compiles anything: the compile step, the `↳` inline-target rule, and the instruction to follow a bundle from its Prosiform section. A skill's bootstrap is therefore one instruction: run `pf` and follow it. The example's `bootstrap.md` is retired. The repository's documentation then states the output folder, the dispatched bundle set, the dispatch and parallel sub-sections, and the Prosiform section.

Every corpus restated how to use pf in prose of its own. That prose now describes a build that no longer exists, with withheld dispatches, run-sets and `-o FILE`. Once pf states the guide itself, every corpus reads the same text, and the documents describe the build as it is.
