## Overview

The requester's ruling on each specimen set is recorded, and the design states the forms as accepted.

## Problem

A specimen the requester has not ruled on fixes nothing, and a form changed at scrutiny leaves the design stating the form it replaced.

## Proposal

- Each of the four sets is put to the requester as an accept-or-change question, with its files linked.
- Each open design point is put as its own question, with the candidate answers the combined set states.
- The decisions record takes each ruling beside the set and point it answers. An unanswered question leaves the task open.
- The design is restated wherever a ruling changes a form, and the affected specimen files are corrected to match.

## Work Breakdown

| Part | Description |
| --- | --- |
| Analysis | Read the four sets and the open points the combined set lists. |
| Plan | Order the questions so a ruling that changes a later form is asked first. |
| Implementation | Put each question to the requester, record each answer, and restate the design for every changed form. |
| Review | Confirm every set and every open point carries one recorded ruling, and that the design and the sets agree. A model of another family than the delivering session runs this review. |
| Test | Read the decisions record against the list of sets and open points; resolve every link from the design into the sets. |
