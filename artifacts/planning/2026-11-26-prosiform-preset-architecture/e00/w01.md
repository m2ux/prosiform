## Overview

The import set shows, as files, a preset reusing another source's levels and substitutions, and every way that reuse is refused.

## Problem

The import form, its origins and its refusals are described in prose, so no reader can see what an author writes or what a refusal says.

## Proposal

- The proposed source has an entry importing a shared level map and a worker importing a shared substitution, the shared source sitting in another folder so the imported key's origin is visible.
- An inline control states the same settings in place. The 0.36.0 release bundles it, and those bundles are the output the proposed form must equal byte for byte.
- The 0.36.0 refusal of the proposed source is retained as it is written, beside the hand-written diagnostics the proposed form raises.
- One small source per refusal shows a missing source, a missing preset, an impure target, a cycle, two imports in conflict and an import in conflict with the receiving preset, each with its proposed code, message and remedy.
- A hand-written ledger traces each imported setting to the declaration that contributed it.
- The README states the open points with their candidate answers: budget counting of a source read only for an import, the unused-pair warning in each receiving document, and new codes against existing ones.
