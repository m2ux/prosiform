## Overview

The combined set shows the three proposed features in one run, and gathers every open design point with its candidate answers.

## Problem

Each feature set shows its own form alone, so how imports, groups and the ledger meet in one build is not shown.

## Proposal

- One source has an entry importing its level map and a worker whose grouped alternatives import their substitutions.
- Hand-written bundles and a hand-written ledger show the build that source produces: each group's choice, each imported setting's origin and the invocation.
- The README lists each open design point once, with its candidate answers and the file in any set that shows each answer.
- The specimen matrix links the four sets, each of whose READMEs marks its files real or hand-written.

## Work Breakdown

| Part | Description |
| --- | --- |
| Analysis | Read the three delivered sets and collect every point their READMEs leave open. |
| Plan | Choose the one source that exercises an imported level map, an imported substitution and both groups. |
| Implementation | Write the combined source, its hand-written bundles and ledger, the open-points README and the matrix index. |
| Review | Hold the combined ledger to the three sets' field, origin and group forms, and confirm no open point is stated twice or left out. A model of another family than the delivering session runs this review. |
| Test | Parse the ledger with a TOML reader, validate it against the ledger set's schema and resolve every README link. No agent is called. |
