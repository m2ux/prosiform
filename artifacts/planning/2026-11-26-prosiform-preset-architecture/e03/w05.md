## Overview

Only changed agent-facing path classes receive a small frozen agent observation.

## Problem

Matrix coverage of the build does not show that an agent preserves the fixed and chosen bindings of a changed pick.

## Proposal

- The unchanged public diagram-following harness, agent adapter, scorer and runbook are reused at the frozen candidate revision; the declared scripts are thin scenario and receipt adapters.
- A sixty-minute instrument-fit checkpoint stops for a replan where those owners cannot support the bounded mechanism without broader harness changes.
- The first checkpoint freezes the source, the control and candidate bundles, the task inputs, the client, bundler, model and effort, and calibrated receipt observers.
- Byte equality is proved in place of an agent run where the path is unchanged.
- Where one mechanism path changes, at most one matched control and candidate pair runs: one fresh caller and one child in each arm, at most four fresh contexts and six hundred seconds for each arm, under its own explicit model release.
- The run stops after that pair. Every failed attempt is retained, and further cases, retries or model changes need a separate replan.
