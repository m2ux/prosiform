# Confirmed Goal And Boundary

Plan an incremental extension of the Python Prosiform compiler: an effective-build manifest first, explicit pure preset imports next, and named local exclusive component/test choice groups after that. An author can reuse narrowly scoped settings and select independent local alternatives, while an operator can inspect the effective source/configuration of each bundle.

The compiler's fixed 0.34.0 semantics remain the comparison baseline. New syntax and output are future proposals until their implementation and release are delivered. Authored Contracts, operations and governing Rule links remain readable Markdown. Metadata imports carry only levels and substitutions; they carry no body, Rule injection, brief, capability declaration, layout, alternative or stub role. The receiving preset retains its declared scope, including the existing explicit entry-stub scope.

Runtime profiles remain a harness boundary. Structured model/effort values and focused reviewer presets are exploratory follow-up concerns, excluded from implementation here. Permissions, secrets, sessions and capacity do not belong in presets. This work introduces no generic inheritance, automatic global context or inline-brief behavior.

Public sources and specimens use generic synthetic components and tests only. No private application source, names, findings, journals or fixture content is part of the upstream plan.

The planning scope is feature-scale and user-approved, so no new proposal is required. Selected provisional identity is I20, subject to a fresh numbering read immediately before publication. Confirmed order is Effective Manifest, Preset Imports, Local Choice Groups. Work Planner's numeric labels run largest first: 3, 2, 1.
