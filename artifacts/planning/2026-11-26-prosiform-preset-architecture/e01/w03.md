## Overview

A public synthetic example demonstrates the delivered ledger and its limits.

## Problem

A machine-readable output without an executable public example can be mistaken for proof of delivery or of meaning.

## Proposal

- The pages that own publication and architecture state the delivered ledger, and the glossary defines the term the contract marks.
- A generic dispatched example ships with a check relating its source selections, ledger facts and bundle hashes.
- Runtime receipts and authored policy stay separate from the ledger in every page.

## Work Breakdown

| Part | Description |
| --- | --- |
| Analysis | Read the delivered ledger and the existing public-document checks. |
| Plan | Use the declared files; state the ledger at the pages that own publication. |
| Implementation | Write the page sections, the glossary entry, the example and its check. |
| Review | Confirm the example demonstrates build facts only and holds no private application name, source or journal. |
| Test | Build and validate the example through the real command line in its check; run the documentation, link and vocabulary checks and `make check`. |
