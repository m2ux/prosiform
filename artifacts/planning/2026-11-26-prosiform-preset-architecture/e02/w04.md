## Overview

Only changed agent-facing path classes receive a small frozen native observation.

## Problem

Compiler matrix coverage does not prove an agent preserves the fixed and chosen bindings of a changed pick.

## Proposal

Reuse the unchanged public evals/diagram-following/harness.py, codex_agent.py, score.py and RUNBOOK.md interfaces at the frozen candidate revision. The declared checkpoint scripts are thin scenario/receipt adapters only, not a new general harness. A 60-minute instrument-fit checkpoint stops for replan if those owners cannot support the bounded mechanism without broader harness changes. First checkpoint freezes actual source, control/candidate bundles, task inputs, client/compiler/model/effort and calibrated receipt observers. Prove byte equality instead of running native where the path is unchanged. If a single mechanism path changes, propose at most one matched control/candidate pair, one fresh caller plus one child per arm, at most4 fresh contexts and600 seconds per arm. Execution needs its own explicit model/category release. Stop after that cohort, preserve every failed attempt and independently audit all actual outcomes. Additional cases, retries, physical-model changes or several-hour expansion require a separate replan; no native three-by-three sweep.
