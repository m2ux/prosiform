`shared/settings.md` is read for its presets alone. No link names it, so no
bundle carries its heading or its sentence, and its `models` and `strict`
presets count as selected.

A source read only for an import, and the budgets

`shared/settings.md` is one of the run's `files`, and its bytes count toward
`file-bytes` and `input-bytes`, as any source the run opens. It is rechecked
before publication, so one that changed fails the run with E_SOURCE_CHANGED.
One rule covers every file the run reads, and a chain of imports is bounded
by the budgets that bound every other source.

preset may hold more than one importer needs. It warns once where no document
