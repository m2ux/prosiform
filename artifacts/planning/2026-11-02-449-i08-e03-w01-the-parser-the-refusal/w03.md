**Component:** main:fixtures/README.md

## Overview

The fixtures the option carried are withdrawn or rewritten, and no manifest in the corpus names `-f`.

## Problem

Four fixtures reach the option.

- **`cli/fragment-only-reference-without-from` tests the refusal.** Its subject is that a bare `#a-section` is refused when `-f` is absent, which the removal replaces with a refusal naming `document#fragment`.
- **`extraction/a-fragment-alone-selects-from-the-referrer` tests the capability.** It passes `-f guide.md '#stop'` and expects `## Stop`, which `guide.md#stop` now states.
- **`usage-example/a-bare-fragment-and-its-referring-document` does the same over the real example tree,** and the example README quotes its command and links its manifest.
- **`mock/a-redirected-referrer-carries-its-entry` tests a redirected referrer,** and no referrer survives. A redirected positional entry's derived name is held by `mock/a-redirected-entry-derives-its-name-from-the-substitute`.
- **The corpus README cites the refusal,** in its `message_contains` example and its table of `E_INVALID_USAGE` faults, and the runner's own tests use the same text.

## Proposal

**The scene.** A fixture declares its invocation as `arguments`, and `runner.py` passes them as the process's working directory and argv.

**The design.**

- **The refusal fixture is rewritten.** `cli/fragment-only-reference-without-from` becomes `cli/a-bare-fragment-is-invalid-usage`: `guide.md` holds `## Stop`, the run passes `#stop`, and it declares exit status `2` and a message carrying `#stop` and `document#fragment`.
- **The capability fixture is rewritten to the spelling that survives.** `extraction/a-fragment-alone-selects-from-the-referrer` becomes `extraction/a-section-entry-selects-its-section`, passing `guide.md#stop`; its expected bundle `guide__stop.bundle.md` is unchanged, which is also the derived-name evidence W02 needs.
- **The example fixture is rewritten the same way** as `usage-example/a-section-entry-and-its-document`, passing `artifacts/epic-issue-body.md#record-epic-delivery`, and the example README quotes that command.
- **The substitution fixture is withdrawn.** It goes with the capability it tests.
- **The README and the runner tests name the new refusal.**
- **No manifest names the option,** which a corpus-wide search shows.
