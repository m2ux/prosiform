**Component:** main:src/prosiform/cli.py

## Overview

The parser declares no referrer, a bare `#section` is refused as a usage error naming `document#fragment`, and `entry` is reached for positional references alone.

## Problem

The option, its refusal and its plumbing sit in one file.

- **The parser declares it.** `parser()` adds `-f` with `dest="referrer"`, the positional's help names `#fragment with -f`, and `diagnostic_format` reads a value after `-f` (and after the retired `-r`).
- **`execute` refuses a bare fragment only when the option is absent.** The refusal names `-f` as the remedy.
- **The referrer is threaded through the run.** `execute` resolves it with `entry`, seeds its chain and passes it to `entered`, `compiled`, `declared_entries`, `traverse`, `compose`, `placement` and `contributing`, each of which falls back to the referrer's path for a reference carrying none, and `traverse` reads it as part of the first frontier.

## Proposal

**The scene.** `execute` normalises the command line's references through `entry`, refuses what the grammar does not admit, and passes the entries to the run.

**The design.**

- **The option is removed.** `parser()` declares no `-f`, the positional's help names `document` and `document#fragment` alone, and `diagnostic_format` names only the value-taking options the grammar declares.
- **A bare `#section` is a usage error naming the remedy.** The refusal names the reference and `document#fragment`, exits `2`, and holds for every positional carrying no path.
- **No referrer value exists to thread.** Every function that took one loses the parameter, and each `one.path or base` fallback reads `one.path`, because an entry always carries a path.
- **The link form never reaches this file.** A fragment-only link inside a document is resolved by `closure` against the document that carries it, which no command-line option touches; the corpus fixtures over fragment-only links hold it.
