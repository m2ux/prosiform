**Component:** fixtures/dispatch

## Overview

The corpus proves the bundle set end to end for every layout a source tree can give it: each layout has a fixture whose run reproduces its expected set of bundles under `make corpus`. Earlier tasks' fixtures cover most layouts; this task adds a fixture for each layout none covers, and names the existing fixture covering each of the rest.

## Problem

The earlier tasks each prove the rule they add. Three layouts have no fixture at all: a dispatch in a section nested below the second level, a chain of exactly two dispatches, and sets in sibling and nested sections of one bundle. A run of several joined entries has a fixture, but none of its entries dispatches, so nothing proves that a joined bundle opens with one Prosiform section and carries each entry's sub-sections under its own file heading.

## Proposal

An author writes a procedure whose steps sit at several depths, hand some of them to sub-agents and run sets of them together, and passes more than one entry on one command line. The run must publish the same bundle set the design derives for that tree, whatever the layout.

Each layout is one fixture whose `expected/` holds every bundle the run writes, by derived name, and whose expected bytes are derived from the pinned design (`429eaf81`) before any run.

- **Nested section.**
  A dispatch in a level-3 section with a child section takes a level-4 sub-section after the section's content and before its child.
- **Chain of two.**
  Three bundles; the entry's and the first target's each open with the Prosiform section; no warning.
- **Sibling and nested sets.**
  Three sets — a section, its child section and its sibling — each take a `Dispatch in parallel` sub-section one level below their section, the repeats taking ordinals in bundle order. A target two sets name is one bundle, listed in each set with that set's link text.
- **Joined entries.**
  Two entries dispatching one shared target and one target of their own publish one joined bundle and one bundle per target. The joined bundle opens with one Prosiform section; each file heading carries its own sub-sections, and the second sub-section naming the shared target takes an ordinal.
- **Clauses.**
  Each new fixture names the design clauses it exercises, so `make conformance` reports them covered. Each description uses the contract's vocabulary alone.
