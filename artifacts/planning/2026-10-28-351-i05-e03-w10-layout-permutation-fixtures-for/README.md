# I05:E03:W10 Layout-Permutation Fixtures for the Bundle Set — October 2026

> Task delivery · Created 2026-10-28

## Executive Summary

This record holds the delivery of I05:E03 W10: an end-to-end fixture for each layout a source tree can give the bundle set. Each fixture's expected bundle set is reproduced by the run under `make corpus`. The layouts covered are:

- a dispatch in a section, in a nested section and in the preamble;
- one target dispatched from two sections;
- chains of dispatches from one to three deep, and past the limit;
- a cycle, and a dispatch from a level-6 section, both refused;
- a set in one section, in sibling and nested sections, and beside a `⇉` link;
- one target named twice in a set;
- several joined entries.

Each earlier task proves the rule it adds. Nothing yet proves those rules together across the shapes a source tree takes, where a sub-section's placement, a shared target and a set beside a dispatch interact.
