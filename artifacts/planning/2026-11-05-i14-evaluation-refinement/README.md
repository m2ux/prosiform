> Initiative planning · Created 2026-11-05

## Executive Summary

I14 holds the measured shakedown, live edge-workflow run and results publication deferred from I10. The goal is an auditable evaluation of how agents follow composition, deferral and dispatch, with measured budgets and a recorded disposition for every failed session.

This work is deferred beyond MVP release preparation. The corpus and harness implementation stays in I10; its integration review remains separate from the future measurement. No live run starts as part of board alignment.
