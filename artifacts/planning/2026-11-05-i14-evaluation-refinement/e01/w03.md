**Component:** main:evals/diagram-following/README.md

## Overview

The eval's README names the committed default-matrix baseline and each harness's default-matrix record, and states the crash-free result each committed run shows.

## Problem

- **The page states coverage the records do not hold.**
  The README describes the default matrix and the committed baseline, and no section names a harness record or the crash-free result one shows.

## Proposal

**The scene.** The README's Running section states the default matrix, its sessions and the committed baseline, and a harness's record is a `report.json` committed beside it.

- **The matrix statement follows the cells.**
  The matrix's session and cell counts agree with the cells the committed baseline carries, the bootstrap-audit scenarios among them.
- **Each harness record is named.**
  A section names each `default-matrix-<harness>.json` and its `report.md`, and states which sessions it covers and the exit statuses it records.
- **The page is checked against the records.**
  The README's test reads the committed records, so a count or a harness name the records do not support fails `make check`.
