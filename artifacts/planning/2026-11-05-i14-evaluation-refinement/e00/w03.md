**Component:** main:evals/diagram-following/README.md

## Overview

The eval's README states the `compiled` form, each edge workflow and scenario, and the pass rates each harness's edge-case record holds.

## Problem

- **The edge workflows have no published measurement.**
  A reader needs each recorded run's revision, harness, model and pass rates beside the workflow descriptions.

## Proposal

**The scene.** A workflow is a directory under `workflows/`, with `scenarios.toml` naming its inputs, path, sub-agent starts and ordered `pf` runs. A `compiled` session receives its sources, bundle set and the build as `pf`; the scenario passes when its recorded path and commands match that walk.

- **The form and workflows.**
  The Forms table describes `compiled`, and each edge workflow and scenario is listed beside the dispatch scenarios, using `↳`, `¬↳`, inline `⇉` links and the guide's dispatch-set heading.
- **The record.**
  A section names each `composition-edges-<harness>.json` and states its pass rates.
