## Executive Summary

The diagram-following eval walks one bundled diagram from its entry to a terminal state and records no sub-agent start. The dispatch protocol `pf` compiles around a dispatching link is therefore unmeasured: nothing observes an agent reading it, so a change to its wording or to the sub-section's shape cannot be judged by its effect.

This record holds the delivery of W01: the dispatch scenarios written in the two forms the report compares, the bundle set `pf` publishes and the same source tree carrying the protocol an author wrote, each bundling clean.
