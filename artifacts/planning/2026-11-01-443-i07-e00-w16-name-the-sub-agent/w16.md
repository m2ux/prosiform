**Component:** evals/diagram-following/instruction.md

## Overview

The dispatching instructions, so a session in every form the matrix runs tells each sub-agent it dispatches to record its states under the trace name the runner keeps.

## Problem

`instruction-bootstrap.md` names the sub-agent trace `trace-<section>.log`, and `instruction.md`, which every other form uses, names none. The runner's `keep()` keeps `trace*.log`, so in the compiled and authored forms a sub-agent either writes no trace or appends its states to the dispatching session's `trace.log`.

The bootstrap sentence also addresses the sub-agent, which never reads the session's instruction: the agent CLI hands a sub-agent only the prompt its dispatching session writes. AC16's scored test passed only because the stub agent writes each sub-agent trace whatever its prompt states.

## Analysis

- **Instructions.** `workflow.instruction()` reads `instruction-bootstrap.md` for the `bootstrap` form and `instruction.md` for every other. The forms that dispatch are `compiled` and `authored` (both on `instruction.md`) and `bootstrap`.
- **Kept name.** `keep()` copies `TRACES`, `trace*.log`, so `trace.log` and every `trace-<section>.log` survive the workspace.
- **Who reads what.** A dispatched sub-agent starts from the prompt its session writes in the `Task` call, so the session is the reader a trace sentence must address, and the sub-agent is told the name only through that call.
- **The stub.** `write_sub_agent_traces` writes one `trace-<section>.log` per start unconditionally, and its `Task` prompt names no trace.

## Proposal

**The scene.** A scored run in the compiled form dispatches a section, and the score keeps that section's trace. The trace exists because the instruction told the session to pass the name on and the session told its sub-agent, not because a stub wrote it.

**The design.**

- **One sentence, every instruction.** Both instruction texts carry the same bullet, addressed to the dispatching session: tell each sub-agent to append its states to `trace-<section>.log`, named for the section it is handed, and leave `trace.log` to the session's own path. The bootstrap form's sub-agent-addressed bullet is replaced by it.
- **The stated name is one constant.** `SUB_AGENT_TRACE` sits beside `TRACE` and `TRACES` in `score.py`, so the name the instruction states, the pattern `keep()` reads and the name the stub writes cannot drift.
- **The stub writes only what it was told.** The stub's dispatching session passes the trace name in each `Task` prompt only when its own instruction states it, and a sub-agent's trace is written only from a prompt that names it. A prompt without the sentence produces no sub-agent trace.
