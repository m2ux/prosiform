**Component:** main:evals/diagram-following/workflows/deferred-composition/scenarios.toml

## Overview

A `staged` workflow whose bundle holds a `↳` line generated from `[¬→]` under a conditional step, with scenarios where the path reaches it and where it does not, and a nested deferral run only where the path needs it.

## Problem

- **Activation is a fixture, not a reading.**
  The corpus shows the `↳` line and the bundle its run writes; no session shows an agent deciding to run it.
- **A nested line is the agent's decision.**
  Activation is its own entry run, so only the agent following the activated bundle knows whether its path needs the next line.

## Proposal

**The scene.** A workflow is a directory under `workflows/`, its forms beside a `scenarios.toml` naming each scenario's inputs, the path a correct session walks, the sub-agents it starts and the `pf` runs it makes. A `staged` session receives the compiled bundle set with the build under test as `pf` on its path; the scenario passes when the session's path is the one its bundle states.

- **A conditional step.**
  A step opening with a condition, "If `inputs/<file>` reads `<value>`,", reaches the `↳` lines its directives link only where the condition holds. `Relocate` defers `reference/migration.md#steps` under one reading `scope.txt`.
- **A nested deferral.**
  The migration's steps defer `reference/archive.md#steps` under one reading `history.txt`, so that line exists only in the bundle the migration's run writes.
- **Four scenarios.**
  `deferral-reached` runs the migration's line; `deferral-passed` runs none; `nested-needed` runs the migration's line, then the archive's; `nested-unreached` runs none, since the archive's step holds but its bundle is never compiled.
- **The corpus test walks the bundles.**
  It compiles the entry's bundle, runs `pf` from the staged sources on each line a step of the walk reaches, reads each run's bundle as part of the state that reached it, and holds the scenario's session runs and path to that walk. The inputs a conditional deferral reads are inputs the scenario states.
- **The boundary with the MVP proof.**
  Its section-composition workflow ([#523](https://github.com/m2ux/prosiform/issues/523)) carries one unconditional deferral in a bundle no session compiles; this workflow measures the conditions.
