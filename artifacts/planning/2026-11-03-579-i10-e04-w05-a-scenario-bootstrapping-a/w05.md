**Component:** main:evals/diagram-following/workflows/inline-bootstrap/scenarios.toml

## Overview

A `bootstrap` workflow whose skill entry declares no `prosiform` and holds a hand-written `[↳ <title>](<path>)` link, so the eval measures an agent running `pf`, then compiling the link, before following it.

## Problem

- **No skill hands over an undeclared entry.**
  `bootstrap-audit`'s `SKILL.md` declares `prosiform`, so no scenario shows a skill whose entry `pf` never reads handing over a `↳` link and the guide alone.
- **Two checks name one missed run.**
  With bootstrap scenarios stating their runs, `uncompiled` already fails a bootstrap session that ran no `pf`, and the scorer's `unbootstrapped` class states that check a second time.

## Proposal

**The scene.** A workflow is a directory under `workflows/`, its forms beside a `scenarios.toml` naming each scenario's inputs, the path a correct session walks, the sub-agents it starts and the `pf` runs it makes. A `bootstrap` session finds a skill under `.claude/skills/<workflow>/` with the build under test as `pf` on its path; the scenario passes when the session's path is the one the bundle it compiles states and its runs are the ones the scenario states.

- **The skill is one link.**
  `inline-bootstrap`'s `SKILL.md` declares no `prosiform`, says to run `pf`, and holds `[↳ Release](sources/workflow.md)`, titled as that document is headed. Its sources draw a release: `Freeze`, then `Tag` for a feature or `Backport` for a fix, then `Broadcast`.
- **The runs are stated.**
  Each scenario states bare `pf`, then `pf sources/workflow.md`, and its path is the walk of the bundle that run writes.
- **The corpus test compiles the line.**
  For every bootstrap workflow it reads the skill's one `↳` line, holds its title to the heading of the document it names and the scenario's runs to bare `pf` then the line's path, and walks the bundle `pf` writes from the skill's directory. A skill entry may declare nothing, since the agent CLI reads it rather than `pf`. `bootstrap-audit`'s line takes its document's title, `Audit`.
- **One class for a missed run.** (User, 2026-11-03.)
  The `unbootstrapped` class, and the run's compiled flag that fed it, are removed from the scorer and the runner; `uncompiled` names a bootstrap session that ran no `pf`. Its triage-rubric row in `RUNBOOK.md` is W17's to settle, since the runbook is not on this base.
