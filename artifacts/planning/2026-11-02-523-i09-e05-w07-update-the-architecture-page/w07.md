**Component:** main:docs/architecture.md

## Overview

The architecture page names each module, its responsibility and the data flow between them as the merged source holds them.

## Problem

- **The source moved under it.**
  Presets, placement and composition added and split modules the page predates.
- **Nothing checks the page against the code.**
  A module renamed or added leaves the page stale without a failing check.

## Proposal

**The scene.** The page describes `src/prosiform`'s modules and how a run passes data between them.

**The design.**

- **The page follows the code.**
  Each module, its responsibility and its callers come from a GitNexus read of the merged revision.
- **The evidence is recorded.**
  The pull request carries the query and its result beside the page's diff.
