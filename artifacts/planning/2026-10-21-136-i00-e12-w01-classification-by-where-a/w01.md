**Component:** `src/prosiform/closure.py`

## Overview

This task makes a reference's position decide what the bundle does with it. A local Markdown reference carrying no scheme and no authority, resolving to a Markdown file under the allowed source root, is a dependency: it is resolved, recursively bundled and rewritten to its target's bundle destination. One resolving outside that root is emitted exactly as authored, and the document it names is never opened.

It is the row the rest of the epic stands on. The deferral, the missing-target failure, the resource rule, the self-reference rule and the root confinement each state an exception to this classification, and none of them can be written while the classification itself reads a mark.

## Problem

The build selects a dependency by a mark on the link text, which is the rule [D32](https://github.com/m2ux/prosiform/blob/engineering/artifacts/planning/2026-10-17-prosiform-v1/decisions.md) wrote and [D59](https://github.com/m2ux/prosiform/blob/engineering/artifacts/planning/2026-10-17-prosiform-v1/decisions.md) withdrew.

- **A forgotten mark is a silent omission.**
  A dependency nobody marked is not resolved, not opened and not rewritten, and the run still succeeds, so the bundle is missing material and reports nothing about it.

- **Two statements say one thing.**
  The allowed source root already decides what a run may reach, and the mark decided it again inside that root, so an author kept two declarations in agreement to express one intent.

- **The mark is read in five places.**
  Discovery, emission, heading text, candidate validation and the destination map each ask whether a link carries the mark, so the selector is restated wherever a link is handled rather than resolved once.

## Proposal

The root is the lever the author already controls: material a document must carry sits under it, material it only names sits outside. Classification therefore reads where a reference resolves, and the mark selects nothing.

- **One classifier, in the module that resolves a reference.**
  `closure.bundled()` returns the reference a link names where the bundle compiles it — no scheme, no authority, normalizing under the root, naming a Markdown file — and nothing where it does not. Discovery, emission, heading text and candidate validation each call it, so the five readings of the mark become one reading of position.

- **A reference leaving the root is text.**
  Discovery no longer refuses it. The reference is not resolved further, its document is not opened, and the link reaches the bundle as its author wrote it.

- **The mark goes with the rewrite.**
  A compiled link loses its mark as it gains its destination, which is what the build does today. A link the bundle does not compile keeps every byte its author wrote, the mark included, so emission and the preservation comparison agree on one text.

- **The corpus states position.**
  Every fixture that selected a dependency with the mark states it by where its target sits, and the two fixtures whose subject was the mark above the root state what a reference above the root is.

- **A rule this epic has not delivered keeps the behaviour the build has.**
  A marked resource and a marked direct self-reference are still refused, which `W04` and `W05` retire; a marked link under the root still compiles, which `W02` defers; an entry reference above the root still fails, which `W06` states. Each is named in the work this row leaves alone.
