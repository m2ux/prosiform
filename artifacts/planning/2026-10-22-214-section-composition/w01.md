**Component:** artifacts/planning/2026-10-17-prosiform-v1/design.md

## Overview

Specify the syntax, occurrence identity, composition ordering, collision compatibility, budgets and deferred activation interface before compiler work.

## Problem

The canonical design lacks the section-composition contract.

## Proposal

Extend the canonical design with the complete issue requirements. Define deferred activation as recompilation from original source entries with explicit occurrence selection; the selection identifies the source occurrence and expansion ancestry, and retains its containing section. Specify how authors discover and select an occurrence, including repeated occurrences and nested deferrals. Define compatibility for authored child headings; the safe default is a collision error unless an existing generated destination belongs to the same scope and exact title. Declare a positive materialized-occurrence budget and charge final output bytes incrementally. Record the exact CLI grammar, defaults, diagnostics and worked staged examples in the design before implementation.
