**Component:** src/prosiform

## Overview

Identify inline and deferred placement as independent properties of parsed link occurrences.

## Problem

The occurrence model retains an opening character for deferral but has no scalar-qualified inline placement.

## Proposal

Extend the existing profile and rewrite occurrence representation. Read decoded plain-text children without flattening formatted tokens. Consume only the defined deferral prefix and separator; exclude the lone marker. Preserve full source occurrence identity, link spans and definition bindings. Cover admitted inline and reference-style links without broadening the Markdown profile.
