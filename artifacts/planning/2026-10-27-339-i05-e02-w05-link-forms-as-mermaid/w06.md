**Component:** src/prosiform/source.py

## Overview

A `links` object is read as `JSON.parse` reads it: a repeated key keeps its last value, and a value that is not a string ends the run in a fault naming the line.

## Problem

Review findings 4 and 5 ([review.md](review.md)): every value of a repeated key is bundled, and a value that is not a string is skipped without a fault while its siblings are bundled. Mermaid renders the last value of a key alone, and a value that is not a string as a broken menu entry.

## Proposal

- **One decode.**
  The object's text is decoded once, its members kept as written pairs. A lexical walk over the same text locates each member's value: a string literal's span, or a nested value skipped by bracket depth. The decode and the walk meet member for member.
- **The last value of a key.**
  A member whose key a later member repeats names nothing, and its bytes are carried as written.
- **A value that is not a string.**
  A surviving value that is not a string makes the line a broken menu line. The line yields no destination, and the profile refuses it with `E_UNSUPPORTED_CONSTRUCT`, naming the line, where the run reads the region carrying it, as it refuses every other construct.
- **The boundary.**
  A value holding a JSON escape is carried as written and names nothing; a text that is no JSON object names nothing.
