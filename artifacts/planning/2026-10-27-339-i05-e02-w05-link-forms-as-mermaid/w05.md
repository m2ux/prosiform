**Component:** src/prosiform/source.py

## Overview

Each diagram link form is read where Mermaid 11.16.0 reads it: the class `link` form in a class diagram alone, the sequence `link` and `links` forms in a sequence diagram alone, and a sequence destination ending where the sequence lexer ends the statement's text.

## Problem

Review findings 1–3 ([review.md](review.md)):

- A state line `link --> done : retry @ ops.md` is read as a sequence menu entry, so `ops.md` is bundled and the label rewritten.
- `@ a.md;b.md` reads as `a.md;b.md`, where Mermaid's sequence `TXT` token, `:(?:(?:no)?wrap)?[^#\n;]*`, ends at `;`.
- `doc.md#35;intro`, the only anchor spelling the sequence lexer keeps, resolves as the fragment `35;intro`.

## Proposal

- **The diagram type.**
  A fence's type is read from its text as Mermaid's `detectType` reads it: a leading front matter block, every `%%{…}%%` directive and every `%%` comment line removed, then the text opening, after whitespace, on `classDiagram` or `sequenceDiagram`. The class `link` form is read in a class diagram, the sequence forms in a sequence diagram; `click` is read in every diagram.
- **Where a sequence statement's text ends.**
  The text after the actor's `:` runs to the first `;` or `#` that opens no entity. Mermaid's `encodeEntities` replaces every `#<word>;` before lexing, so `#35;` and its `;` are part of the text. A `link` entry's destination is the trimmed text after the first `@` within it; a `links` object is the trimmed text itself. Every byte past the end is carried as written.
- **The entity anchor.**
  Each `#35;` a sequence destination holds resolves as `#`, so `doc.md#35;intro` names the section `intro` of `doc.md`. `Click` carries the destination so resolved and the text as written, whose span the rewrite replaces.
- **Candidate validation reads the resolved destination.**
  A rewritten sequence destination `#35;<slug>` reads back as `#<slug>`, the destination every other form takes, so the intended destination is `#<slug>` for each form. A bare `#<slug>` on a sequence line opens a comment, reads as no destination, and fails reference preservation.
