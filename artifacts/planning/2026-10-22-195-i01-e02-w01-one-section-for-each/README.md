# One Section for Each Member Carried — October 2026

> Delivery · Created 2026-10-22

## Executive Summary

A merged group arranges a folder's documents under one heading, keyed on heading text. A document is therefore scattered across the sections it happens to contribute to, named only where another document contributed the same text, and wrapped in an overview section whether or not its content needs one. This unit replaces that arrangement with one section for each member the group carries, titled from the member and holding the member's own content beneath it.

The arrangement is what a reader of a bundled skill meets first, so the shape it takes decides whether the sources read as documents or as a pool of headings. Settling it also removes the generated structures that the destination rule and the heading-casing convention were working around, which is why the rows that follow this one depend on it.
