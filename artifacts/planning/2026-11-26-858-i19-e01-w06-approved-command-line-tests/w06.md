**Component:** main:src/tests/test_cli.py, main:AGENTS.md

## Overview

Each command-line test the user approved for removal leaves the build's tests, and the repository states which layer a new behaviour's test belongs to, so the overlap does not grow back.

## Problem

- **An approved removal is still a test to maintain.**
  A test the overlap table records as held by a fixture fails beside that fixture on every change to the behaviour.
- **Nothing states where a new test belongs.**
  [The agent instructions](https://github.com/m2ux/prosiform/blob/b0eb7a2335436f2ce9c35546d3bfd2e39f7ae3be/AGENTS.md) say how code is documented and nothing about which suite holds a behaviour.

## Proposal

The overlap table carries the user's verdict on each test a fixture holds.

- **Approved tests are removed.**
  Each approved row's test leaves the file, with any helper nothing else calls.
- **Coverage of the contract is held.**
  The conformance report is read before and after, and a clause newly uncovered returns its test.
- **The layer rule is stated once.**
  A behaviour a source tree and an invocation can state is held by a fixture. A build test holds what no fixture reaches.
