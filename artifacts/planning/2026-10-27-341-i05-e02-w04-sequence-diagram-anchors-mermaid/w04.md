**Component:** src/prosiform/source.py

## Overview

A rewritten sequence diagram `link` or `links` destination is spelled `#35;<slug>`, Mermaid's entity for `#` followed by the group's slug, so a renderer drawing the bundle's diagram gives each participant's menu one entry per destination, each opening its group's heading.

## Problem

The bundle rewrites a sequence menu destination to `#<slug>`. Mermaid 11.16.0's sequence lexer reads `#` to the end of the line as a comment, so `link Client: Client guide @ #client` reaches the diagram with an empty destination, and `links Server: {"Server guide": "#server"}` reaches `JSON.parse` cut at the `#`, which throws, so the participant carries no menu.

## Proposal

Mermaid encodes every `#<word>;` in a diagram's text before lexing and decodes it in the rendered SVG, so `#35;` passes the lexer as an opaque token and reaches the menu entry's `xlink:href` as `#`.

- **The spelling is the form's.**
  The reader that recognises a diagram link line also states how that line's form spells a heading anchor: `#` for a quoted `click` or class `link` destination, `#35;` for a sequence `link` or `links` destination. `Click` carries that spelling, so it lives in `source.py` beside the forms, and the rewrite in `bundle.py` and candidate validation in `candidate.py` read it from the click rather than each deciding it. The brief named `bundle.py` as the component; the spelling belongs to the reader of the forms, so this file declares `source.py`.
- **The rewrite writes it.**
  A compiled sequence destination is replaced with `#35;<slug>`, a quoted destination with `#<slug>`. A destination the bundle compiled nothing for keeps its author's text.
- **Candidate validation reads it back.**
  A diagram use carries its click's anchor spelling, so the destination the source's use is intended to take is spelled as the rewrite spells it, and a candidate carrying a bare `#<slug>` on a sequence line fails reference preservation.
- **Render evidence.**
  A render of an end-to-end fixture's bundle under Mermaid 11.16.0 (`mmdc`, headless Chromium) gives each participant's popup menu one `<a xlink:href="#<slug>">` per destination; the bare `#<slug>` spelling renders no anchor. [validation.md](validation.md) holds the run.
