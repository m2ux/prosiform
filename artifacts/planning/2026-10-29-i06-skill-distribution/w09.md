**Component:** skills (a submodule in the workspace checkout)

## Overview

The workspace reaches the skill through a submodule at `skills/`, so one tree serves the published example and the live agent alike, and no copy is maintained by hand.

## Problem

The workspace's `skills/work-planner` is a hand-maintained copy with no reference to the tree prosiform publishes, and every artifact file has already diverged between them.

## Proposal

- **The folder becomes a submodule.**
  `skills/` is replaced by a submodule naming the branch, and the three agent roots that already link to it keep resolving without a change.
- **The shared files live in the branch.**
  `skills/guidelines.md`, `skills/scripts/` and `skills/test/` move to the branch rather than staying in the workspace, so a citation and its target live in one tree.
- **The workspace's own rules are untouched.**
  Nothing outside `skills/` changes, which is what keeps the submodule a single seam.

## Work Breakdown

| Part | Description |
| --- | --- |
| Analysis | Every workspace path resolving under `skills/`, and every citation into it from elsewhere in the workspace. |
| Plan | The submodule's URL, branch and path, and the order the replacement lands in. |
| Implementation | The submodule added, the copy removed and the workspace's ignore rules brought to the submodule's shape. |
| Review | Each agent root resolving to the branch's entry point. |
| Test | A fresh workspace checkout, with each agent root's resolution listed. |
