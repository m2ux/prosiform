**Component:** skills (a submodule in the workspace checkout)

## Overview

One live agent session finds the skill from its workspace roots and completes a board operation through it, which is the evidence that the tree is a skill an agent runs rather than a document set a reader admires.

## Problem

Nothing has observed an agent finding this skill and using it on real work. Without that observation, the migration is a claim about discovery rather than a demonstration of it.

## Proposal

- **The session is ordinary.**
  A fresh session in the workspace checkout is asked for a small board operation, with no instruction naming the skill or its path.
- **The operation leaves evidence.**
  The operation is one the skill's own procedures perform, so the board's history records it and the session's transcript records how the skill was found.
- **What the session could not run is a finding.**
  A command the session reached and could not run is recorded in the planning record, so the demonstration reports the tree's gaps rather than hiding them.

## Work Breakdown

| Part | Description |
| --- | --- |
| Analysis | The operation to ask for, and the observations that show the skill was found rather than guessed at. |
| Plan | The transcript's tell, and where the findings are recorded. |
| Implementation | The session run once against the workspace checkout. |
| Review | The board operation confirmed against the board, not against the transcript's claim. |
| Test | The transcript showing the skill found from its roots, and the board showing the operation applied. |
