## Problem

## Proposal

- **The directory and the family go together.**
  `example/work-planner`, `fixtures/usage-example/` and the paragraph describing the corpus's one leaving link are removed in one change, so no fixture is left resolving to nothing.

  `README.md`, `invocation.md` and `example/README.md` name the branch where they named the directory.
- **The clause about published examples is retired.**
  It is a rule about an example main no longer publishes, so the clause and its fixtures leave with the tree rather than leaving a rule with no subject.
