**Component:** evals/diagram-following (the branch's fixture harness, new tree on the `skills` orphan branch)

## Overview

The usage-example fixture family, the manifest schema, and the modules that decide a fixture, arriving on the branch so its own tree is proved by a command run from the branch alone.

## Problem

Seven fixtures reach `../../example/work-planner` through a `source` link, the only link in the corpus that leaves its fixture. The modules that decide a fixture take their corpus root from the repository holding them, so fixtures standing on a branch with none of those modules are read by nothing.

## Proposal

- **The family and the schema move together.**
  `fixtures/manifest.schema.json` and `fixtures/usage-example/` arrive at the branch root's `fixtures/`.
- **The deciding modules move with them.**
  The manifest reader, the fixture runner and the corpus walker arrive beside the fixtures, because a corpus root is derived from where they sit.
- **The build is configuration, not a copy.**
  The branch holds no compiler, so the run names the build the caller configures, and the target fails without one.
- **The fixtures stop leaving their own directory.**
  Each `source` link points into the corpus at `work-planner/`, so a fixture is self-contained wherever the branch is checked out.
