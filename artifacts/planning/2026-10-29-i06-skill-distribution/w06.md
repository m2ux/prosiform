**Component:** Makefile (the branch's own check command)

## Overview

The branch runs its own corpus, so the proof that its documents bundle is a command run from the branch rather than a claim it makes.

## Problem

The corpus runner is invoked by a target on the branch, and the branch holds no compiler, so the target has to name a build the caller configures. A target that fell back to a default build would report a corpus as holding against a build that never ran.

## Proposal

- **One target, one run.**
  A `check` target runs the corpus walker over the branch's fixtures.
- **The build comes from configuration.**
  `PROSIFORM_BUILD` holds the build's command line, and the target fails without it, which is the rule the corpus already states.
- **The check the branch also runs is named.**
  The shared checker over the skill is a second target, so a reader runs both from the branch root.
