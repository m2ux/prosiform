## Overview

The design gains *Conformance faults*, a section of its own stating `PROSIFORM_FAULT`, its three values and why the mechanism exists, and the README's design pin moves to the revision carrying it, so the epic's fixtures can name its clauses.

## Problem

The contract no longer states how a conformance run reaches the clauses no source tree produces.

- **The variable has nowhere to be stated.** The CLI contract names no `-x`, and no section states the channel a run reads a fault from, although the design states that a run reads Markdown and its own frontmatter and a second input channel belongs in the contract even when it is not an option.
- **Three clauses depend on it.** *Source consistency*, the internal-error exit status and the earlier-set retention warning each state behaviour no source tree produces, and each is fixtured through a fault.
- **A fixture can name only what the pin carries.** `make conformance` reads the design at the revision the README links, so a clause landed on the engineering branch but not pinned is one no fixture can name.

## Proposal

**The scene.** The CLI contract enumerates each option as a clause, and `make conformance` lists the clauses no fixture reaches at the revision the README pins.

**The design.**

- **A section of its own.** *Conformance faults* sits under the CLI contract beside *Guide*, outside the option table, and states why the mechanism exists: some clauses state behaviour no source tree can produce, so a run performs the fault a fixture describes without a caller being able to ask for it as an option.
- **One clause per rule.** Bold-led bullets name the values, the run without the variable and the unknown value, so a fixture names each as `Conformance faults — <rule>`.
- **An unknown value is invalid usage.** A value outside the three fails with `E_INVALID_USAGE` and exit status `2`, so a mistyped conformance setting is a fault rather than a silent pass.
- **The pin moves to the amendment.** The README's design link names the engineering commit carrying the section.
