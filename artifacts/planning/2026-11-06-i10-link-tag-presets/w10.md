**Component:** main:docs/

## Overview

Audit all maintained repository documentation for accuracy and completeness against the delivered link-tag preset contract, and correct the discrepancies before the epic enters review.

## Problem

Earlier rows updated individual guides and examples, but those targeted changes do not establish that every maintained documentation surface agrees with the final compiler and eval behavior or that the complete feature is explained.

## Proposal

After W09, inventory all documentation surfaces: root and package READMEs, CLI help and the plain-text invocation guide, focused guides, architecture and glossary, eval instructions, checked examples, and maintained design and planning entry points. Trace factual claims and executable examples to the final implementation and named checks. Check complete-name tag normalization, default layering, occurrence-local selection, resource exclusions, single-entry grammar, relative destinations and fragments, shell quoting and leading-dash values, deferred activation, distinct/equivalent dispatch variants and output naming, diagnostics and boundaries. Correct stale claims and missing explanations, and add observing checks where the existing checks leave a documentation claim unverified.

Historical records remain historical: identify superseded material and its current replacement rather than rewriting past evidence to claim a different implementation. Record every inventoried surface, revision, finding, correction and verification; any excluded surface or unverified claim needs an explicit reason. This is a documentation audit and repair task, not authorization to redesign compiler behavior, run paid evals or change unrelated features.

| Part | Description |
