# I00:E02:W05 Fixtures From Unmodified Workspace Skills - October 2026

> Task Plan - Created 2026-10-19

## Executive Summary

This record holds the local plan for the fifth task of [I00:E02] Walking Skeleton. Documents are copied from this workspace's skills into the fixture corpus without alteration, and the bundle each produces is recorded as its expectation. The documents are chosen for the breadth of profile constructs they carry between them, not for how easily they bundle, and each copy is confirmed byte-identical to its source.

It matters because every fixture the corpus holds so far was written for the test. A source authored to exercise one clause exercises that clause and says nothing about the documents the tool exists to bundle, so the claim that ordinary Markdown bundles with no added markup rests on sources that were never ordinary. It matters more because of the rule this task runs under: a document that needs an edit to bundle is a defect in the build or a gap in the design, and the document is not edited to accommodate either. That makes this the first task whose failures are findings rather than work, and the first evidence that the walking skeleton meets real prose. The task covers AC6.
