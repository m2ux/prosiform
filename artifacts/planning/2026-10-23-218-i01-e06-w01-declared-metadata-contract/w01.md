## Overview

The contract makes metadata ownership, accepted YAML, grouping and diagnostic behavior explicit before the compiler consumes it.

## Problem

The design describes frontmatter as discarded transport data and grouping as invocation-wide directory rules.

## Proposal

Amend the normative design on its owning engineering branch. Define the paired string fields, explicit membership, absent-field behavior, malformed-YAML rules, per-file fragment semantics, deferred validation, consistent group depths and input diagnostics. Preserve operational CLI controls. Assign diagnostic codes and identify obsolete group-rule codes. Record the source-language change and the tagged-contract handoff for the Rust implementation; implementation of that compiler is outside this task.
