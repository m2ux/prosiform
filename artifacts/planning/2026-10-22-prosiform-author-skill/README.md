# Prosiform Author Skill — October 2026

> Skill plan · Created 2026-10-22

## Executive Summary

The proposed `prosiform-author` skill guides an agent from a writing request to Markdown source files whose intended entry points compile successfully with Prosiform. The user confirmed that it covers any Prosiform-compatible Markdown, including instruction sets and ordinary documents, rather than agent skills alone.

Compatibility includes both accepted syntax and explicit links to the content a selected document or section needs. This plan separates compiler requirements from writing conventions, specifies a small skill and observable acceptance checks, and records the evidence needed to validate its implementation.
