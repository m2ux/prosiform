## Overview

A deferral is a link the compiler leaves for the reader to compile. Its published path named the target from the working directory `pf` was run in, and nothing in the bundle names that directory. This hot-fix publishes the path from the folder the bundle is written into, calculated at compile time, so the bundle alone states where its targets are.

## Problem

- **A deferral resolves only from a directory the bundle does not name.**
  On a deferred-composition specimen, 5 of 5 Haiku 5.5 runs looked for the target beside the bundle; 2 stopped on `E_TARGET_NOT_FOUND` and 3 found the source by searching the file system.

## Proposal

- **The compiler publishes a deferral's path from its bundle's folder.**
  `BundleFolder` holds the working directory and the run folder `<-o>/<run>.bundles/`, known before rendering; `rebased` publishes the target's path from that folder, its fragment, escaping, substitution and title tags as they were.
- **The guide runs a link from the bundle's folder.**
  "Compiling a link" reads "from the folder that bundle is in".
