**Component:** example/work-planner (SKILL.md, bootstrap.md, rules.md, conventions.md, guidelines.md, modes/), example/guidelines.md

## Overview

A mode is followed from its `pf` bundle. The skill's Rules and Conventions bind every mode, yet sit in `SKILL.md`, which no mode links. This row gives each its own file and links both from every mode's preamble, so every mode bundle carries them.

## Problem

- **No mode bundle carries Rules or Conventions.**
  Both are `SKILL.md` sections, and no mode links `SKILL.md`.
- **Each Procedure restates its Outcomes link.**
  `The main path meets [Outcomes](#outcomes).` opens every mode's Procedure.
- **The guidelines describe the previous structure.**
  They place Rules and Conventions in the entry point, require Prerequisites sections the tree no longer carries, and describe reading linked sections by hand.

## Proposal

- **`rules.md` and `conventions.md` beside `SKILL.md`.**
  Titled `# Rules` and `# Conventions`, frontmatter `prosiform: root: "."`; link destinations unchanged, since both sit in `SKILL.md`'s directory.
- **Every mode preamble closes with one sentence.**
  `Follow [Rules](../rules.md) and [Conventions](../conventions.md) and ensure all [Outcomes](#outcomes) are met.`
- **No Procedure opens with the Outcomes line.**
- **`bootstrap.md` beside `SKILL.md`.**
  `# Bootstrap`, body unchanged; the Modes section opens by linking it.
- **Guidelines restated to the structure; conflicting guidance removed.**

- **Two usage fixtures change.**
  The plan-mode and hoist-mode bundles gain `# Conventions`, `# Rules` and the `Allowance` subsection `rules.md` links; the section fixtures reach no mode.
- **The plan-mode fixture's deferred-link count rises to three.**
  `rules.md` carries a deferred link to `guidelines.md#modes`; the fixture description names three.
- **AC14 tension.**
  The preamble sentence and the guidelines' links to `rules.md` and `conventions.md` have no counterpart in the skill's copy, so those destinations differ from it at the same place.
