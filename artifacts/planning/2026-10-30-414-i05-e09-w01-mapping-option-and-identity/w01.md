**Component:** src/prosiform/closure.py

## Overview

The substitution mapping, the option that carries it, and the identity it matches on, with the three fixtures that show a redirected link, the exemption from the writing source's root, and a key naming an absent document. The mapping and the option are one change: a mapping nothing can be passed is unobservable, and an option with nowhere to put its pairs is unused.

## Problem

Resolution is reached through `inside`, `resolvable`, `bundled` and `withholding_target`, and each returns a `Reference` its caller reads directly. A mapping has nowhere to sit that a caller cannot bypass, and the grammar admits no option carrying a pair of references: `override`, the only value parser the command has, admits a positive decimal integer.

`entry` is a second path rather than a caller of the first. It normalizes a positional reference and `-f` through `resolve` directly, before any source is read, so a mapping threaded through `inside` alone would leave the command line's own references unredirected.

## Proposal

**The scene.** `cli.required` asks `inside` for each link in selected content, `bundle.target` asks `bundled` and `withholding_target` while rewriting the same link, `candidate` asks both again while comparing the emitted text, and `cli.entry` resolves a positional reference before any source is read. Four of those five are one question asked at different times.

**The design.**

- **One seam per resolution path.** The mapping is a parameter of `inside`, threaded through `resolvable`, `bundled` and `withholding_target` beside the `root` each already takes. `entry` normalizes a positional reference and `-f` through `resolve` directly, before any source is read, so it takes the mapping too. Both paths apply it in the same place: to the reference a caller authored, before the name of the file the run opens is decided.
- **The mapping is applied after the root check, not before.** `inside` holds a normalized path to `covers(root, path)` and raises `OutsideRoot` where it fails. A substitute is exempt from the writing source's root, so applying the mapping before that check would refuse every substitute kept beside the tree under test — which is the case the feature exists for. The mapping is applied to the reference `inside` returns, after the check has been made against the authored path, and to the reference `entry` returns after `resolve` has normalized it.
- **A mapping value.** An immutable type holding keys to references, offering one lookup: the exact `(path, fragment)` key first, then `(path, None)`. A lookup returns the substitute's `Reference` whole, so the resolved path, the fragment, the authored text and the carried access walk are the substitute's.
- **Both sides resolve from the invocation working directory.** Each passes through `resolve` with parent bootstrap permitted, as a positional entry does, so percent decoding, control-character refusal and `..` normalization are the grammar already there. Neither is held to the writing source's root.
- **The option.** `-m`, long form `--mock`, `action="append"`, metavar `ORIGINAL=ALTERNATIVE`. A local value parser splits on the first `=` and resolves each side through `entry`, so a malformed reference is reported with the diagnostic an entry already carries. The option takes a value, so `diagnostic_format` reads it as one.
- **The design's own option table names it.** `CLI contract` enumerates the options and each row is a clause `make conformance` reads, so the design gains a `-m ORIGINAL=ALTERNATIVE` row beside `-f DOC`. `invocation.md`'s row lands with W09, because `make invocation` holds that table to the help output in both directions and this row's help text cannot exist before the option does; the design's table is held to nothing but its own prose.
- **The carried walk is the substitute's.** `walk` becomes the substitute's authored path, so the no-follow walk, the bound root and the recheck read the file the parameter named.

## Fixtures

| Fixture | What its source tree and manifest declare |
| --- | --- |
| `fixtures/mock/a-mocked-dependency-is-compiled` | `guide.md` links `rules.md`, which holds `# Rules` and a sentence. The run is given `-m rules.md=stand-in.md`. Exit status `0`, and the bundle carries `guide.md`'s group then the substitute's, under a file heading naming `stand-in.md` rather than `rules.md`. The manifest declares no diagnostic: the substitution warning and its code are W04's, and the schema's warning catalogue cannot name a code before the row that emits it. |
| `fixtures/mock/a-substitute-outside-the-writing-root-is-reachable` | `guide.md` declares `prosiform.root: .` and links `rules.md`, and `stand-in.md` sits beside the source tree rather than inside it. The run is given `-m rules.md=../stand-in.md`. The substitute is reached although the writing source's root cannot contain its path, where the same tree without `-m` refuses the link with `E_TARGET_NOT_FOUND`, which `src/tests/test_mock.py` holds. |
| `fixtures/mock/a-key-naming-an-absent-document-is-substituted` | `guide.md` links `rules.md`, which the fixture does not hold. The run is given `-m rules.md=stub.md`. The substitute is compiled and the bundle published with exit status `0`, where the same tree without `-m` fails with `E_TARGET_NOT_FOUND`. This is what makes an artifact under authoring testable before it lands. |

## Additions from review

| Addition | What it states |
| --- | --- |
| `-m` is a value-taking option in `diagnostic_format` | The function reads the format from the command line before the grammar is checked, walking the value of every option that takes one. An option missing from that set leaves a `-d` written after it unread, so a run asked for JSON diagnostics would report prose. |
| The mapping is threaded past `comparable` stages | `bundle.target` and `candidate.intended` resolve a link a second and third time, so a parameter held only at discovery would emit the authored target and fail candidate validation against the mocked one. |
