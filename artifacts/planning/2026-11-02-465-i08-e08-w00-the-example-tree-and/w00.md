**Component:** main:Makefile

## Overview

The example tree and every check, target, fixture, test, drawing and document built on it are removed, after the annotated tag `archive/example-work-planner` is placed on the last commit holding `example/work-planner`, so the tree stays readable from git history and nothing the repository runs holds to it.

## Problem

The example tree is stale, unmaintained, and holds checks to it.

- **It copies a skill that has moved on.**
  `example/work-planner` is a snapshot nobody maintains, and `example/my-skill` exists only to draw the README's two diagrams.
- **Four targets read it alone.**
  `make steps`, `make authoring`, `make boundary` and `make mock-scenarios` read `example/work-planner` and nothing else, and `make check` names all four.
- **A fixture family and a test suite reach it.**
  Every `fixtures/usage-example/` case's `source` is a symbolic link into the tree, `src/tests/test_handoff_round_trip.py` copies it to compile its modes, and `checks/independence.py` admits its headings as contract names.
- **Documents name it.**
  `README.md`, `invocation.md`, `checks.md`, `checks/README.md`, `fixtures/README.md` and the `Makefile` header describe the tree or link into it, and `docs/images/compilation.*` and `docs/images/agent-rules.*` draw `example/my-skill`.

## Proposal

**The scene.** `make check` runs the step, authoring and boundary guards over `example/work-planner` ahead of `make test` and `make corpus`, which bundle it, and `make mock-scenarios` last.

**The design.**

- **The tag comes first.**
  The annotated tag `archive/example-work-planner` names `00f166920`, the epic base head and `main`, and the commit removing the tree is its child, so `git show archive/example-work-planner:example/work-planner/SKILL.md` reads the tree.
- **Everything built on the tree is removed.**
  `example/`, the `usage-example` fixtures, the drawings of `example/my-skill`, `checks/steps.py`, `checks/authoring.py`, `checks/boundary.py`, `checks/mock_scenarios.py` with their tests and targets, `test_check_order.py`, `test_handoff_round_trip.py`, and the example-heading admission in `checks/independence.py`.
- **`make examples` stays.**
  Each `scripts/examples.json` case writes its own sources inline and reads no file of the tree, so the target and the drawings it renders are not built on it.
- **The documented runs read the corpus.**
  The README and the invocation guide run their worked commands over fixture source trees, and the README's overview draws the `run` case.
- **Nothing is refused in its place.**
  A retired tree is removed, so no check or fixture asserts its absence.
