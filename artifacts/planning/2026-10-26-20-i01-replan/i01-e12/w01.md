## Overview

States parent-owned grouping in the contract before the build or the corpus changes, so the fixtures that follow cite a clause rather than a build's behaviour.

## Problem

The design's Grouping clauses, `invocation.md` and `docs/glossary.md` tell each file to declare the group it belongs to, and require every contributing file declaring one group to agree on its depth. A parent that writes the grouped links has no clause to state its rule under.

## Proposal

An author writes a mode that links its artifacts and its protocols, and wants each set grouped under its own heading. The contract states that the mode's group rules govern the composed results of the links it lists, that each linked file is composed before the mode merges it, and that a link the mode does not assign to a group stays the mode's own content. The member-declared rule and the depth-agreement fault it needs leave all three documents together, and the fault code goes with them where no other rule raises it.

## Work Breakdown

| Part | Description |

| Review | A search of the three documents for any surviving member-declared statement |
| Test | The repository's link and vocabulary checks over the changed documents |
