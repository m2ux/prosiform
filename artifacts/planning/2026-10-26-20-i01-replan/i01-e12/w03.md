**Component:** example/work-planner

## Overview

Moves the worked example's group declarations onto the files that write the grouped links, so the example demonstrates the contract it documents.

## Problem

Each artifact, protocol and reference under `example/work-planner` declares the group it belongs to, while the modes that link them, and that name those inclusions in their bundles, declare none.

## Proposal

A reader opens a mode and finds the group rules for its artifact and protocol links in that mode's own metadata, while the artifacts it links carry none. The usage fixtures recording each mode bundle are regenerated against the regrouped tree, and each mode still bundles within the default output budget.

## Work Breakdown

| Part | Description |
| --- | --- |
| Analysis | Every group declaration in the tree, and the file that writes each grouped link |
| Plan | The group rules each linking file declares |
| Implementation | The declarations moved, and the usage fixtures and README excerpts regenerated |
| Review | A search of the tree for a group declared on a file that writes none of the grouped links |
| Test | `make corpus`, each mode bundle's byte count against the default budget, and the round-trip suite |
