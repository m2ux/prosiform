**Component:** src/prosiform/bundle.py

## Overview

Builds parent-owned grouping: each linked file is composed first, and the file that lists it merges that result under the group it names.

## Problem

The group pass reads `group` from every opened file and places those files together in one pass, so an intermediate file's group becomes another top-level heading rather than wrapping the files that intermediate file links.

## Proposal

A mode links three artifacts, one of which links a protocol of its own. The build composes the artifact with its protocol inside it, then merges the three artifacts under the group the mode names, so the protocol sits within the artifact's result rather than beside the mode. Grouping fixtures state a two-level and a three-level arrangement and a link the parent leaves ungrouped, each citing the clause the design states.
