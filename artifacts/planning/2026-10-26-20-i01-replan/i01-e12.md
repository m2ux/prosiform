## Overview

Grouping belongs to the file that writes the links. That file's group rules merge the composed results of the links it lists, and a linked file is composed before its parent merges it, so an intermediate file's groups sit inside the result its parent merges. This epic states that rule in the design, builds it, and moves the worked example's group declarations onto the files that write the grouped links.

## Problem

A linked file declares a group for a section it does not contain, and one run places every reached file's group together as a peer of the entry.

- **A leaf declares a group its parent names.**
  Each artifact under `example/work-planner/artifacts` declares `group: "artifacts"` and `group-depth: 1`. None of them holds an Artifacts heading; the mode that links them is the file that names that inclusion.

- **Assembly places every opened file in one pass.**
  The group pass reads `group` from every opened file and places those files together, so an intermediate file's group becomes another top-level heading rather than wrapping the files that intermediate file links.

- **The contract states the member-declared model.**
  The invocation guide tells each file to declare its own group, and contributing files declaring one group must agree on its depth, so the rule a parent would state is spread across every member.

## Proposal

- **The file that writes a link owns the group rules for it.**
  Its group names and depths apply to the direct links it lists, after each of those files has been composed. The included file declares no group it belongs to.

- **Composition finishes the child, then the parent merges that result.**
  A grandchild is already inside the child's result. A link the parent does not list in a group remains content of the parent.

- **A parent can name more than one group.**
  It can link more than one section, so a mode can group its artifact links and its protocol links separately.

- **A group rule names a heading of the file that declares it.**
  The links written under that heading join that group, so the assignment reads from the structure the author already writes and adds no list to keep in step with the body.

- **The design changes first.**
  The Grouping clauses, the invocation guide and the glossary state the parent-owned rule before the build or the corpus changes.

- **Root resolution is unchanged.**
  A source's root resolves as the design states it today; this epic moves grouping alone.
