**Component:** src/prosiform/closure.py

## Overview

A substitution mapping that resolution applies, so every stage that asks what a reference names receives the substitute and no stage carries a rule of its own.

## Problem

Resolution is reached through five helpers — `inside`, `resolvable`, `bundled`, `withholding_target` and the entry normalizer — and each returns a `Reference` the caller reads directly. A mapping has nowhere to sit that a caller cannot bypass, and a stage that applied it while another did not would compile one document and point the link at another.

## Proposal

**The scene.** `cli.required` asks `inside` for each link in selected content and yields what it returns. `bundle.target` asks `bundled` and `withholding_target` while rewriting the same link, `candidate` asks both again while comparing the emitted text, and `cli.entry` resolves a positional reference before any source is read. Four of those five are the same question asked at different times.

**The design.**

- **One seam.** The mapping is a parameter of `inside`, threaded through `resolvable`, `bundled` and `withholding_target` beside the `root` each already takes. Application happens immediately after normalization and before the Markdown-suffix test, so `is_markdown` is asked of the substitute rather than the key.
- **A mapping type.** An immutable value holding keys to references. It offers one lookup: the exact `(path, fragment)` key first, then `(path, None)`. What a lookup returns is the substitute's `Reference`, taken whole, so the resolved path and fragment are the substitute's.
- **Keys and values resolve from the invocation working directory.** Both pass through `resolve` with parent bootstrap permitted, exactly as a positional entry does, so percent decoding, control-character refusal, `..` normalization and drive-path refusal are the grammar already there. Neither is held to the writing source's root, because the parameter named the document rather than the source.
- **A substitute is a reference, not a redirect.** Returning it whole is what makes the redirect total: the caller's existing code reads `found.path` and `found.fragment`, and both are the substitute's.
- **Matching is by identity.** `identity(reference)` already joins a path and fragment into the name two spellings share, so a lookup is a dictionary read against it.
- **The carried walk is the substitute's.** `walk` names the authored access path a read opens by, so it becomes the substitute's authored path. The no-follow policy, the bound root and the recheck are unchanged: the run reads a file it was told about, at a path it verified.
