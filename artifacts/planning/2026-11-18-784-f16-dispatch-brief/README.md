# Dispatch Brief — November 2026

> Hot-fix · Created 2026-11-18

## Executive Summary

A dispatching document that must tell its agent what a target asks of it restates the target's own section beside each dispatch, with a composition link that lands after the section's content and so may follow the dispatch it should govern, and nothing ties the restatement to the dispatch.

The fix lets a target's preset declare a brief: a section of the target, compiled into the dispatching bundle as a composition and placed in a sub-section lifted from the dispatch, ahead of the dispatch link, so the dispatching agent reads it before it hands the bundle on.
