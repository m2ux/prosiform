**Component:** main:src/prosiform/cli.py

## Overview

A document reached by a link is governed by its own presets whose names appear as whole words in the title of the section holding the link, layered above its `default`, and a command-line entry reads the presets of the file it names against that file's own title or the section it names. Until now `default` alone placed a document, so a preset other than `default` stated settings no run read.

## Problem

Every reader of a document's settings reads `default`.

- **Placement reads one preset.** `cli.group_depths`, the member-heading warning in `cli.coincident` and the merged-group arrangement in `cli.assembled` each read `conversion.default.memberships`, so a named preset's `group-depth` pairs place nothing.
- **A reference does not know its section.** `source.uses` yields a use with its line and opening, and `cli.required` builds the reference from it, so the title of the section the link sits in is lost before the target is read.
- **An entry is written in no section.** A positional `guide.md` or `guide.md#checks` has no containing heading, so the title it selects by has to come from the file it names.
- **The conflict names the wrong preset.** `E_GROUP_DEPTH_CONFLICT` names `prosiform.default` whatever preset stated the pair.

## Proposal

**The scene.** `traverse` collects every reference the run carries, `contributing` groups them by the document they reach, and `compose` builds the bundle, reading each document's placement in `group_depths`, `assembled` and `coincident`.

**The design.**

- **A use carries its section title.** `source.uses` reads the heading rooting the section each use sits in — the nearest document-level heading at or above its line — and yields it as `Use.title`. A heading a container carries roots no section, and a use in the preamble has no title. `cli.required` copies it onto `Reference.title`.
- **An entry reads its own file.** `cli.entry_title` gives a section entry the text of the heading it names, and a whole-document entry the document's title, absent where it carries none.
- **Keywords are whole words, case-insensitive.** `cli.keyworded` compares a preset name and a title casefolded, each end of the match meeting the edge of the title or a character that is neither a letter nor a digit, so `checks` appears in `Checks and Draft` and not in `Checklist`. `cli.keywords` returns the declared presets a title selects, never `default`.
- **`default` is beneath every selection.** `cli.pairs` gives `default`'s `group-depth` pairs, but those for a group a selected preset also pairs, followed by the selected presets' pairs.
- **Placement reads the pairs in force.** `cli.joined` maps each document to the pairs every reference reaching it put in force, once each, and `group_depths`, `assembled` and `coincident` read that map.
- **The conflict names the preset.** `Membership` carries the preset stating it, and `E_GROUP_DEPTH_CONFLICT` names it on both sides.
- **Stale statements go.** The invocation, the source page and the hierarchy page state selection above `default` where they said `default` alone placed a document.

## Scope

- **`path-sub` and `exclude` take no effect here.** Substitution from a preset is [I08:E06](https://github.com/m2ux/prosiform/issues/461)'s and the carve [I08:E02](https://github.com/m2ux/prosiform/issues/445)'s; `group-depth` is the setting a run reads, so it is what the fixtures observe selection by.
- **Union and its refusals are W05's.** Two selected presets pairing one group at two depths raise `E_GROUP_DEPTH_CONFLICT` naming both presets until W05 refuses them as invalid usage.
- **One document under two selections is AC8's.** The traversal records the first reference to each document and section, so a second reference from another section adds no selection.
