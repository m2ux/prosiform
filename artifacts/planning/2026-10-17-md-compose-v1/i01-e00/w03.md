## Overview

The record of each composition run, and the declared set of sources the stage must exercise.

## Problem

A ledger holding only surprises cannot show whether the tool was used, so a condition counting recorded findings is satisfied by a ledger nobody wrote in.

## Proposal

Each composition run is recorded with the source identities it composed and its outcome, and a surprise entry cites the run it came from. Alongside it, an exposure set names the real sources the tool must have composed before the specification can be called settled. The set is declared at the start of the stage, so it is a target to work toward rather than a figure chosen once the work is done.

## Work Breakdown

| Part | Description |
| --- | --- |
| Analysis | What a run record must hold for exposure to be countable, and which real sources belong in the set |
| Plan | The run record's fields, the exposure set's declaration and where each lives |
| Implementation | The run record, its schema check and the declared set |
| Review | The set confirmed to name real sources rather than fixtures, and the record confirmed to cover successful runs as well as failures |
| Test | The schema check rejects a run record missing each required field in turn, and a surprise entry citing no run |
