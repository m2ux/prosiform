## Overview

The gate report and the route decision it records for any failed gate.

## Problem

Three recorded runs are evidence, and nothing yet states what they mean for the production build.

## Proposal

The report states, per gate, whether the pinned parser's public interface satisfies it, citing the recorded run that establishes the answer. A gate the parser fails carries a decision naming the route taken among parser-aware occurrence collection, narrowly scoped instrumentation, a different parser candidate and a separate upstream proposal, with the reasoning for it. The report is an artifact of the planning record.

| Part | Description |
| --- | --- |
| Analysis | The three recorded runs read against the design's gate conditions |

| Implementation | The report and the recorded decisions |

| Test | The report's cited runs are reproduced, and each failed gate is confirmed to carry a route decision |
