## Overview

What a file group emits: the order its regions appear in, and the source title its file heading absorbs.

## Problem

A file heading names the document, and 37 of this workspace's 38 skill documents open with an H1 restating that same name, so emitting both puts the name twice at the head of almost every group and twice in every destination into it. The one document whose H1 differs carries a title the path does not, so dropping every H1 would lose it.

Separately, nothing states the order a file group's regions appear in. Selections arrive in discovery order, and emitting them that way would break outline reconstruction and the bytes the composite promises for one selection.

## Proposal

A file heading absorbs the source's first heading when that heading is the document's only H1 and its slug equals the final segment of the file heading's path. An absorbed title is not emitted, contributes no destination segment and is not a target. Its group keeps its source heading levels, the file heading having taken the level the shift makes room for. A source whose H1 differs keeps it and shifts by one as usual.

A file group emits its selected regions and structural ancestors in their original source order, so a document's preamble sits after its file heading and before its first retained heading.
