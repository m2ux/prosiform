## Overview

Resource budgets that fail at the first boundary crossed.

## Problem

Without enforced budgets, a pathological source tree is discovered by exhausting memory rather than by a diagnostic.

## Proposal

Each limit the profile names is counted as the design states: distinct source identities opened, raw bytes per source, summed raw bytes, complete composite bytes, distinct targets discovered, authored link occurrences in selected content, and syntactic container nesting. Crossing one fails the compilation with no output and no truncation. A positive decimal override is accepted and zero is refused. Nesting is enforced as an explicit failure rather than left to a parser option.

## Work Breakdown

| Part | Description |
| --- | --- |
| Analysis | The counting rule for each limit and where in the pipeline it is known |
| Plan | The counters, their placement and the override parsing |
| Implementation | The limits, their failures and their overrides |
| Review | Confirmed that no limit truncates and that parsing-safety limits apply to the complete opened source |
| Test | Corpus fixtures crossing each limit at its first boundary, a zero override, a negative override, and over-deep nesting that must not be reinterpreted |
