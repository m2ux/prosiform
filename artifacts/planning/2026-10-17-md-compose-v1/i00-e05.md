## Overview

Destination identity makes the composite navigable. Every included document and section takes one generated identifier derived from its source identity, every rewritten reference points at exactly one of them, resolved reference-style links become inline links with their definitions removed, and relative resource references are rebased for the output destination or fail.

## Problem

Links that resolved in their source documents resolve to nothing, or to the wrong thing, once those documents are one document.

- **Fragments collide across files.**
  Two source documents can each hold a section whose heading produces the same fragment, so a composite carrying both has two destinations with one name.

- **A definition has file scope and the composite has none.**
  A reference-style link resolves against its own document's definitions, so moving the use without its definition breaks it, and moving every definition into one document makes labels from different files compete.

- **An unresolved bracket is not a link.**
  Text that one document leaves as literal brackets would become a link if another document's definition were in scope, which changes what the source said.

- **A custom anchor is a second name for a section.**
  An anchor preceding a heading and that heading's own fragment are aliases, and treating them as two destinations splits one section in two.

- **A relative resource path is relative to its source.**
  An image path that resolved from its source directory resolves from somewhere else once the content is published at a different location.

## Proposal

- **Destinations carry a reserved namespace.**
  A generated identifier combines a readable path slug, a readable target slug and a digest over the root-relative path, the target kind and the canonical source fragment. Collisions fail explicitly rather than relying on digest uniqueness.

- **Aliases resolve to one canonical section.**
  A supported empty anchor immediately preceding an eligible heading and that heading's own fragment select the same section and rewrite to one destination. The original anchor node is removed and the qualified anchor is emitted at the heading. An anchor at an unsupported position fails as a target.

- **References resolve in their own source.**
  Reference-style uses are resolved against their own document's definition environment, converted to inline form with visible content and titles preserved, and every original definition node is removed, unused definitions included.

- **Literal brackets stay literal.**
  Text a source parser did not resolve as a link is emitted as literal text and cannot acquire a destination from another document's definitions.

- **Resources are rebased or fail.**
  Relative resource references are recomputed for the output destination, or mapped under an explicit resource base for standard output. A reference that cannot be rebased safely fails rather than acquiring an invented destination.

## Acceptance Criteria

- [ ] **AC1.** A supported empty anchor immediately preceding an eligible heading selects the same section as that heading's own fragment and rewrites to the same destination, as the alias fixtures show.
- [ ] **AC2.** An anchor at an unsupported position fails as a target with its declared error code, as the anchor-target fixtures show.
- [ ] **AC3.** Each included document and section carries one reserved-namespace destination derived from its root-relative path, its target kind and its canonical source fragment, occurring once in the composite, as the destination fixtures show.
- [ ] **AC4.** Two distinct source identities producing the same destination identifier fail with the declared collision error code, as the collision fixtures show.
- [ ] **AC5.** A resolved reference-style link or image in selected content is published inline with its visible content and title preserved, and no original definition node is present, as the reference fixtures show.
- [ ] **AC6.** Bracketed text a source parser left unresolved is published as literal text, as the literal-bracket fixtures show.
- [ ] **AC7.** A relative resource reference is rebased for the selected output destination, or fails with its declared error code when no safe rebasing exists, as the resource fixtures show.
