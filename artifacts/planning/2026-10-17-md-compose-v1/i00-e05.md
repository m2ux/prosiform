## Overview

Destination identity makes the composite navigable by name. Every included document and section takes a destination that is its root-relative path followed by the slugs of its ancestors and itself, every rewritten reference points at one, resolved reference-style links become inline links with their definitions removed, and relative resource references are rebased or fail.

## Problem

Links that resolved in their source documents resolve to nothing once those documents are one document.

- **A heading slug is not unique across files.**
  Two documents can each hold a section whose heading produces the same slug, so a name derived from heading text alone cannot tell them apart.

- **A definition has file scope and the composite has none.**
  A reference-style link resolves against its own document's definitions, so moving the use without its definition breaks it, and moving every definition into one document makes labels from different files compete.

- **An unresolved bracket is not a link.**
  Text one document leaves as literal brackets would become a link if another document's definition were in scope, which changes what the source said.

- **A relative resource path is relative to its source.**
  An image path that resolved from its source directory resolves from somewhere else once the content is published at a different location.

## Proposal

- **A destination is a path through the composite.**
  The root-relative document path, then the source-heading slug of each eligible ancestor, then the section's own slug. A whole-document destination is the path alone.

- **Uniqueness comes from the structure.**
  Two destinations coincide only when file, ancestor chain and slug all coincide, which means duplicate siblings. Those are refused as ambiguous, so there is no digest, no counter and no collision check to get right.

- **Every internal link points at its destination.**
  A local Markdown link and a fragment-only link in selected content are rewritten through the same map that produced the destination. A composite whose destinations are right and whose links still name source paths is the failure this guards against.

- **Nothing is emitted at a destination.**
  The composite carries Markdown and nothing else. A destination names a place in the document; it is not an element in it.

- **References resolve in their own source.**
  Reference-style uses are resolved against their own document's definition environment, converted to inline form with visible content and titles preserved, and every original definition node is removed, unused definitions included.

- **Literal brackets stay literal.**
  Text a source parser did not resolve as a link is emitted as literal text and cannot acquire a destination from another document's definitions.

- **Resources are rebased or fail.**
  Relative resource references are recomputed for the output destination, or mapped under an explicit resource base. A reference that cannot be rebased safely fails rather than acquiring an invented destination.

## Acceptance Criteria

- [ ] **AC1.** Each included document and section carries a destination formed from its root-relative path and the source-heading slugs of its ancestors and itself, as the destination fixtures show.
- [ ] **AC2.** Two headings in one source sharing an ancestor chain and a slug fail as ambiguous when a link requires one of them, as the ambiguity fixtures show.
- [ ] **AC3.** Each local Markdown link and fragment-only link in selected content is rewritten to the destination of the target it resolved to, as the rewriting fixtures show.
- [ ] **AC4.** A resolved reference-style link or image in selected content is published inline with its visible content and title preserved, and no original definition node is present, as the reference fixtures show.
- [ ] **AC5.** Bracketed text a source parser left unresolved is published as literal text, as the literal-bracket fixtures show.
- [ ] **AC6.** A relative resource reference is rebased for the selected output destination, or fails with its declared error code when no safe rebasing exists, as the resource fixtures show.
