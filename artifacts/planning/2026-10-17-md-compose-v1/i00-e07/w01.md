## Overview

Installation of the build and the entry point callers depend on.

## Problem

The command runs only from a checkout, so every caller resolves the build's location for itself.

## Proposal

The build is packaged so it installs into an environment and exposes one documented command name. The entry point is resolvable without knowing where the repository sits, and reports its version and profile identifier.

## Work Breakdown

| Part | Description |
| --- | --- |
| Analysis | How callers in this workspace resolve a tool, and what an entry point must satisfy to be one of them |
| Plan | The packaging, the entry point name and the version reporting |
| Implementation | The package metadata and the entry point |
| Review | The entry point confirmed resolvable from a directory unrelated to the repository |
| Test | An installation smoke run composes a reference from a source root and reports the profile identifier |
