## Overview

The mapping from each behavioural clause of the design to the fixtures exercising it.

## Problem

Fixtures accumulate alongside the work that needed them, so a clause nobody implemented has no fixture and no record that it has none.

## Proposal

Clauses are identified in the design and each carries the identifiers of the fixtures that exercise it. The mapping is generated from the design and the corpus rather than maintained by hand, and the report lists clauses with no fixture in an uncovered section rather than omitting them.

## Work Breakdown

| Part | Description |
| --- | --- |
| Analysis | How a behavioural clause is identified in the design and referenced stably |
| Plan | The clause identification, the mapping source and the report sections |
| Implementation | The generator and the report |
| Review | A sample of clauses traced by hand against the generated mapping |
| Test | The report run against a deliberately unfixtured clause lists it as uncovered, and the generated mapping is reproduced on a second run |
