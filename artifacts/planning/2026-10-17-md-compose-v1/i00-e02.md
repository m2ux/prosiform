## Overview

The walking skeleton is the smallest prosiform that works end to end: a command that takes a source root and a whole-document reference, reads and parses the document under the declared profile, strips its transport metadata, and publishes one bundle under a heading naming the source file. It carries no dependency traversal and no link rewriting, so the epics after it extend a product that already runs.

## Problem

Nothing executable exists, so every later behaviour has nowhere to attach.

- **The declared profile is a list of options, not a configuration.**
  CommonMark with pipe tables, strikethrough and preserved task markers, with typographic substitution disabled, is stated as a requirement and configured nowhere.

- **Transport metadata reaches bundled content.**
  A leading byte-order mark and leading frontmatter are source transport, not instructions, and would otherwise be published as body text.

- **Success and failure share one stream.**
  Without a declared split, a bundle and the diagnostics explaining a failure arrive together, and a consumer cannot tell a published document from an error report.

- **An exit status carries the only reliable signal.**
  A caller that reads the presence of Markdown as success accepts a truncated or failed run as a complete one.

## Proposal

- **One command, two streams.**
  Bundled Markdown goes to standard output and diagnostics to standard error. Success output holds the bundle and nothing else.

- **The profile is configured explicitly.**
  `markdown-it-py` is configured to the declared profile rather than inheriting a default or an everything-enabled preset, and the configuration is pinned with the profile identifier.

- **Raw HTML is refused, not copied.**
  The bundle carries Markdown and nothing else, so a source with raw HTML in selected content fails rather than passing elements and identifiers the tool neither created nor tracks into the output.

- **An unsupported construct fails rather than becoming prose.**
  Footnotes, wiki links, heading-attribute syntax and transclusion directives are outside the profile. One recognized as a dependency or a section-naming construct in selected content fails the run, because publishing it as literal text would drop a dependency without reporting it. Ordinary prose that merely resembles an extension is left alone.

- **Source encoding is required, not assumed.**
  A source must be valid UTF-8. One that is not fails, rather than being decoded with replacements that change the bytes the tool promises to preserve.

- **Transport metadata is removed by delimiter scanning.**
  One optional leading byte-order mark, then an exactly matching frontmatter opener and closer, are stripped without parsing the metadata. Original source coordinates survive for diagnostics.

- **Each source becomes a file group.**
  Its content is published beneath one generated heading carrying its normalized root-relative path, Markdown extension removed, as escaped literal text, and its own headings move down one level.

- **Real skill documents are fixtures.**
  Documents taken unmodified from this workspace's skills are corpus inputs, so the claim that ordinary Markdown bundles is tested against ordinary Markdown.

## Acceptance Criteria

- [ ] **AC1.** A whole-document reference produces one bundle whose source headings sit beneath a generated heading carrying the document's normalized root-relative path without its Markdown extension, as literal text, as the skeleton fixtures show.
- [ ] **AC2.** One leading byte-order mark and one leading frontmatter block are absent from bundled content while the body that follows them is unchanged, as the frontmatter fixtures show.
- [ ] **AC3.** A successful run writes the bundle to standard output and nothing else to that stream, as the stream fixtures show.
- [ ] **AC4.** The command returns the declared exit status for each outcome the design names, as the exit-status fixtures show.
- [ ] **AC5.** Typographic substitution is absent and source task-list markers survive bundling, as the profile fixtures show.
- [ ] **AC6.** A document taken unmodified from a workspace skill bundles with no added markup, as the real-source fixtures show.
- [ ] **AC7.** A construct recognized as an unsupported dependency or section-naming extension in selected content fails the run, as the unsupported-syntax fixtures show.
- [ ] **AC8.** A source that is not valid UTF-8 fails rather than being decoded with replacements, as the encoding fixtures show.
- [ ] **AC9.** Raw HTML in selected content fails rather than being copied into the bundle, as the HTML fixtures show.
- [ ] **AC10.** A filesystem path written as ordinary prose, rather than as a link, is left as text and resolved as no dependency, as the bare-text fixtures show.
