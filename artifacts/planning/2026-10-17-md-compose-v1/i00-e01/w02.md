## Overview

The runner that executes one fixture and decides its result from the manifest alone.

## Problem

A declared fixture produces no verdict, and a comparison that reports only a mismatch does not locate it.

## Proposal

The runner reads a manifest, invokes the build named by configuration against the fixture's source tree, and compares standard output, exit status and diagnostics against the declaration. A mismatch reports which expectation differed and the differing region. The runner holds no knowledge of any implementation's modules, flags or internal wording.

## Work Breakdown

| Part | Description |
| --- | --- |
| Analysis | The comparison each expectation kind needs, and how a difference is located |
| Plan | The runner interface, its configuration of the build under test, and its result shape |
| Implementation | The runner, its comparison and its difference reporting |
| Review | The runner read for any implementation-specific assumption |
| Test | Unit tests covering a passing fixture, a mismatch in each expectation kind, and the reported differing region |
