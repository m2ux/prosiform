## Overview

The rewriting of every internal link to the destination of the target it resolved to.

## Problem

A composite whose destinations are correct and whose links still name source paths is a document whose links go nowhere.

Every local Markdown link in the composed content pointed at a separate file. That file's content is now in the same document, so the link has to become a reference to the place it occupies here. A fragment-only link is the same problem within one source.

## Proposal

Each local Markdown link and each fragment-only link in selected content is rewritten to the destination of the target it resolved to, through the same map that produced that destination. After rewriting, no link in the composite names a source path.

The rewrite is the point of the composition: an outbound reference becomes a reference inside the document the reader already holds, so the content it names is present rather than fetched.

## Work Breakdown

| Part | Description |
| --- | --- |
| Analysis | The link kinds that carry a local destination, and where each resolved |
| Plan | The map lookup, the rewrite, and the check that no source path survives |
| Implementation | The rewriting and its application to the emitted content |
| Review | Confirmed that every rewritten link names a destination the composite defines |
| Test | Corpus fixtures covering cross-file links, fragment-only links, a link to a whole document, and a composite asserted to contain no link naming a source path |
