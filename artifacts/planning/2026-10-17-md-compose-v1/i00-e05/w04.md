## Overview

Rebasing of relative resource references for the selected output destination.

## Problem

An image path that resolved from its source directory resolves from somewhere else once the content is published at a different location.

## Proposal

For file output, resource URLs are computed relative to the destination's directory, and an output that would overwrite an input source is refused. For standard output with a resource base, the base must be an HTTPS directory URL ending in a slash with no credentials, query or fragment, and the percent-encoded source-root-relative resource path is appended while the reference's own query or fragment is preserved. A resource outside the source root has no mapping and fails. A resource base with a real output file is refused. Standard output without a base leaves references unchanged and warns.
