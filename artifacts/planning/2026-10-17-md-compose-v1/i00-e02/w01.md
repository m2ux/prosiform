## Overview

The command interface: its options, its two output streams and its exit statuses.

## Problem

Nothing executable exists, and without a declared split between bundled output and diagnostics a consumer cannot tell a published document from an error report.

## Proposal

One command takes the source root, the referring document, the output destination, the validation-only mode, the resource base and the diagnostic format. Bundled Markdown goes to standard output and diagnostics to standard error. Each outcome the design names returns its declared exit status.

## Work Breakdown

| Part | Description |
| --- | --- |
| Analysis | The option set, its defaults and the outcome-to-status mapping the design declares |
| Plan | The argument parsing, the stream discipline and the status codes |
| Implementation | The command, its options, its streams and its statuses |
| Review | Each declared option and status present and no undeclared one added |
| Test | Corpus fixtures asserting the stream split, each exit status, and usage failure on an invalid option combination |
