## Overview

The plus-one heading shift, including conversion of Setext headings.

## Problem

A Setext heading has no prefix to edit, so a uniform level shift cannot be applied by the same means as an ATX heading.

## Proposal

Every emitted source heading moves down exactly one level, inside retained containers included, preserving visible text and relative depth. A Setext heading becomes the equivalent ATX heading with its visible text and inline semantics unchanged, multiline source forms included. Containers keep their structure, and heading-like text inside code is untouched.

## Work Breakdown

| Part | Description |
| --- | --- |
| Analysis | The source forms a heading can take and what each shift must preserve |

| Test | Corpus fixtures covering H1 to H5 shifts, Setext and multiline conversion, headings inside containers, and unchanged heading-like code |
