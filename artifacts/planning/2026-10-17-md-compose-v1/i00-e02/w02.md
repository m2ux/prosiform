## Overview

The declared Markdown profile, configured explicitly, and the parse it produces.

## Problem

A default parser configuration is not the declared profile, and the difference changes whether a construct is a table, a strikethrough, a task marker or ordinary text.

## Proposal

`markdown-it-py` is configured to the profile: pipe tables and strikethrough enabled, source task-list markers preserved without checkbox generation, typographic substitution disabled, and unsupported extensions off. The configuration carries the profile identifier the version option reports.

## Work Breakdown

| Part | Description |
| --- | --- |
| Analysis | The parser's plugin and option surface against the profile the design declares |
| Plan | The explicit option set, the profile identifier and where it is reported |
| Implementation | The configuration and the parse it drives |
| Review | Each profile clause traced to the option that enforces it |
| Test | Corpus fixtures asserting preserved task markers, absent typographic substitution, and an unsupported extension construct left as ordinary text |
