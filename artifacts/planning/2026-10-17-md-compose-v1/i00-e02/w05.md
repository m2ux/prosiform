## Overview

Corpus fixtures built from documents taken unmodified from this workspace's skills.

## Problem

A claim that ordinary Markdown composes is untested while every fixture is written for the test.

## Proposal

Documents are copied from the workspace's skills into fixtures without alteration, and their expected composites are recorded. A document needing an edit to compose is a defect in the build or a gap in the design, not a reason to edit the document.

## Work Breakdown

| Part | Description |
| --- | --- |
| Analysis | The skill documents whose constructs cover the profile most broadly |
| Plan | Which documents become fixtures and how their expected composites are produced |
| Implementation | The fixtures and their recorded expectations |
| Review | Each copied document confirmed byte-identical to its source |
| Test | The fixtures run in the corpus and pass without any source document being edited |
