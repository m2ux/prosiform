## Overview

Closure and budgets bring the production build from one document to a compiled dependency graph: reference normalization, root confinement without following symbolic links, recursive traversal to a fixed point, overlap consolidation, self- and ancestor-reference classification, and every resource limit the profile names. The corpus's closure and limit fixtures are what it is measured against.

## Problem

Confinement and termination are properties of the access path and the traversal, and neither survives being assumed.

- **A string check is not confinement.**
  A path validated before opening can still reach outside the root through a symbolic link resolved at open time.

- **A reference graph has cycles.**
  Instruction sets link back to one another, so a traversal without a fixed point repeats regions or does not terminate.

- **The same region arrives by several paths.**
  A section selected directly and again inside a later whole-document inclusion is one region.

- **An unbounded compilation fails late.**
  Without enforced budgets, a pathological tree is discovered by exhausting memory rather than by a diagnostic.

- **Parser nesting limits can reinterpret syntax.**
  A limit expressed only as a parser option can cause over-deep syntax to be read as something else rather than failing.

## Proposal

- **Access is rooted and no-follow.**
  Confinement is enforced by the access mechanism, and a platform unable to enforce it declares a narrower supported environment rather than weakening the policy.

- **Normalization follows the declared sequence.**
  Components split before decoding, escapes validate strictly, decoding happens once, and relative segments normalize against the proper base.

- **Traversal runs to a fixed point with consolidation.**
  Newly included content is traversed, and a larger region replaces the narrower selections inside it.

- **Identity decides self-reference.**
  Comparison happens after canonical path and fragment resolution, and link ownership is stored separately from inclusion so consolidation cannot change the classification.

- **Nesting fails explicitly.**
  The declared nesting limit is enforced as a failure of this build, not left to the parser's own reinterpretation.

## Acceptance Criteria

- [ ] **AC1.** A local Markdown reference carrying a query, an unsupported scheme or an unsupported path form fails with its declared error code, as the corpus's normalization fixtures show.
- [ ] **AC2.** A reference whose normalized path leaves the allowed root, or reaches a source through a symbolic link below it, fails with its declared error code, as the corpus's confinement fixtures show.
- [ ] **AC3.** A cyclic reference graph composes to a fixed point with each reachable region present once, as the corpus's cycle fixtures show.
- [ ] **AC4.** A selection contained within a larger selection is represented by the larger region alone, with that region's own references resolved, as the corpus's consolidation fixtures show.
- [ ] **AC5.** A link to the same canonical section fails as a direct self-reference while a link back to an including ancestor resolves to that ancestor's destination, as the corpus's self-reference fixtures show.
- [ ] **AC6.** Each limit the profile names fails the compilation at the first boundary it crosses, with nothing published and nothing truncated, as the corpus's limit fixtures show.
- [ ] **AC7.** Syntax exceeding the declared nesting limit fails rather than being read as different syntax, as the corpus's nesting fixtures show.
