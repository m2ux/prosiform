## Overview

The Python environment and the lockfile that pins what a checkout installs.

## Problem

The parser is decided and unpinned, so two checkouts can resolve different parser versions and disagree about what a document means.

## Proposal

A project definition declares the supported Python version and the build's dependencies, including the parser and the plugins the declared profile needs. A lockfile records the exact resolved versions, and a documented command creates an environment from it. A fresh checkout installing from the lockfile obtains those versions and no others.
