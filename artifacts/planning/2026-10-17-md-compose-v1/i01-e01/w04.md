## Overview

The procedure by which a skill's prerequisite section is removed and replaced by the invocation that bundles what it named, and the record that justifies each removal.

## Problem

A prerequisite section names whole documents, coarsely but completely, and the inline links inside a procedure name sections precisely but may not cover everything that list covered.

Removing a list before bundling demonstrably replaces it loses context the tool never supplies, and nothing would report the loss: the agent simply proceeds without material it used to be told to read.

Deleting the list and putting nothing in its place leaves the agent to decide for itself whether to read the linked documents or bundle them, which is the decision this work exists to remove.

## Proposal

A skill's prerequisite section is removed only once a recorded bundling run supplies the sources that section named. The removal record cites that run, so a later reader can see what justified it.

In the section's place the skill's own text names the invocation that bundles those sources. The instruction form is deliberate rather than permanent: it needs nothing built, and how reliably agents follow it is evidence for whether the bundling should later be performed by the harness instead of asked for in prose.

A source the section named and the bundling did not supply is a ledger entry, triaged like any other finding. The usual outcome is a missing inline link in the procedure that needed it, which is a change to the source; where the shortfall is the tool's, it becomes a design or build change under the ordinary revision order.

Removal proceeds one skill at a time, so a shortfall is found against one document rather than across all of them at once.

## Work Breakdown

| Part | Description |
| --- | --- |
| Analysis | For one skill, the sources its prerequisite sections name against the sources its runs reach |
| Plan | The removal procedure, the wording of the invocation that replaces a section, the removal record, and the triage of a shortfall |
| Implementation | The procedure, the record, the replacements, and the removals they justify |
| Review | Each removal confirmed to cite a run that supplied every source the section named, and to leave an invocation in the section's place |
| Test | A deliberately incomplete procedure produces a shortfall entry rather than a removal, and a complete one produces a removal citing its run |
