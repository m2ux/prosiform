## Overview

A reproducer recording whether reference-expansion suppression is observable.

## Problem

The inspected lookup returns nothing once its budget is zero, before definition lookup, so a reference the limit suppressed and brackets that were never a link arrive identically.

## Proposal

Sources drive reference-expansion suppression below the compositor's declared input and output limits, and the reproducer records whether the pinned parser's public interface makes the suppression observable and with what source span. A separate source exhausts the budget on its last valid reference with no later lookup, and is recorded as carrying no suppression. No parser resource protection is disabled to obtain a result.

## Work Breakdown

| Part | Description |
| --- | --- |
| Analysis | The expansion accounting and how to reach suppression within the compositor's own limits |
| Plan | The source set, including the exhausted-but-not-suppressed case, and the recording format |
| Implementation | The reproducer and its recorded run |
| Review | Confirmed that a broken-reference callback is not accepted as an exhaustion signal without evidence it fires for every suppressed lookup |
| Test | The reproducer runs against the pinned version and distinguishes the suppressed case from the exhausted-budget case |
