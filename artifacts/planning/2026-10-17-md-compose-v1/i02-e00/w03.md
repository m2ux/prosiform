## Overview

Execution of the upstream-reported offset-iterator behaviour against the pinned version.

## Problem

An offset-iterator defect on definition-bearing list items is reported upstream with a fix described on the project's main line, and which released version carries it has not been established here.

## Proposal

The reported reproducer, including its printable-character variant, is executed against the pinned version and against the version the tool would otherwise select. The result is recorded against the existing upstream report. No new report is opened.
