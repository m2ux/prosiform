## Overview

Deferral decisions for the entries that remain when the stage is judged settled.

## Problem

A single awkward finding can hold the stage open indefinitely, and without a deferral path one unresolved entry blocks the freeze regardless of its weight.

## Proposal

Each entry still open at the freeze is either resolved or deferred by an explicit decision naming what is deferred and why. A deferred entry stays in the ledger for the stage that takes it; it is not closed and it is not silently dropped.

## Work Breakdown

| Part | Description |
| --- | --- |
| Analysis | The entries still open and what each would cost to resolve |
| Plan | The deferral record and the decision put to the user for each entry |
| Implementation | The recorded deferrals |
| Review | Each deferral confirmed to name what is deferred and the reasoning for deferring it |
| Test | The status summary reports no entry that is neither resolved nor deferred |
