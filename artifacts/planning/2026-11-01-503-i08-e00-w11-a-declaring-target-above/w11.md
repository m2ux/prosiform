**Component:** src/prosiform/closure.py

## Overview

Compiles an authored link naming a declaring document above the invocation working directory, so the target's declaration alone decides whether a link is compiled, wherever the target sits.

## Problem

`closure.inside` refuses an authored link that normalizes above the working directory with `OutsideRoot`, and discovery catches the refusal and emits the link as authored without probing the target. Run from `skills/plan/`, a link in `guide.md` to a declaring `../shared/conventions.md` is published as text, so the bundle silently omits material its author declared. The pinned design bounds only positional entries and the paths diagnostics name by the working directory; nothing confines an authored link to it.

## Proposal

An author runs `pf guide.md` from `skills/plan/`, and `guide.md` links `../shared/conventions.md`, which declares `prosiform`. The bundle carries the conventions and the link points at their heading.

- **Normalization keeps leading parents.** `closure.normalized` keeps the leading parent segments of any path that climbs above its base's root, so an authored link and a positional entry share one grammar and `resolve` takes no parent switch.
- **Classification asks the target.** `closure.inside` returns the path above the working directory; the probe answers whether it declares, and the bounded no-follow walk from the working directory opens it, the access a positional entry already takes. A drive path and a root-relative path stay refused as `OutsideRoot`.
- **The boundary holds a path above.** `closure.boundary` spells a boundary above the working directory with leading parent segments; where named paths climb different distances, the boundary is the directory the furthest climb reaches. `checks/boundary.py` holds a path to such a boundary by its climb.
- **Fixtures expect the declared outcome.** The citation, normalization, diagram-click, traversal, deferral and dispatch fixtures that cite a document above the working directory cite one that declares nothing; the Revise usage example compiles the shared guidelines, which declare; a new inclusion fixture observes the declaring target compiled.
