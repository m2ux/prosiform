## Overview

The contract defines compilation from one file argument.

## Problem

Root and output choices require caller-supplied options.

## Proposal

Specify the top-level prosiform mapping with full root, group and group-depth keys, string root/group values and integer depth. Specify file-relative explicit roots and invocation-working-directory defaults for every absent root, including linked files. Define bounded bootstrap capture, per-source link resolution and confinement, deterministic shared-file resolution, normalized entry filenames, fragment suffixes, combined destinations and the file-owned root interface. Preserve pf and short operational flags. Define invalid-root and source-access diagnostics and retain atomic publication.
