**Component:** src/prosiform/cli.py

## Overview

An omitted root resolves from the parent that reached the file. An entry has no parent, so its omitted root is the invocation working directory. A declared root still resolves from the file that writes it.

## Problem

An omitted `prosiform.root` resolves from the invocation working directory on a linked file as well as on an entry. A nested file that shares its parent's root writes a climb to name that directory.

## Proposal

The scene is a chain of files. The entry omits its root. A linked file omits its root and links a further file that also omits its root.

- The entry's links resolve from the invocation working directory.
- The linked file's links resolve from the entry's effective root, and the further file's links resolve from that same root.
- A file that declares `prosiform.root` resolves that value from its own directory. The parent's root does not replace it.
