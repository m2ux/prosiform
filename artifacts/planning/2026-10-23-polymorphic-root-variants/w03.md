**Component:** invocation.md

## Overview

Authors read one root rule. A linked file that omits `prosiform.root` uses the effective root of the parent that reached it, and a file reached under two roots is emitted once for each.

## Problem

The invocation guide, the glossary, and the fixtures note say an omitted root uses the invocation working directory for every file. Group and group-depth are already per file, and the root rule is the sentence that disagrees with the planned resolution.

## Proposal

The scene is an author choosing whether to write `prosiform.root`.

- The invocation guide states the entry case, the linked omission, the declared root, and one emission per distinct reaching root.
- The glossary root row and the fixtures root sentence state that same rule.
- Group and group-depth remain the file's own declarations when the reaching parent declares different ones.
