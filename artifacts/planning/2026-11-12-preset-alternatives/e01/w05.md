## Overview

An agent-pick workflow puts the pick in front of a headless agent: a workflow reaches a kind router through a `?` link, the session compiles it with `pf`, reads the alternatives, and continues with the one its inputs call for. The eval scores the path, so a session that picks the wrong kind or reads a source fails.

## Problem

- **No agent makes a pick.**
  The router fixtures show `pf` printing the listing and each pick's bundle, and the bare-command test shows the guide stating `?`; neither shows an agent resolving one.

## Proposal

**The scene.** The diagram-following eval's `compiled` form gives a session the entry's bundle, a shell limited to `pf` and the sources to compile from; its deferral workflows already hold a session to compiling what a bundle defers.

- **The workflow.**
  `agent-pick`, written in the `compiled` form alone: a state links a kind router's section with `¬` and `?`; each alternative routes the section's links to a state document of its own kind.
- **The scenarios.**
  One per alternative, each with an input naming the work's kind in plain words that match one choice line and no alternative's name; and one whose input matches no choice line, where the expected path ends at the state the router names for an unknown kind.
- **The score.**
  A session passes when its path enters the picked kind's states and no other, it ran `pf` with `?` replaced by that alternative, and it read no source file.
- **The README.**
  The workflow joins the deferral scenarios with what it isolates.
