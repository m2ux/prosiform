The documentation states the `?` tag, where it is accepted and refused, and how an agent resolves it, and pins the v1 design commit that states them.

## Problem

- **The pages state fixed tags alone.**
  Selection by reference and the operator rules describe tags an author writes, and the invocation examples compile a title's tags as written.

## Proposal

**The scene.** Each page states its rules once and links the v1 design at a pinned commit.

- **References.**
  Selection by reference states `?`; Operators states that a compiled link refuses it and a deferral publishes it.
- **Invocation.**
  The Guide paragraph names the new entry, and Examples show the listing and the rerun.
- **Glossary.**
  Pick and the pick token are defined.
- **Pins.**
  Each design link moves to the commit stating these rules.
