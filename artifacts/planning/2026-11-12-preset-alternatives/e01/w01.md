**Component:** main:src/prosiform/tags.py, main:src/prosiform/closure.py

## Overview

A `?` token in a link title requests the agent's pick. It is accepted on a deferred link and published with the deferral's title, and refused on every link the run compiles itself.

## Problem

- **Every title token names a preset.**
  The tag reader returns each trimmed, case-folded name, and a name the target does not declare selects nothing, so `?` reads as one more unknown name.
- **Nothing ties a tag to an operator.**
  Operators decide how a target is compiled and titles decide its presets, so no rule refuses a tag a compiled link cannot honour.

## Proposal

**The scene.** `closure.py` reads each link's operator marks and refuses the combinations that cannot be carried out, as `¬⇉` is refused; a deferral publishes its destination from the working directory with its title as authored.

- **`?` is the pick token.**
  The tag reader marks `?` apart from the preset names, and it selects no preset.
- **A deferred link carries it.**
  `?` is accepted on a `¬` or `¬↳` link, and the deferral publishes the title unchanged.
- **A compiled link refuses it.**
  `?` on an ordinary, `↳`, `⇉` or `⫽` link is refused with `E_UNSUPPORTED_CONSTRUCT`, naming the link and the deferral that would carry it.
