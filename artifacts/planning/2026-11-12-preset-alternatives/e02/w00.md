## Overview

The agent-pick scenarios accept either path to a pick: a first-run `--pick` beside the link as written, or the listing run followed by the rerun with `--pick`. The scorer states which path a session took, so a session following the guide is never scored as uncompiled.

## Problem

- **A guide-compliant pick fails scoring.**
  Each agent-pick scenario lists two compile entries, the bare `?` run and the picked rerun, and the scorer holds a session to both, so a session that passes `--pick` on its first run never makes the listing run.

## Proposal

**The scene.** The link invocation gives `pf` a published link as its entry and `--pick` beside a `?` link. The guide tells an agent that knows its pick to pass `--pick` on its first run, and one that does not to read the listing and rerun.

- **A picked run, two ways.**
  A scenario states its picked run once; a session meets it by a first-run `--pick` naming that alternative, or by the listing run followed by the rerun naming it.
- **The scorer names the path.**
  Each scored session records `first-run` or `after-listing` for its pick, and the report shows it beside the session.
- **The unknown-kind scenario is unchanged.**
  Its session still lists the alternatives and takes `other` into Hold, by either path.
