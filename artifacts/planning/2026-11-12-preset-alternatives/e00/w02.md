**Component:** main:src/prosiform/cli.py

## Overview

A document declaring alternatives compiles only with exactly one of them in force in each bundle; none or several fail with `E_ALTERNATIVE_UNRESOLVED`, naming every alternative with its choice line, and an unpicked alternative raises no `W_PRESET_UNUSED`.

## Problem

- **Nothing requires a pick.**
  A document's presets in force are whatever its references select, and a reference selecting none compiles `default` alone.
- **Unpicked kinds warn.**
  `unused_presets` warns for each preset no reference selected, so every compile of a router warns for each kind it did not pick.

## Proposal

**The scene.** The run gathers each document's presets in force from the references reaching it, refuses conflicting `group` and `subst` settings with `E_INVALID_USAGE`, and reports `W_PRESET_UNUSED` from each bundle's unselected presets.

- **The count is per bundle.**
  For each document declaring alternatives, the alternatives in force are the union every reference reaching it selects in that bundle, the set its `subst` pairs resolve through.
- **None or several fail.**
  Either count fails the run with `E_ALTERNATIVE_UNRESOLVED` and exit status 2 before publication, naming the document and each alternative with its choice line in declaration order, with a remedy naming `--presets`.
- **The code is listed.**
  `-C` lists `E_ALTERNATIVE_UNRESOLVED` with the other codes.
- **Unpicked alternatives are silent.**
  `unselected` leaves alternatives out, so `W_PRESET_UNUSED` names ordinary presets alone.
