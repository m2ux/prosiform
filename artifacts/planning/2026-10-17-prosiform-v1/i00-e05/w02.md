## Overview

The rewriting of every internal link to the destination of the target it resolved to.

## Problem

A bundle whose destinations are correct and whose links still name source paths is a document whose links go nowhere.

Every local Markdown link in the bundled content pointed at a separate file. That file's content is now in the same document, so the link has to become a reference to the place it occupies here. A fragment-only link is the same problem within one source.

## Proposal

Each local Markdown link and each fragment-only link in selected content is rewritten to the destination of the target it resolved to, through the same map that produced that destination. After rewriting, no link in the bundle names a source path.

The rewrite is the point of the bundling: an outbound reference becomes a reference inside the document the reader already holds, so the content it names is present rather than fetched.

## The Entry Line This Row Completes

The entry line links each entry reference to the destination it resolved to, so it is written through the same map this row applies and is finished here. Two parts of it reach this row unsettled, and the contract gains both.

The design shows an entry line naming one entry. A bundling of several entries emits one line naming each, and the form it takes is stated rather than left to an implementation: `I00:E02:W04` chose `[a](#a), [b](#b) and [c](#c)` in group order with nothing in the contract behind it, and a second implementation reading the design would guess differently.

The single whole-document form was delivered by `I00:E02:W04`, which is three epics ahead of the criterion naming it, because thirteen fixtures declare a bundle that opens with the line and none of them could pass without it. `I00:E05:AC7` therefore states the remainder — the destination map proper, a grouped entry resolving to an overview subsection, the rewriting, and the integrity invariant — rather than the whole clause. The design records which part landed where, so a reader is not left to infer it from delivery order.
