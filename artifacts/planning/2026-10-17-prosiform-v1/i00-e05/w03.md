## Overview

Conversion of resolved reference-style uses to inline form, and removal of every original definition.

## Problem

A reference-style link resolves against its own document's definitions, so moving the use without its definition breaks it, and moving every definition into one document makes labels from different files compete.

## Proposal

Each source is parsed independently and its reference-style uses are resolved against its own definition environment, including definitions outside the selected region. A resolved use is emitted inline with its visible text, image alternative content and optional title preserved and escaped as needed. Every original definition node is removed from emitted content, unused definitions included. Bracketed text the source parser did not resolve is emitted as literal text, and examples inside code spans and code blocks are unchanged.

## Work Breakdown

| Part | Description |
| --- | --- |
| Analysis | The definition environment of a source and which uses it resolves |
| Plan | The resolution, the inline conversion, the escaping and the removal |
| Implementation | The conversion and the definition removal |
| Review | Confirmed that one source's definition cannot resolve another source's literal brackets |
| Test | Corpus fixtures covering definitions outside a selected section, conflicting labels across files, unused definition removal, reference-style images with titles, and literal brackets that must stay literal |
