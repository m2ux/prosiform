## Overview

A reproducer recording which reference-definition occurrences the pinned parser exposes.

## Problem

The inspected first pass inserts definitions with a first-wins entry, so a later duplicate occurrence becomes no map entry, while emission must remove every occurrence.

## Proposal

Sources are constructed carrying later duplicate definitions, case-fold-equivalent labels, unused definitions, multiline definitions and definitions in supported container contexts. Each is parsed with the pinned parser and the reproducer records, per occurrence, whether the public interface exposes it and with what source range. The recorded run is the evidence, not a reading of the parser's source.

## Work Breakdown

| Part | Description |
| --- | --- |
| Analysis | The occurrence kinds the design requires and the parser interfaces that might expose them |
| Plan | The source set, the recording format and the pinned version |
| Implementation | The reproducer and its recorded run |
| Review | Confirmed that a retained winning definition is not recorded as evidence of duplicate enumeration |
| Test | The reproducer runs against the pinned version and produces a recorded result for every occurrence kind |
