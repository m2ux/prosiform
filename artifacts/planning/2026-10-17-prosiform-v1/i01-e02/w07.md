**Component:** [src/prosiform/cli.py](https://github.com/m2ux/prosiform/blob/main/src/prosiform/cli.py)

## Overview

A bundle offered back as a source refused whatever capitalization the source root spells its paths with.

## Problem

Generated-input detection reads a source's opening file heading and asks whether that text, with a Markdown suffix appended, names a document under the allowed root. A file heading carries its path in title case, so a root spelling its paths in lower case produces a bundle whose opening heading names no document under it.

- **The common case is undetected.**
  A root holding `docs/guide.md` produces a bundle opening `# Docs/Guide`. No document is named `Docs/Guide.md`, so the probe finds nothing and the bundle is read as an ordinary source.

- **Reading the heading against another capitalization refuses authored sources.**
  Lower-casing the heading before the probe makes a document at `guide.markdown` titled `# Guide` name `guide.md`, and the run refuses a source an author wrote. The corpus states that collision in `identity/paths-differing-only-by-suffix`.

## Proposal

The detection rests on a signal a bundle carries that an authored document does not, or reads the file heading against the root in a way an authored title cannot match. The design states the reach it claims and the reason before the corpus declares it, since a false refusal costs more than a missed bundle and the choice between them is the decision this row takes.
