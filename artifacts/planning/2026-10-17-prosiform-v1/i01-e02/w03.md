**Component:** [src/prosiform/cli.py](https://github.com/m2ux/prosiform/blob/main/src/prosiform/cli.py)

## Overview

The grouping rule the command takes, naming a folder and nothing else.

## Problem

The rule carries a folder slug and a source heading level. Arranging a group by member leaves no heading level to select, so the level is read from the argument and reaches nothing: two rules differing only in their level produce one bundle.

## Proposal

The grouping rule is the folder slug. The command takes it, repeats it once per folder, and refuses a rule carrying a heading level rather than accepting and ignoring one. The help text and the invocation guide state the rule in that form.
