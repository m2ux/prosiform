**Component:** [src/prosiform/grouping.py](https://github.com/m2ux/prosiform/blob/main/src/prosiform/grouping.py)

## Overview

One destination for a name both options give, with each source region carried once and the arrangement's membership bounded by the selection.

## Problem

A name given to both options describes one output section, and nothing states what happens where a gathered section already carries that name, nor whether a region both selections reach is emitted twice.

## Proposal

The section and folder contributions for one name merge beneath a single parent of that name. A region both reach is emitted once, and a wrapper carrying the group's own name collapses into the parent rather than nesting beneath it, member subsections and source order preserved within each contribution. Membership stays the selected documents and the non-deferred dependencies they reach, and entry and internal links resolve against the headings the arrangement emits.
