**Component:** [src/prosiform/cli.py](https://github.com/m2ux/prosiform/blob/main/src/prosiform/cli.py)

## Overview

The two grouping options the command takes, and the retirement of the one that carried both selections.

## Problem

`--group SLUG:DEPTH` names a directory and a source-heading depth in one argument, so neither selection can be asked for alone and the folder arrangement arrives with the depth whether or not it was wanted.

## Proposal

The command takes `--section-group` and `--folder-group`, each repeatable for a further group name, and refuses `--group`. A run naming neither takes the default document arrangement. The retired option leaves the command, its help and its documentation with no alias standing in for it.
