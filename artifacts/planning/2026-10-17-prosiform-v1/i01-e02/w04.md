**Component:** [invocation.md](https://github.com/m2ux/prosiform/blob/main/invocation.md)

## Overview

The documented grouping examples and the diagrams beside them, carrying what a run of them emits.

## Problem

The documented commands and their rendered diagrams show the overview wrapper where it is no longer emitted and the mixed heading casing, so the documentation describes output no run now produces.

## Proposal

The examples beside the documented commands carry the arrangement and the heading spelling a run of them emits, and the rendered diagrams and retained planning SVGs are regenerated against that output.

## Work Breakdown

| Part | Description |
| --- | --- |
| Analysis | Every document, example and diagram showing a grouped bundle or a generated heading |
| Plan | Which examples change and which diagrams are regenerated |
| Implementation | The documented examples and the regenerated diagrams |
| Review | No surviving depiction of the unconditional wrapper or the mixed casing |
| Test | Each documented command run and its output compared with the example and diagram beside it |
