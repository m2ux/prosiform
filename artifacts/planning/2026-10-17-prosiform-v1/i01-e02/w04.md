## Overview

The documentation of the two grouping modes, with the examples and diagrams carrying what a run of them emits.

## Problem

The documentation describes a grouping option the command no longer takes, and its diagrams show output no run now produces.

## Proposal

The documented commands name the two options, and the examples beside them, their rendered diagrams and the retained planning SVGs carry the headings a run of those commands emits.

## Work Breakdown

| Part | Description |
| --- | --- |
| Analysis | Every document, example and diagram that names the retired option or shows its output |
| Plan | The examples the two modes need, and which diagrams are regenerated |
| Implementation | The documented commands, examples and regenerated diagrams |
| Review | No surviving description of the retired option |
| Test | Each documented command run and its output compared with the example and diagram beside it |
