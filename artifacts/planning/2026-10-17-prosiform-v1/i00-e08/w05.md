## Overview

A link-reference definition the author spelled across more than one line is published inline carrying its destination and title as authored, and its definition is removed, like any other resolved definition.

## Problem

Reference conversion composes the inline target from the definition and writes it into the span its use occupies, and that span lies within one physical line.

- **A definition is a block and a use is a span.**
  CommonMark lets a definition's destination and title stand on lines of their own, so a label answering to three authored lines resolves into a target the use must carry in one.

- **A refusal stands where the contract states a publication.**
  `published()` raises `Unrewritable` when the composed target holds a line feed, and nothing catches it, so valid input ends the run in `E_UNEXPECTED_INTERNAL_ERROR`. The contract says a resolved reference is published inline with its title preserved, and names no failure here.

- **An internal error names the wrong party.**
  The code reports a fault in the tool for a document CommonMark accepts and the profile does not refuse, which tells an author to change nothing because nothing they wrote is wrong.

## Proposal

The composed target is written as authored, line feeds included, and the rewrite accepts a replacement spanning more than one line. A title the author broke across two lines reaches the bundle broken in the same place, because the title is the author's text and the conversion moves it rather than reflowing it.

`Unrewritable` keeps the two cases it was raised for that remain faults — a definition naming no destination, and the spans the rewrite cannot locate — and loses the one the contract answers.

The rewrite already changes how many lines a source contributes, because every definition node is removed. Inserting a line feed into a span is the same accounting in the other direction, and the destination map is built after the groups are assembled, so a replacement's line count is read from the replacement rather than assumed from the source.

The defect is in the reference conversion [I00:E05:W03](https://github.com/m2ux/prosiform/pull/90) delivered, and that epic is closed. No later epic owns reference handling, so the choice was this epic or the deferred-debt one.

It sits here because this epic's rows close the ways a bundle can be wrong that first use exposed, and because an internal error on accepted input is the one defect class that cannot wait behind the whole initiative: it publishes nothing, so no caller can work around it.
