## Overview

Dependency closure is what makes a bundle complete. Supported local Markdown links in selected content are resolved, bundled and included; traversal continues until no new content is reachable; overlapping selections become one region; and every budget the profile names fails at its first crossed boundary rather than truncating. This is the epic that turns a document transformer into a compiler.

## Problem

A link identifies a destination and retrieves nothing, and a traversal that is not bounded or consolidated produces the wrong document.

- **A reference graph has cycles.**
  Documents in an instruction set link back to one another, so a traversal without a fixed point repeats regions or does not terminate.

- **The same region arrives by several paths.**
  A section selected directly and again inside a later whole-document inclusion is one region, and emitting it twice makes the bundle disagree with its sources.

- **A link string is not a path.**
  Percent escapes, an encoded delimiter, a query, a relative segment and a symbolic link each change which file a reference names, and a check performed on the string alone can confine a reference that escapes the root.

- **A self-link and an ancestor link look alike.**
  A section linking to itself is a defect, while a nested section linking back to an including ancestor is ordinary, and both are a link whose target is already present.

- **An unbounded compilation fails late or not at all.**
  Without declared budgets, a pathological source tree is discovered by exhausting memory rather than by a diagnostic.

## Proposal

- **References normalize before they resolve.**
  URI components split before percent-decoding, escapes validate strictly, decoding happens exactly once, and `.` and `..` normalize against the proper base. A query on a local Markdown reference, an unsupported scheme and an unsupported path form each fail.

- **The root is enforced by access, not by string inspection.**
  Rooted, no-follow access confines every source read, and a path reaching a source through a symbolic link below the root fails.

- **A bundle does not depend on how it was asked for.**
  File groups are emitted in root-relative path order. Neither discovery order nor argument order decides the arrangement, so the same selection always produces the same bytes. Source order within a file is preserved.

- **Only a Markdown link is a dependency.**
  An image, a script, a stylesheet or any other non-Markdown resource is classified and preserved, never opened and never traversed. Following one would widen every closure that mentions a diagram, and the bundle guarantees Markdown dependencies rather than offline resources.

- **Traversal runs to a fixed point.**
  Newly included content is traversed before compilation completes, so a dependency discovered inside a late inclusion is resolved rather than left out.

- **A reference expands a structural ancestor into its content.**
  A link whose target is present only as a heading-only ancestor expands closure to include that section's selected body, replacing the structural ancestor. A displayed title does not satisfy a reference.

- **Expansion reaches only so far.**
  A target beyond the declared expansion depth, counted in link hops along its shortest path from an entry reference, fails the run. The budget constrains the shape of the reference graph; the file, byte and target budgets bound its size.

- **Overlaps consolidate upward.**
  A later reference including an ancestor section or a whole document replaces the narrower selections inside it, and the larger region's own dependencies are traversed.

- **Identity decides self-reference.**
  A link is compared after canonical path and fragment resolution. A link from a section to that same canonical section fails; a link from a section to an including ancestor resolves to the existing destination. Link ownership is stored separately from inclusion, so consolidation does not change the classification.

- **One budget is set by measurement.**
  The closure the proposal measured is bundled and its output size recorded against the configured budget, so the output limit rests on a real bundling rather than on an assumed figure.

- **Budgets fail at the boundary.**
  Each declared limit is counted as the design states and fails the compilation when crossed. No output is truncated to fit.

## Acceptance Criteria

- [ ] **AC1.** A marked local Markdown link in selected content is resolved, bundled and present in the published bundle, as the traversal fixtures show.
- [ ] **AC2.** A cyclic reference graph bundles to a fixed point with each reachable region present once, as the cycle fixtures show.
- [ ] **AC3.** A selection contained within a larger selection is represented by the larger region alone, and that region's own references are resolved, as the consolidation fixtures show.
- [ ] **AC4.** A link to the same canonical section fails as a direct self-reference, while a link back to an including ancestor resolves to that ancestor's existing destination, as the self-reference fixtures show.
- [ ] **AC5.** A reference whose normalized path leaves the allowed root, or reaches a source through a symbolic link below it, fails with its declared error code, as the confinement fixtures show.
- [ ] **AC6.** A schemeless reference carrying a query or a path form the root cannot contain fails with its declared error code rather than being opened, while a reference carrying a scheme or an authority is emitted as authored, as the normalization fixtures show.
- [ ] **AC7.** Each limit the profile names fails the compilation at the first boundary it crosses, with no bundle published and no content truncated, as the limit fixtures show.
- [ ] **AC8.** The bundled size of the closure the proposal measured is recorded against the configured output budget, as the measurement fixture shows.
- [ ] **AC9.** Markdown classification recognizes the `.md` and `.markdown` suffixes case-insensitively, and an explicit entry carrying another suffix fails, as the suffix fixtures show.
- [ ] **AC10.** The same selection produces the same bundle whatever order its entry references are given in and whatever order its dependencies were discovered in, with groups ordered by root-relative path, as the determinism fixtures show.
- [ ] **AC11.** A link to a section present only as a heading-only ancestor expands closure to include that section's selected body, as the ancestor-promotion fixtures show.
- [ ] **AC12.** A target further from every entry reference than the declared expansion depth fails the run, as the depth fixtures show.
- [ ] **AC13.** An image, a web URL or another non-Markdown reference in selected content is preserved without being opened, fetched or traversed as a dependency, as the resource-classification fixtures show.
- [ ] **AC14.** Link ownership and direct-self-reference classification are the same before and after a selection is consolidated into a larger region, as the ownership fixtures show.
- [ ] **AC15.** A filesystem path written as ordinary prose, rather than as a link, is left as text and resolved as no dependency, as the bare-text fixtures show.
- [ ] **AC16.** An unmarked local Markdown link is emitted as authored, resolves as no dependency, and is left unrewritten even where the bundle carries the document it names, as the unmarked-link fixtures show.
- [ ] **AC17.** A document whose unmarked references name material outside the allowed root bundles successfully, while marking one of them fails the run with its declared error code, as the citation fixtures show.
- [ ] **AC18.** Each usage example the design publishes runs against a tree the repository carries, and that tree shows a reference marked as required beside one left as a citation, as the example-tree fixtures show.
