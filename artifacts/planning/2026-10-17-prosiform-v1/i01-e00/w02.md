## Overview

Reduction of a recorded entry to a minimal corpus fixture that reproduces it.

## Problem

A finding stated in words cannot be re-run, so whether a change fixed it is a matter of opinion; and the skill tree that triggered it is too large to be a fixture.

## Proposal

A capture tool takes an entry's invocation and the source closure it reached, and emits a fixture directory and manifest holding the smallest source set that still reproduces the observed result. The reduced fixture is attached to its ledger entry and enters the corpus with the revision that resolves the entry, so the corpus never carries a fixture declared to fail.

## Work Breakdown

| Part | Description |
| --- | --- |
| Analysis | How the reachable closure is captured and how a minimal reproducing subset is found |
| Plan | The reduction strategy, the emitted fixture shape and where a reduced fixture waits |
| Implementation | The capture tool and its reduction |
| Review | A reduced fixture confirmed to reproduce the observed result and to carry no source the result does not need |
| Test | Reduction tests over recorded entries, each asserting that the emitted fixture reproduces the entry's observed result |
