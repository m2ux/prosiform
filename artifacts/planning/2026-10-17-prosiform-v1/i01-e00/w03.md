## Overview

The record of each bundling run, counted against the declared set of sources the stage must exercise.

## Problem

A ledger holding only surprises cannot show whether the tool was used, so a condition counting recorded findings is satisfied by a ledger nobody wrote in.

## Proposal

Each bundling run is recorded with the source identities it bundled and its outcome, and a surprise entry cites the run it came from. The exposure set in `ledger/exposure.toml` names the real sources the tool must have bundled before the specification can be called settled; it is declared at the start of the stage, so it is a target to work toward rather than a figure chosen once the work is done. A run record names its sources the way that set does, so exposure is counted against it.

## Work Breakdown

| Part | Description |

| Analysis | What a run record must hold for exposure to be countable against the declared set |

| Review | The set confirmed to name real sources rather than fixtures, and the record confirmed to cover successful runs as well as failures |
