**Component:** `main:ledger/exposure.toml`, `main:ledger/exposure.schema.json`, `main:ledger/README.md`, `main:checks/ledger.py`, `main:checks/tests/test_ledger.py`

## Overview

Declares the exposure set's external part: the example skill deployed in `prosiform-skills`, beside the workspace skills agents invoke, so the declaration check reads the sources the freeze requires.

## Problem

The exposure declaration names commands under the local `example/work-planner` tree, which is not the example the exposure set requires. The example skill in `prosiform-skills` is user-owned and not yet deployed, so its repository identity, revision, entry paths and invocation are unknown, and nothing in the declaration or its check can name or read an external source.

## Proposal

A reader opens the exposure declaration and finds the `prosiform-skills` example identified by repository, revision, entry paths and invocation, and the workspace skills agents invoke, with no entry under `example/work-planner`. The schema admits an external source identity, and the declaration check reads each entry and fails on one it cannot resolve. The run records name the same source identity.

The task starts once the user records the deployed example's identity and invocation.
