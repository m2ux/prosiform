## Overview

The procedure by which a workspace skill's prerequisite section is removed and replaced by the bootstrap the worked example states, and the record that justifies each removal.

## Problem

A prerequisite section names whole documents, coarsely but completely, and the inline links inside a procedure name sections precisely but may not cover everything that list covered.

The worked example's copy of the skill carries no prerequisite section: its modes open with `↳` links, and its `bootstrap.md` states the one `pf` command that compiles a mode and the symbols its bundle uses. The workspace skills it was copied from still carry their lists, so the agents doing real work read whole documents the example's agents receive bundled.

Removing a list before bundling demonstrably replaces it loses context the tool never supplies, and nothing would report the loss. The example showed one such cost: removing its lists lengthened a route past the default output budget, which per-mode bundling and dispatch then absorbed.

## Proposal

A workspace skill's prerequisite section is removed only once a recorded bundling run supplies the sources that section named. The removal record cites that run, so a later reader can see what justified it.

In the section's place the skill follows the example's pattern: mode links open with `↳`, and a bootstrap states the `pf` command that compiles each mode and the symbols its bundle uses. The skill edits land in the repository that holds the skills; this initiative raises no issue or pull request there, and keeps the removal record and the gating runs here.

A source the section named and the bundling did not supply is a ledger entry, triaged like any other finding. The usual outcome is a missing inline link in the procedure that needed it, which is a change to the source; where the shortfall is the tool's, it becomes a design or build change under the ordinary revision order.

Removal proceeds one skill at a time, so a shortfall is found against one document rather than across all of them at once.

## Work Breakdown

| Part | Description |
| --- | --- |
| Analysis | For one skill, the sources its prerequisite sections name against the sources its runs reach, and the example's bootstrap and mode links as the target form |
| Plan | The removal procedure, the bootstrap each skill states, the removal record, and the triage of a shortfall |
| Implementation | The procedure, the record, the bootstraps, and the removals they justify |
| Review | Each removal confirmed to cite a run that supplied every source the section named, and to leave a bootstrap in the section's place |
| Test | A deliberately incomplete procedure produces a shortfall entry rather than a removal, and a complete one produces a removal citing its run |
