**Component:** [src/prosiform/bundle.py](https://github.com/m2ux/prosiform/blob/main/src/prosiform/bundle.py)

## Overview

One title-casing convention over every heading the compiler generates, so a bundle's generated headings read the same whichever construction emitted them.

## Problem

The group construction title-cases its slug and the document arrangement emits the path it derived, so one run produces `# Rules` beside `# procedure` and `# rules/codex`. The README's rendered diagrams carry both spellings, so the mixed output reads as the intended output.

## Proposal

The casing the group construction applies becomes the convention every generated heading takes, path structure preserved. A heading an author wrote and a filesystem path a run names keep the spelling their source gave them, so the convention reaches what the compiler wrote and nothing else. Entry links, internal references and the collision rule resolve against the emitted headings, and the fixtures, the documented commands, their diagrams and the retained planning SVGs carry what running them produces.
