## Overview

An example tree the repository owns, carrying marked and unmarked references, which the design's usage examples name.

## Problem

The design's usage examples name `skills/work-planner`, a tree that lives in another repository and is not checked out here. No check reads those examples, no run executes them, and nothing notices when one stops being a valid invocation. An example the repository cannot run is prose.

The tree they name also cannot be altered from here, so the marking the contract now requires cannot be demonstrated on it. A reader looking for what a marked reference looks like in place has nowhere to look.

## Proposal

The repository carries a small example tree, taken from the closure of one real skill procedure and renamed, so the documents are real prose rather than invented filler. Its references are marked where the material is required and left unmarked where it is cited, so the tree shows both halves of the rule in one place.

The design's usage examples name that tree. Each published invocation is then one a reader can run against something present, and the corpus bundles it, so an example that stops working fails a run rather than going quietly stale.

The tree is a copy and does not track its source. It is example material the repository owns, not a mirror of another repository, and it is maintained here when the contract changes.

## Work Breakdown

| Part | Description |
| --- | --- |
| Analysis | The source closure to copy, the renaming, and which of its references are requirements and which are citations |
| Plan | The tree's layout, the mark on each reference it keeps, and the usage examples it replaces |
| Implementation | The tree, the revised usage examples, and the fixtures that bundle it |
| Review | Each published usage example confirmed to run against the tree, and the tree confirmed to carry both a marked and an unmarked reference |
| Test | Fixtures bundling the tree through each published example's invocation, and a fixture showing an unmarked reference reaching the bundle as authored |
