## Overview

Confinement of source reads to the allowed root, without following symbolic links.

## Problem

A path validated as a string can still reach outside the root through a symbolic link resolved when the file is opened.

## Proposal

The allowed root is canonicalized once. Source access is rooted and no-follow, so a path containing a symbolic link below the root fails with its declared error code, as does a normalized path outside the root. A platform unable to enforce this fails or declares a narrower supported environment. Non-Markdown resource links are not opened as sources.
