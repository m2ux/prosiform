## Overview

Failure when a shifted heading would pass the sixth level.

## Problem

Markdown carries six heading levels, so a deep selection beneath a generated file heading can require a seventh, which has no heading spelling.

## Proposal

Before publication, every emitted source heading and structural ancestor is checked against the sixth level. A bundling requiring a deeper heading fails with its declared error code, naming the heading and its required level. The level is not flattened, clamped, or emitted as heading-like text.

## Work Breakdown

| Part | Description |
| --- | --- |
| Analysis | Where in the pipeline every emitted heading level is known |
| Plan | The check, its placement before publication and its diagnostic |

| Test | Corpus fixtures covering an H6 source heading, a structural ancestor at the limit, and a passing H5 case |
