## Overview

Separation of emitted regions, and failure where a boundary would absorb what follows it.

## Problem

Two regions joined without safe separation can place later content inside an earlier code fence, HTML block, list or quote, which changes meaning without producing invalid Markdown.

## Proposal

Blank-line separation is inserted between maximal emitted regions and the candidate is reparsed. A boundary that merges or absorbs content into an unintended code fence, list, quote, HTML block or other non-heading container fails with its declared error code, naming the source regions and the conflicting output boundary. Fences are not silently closed and code examples are not repaired.
