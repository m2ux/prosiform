## Overview

The content of a diagnostic and its JSON Lines form.

## Problem

Without a code, a location, the offending reference and the chain that reached it, a calling agent can report only that bundling failed.

## Proposal

Each diagnostic carries a stable error code, the referring source location in original coordinates, the original reference as authored, the resolved identity where one exists, the inclusion chain that reached it, and a remedy where one can be stated accurately. Selecting the JSON format emits one object per line on the diagnostic stream carrying those fields and a severity, with no progress prose mixed into that stream.
