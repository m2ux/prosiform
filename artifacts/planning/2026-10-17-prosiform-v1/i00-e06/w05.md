## Overview

The boundary between what a bundling validates and what it merely parsed, and the diagnosis of a source that cannot be indexed safely.

## Problem

Indexing a source means parsing all of it, and the natural implementation then validates all of it.

- **A whole file is parsed to answer questions about one section.**
  Heading enumeration, definition environments and fragment ambiguity are file-wide facts, so the parser sees sections nobody selected.

- **A defect in an unselected section is not a defect in the bundling.**
  An unrelated broken link or a self-referential link elsewhere in the same file would fail a bundling that never included it, so selecting one section of a large skill would fail on material it does not use.

- **An unsafe source and an unwanted dependency look alike.**
  When an unselected construct exceeds a file-wide parsing-safety limit, the file cannot be indexed at all. Reporting that as a dependency on the offending construct would suggest the bundling reached for something it never selected.

## Proposal

Link resolution, self-reference, supported syntax and resource rules are validated within the selected dependency closure. Parsing a file to index it does not make its unselected sections dependencies, and a defect in one of them does not fail a run that did not select it. If closure later includes that section, its links become subject to validation like any other.

Whole-file checks stay limited to what safe access and correct interpretation require: source identity and encoding, raw-byte and parsing-resource limits, frontmatter, change detection, heading enumeration, the definitions selected uses need, ambiguity of requested fragments, and generated-input detection.

A file-wide parsing-safety limit exceeded by an unselected construct fails as an inability to index that source safely, and is diagnosed as such. The authored-occurrence budget stays scoped to the selected closure; any separate budget full-file indexing needs is specified in its own right rather than borrowed from that option.
