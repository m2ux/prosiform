## Overview

A `staged` workflow whose dispatched bundles carry a `↳` line or a deferred dispatch and so open with the Prosiform section saying `pf` runs first, so the eval measures a sub-agent running bare `pf` before it acts on the line, at the first hop and at the second and third.

## Problem

- **A sub-agent has not read the guide.**
  It reads only its bundle, so the Prosiform section referred to from the preamble is its one instruction to run `pf`.

## Proposal

**The scene.** A workflow is a directory under `workflows/`, its forms beside a `scenarios.toml` naming each scenario's inputs, the path a correct session walks, the sub-agents it starts and the `pf` runs it makes. A `staged` session receives the compiled bundle set with the build under test as `pf` on its path; the scenario passes when the session's path is the one its bundle states.

- **Tested by effect.** (User, 2026-11-03.)
  No harness reports a command a sub-agent runs, so a sub-agent's `pf` run is shown by what it makes possible: the scenario states actions only the content that run compiles defines, which a sub-agent that ran no `pf` cannot take. The actions are files the sub-agent writes in the workspace, which the scorer reads whatever the harness's stream carries; the scenarios run on the harnesses carrying a shell.
- **Stated on the trace.**
  A `[[scenario.trace]]` entry's `actions` names each file and value. The corpus test compiles the bundle the entry's section follows, runs `pf` on each deferred line its steps reach, and holds `actions` to what that material states and the bundle does not; the scorer holds a record passing the dispatch checks to them as `missing_action`.
- **First hop.**
  `first-hop-run`: `Entrust` dispatches `hop/ledger#balance`, whose `[¬→](../steps/closing.md#close)` publishes a `↳` line; the closing states `actions/closing.txt`.
- **Second and third hop.**
  `deep-hop-runs`: `Cascade` dispatches `hop/audit#sweep`, which dispatches `hop/review#scan`, whose deferred dispatch names `steps/weighing.md#weigh`; the weighing states `actions/weighing.txt` and dispatches `steps/ruling#rule`, whose `↳` line compiles the recording that states `actions/ruling.txt`.
