## Overview

The design clause stating the eight resource budgets as one named set behind one repeatable option, `--budget NAME=VALUE`, and the README pin moved to the revision carrying it, so every later row of the epic cites a clause the pinned design holds.

## Problem

The contract enumerates eight options of one shape.

- **The contract states one rule eight times.** `-F`, `-B`, `-I`, `-O`, `-T`, `-L`, `-N` and `-E` each take a positive integer and each bound a different count.
- **The letters are unreadable.** Nothing in `-E` says it bounds link hops, and `-O` is one case from the unrelated `-o`.
- **The refusals have no clause.** An unknown budget name, a malformed entry, a name given twice and a nesting ceiling below 2 are refusals this epic's fixtures will declare, and the design states none of them.
- **Fixtures name the letters.** Sixteen manifests declare `Resource limits — -F` and its siblings, so renaming the rows without them would leave `make conformance` failing on declarations that match no clause.

## Proposal

**The scene.** The CLI contract table lists the operational options and defers the budgets to Resource limits, whose table keys each budget by its letter beside its default and counting rule. The README's design badge pins the revision `make conformance`, `make vocabulary` and `make independence` read.

**The design.**

- **One row, one option.** The CLI contract states `--budget NAME=VALUE`, repeatable, given once per ceiling, and links Resource limits for the names.
- **The names replace the letters.** The Resource limits table is keyed by `files`, `file-bytes`, `input-bytes`, `output-bytes`, `targets`, `links`, `nesting` and `depth`, each beside its unchanged default and counting rule, so a reader meets one table.
- **The refusals sit with the budgets.** A name outside the eight, an entry carrying no `=` or an empty name, a value that is no positive decimal integer, a name given twice and `nesting` below 2 are each stated under Resource limits as invalid usage, exit status 2; the CLI contract's invalid-usage list links them.
- **No section names a retired letter.** Every prose mention of `-F`, `-N`, `-E` and `-L` names the budget.
- **Declarations follow the rows.** Each manifest naming a lettered row names the budget row instead; its invocation stays as it is for W03.
- **The pin moves.** The README badge names the engineering commit carrying the clause.
