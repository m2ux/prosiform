# I05:E03:W01 Output Folder and Joined Derived Names — October 2026

> Task delivery · Created 2026-10-28

## Executive Summary

This record holds the delivery of I05:E03 W01: `-o` names the folder a run writes its bundles into, the working directory by default; every bundle takes its derived name, and a run of several entries takes one name joining each entry's with `+`. Standard output carries no bundle, so the corpus runner reads each fixture's output folder and the delivery wrapper is removed.

Every later row of the epic publishes into this folder: a run that compiles a bundle per dispatched target needs a place and a naming scheme that covers every bundle, and standard output can carry only one.
