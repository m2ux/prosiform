# Click Titles — November 2026

> Initiative · Created 2026-11-12

## Executive Summary

A Mermaid `click` line names a destination prosiform follows, and may carry a quoted tooltip after it. The tooltip is read past today, so a diagram link is always an ordinary link: it can carry no operator and select no preset. A workflow drawn as a flowchart whose nodes are sub-agent units cannot mark a node's click as a dispatch, and must restate it as a Markdown link.

This initiative reads a click's tooltip as its link's title: marks opening it state the operator, and the rest selects presets as a Markdown link's title does. `click Intake href "activities/intake.md" "⇉"` bundles as a dispatch and `"¬"` as a deferral. The design, corpus and documentation state the rule, and a release ships it.
