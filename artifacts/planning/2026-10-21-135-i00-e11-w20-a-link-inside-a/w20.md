**Component:** [`src/prosiform/rewrite.py`](https://github.com/m2ux/prosiform/blob/main/src/prosiform/rewrite.py)

## Overview

The emission's bracket scan reads a link as literal text only where the link's own label holds a link, so a link an image inside that label carries leaves the enclosing link the reference it is.

## Problem

A link written inside an image's alternative content, where an enclosing link carries that image, ends the run with `E_UNEXPECTED_INTERNAL_ERROR`.

- **The two readings of one run disagree on that shape alone.**
  The parser keeps the outer link, the image and the nested link, so the walk over the run yields three uses. The scan reads the nested link, reads the image and discards the outer link as text, so it offers two spans to edit. The emission checks one count against the other and refuses a run it cannot account for, which it reports as a fault in the tool.

- **The rule the scan applies is wider than the one the profile's parser applies.**
  A link may not hold a link, and an image's alternative content is a run of its own in which a link is allowed. The scan compares bracket positions alone, so a link an image inside the label carries counts against the outer link as if it were written beside it.

- **The status is the one the contract reserves for a fault in the tool.**
  `E_UNEXPECTED_INTERNAL_ERROR` names a defect an author cannot reach, and a source document and a command line alone reach this one.

- **No fixture states the shape.**
  The reference fixtures carry a link inside an image, and none carries one inside an image an enclosing link holds, so neither reading is written down.

## Proposal

A link is text only when its own label holds a link. A link that label carries inside an image belongs to the image's run, not the label's, so the scan reads the enclosing link as the link it is and the two readings of a run agree wherever the parser accepts the source.

- **Containment decides, not position.**
  A nested link counts against an enclosing link only where no image use already read sits between them. The scan reads an inner pair before the pair that encloses it, so the image is in hand by the time the enclosing link closes and the question is answered from the uses already found.

- **The run is accounted for before a span is edited.**
  The count the emission checks against stays the count the walk yields, so the check keeps its purpose: it catches a run the emission cannot edit rather than a shape it can.

- **The corpus states the outcome.**
  A fixture declares a link inside an image an enclosing link carries, resolving to a document under the allowed source root, so the published bundle rather than one build's tests states where each destination lands.
