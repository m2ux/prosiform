**Component:** src/prosiform/metadata.py

## Overview

A document's frontmatter declares `prosiform` or it does not, and a declaration carrying `root` is refused. Presence becomes a value of its own, so the classification that asks a target whether it declares has a fact to read, and the build stops walking, binding and reporting a declared root.

## Problem

`metadata.decode` answers with a `Conversion()` whose every field is `None` for absent frontmatter, an empty `prosiform` mapping, and frontmatter holding no `prosiform` key.

- **Absence is inferred from the fields.** A caller cannot tell a document declaring an empty block from one declaring nothing.
- **`root` is admitted.** `decode` validates `root` as a relative directory path, and `cli.read_document` walks it, binds its directory identity into the capture and reports `E_ROOT_NOT_FOUND` when it names no directory.
- **Every tree declares a root.** The example trees, the eval workflow skill and the documents the smoke and mock-scenario checks write each carry `root`, so refusing the field fails each of them unless they drop it.

## Proposal

**The scene.** `decode` builds `fields` from the `prosiform` mapping's children, refuses a key outside the admitted set, validates each field's type, and returns `Conversion`. `read_document` decodes the captured bytes, walks the declared root from the document's directory and records the effective root on the source.

**The design.**

- **`Conversion.declared`.** `True` wherever a `prosiform` mapping was read, an empty one included; `False` for absent frontmatter, an empty or comments-only block, and frontmatter carrying no `prosiform` key.
- **`root` refused at its key.** A `prosiform` mapping carrying `root` raises `InvalidMetadata` with `E_INVALID_CONVERSION_METADATA` at the key, naming `prosiform.root` and the remedy: the document declares its inclusion and states no boundary, so the field is removed. The check precedes the value's type test, so any value is refused alike.
- **The root's validation and walk go.** `root` and `root_location` leave `Conversion`, so `metadata.py` holds no rule about paths. `read_document` walks no declared directory, every source is bounded by the invocation working directory, and `E_ROOT_NOT_FOUND` leaves the codes the build reports.
- **Every tree drops `root`.** Each document keeps its `prosiform` block and group fields; one that declared only a root keeps `prosiform: {}`. The `usage-example/` expected bundles hold unchanged, which shows the edit moved no content.
- **Fixtures follow the field.** The fixtures whose premise was a declared root are withdrawn; `E_SOURCE_ACCESS` is reached through a link the filesystem cannot open; the schema catalogue, the catalogue test and the corpus and check pages name no `E_ROOT_NOT_FOUND`. The catalogue test reads a code the design states `retires` as retired rather than declared.
- **Nothing else moves.** The group and depth grammar, the paired-field refusal and the YAML grammar are unchanged. Classification still compiles any local Markdown target under the working directory; asking the target whether it declares is the classification task's.
