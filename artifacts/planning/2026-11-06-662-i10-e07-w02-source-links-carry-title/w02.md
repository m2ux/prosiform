**Component:** main:src/prosiform/source.py

## Overview

Source links carry title tags. Each `Use.tags` is the immutable set of complete names read from its parsed title attribute by the shared list reader.

## Problem

Source uses expose destinations, labels and containing headings, but no explicit preset selection from the link title attribute.

## Proposal

**The scene.** The source reader traverses the parser's events, where inline and resolved reference-style links expose the same decoded attributes under the [preset-selection contract](https://github.com/m2ux/prosiform/blob/c67cf78f020923c4e5bd25d95497ced206be7161/artifacts/planning/2026-10-17-prosiform-v1/design.md#presets).

Read local links' title attributes through `prosiform.tags.read`. Images, external links and diagram destinations expose an empty tag set. Keep target classification in closure, so non-image local links carry their parsed list before their target type is known. Containing-heading context and visible labels occupy their own fields.
