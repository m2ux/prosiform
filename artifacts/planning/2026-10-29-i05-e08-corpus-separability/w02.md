**Component:** evals/diagram-following/baseline.json

## Overview

The committed baseline carries three of the four forms the matrix runs, so every `linked` cell of a report reads `new`. This task runs the four-form default matrix over the corpus W01 hardened, commits the baseline with its report, and states the measured cost in the eval's README.

## Problem

- **The baseline predates a form the matrix runs.**
  `baseline.json` holds 150 sessions over `bundle`, `tree` and `prose` from run `20261028T165414Z`. The default matrix is 200 sessions, the same three forms plus `linked`, so the form the epic was extended to measure has no row to compare with.
- **The documented cost is an estimate.**
  The README states about USD 4.01 for 150 sessions while `make eval-diagrams` passes USD 100 for 200, so the four-form cost is asserted rather than measured.
- **The three-form baseline separates nothing.**
  Every cell is 5 of 5, so the baseline stands as evidence that the instrument cannot yet distinguish the forms.

## Proposal

- **The default matrix is run once the login is available.**
  Its report is reviewed before the cells are committed, and the run's `baseline.json` and `report.md` replace the three-form baseline.
- **The measured cost replaces the estimate.**
  The README's default-matrix section and its `make eval-diagrams` row state the four-form session count, the cost the new baseline records, and the budget that covers it.
- **The form comparison is reported as the baseline shows it.**
  The per-form pass rates are read for what they support. A baseline whose forms still sit at one rate is recorded in this epic's planning record as not separating them, rather than presented as a result.
