**Component:** main:evals/diagram-following/README.md

## Overview

The eval's README lists what the preflight refuses, and names only files in the config directory. This task states each settings file the preflight refuses, the scope it reads that file from, and `--eval-root` as the remedy for a refused file above the workspaces.

## Problem

- **The Isolation section names one scope.**
  It lists `plugins/installed_plugins.json`, `remote-settings.json` and the config directory's `settings.json`, and says nothing of the host's managed settings or of a workspace's or an ancestor's `.claude` settings.

## Proposal

**The scene.** A caller whose run is refused reads the Isolation section to learn what to remove.

- **Each refused file has its scope.**
  The list names the config directory's files, the host's managed settings file, the workspace's `.claude/settings.json` and `.claude/settings.local.json`, and an ancestor `.claude` directory, each with the scope Claude Code reads it under.
- **The remedy is stated.**
  Each entry says what removes the refusal, so a caller can act on it without reading the code. A refused file above the workspaces names `--eval-root`, which moves the workspaces out from under it.
