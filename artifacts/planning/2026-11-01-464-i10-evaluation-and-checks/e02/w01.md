**Component:** evals/diagram-following/harness.py

## Overview

The Claude harness's preflight reads the eval's config directory and refuses a `settings.json` there that declares a hook. Claude Code also reads settings by project scope, from the session's working directory, and the preflight reads none of them. This task makes the preflight read every project-scope settings file a session will see and refuse one declaring a hook before the first session starts.

## Problem

- **Hooks arrive by project scope.**
  A `hooks` block in a workspace's `.claude/settings.json` or `.claude/settings.local.json` reaches a session exactly as one in the config file does, and the preflight reads neither.
- **The workspace is copied from a form's tree.**
  `prepare` copies a form's source tree into the session's workspace, so a form whose tree carries `.claude/settings.json` delivers its hooks to every session of that form.
- **An ancestor `.claude` is project scope too.**
  The eval root defaults to `~/projects/eval/prosiform`, under the caller's home, so a `.claude` directory on the path from a workspace to the filesystem root is read as the project's for every session.
- **The read that catches it pays for the sessions first.**
  The injected-context read refuses a run after a session's hook response is observed, where a preflight refusal costs nothing.

## Proposal

**The scene.** `run()` calls the harness's preflight before it reads the corpus, creates the run directory or starts a session. The preflight takes the config directory alone.

- **The preflight takes the workspace root.**
  It reads the config directory's `settings.json`, each workspace's two project-scope files, and the `.claude` settings of every directory from the workspaces' root to the filesystem root.
- **A refusal names the file and its events.**
  Each refused file is named with the events its `hooks` block declares, in the form the config directory's refusal already takes. An ancestor's refusal names `--eval-root` as the remedy, and the default eval root stays where it is.
- **A bare ancestor refuses nothing.**
  An ancestor `.claude` directory whose settings declare no hook, or which holds no settings file, leaves the run to start.
- **Each scope is planted by a test.**
  Stub-agent tests plant a `SessionStart` hook in a form's `.claude/settings.json` and in its `.claude/settings.local.json`, plant an ancestor declaring a hook, and hold an ancestor declaring none; each asserts the refusal or the started session, the stub log and the results folder.
