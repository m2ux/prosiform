## Overview

Bare `pf` prints the guide W00 states: plain terminal text saying what an agent does with a `↳` link, a `⇉` link, a Dispatch sub-section and a `Dispatch in parallel` section, and the returned-question marker.

## Problem

- **The guide is Markdown and covers one mark.**
  `GUIDE` in `cli.py` prints headings, code spans and a fenced block, and names only the compile step, `↳` and a bundle's Prosiform section.

## Proposal

**The scene.** `GUIDE` is printed by `pf` with no arguments; `fixtures/cli/informational-guide-response` holds its bytes and `tests/test_cli.py` reads it.

- **The guide's text.**
  `GUIDE` carries the wording *Guide* fixes at W00's pin: the compile step; `↳` compiled and kept in context, followed inline; `⇉` compiled and dispatched to a sub-agent; the Dispatch protocol; the `Dispatch in parallel` rule, each `⇉` item compiled first, then the whole set dispatched together, and none dispatched if a compile fails; and the `Question:` marker.
- **Plain text, held by a test.**
  A test refuses a guide carrying a Markdown heading, emphasis, link or code fence.
- **The fixture follows.**
  The guide fixture's expected output is the new text.
