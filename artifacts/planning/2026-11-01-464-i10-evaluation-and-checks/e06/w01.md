## Overview

Bare `pf` prints the guide W00 states: plain terminal text giving an instruction for every mark an agent meets, the dispatch protocols, and the returned-question marker.

## Problem

- **The guide is Markdown and covers two marks.**
  `GUIDE` in `cli.py` prints headings, code spans and a fenced block, and names only the compile step, `↳` and a bundle's Prosiform section.

## Proposal

**The scene.** `GUIDE` is printed by `pf` with no arguments; `fixtures/cli/informational-guide-response` holds its bytes and `tests/test_cli.py` reads it.

- **The guide's text.**
  `GUIDE` carries the wording *Guide* fixes at W00's pin: the compile step, an instruction for each mark and generated list, the Dispatch and Parallel dispatch protocols, and the returned-question marker. The `⫽` and `¬` instructions state that a parallel set is deferred whole or not at all.
- **Plain text, held by a test.**
  A test refuses a guide carrying a Markdown heading, emphasis, link or code fence.
- **The fixture follows.**
  The guide fixture's expected output is the new text.
