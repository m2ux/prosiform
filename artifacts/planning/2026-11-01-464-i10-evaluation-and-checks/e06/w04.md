## Overview

A deferred dispatch is published with its `⇉` mark at a path the agent can compile, so the guide's `⇉` instruction is what an agent applies to it.

## Problem

- **A deferred dispatch reads as a citation.**
  `[¬⇉ four](four.md#do)` publishes as `[four](four.md#do)`, the same shape as a link to a document that declares nothing, so the bundle gives its reader no sign that the target is compiled and dispatched.

## Proposal

**The scene.** `rewrite.py` publishes a deferred link at its rebased path with its marks and the blanks after them removed.

- **The mark is published.** (User, 2026-11-03.)
  A deferred dispatch publishes as `[⇉ four](four.md#do)`: the `¬` goes, the `⇉` and one space stay, and the path is rebased as *A deferred link's destination* states, so it resolves from where the agent runs `pf`. A deferred directive's `↳` line and a plain deferred link are unchanged.
- **Fixtures follow.**
  Every deferred-dispatch fixture's expected bundle carries the mark; W02, W03 and W04 regenerate the fixtures in one pull request.
