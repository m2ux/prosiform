## Overview

A parallel set is one `In parallel` section listing each member as a `⇉` item linking its compiled file, and a set of one is a single inline `⇉` link.

## Problem

- **The set's section names its files without linking them.**
  A `Dispatch in parallel` sub-section lists ``- `<bundle file>` (<text>)`` under a line linking the Parallel dispatch protocol.
- **A set of one is a list.**
  A section with one `⫽` link carries a parallel list of one member.

## Proposal

**The scene.** `dispatch.py` holds `PARALLEL`, `TOGETHER`, `listing()` and set building.

- **One `In parallel` section.** (User, 2026-11-03.)
  The set's `⫽` links point at one `In parallel` section, the set's boundary, listing each member as a `⇉` item, as `- [⇉ the lift](lift__do.bundle.md)`, under the instruction W00 fixes: give each to its own sub-agent at the same time, and continue when all have answered.
- **A set of one is a single inline `⇉`.** (User, 2026-11-03.)
  It publishes as W03's inline `[⇉ x](file)` link, with no `In parallel` section.
