## Overview

Every bundle a run writes opens its preamble with the run-pf line W00 fixes, so its reader is grammar-aware before it meets any mark.

## Problem

- **Only some bundles say to run `pf`.**
  A dispatched bundle carrying a deferred dispatch or a `↳` line opens with `Before following this bundle, run pf first`; an entry's bundle, and a bundle needing no first run, say nothing, so a reader handed one has not read the guide.

## Proposal

**The scene.** `bundle.py` assembles a bundle's preamble and groups; `dispatch.py` inserts the Prosiform section and its first-run line.

- **One opening line.**
  Every bundle opens with the fixed line, ahead of any authored preamble content and every heading, whatever the bundle holds.
- **Fixtures regenerated.**
  Every conformance fixture's expected bundle carries the line; the regeneration lands with W03's, in one pull request.
