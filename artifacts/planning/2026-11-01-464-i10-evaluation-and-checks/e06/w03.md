## Overview

A dispatching bundle carries no protocol: the Prosiform section retires, and a single dispatch is a `Dispatch <text>` section whose line links the dispatched file.

## Problem

- **Each dispatching bundle restates the protocols.**
  `dispatch.py` opens a dispatching bundle with `# Prosiform`, `## Run pf first`, `## Dispatch` and `## Parallel dispatch`, each a fixed paragraph.
- **The dispatch line names its file without linking it.**
  ``[Dispatch](#dispatch) `<bundle file>` to a sub-agent.`` links the protocol, puts the file in a code span and calls it a bundle.

## Proposal

**The scene.** `dispatch.py` holds `PROSIFORM`, `FIRST_RUN`, the protocol paragraphs, `instruction()` and the heading-collision list.

- **The section retires.**
  No bundle carries `# Prosiform` or a protocol sub-section; the first-run line goes, as W02's line covers every bundle.
- **The dispatch line links its file.** (User, 2026-11-03.)
  The `Dispatch <text>` section's line is the wording W00 fixes, linking the dispatched file, as in "Give [the crew](loading__crew.bundle.md) to a sub-agent and continue with its answer." No instruction text says "bundle".
- **Collisions shrink.**
  The headings pf emits no longer include `Prosiform` or the protocol headings, so an authored heading of that text publishes.
