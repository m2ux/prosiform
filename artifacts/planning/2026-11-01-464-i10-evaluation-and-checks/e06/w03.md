## Overview

A dispatching bundle carries no protocol: the Prosiform section retires, and a `⇉` link stays inline with its mark, pointing at the file `pf` compiled for its target, so no dispatch section is generated.

## Problem

- **Each dispatching bundle restates the protocols.**
  `dispatch.py` opens a dispatching bundle with `# Prosiform`, `## Run pf first`, `## Dispatch` and `## Parallel dispatch`, each a fixed paragraph.
- **A dispatch link points away from its file.**
  A `⇉` link publishes without its mark, pointing at a generated `Dispatch <text>` sub-section whose line, ``[Dispatch](#dispatch) `<bundle file>` to a sub-agent.``, links the protocol and names the file in a code span.

## Proposal

**The scene.** `dispatch.py` holds `PROSIFORM`, `FIRST_RUN`, the protocol paragraphs, `instruction()`, the dispatch sub-section's placement and the heading-collision list; `rewrite.py` publishes the link.

- **The section retires.**
  No bundle carries `# Prosiform` or a protocol sub-section; the first-run line goes, as W02's line covers every bundle.
- **The dispatch link stays inline.** (User, 2026-11-03.)
  `[⇉ the crew](loading.md#crew)` publishes as `[⇉ the crew](loading__crew.bundle.md)`, its mark kept and its destination the file compiled for the target. No `Dispatch <text>` sub-section is generated; the guide tells the agent to give the linked file to a sub-agent and continue with its answer. A condition stays in the prose around the link.
- **Compilation is unchanged.**
  Each distinct target is still compiled up front into its own file, with the refusals, `W_DISPATCH_SELF`, `W_DISPATCH_DEPTH` and `E_DISPATCH_CYCLE`.
- **Collisions shrink.**
  The headings pf emits no longer include `Prosiform`, the protocol headings or a dispatch sub-section's, so an authored heading of that text publishes.
