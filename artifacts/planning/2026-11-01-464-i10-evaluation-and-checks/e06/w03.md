## Overview

A dispatching bundle carries only its own dispatch lists: the Prosiform section and its protocol paragraphs retire, since the guide holds the rules.

## Problem

- **Each dispatching bundle restates the protocols.**
  `dispatch.py` opens a dispatching bundle with `# Prosiform`, `## Run pf first`, `## Dispatch` and `## Parallel dispatch`, each a fixed paragraph, and each dispatch line links `#dispatch`.

## Proposal

**The scene.** `dispatch.py` holds `PROSIFORM`, `FIRST_RUN`, the protocol paragraphs, `instruction()`, `TOGETHER` and the heading-collision list.

- **The section retires.**
  No bundle carries `# Prosiform` or a protocol sub-section; the first-run line goes, as W02's line covers every bundle.
- **The lists stay, unlinked.**
  A dispatch sub-section's line and a `Dispatch in parallel` list's lead line carry the wording W00 fixes, linking no protocol.
- **A mixed set is refused.** (User, 2026-11-03.)
  A section's `⫽` set holding both deferred and immediate members fails with `E_UNSUPPORTED_CONSTRUCT`, naming the set and each member as immediate or deferred, and publishes nothing; a refused fixture holds it.
- **Collisions shrink.**
  The headings pf emits no longer include `Prosiform` or the protocol headings, so an authored heading of that text publishes.
