**Component:** main:evals/diagram-following/workflows/deferred-dispatch/scenarios.toml

## Overview

A `staged` workflow whose entry bundle carries a deferred dispatch, `[¬⇉ <text>]`, published as a plain link, so the eval measures an agent that has read the guide compiling it when its path reaches it and dispatching what that run dispatches.

## Problem

- **A deferred dispatch looks like a link.**
  The bundle removes its marks, so only the guide tells the agent that the link is compiled.

## Proposal

**The scene.** A workflow is a directory under `workflows/`, its forms beside a `scenarios.toml` naming each scenario's inputs, the path a correct session walks, the sub-agents it starts and the `pf` runs it makes. A `staged` session receives the compiled bundle set with the build under test as `pf` on its path; the scenario passes when the session's path is the one its bundle states.

- **Compile, then dispatch.**
  The scenario states `pf` on the link's path where the walk reaches it, and the sub-agents that run's bundle dispatches as its trace.
