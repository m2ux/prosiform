**Component:** main:evals/diagram-following/carrier.py

## Overview

Two further forms of the sub-agent first-run scenarios carry the instruction to run `pf` first as a frontmatter entry and as a top blockquote line, so the live run compares them with the Prosiform section the build emits.

## Problem

- **The carrier is a choice.**
  The Prosiform section was chosen; nothing measures it against the two alternatives considered.

## Proposal

**The scene.** A workflow is a directory under `workflows/`, its forms beside a `scenarios.toml` naming each scenario's inputs, the path a correct session walks, the sub-agents it starts and the `pf` runs it makes. A `staged` session receives the compiled bundle set with the build under test as `pf` on its path; the scenario passes when the session's path is the one its bundle states.

- **The run rewrites the carrier.**
  After compiling, each dispatched bundle's first-run section is replaced by the same instruction in frontmatter, or as a blockquote above the first heading.
- **Only the first-run workflow takes them.**
  Both forms are outside the default `--forms`.
