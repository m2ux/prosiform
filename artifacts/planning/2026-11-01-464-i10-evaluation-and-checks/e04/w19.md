## Overview

The edge workflows' corpus test and scenarios read the bundles I10:E06 publishes, and write no mark E06 retires: every bundle opening with the run-pf line, plain `Dispatch` and `In parallel` sections linking their files, no Prosiform section, no `¬⇉` or `¬⫽`, `↳` as the composition mark in place of the arrow directive, and one `compiled` form in place of `staged`.

## Problem

- **The test reads the retired section.**
  The corpus test W12 added holds a dispatched bundle reaching a deferred line to `Before following this bundle, [run pf first](#run-pf-first).` above `# Prosiform`, and `subagent-first-run`'s scenarios state it. Once E06's bundles reach E04's base, that test fails.
- **Scenarios write retired marks.**
  `deferred-dispatch` (W10) is built on `¬⇉`, and `dispatch-depth` (W11) and `subagent-first-run` (W12) carry `¬⫽` cases; E06 refuses both, so their sources no longer compile.
- **Scenarios compose with an arrow.**
  `inline-bootstrap` (W05), `deferred-composition` and its nested deferrals (W06), `preset-deferral` (W07), `conditional-composition` (W08) and `directive-labels` (W09), with every other workflow writing `→` or `¬→`, compose with the arrow directive E06 refuses.

## Proposal

**The scene.** `test_workflow.py` compiles each scenario's bundles with the build under test and holds the scenarios to them.

- **The first-run test reads the run-pf line.**
  A dispatched bundle's sub-agent is held to its `pf` runs by the line every bundle opens with, and to the `Dispatch` and `In parallel` sections by the files they link.
- **Staged scenarios move to `compiled`.**
  E06 W07 folds `staged` into `compiled`, so every scenario written only in `staged` is written in `compiled`, which carries the build and a `pf` shell.
- **Composition moves to `↳`.**
  Each `[→](p.md#s)` becomes `[↳ Title](p.md#s)` and each `[¬→](p.md#s)` becomes `[¬↳ Title](p.md#s)`. `directive-labels`, which measures an arrow beside a footnote link, keeps the footnote link and measures the `↳` composition beside it.
- **The retired marks are rewritten.**
  `deferred-dispatch` becomes a scenario of an immediate dispatch reached from a `↳`-compiled section, or retires where an existing scenario already states that path; the `¬⫽` cases become immediate `⫽` members or `↳` lines. Each scenario keeps stating actions only a sub-agent's `pf` run defines.
