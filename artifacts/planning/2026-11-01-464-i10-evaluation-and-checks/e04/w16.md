## Overview

The edge run's runbook proven on the edge workflows: a session shakes it down before the run on the user's model, checks the rubric's `pf`-run entries against real sessions, and sets its budget, so the edge run carries no judgement of its own.

## Problem

- **The edge run's runbook is written before its scenarios exist.**
  E05 W00 writes its text, and W03 adds rubric entries for classes no live session has produced.

## Proposal

**The scene.** `RUNBOOK.md` holds the triage rubric and a runbook per live run; a run row follows its runbook and escalates what the rubric marks a defect.

**The design.**

- **A shakedown over the edge workflows.**
  The session runs the edge runbook's shakedown on the model `RUNBOOK.md` records, on each harness carrying a shell, fixes every harness, scenario or plumbing fault it finds in this pull request, and sets the budget and cost cap from the measured cost.
- **The `pf`-run entries meet real sessions.**
  Each rubric entry W03 added decides at least one shakedown session, or the shakedown records that no session produced its class.
