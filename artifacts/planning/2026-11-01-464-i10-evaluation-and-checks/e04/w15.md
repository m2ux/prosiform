## Overview

The eval's README states the `staged` form, each edge workflow and scenario, and the pass rates each harness's edge-case record holds.

## Problem

- **The README names the forms and workflows it has.**
  A reader finds no `staged` form, no edge workflow and no record of their run.

## Proposal

**The scene.** A workflow is a directory under `workflows/`, its forms beside a `scenarios.toml` naming each scenario's inputs, the path a correct session walks, the sub-agents it starts and the `pf` runs it makes. A `staged` session receives the compiled bundle set with the build under test as `pf` on its path; the scenario passes when the session's path is the one its bundle states.

- **The form and workflows.**
  `staged` joins the Forms table, and each edge workflow and scenario is listed as the dispatch scenarios are.
- **The record.**
  A section names each `composition-edges-<harness>.json` and states its pass rates.
