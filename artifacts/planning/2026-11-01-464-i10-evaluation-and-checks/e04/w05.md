**Component:** main:evals/diagram-following/workflows/inline-bootstrap/scenarios.toml

## Overview

A `bootstrap` workflow whose skill entry declares no `prosiform` and holds a hand-written `[↳ <title>](<path>)` link, so the eval measures an agent running `pf`, then compiling the link, before following it.

## Problem

- **The bootstrap skill states its compile in prose.**
  `bootstrap-audit`'s `SKILL.md` says to run `pf` over the sources; no skill hands over a `↳` link and the guide alone.

## Proposal

**The scene.** A workflow is a directory under `workflows/`, its forms beside a `scenarios.toml` naming each scenario's inputs, the path a correct session walks, the sub-agents it starts and the `pf` runs it makes. A `staged` session receives the compiled bundle set with the build under test as `pf` on its path; the scenario passes when the session's path is the one its bundle states.

- **The skill is one link.**
  An undeclared `SKILL.md` holds the `↳` link; bare `pf` prints the guide, which says to compile and follow it.
- **The runs are stated.**
  Bare `pf`, then `pf` on the link's path, then the path the compiled target states.
