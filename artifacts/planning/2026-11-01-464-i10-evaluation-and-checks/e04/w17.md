## Overview

The triage rubric decides each class the scorer gives a session's `pf` runs, so a live run meeting one has a disposition to give it.

## Problem

- **The run classes have no rubric entry.**
  W03 adds `uncompiled`, `overcompiled` and `misordered_compile` to the scorer, and `RUNBOOK.md`, whose rubric decides every class, arrives with I10:E05 W00 on a base W03 did not hold.

## Proposal

**The scene.** `RUNBOOK.md` holds the triage rubric and a runbook per live run; a run row follows its runbook and escalates what the rubric marks a defect.

- **One row per run class.**
  Each of the three classes gets its `miss`, `defect` and `unclear` reading in the rubric's By Class table, read against the session record's `commands` and each start's `commands`, the transcript's shell calls and the scenario's `[[scenario.compile]]` tables.
- **The rubric test holds it.**
  The runbook test holding the rubric to every class the scorer gives passes on a base carrying both W03 and E05 W00.
