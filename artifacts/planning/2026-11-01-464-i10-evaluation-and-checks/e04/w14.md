**Component:** main:evals/diagram-following/composition-edges.json

## Overview

One live run of the edge workflows on every harness carrying a shell, committed as its own record beside the baseline, so the eval states how agents follow deferred, composed and dispatched bundles.

## Problem

- **The edge scenarios have no measurement.**
  The baseline runs the Claude harness, which carries no shell, so no committed run holds a `staged` session.

## Proposal

**The scene.** A workflow is a directory under `workflows/`, its forms beside a `scenarios.toml` naming each scenario's inputs, the path a correct session walks, the sub-agents it starts and the `pf` runs it makes. A `staged` session receives the compiled bundle set with the build under test as `pf` on its path; the scenario passes when the session's path is the one its bundle states.

- **A record of its own.**
  The run's `report.json` is committed as `composition-edges.json` and its `report.md` beside it; `baseline.json` and `mvp-proof.json` are untouched.
- **A measurement, not a gate.**
  Failing sessions are recorded with the class the scorer names; a refused run is not committed.
