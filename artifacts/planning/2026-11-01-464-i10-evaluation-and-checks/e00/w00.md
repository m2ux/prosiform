## Overview

The default matrix runs the one model the user chose at W01, which W04 records, so the corpus is calibrated against and the baseline measures that model.

## Problem

- **The default matrix runs two models.**
  `run.py` defaults to two models, so a baseline costs both and a corpus calibrated for one is measured on the other.

## Proposal

**The scene.** `make eval-diagrams` runs `run.py` with its default `--models`, `--harness` and `--forms` unless a run names them.

**The design.**

- **One default model.**
  `--models` defaults to the model `RUNBOOK.md` records as the user's choice (W04); the eval's README and its cost figures state one model.
- **The default harness follows it.**
  That model is reached through `opencode` alone, so `--harness` defaults to it and `matrix()` does too. The default matrix is 74 cells on that harness, and five repetitions is 370 sessions.
- **The token budget covers that matrix.**
  `EVAL_BUDGET_TOKENS` is 370 sessions at the 2 830 000-token cap, 1 047 100 000.
- **Each default is held to the record.**
  `test_runbook.py` reads the model, harness and largest session its Baseline shakedown table states, so a default that departs from the measurement fails.

## Validation

### T1: Defaults

`test_runbook.py` reads the model and harness rows of the Baseline shakedown table and asserts `DEFAULT_MODELS` and `DEFAULT_HARNESS` against them. `--models` is `openrouter/deepseek/deepseek-v4.1-flash-1017` and `--harness` is `opencode`, the pair the table records as named by the user on 2026-11-04.

### T2: Budget

`test_runbook.py` reads `EVAL_BUDGET_TOKENS` from the Makefile and compares it with the default matrix's sessions at `DEFAULT_SESSION_BUDGET`. The matrix is 74 cells on the default harness, five repetitions is 370 sessions, and 370 times 2 830 000 is 1 047 100 000, which is the budget set.
