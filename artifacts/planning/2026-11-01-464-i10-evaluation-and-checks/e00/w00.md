## Overview

The default matrix runs the one model the user chose at W01, which W04 records, so the corpus is calibrated against and the baseline measures that model.

## Problem

- **The default matrix runs two models.**
  `run.py` defaults to two models, so a baseline costs both and a corpus calibrated for one is measured on the other.

## Proposal

**The scene.** `make eval-diagrams` runs `run.py` with its default `--models`, `--harness` and `--forms` unless a run names them.

**The design.**

- **One default model.**
  `--models` defaults to the model `RUNBOOK.md` records as the user's choice (W04); the eval's README and its cost figures state one model.
