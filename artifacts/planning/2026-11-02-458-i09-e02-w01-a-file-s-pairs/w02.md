**Component:** main:src/prosiform/cli.py

## Overview

An intermediate file's groups sit inside the result its parent merges, and a link a file does not bundle remains that file's content.

## Problem

- **An intermediate group is a peer of the entry.**
  A group declared on a file the entry links becomes another top-level heading beside the entry's, rather than a heading inside the result its parent merged.
- **An unbundled link has no stated place.**
  Nothing states that a link a file writes and does not bundle stays in that file's content.

## Proposal

**The scene.** W01 composes each file before its parent merges it; this row places the groups that composition produces.

- **A nested group sits in its parent's result.**
  A merged group whose first member a document's link placed stands inside that document's division, after its own content: the document's file group, or the first merged group it joins in bundle order. `merged` takes the level its heading stands at, and every heading beneath moves with it, so a heading past H6 fails as *Depth overflow* states.
- **Validation reads the level.**
  A group's opening heading is held at the level the group stands at, and each heading it places below that opening.
- **An unbundled link stays content.**
  A link the file does not bundle is emitted as the file's content, unchanged in place.
- **The design states one group per contribution.**
  *Group isolation* reads each contribution a source makes as belonging to the one group its membership names, matching *Presets — A document in several groups*, and *Nested groups* names the holder of a group a document in several groups places.
