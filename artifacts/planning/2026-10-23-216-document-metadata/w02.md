**Component:** src/prosiform/metadata.py

## Overview

A dedicated decoder produces a typed conversion value from a frontmatter block.

## Problem

The runtime has no YAML parser or source-metadata schema.

## Proposal

Add the metadata component with immutable settings and field source marks. Verify official library documentation and types before selecting and pinning a safe YAML parser in the package and lockfile. Reject malformed mappings, duplicate keys, custom tags, aliases, merge keys, unknown reserved fields and incomplete group/depth pairs. Enforce the stated byte and nesting bounds before unbounded construction. Keep unrelated skill fields outside the conversion schema. Unit tests are delivered with the decoder.
