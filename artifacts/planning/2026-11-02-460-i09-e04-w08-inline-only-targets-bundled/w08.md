**Component:** main:src/prosiform/cli.py

## Overview

A document that only composition directives reach is carried once, inside the contributions they place, and takes no file group, no merged-group membership and no copy of its own. A document that an ordinary dependency also reaches keeps that inclusion beside its contributions, carrying what the inclusion selects. This removes the second copy W02 left in every bundle that composes a section.

## Problem

- **A composed target is also bundled.**
  Assembly builds a group from every reference that reached a document, so a section composed beneath its scope also stands in its document's file group, and the bundle carries it twice.

## Proposal

**The scene.** The traversal reads each reached section for the dependencies it carries; `placement` orders the documents by the links read from each placed document; assembly builds one division per document or merged group from the references selecting each; W02's composition pass then places each directive's section beneath its scope.

- **A reference states that it composes.**
  A reference a composition directive writes, naming a section, is marked as composing. The traversal still reads what it names, so the links a contribution carries are bundled, and a document reached by both kinds is carried for each.
- **Inline-only targets.**
  Assembly selects from the references that include what they name. A document with none takes no file group and joins no merged group, and its `group` pair places nothing.
- **Mixed reach.**
  A document an inclusion also reaches keeps its group, carrying what the inclusion selects and nothing only a directive reached.
- **Placement through contributions.**
  `placement` reads a composed section where its directive is written, once, so a link a contribution carries places its document as one the scope's document writes, under that document's division.
- **A directive inside a contribution.**
  Composition does not yet place a directive written inside a contribution (W05), so placement reads such a directive as the inclusion its link is and widens its document's selection to the section it names. That section keeps a group for the link to reach.
- **Diagnostic chains.**
  A diagnostic names the route to a source whichever kind of reference reached it, so a fault in an inline-only target still names its chain.
