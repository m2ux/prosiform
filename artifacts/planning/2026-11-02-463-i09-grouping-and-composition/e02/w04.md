**Component:** main:example/README.md

## Overview

The example tree keeps each `group-depth` pair on the file whose sections it places, so its bundles keep their outline under leaves-up composition.

## Problem

- **The example's outline depends on where pairs sit.**
  A parent declaring a pair for a section another file supplies would change the example's bundles once each file's pairs place only its own sections.

## Proposal

**The scene.** The leaves under `artifacts`, `protocols` and `references` declare their own pairs on the I08:E01 base, and the modes declare none.

- **Each leaf declares its own pairs.**
  Every linked leaf states the `group-depth` pairs of its own sections.
- **No parent declares a pair for another file's section.**
  A parent's pairs, where it has any, name only its own sections.
