## Overview

The design states leaves-up composition: a file's `group-depth` pairs place its own sections in the result its parent merges, and a linked file is composed before its parent merges it.

## Problem

- **Groups are flat in the design.**
  *Grouping* states a group as one top-level division, and every document whose pairs name a group joins it directly, whatever links it.
- **Nothing states whose pairs place a linked file.**
  No clause says a parent's pairs leave a child's sections alone, or that an intermediate group nests inside its parent's result.

## Proposal

**The scene.** *Grouping* states membership, depth and the merged arrangement; *Dependency order* states placement order.

- **A file places its own sections.**
  A file's pairs apply to its own sections in the result its parent merges; a parent's pairs apply when it is bundled in turn.
- **Composition runs from the leaves up.**
  Each linked file is composed under its own pairs before the file linking it merges that result, and a link a file does not bundle stays its content.
- **The pin moves.**
  The README's design link moves to the engineering commit carrying the amendment.
