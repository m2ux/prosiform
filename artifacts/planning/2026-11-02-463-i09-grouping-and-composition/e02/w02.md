**Component:** main:src/prosiform/cli.py

## Overview

An intermediate file's groups sit inside the result its parent merges, and a link a file does not bundle remains that file's content.

## Problem

- **An intermediate group is a peer of the entry.**
  A group declared on a file the entry links becomes another top-level heading beside the entry's, rather than a heading inside the result its parent merged.
- **An unbundled link has no stated place.**
  Nothing states that a link a file writes and does not bundle stays in that file's content.

## Proposal

**The scene.** W01 composes each file before its parent merges it; this row places the groups that composition produces.

- **A nested group sits in its parent's result.**
  An intermediate file's group heading sits inside the composed outline its parent merges, at the level that result gives it.
- **An unbundled link stays content.**
  A link the file does not bundle is emitted as the file's content, unchanged in place.
