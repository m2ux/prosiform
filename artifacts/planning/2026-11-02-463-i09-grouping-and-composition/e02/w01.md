**Component:** main:src/prosiform/cli.py

## Overview

Assembly composes each linked file under its own `group` pairs before the file linking it merges the result, so a file's pairs place its own sections.

## Problem

- **Assembly is one flat pass.**
  `assembled` walks every selected document once, appending a file group or a merged-group membership for each, so the bundle is a list of top-level groups.
- **A child's pairs act beside its parent.**
  A file's pairs name a top-level group whatever links it, rather than placing its sections in its parent's result.

## Proposal

**The scene.** The pairs in force for each document come from the presets the references reaching it select, so each file already carries its own pairs.

- **Composition is recursive.**
  A document is composed from the documents it bundles, each composed first under its own pairs, then merged into it.
- **The parent merges a result.**
  What a parent receives from a child is the child's composed outline, placed by the child's pairs.
- **Fixtures follow the arrangement.**
  The corpus fixtures whose outline the leaves-up order changes are re-recorded in this unit, so it passes `make check` alone.
