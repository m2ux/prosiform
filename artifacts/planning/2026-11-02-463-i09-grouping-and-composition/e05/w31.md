## Overview

The design states how the `subst` pairs of several references reaching one document combine, as the build resolves them.

## Problem

- **The design reads per reference; the build reads per document.**
  *One document under several selections* says each reference bundles the document's content under its own selection, while `governing` resolves every link the document writes through the pairs every reaching reference selects.
- **A per-reference reading cannot hold within a group.**
  A region a group emits once carries one resolution of each link, so two references selecting different alternatives for one key leave nothing saying which the region takes.

## Proposal

**The scene.** The [review](review.md#f2-subst-pairs-combine-across-references) found a pair one reference's preset states redirecting a section another reference bundled under `default` alone.

- **Pairs combine across references.**
  *Presets* and *The substitution mapping* state that a document's links resolve through the union of the `subst` pairs its `default` and the presets of every reference reaching it in the run state, a selected preset's pair holding over `default`'s for its key.
- **Disagreement is refused.**
  Two references whose selected presets map one key to two alternatives are invalid usage, exit 2, naming both presets, as *Selected presets union* states for one title.
- **`group` stays per reference.**
  A document whose references select different `group` pairs remains a member of each group.
- **The pin moves.**
  The README's design link moves to the engineering commit carrying the amendment.
