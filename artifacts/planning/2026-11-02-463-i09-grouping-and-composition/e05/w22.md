**Component:** main:evals/diagram-following/workflows/preset-selection/scenarios.toml

## Overview

A diagram-following workflow whose sources use presets selected by the title of the section linking a document, with one scenario per permutation, so the live run tests an agent following a bundle built with that feature.

## Problem

- **No eval workflow uses the feature.**
  The existing workflows predate it, so the eval measures bundles that never exercise it.
- **The corpus proves the bytes, not the reading.**
  A fixture shows what `pf` emits; only a session shows an agent following it.

## Proposal

**The scene.** A workflow is a directory under `workflows/`, its forms beside a `scenarios.toml` naming each scenario's inputs and path.

**The design.**

- **One scenario per permutation.**
  `default` alone, a title-selected preset and two presets one title selects.
- **The path is the bundle's.**
  Each scenario's path is the walk its compiled bundle states, which `make harness` asserts.

## Work Breakdown

| Part | Description |
| --- | --- |
| Analysis | Settle a workflow whose walk turns on the feature in each permutation. |
| Plan | Lay out its forms, states and scenarios. |
| Implementation | Write the workflow and its `scenarios.toml`. |
| Review | Confirm each permutation is the one its scenario names. |
| Test | `make harness`: `test_each_scenario_path_is_the_walk_its_bundle_states` for each `preset-selection` scenario, holding its path to the walk the bundle `pf` compiles states, and `test_the_title_linking_a_document_selects_the_presets_placing_it`, holding each permutation to the arrangement its scenario names; `make check` with `PROSIFORM_BUILD` set. |
