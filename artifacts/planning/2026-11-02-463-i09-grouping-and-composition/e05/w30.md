## Overview

The design states that `-o` names a folder the run makes where it is absent, as the build, its help and its guide have it.

## Problem

- **The design refuses what the build makes.**
  *CLI contract* says the `-o` folder must exist and *Publication* holds the output folder to existing, while `pf` makes a missing folder and refuses only one it cannot make.
- **The guide is the build's text.**
  It tells an agent the run makes the folder, so the design is the one statement left saying otherwise.

## Proposal

**The scene.** The [review](review.md#f1-the-output-folder-is-made) found the build making the folder since commit 1dafc779.

- **`-o DIR` makes its folder.**
  The option row and *Publication* state that a missing output folder is made, and that one the run cannot make — a file standing where a parent belongs, a path the filesystem denies — fails with `E_PUBLICATION_FAILED`.
- **The pin moves.**
  The README's design link moves to the engineering commit carrying the amendment.
