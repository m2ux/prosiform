**Component:** main:evals/diagram-following/workflows/subst-redirect/scenarios.toml

## Overview

A diagram-following workflow whose sources use `subst` entries redirecting the links a document writes, with one scenario per permutation, so the live run tests an agent following a bundle built with that feature.

## Problem

- **No eval workflow uses the feature.**
  The existing workflows predate it, so the eval measures bundles that never exercise it.
- **The corpus proves the bytes, not the reading.**
  A fixture shows what `pf` emits; only a session shows an agent following it.

## Proposal

**The scene.** A workflow is a directory under `workflows/`, its forms beside a `scenarios.toml` naming each scenario's inputs and path.

**The design.**

- **One scenario per permutation.**
  A document redirect, a section redirect and a selected preset's entry holding over `default`'s.
- **The path is the bundle's.**
  Each scenario's path is the walk its compiled bundle states, which `make harness` asserts.
- **Every cell walks one path.**
  Each substitute states the action and transition of the state it stands in for, so the `tree` form, which no `pf` run compiles, walks the path the bundle states.
