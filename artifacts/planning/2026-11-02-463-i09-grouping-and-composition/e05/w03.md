**Component:** main:invocation.md

## Overview

`invocation.md` states every option, declaration and preset entry a run reads as the merged build and the pinned design have it.

## Problem

- **The page was written epic by epic.**
  Each epic amended the parts it touched, so the page as a whole was never read against the merged build.
- **A stale claim reads as current fact.**
  A reader of the MVP takes the page as the contract.

## Proposal

**The scene.** `invocation.md` documents every option, declaration and preset entry a run reads.

**The design.**

- **The page is read whole against the build.**
  Each claim is checked against `make invocation` and the pinned design, and each behaviour of its subject the build has is stated.
- **The evidence is recorded.**
  The pull request lists each claim corrected or added and what showed it.

## Work Breakdown

| Part | Description |
| --- | --- |
| Analysis | Read the page against `make invocation` and the pinned design. |
| Plan | List each claim to correct, add or remove. |
| Implementation | Amend the page. |
| Review | Re-read the page whole against the build. |
| Test | `make links`, `make tables` and `make vocabulary`. |
