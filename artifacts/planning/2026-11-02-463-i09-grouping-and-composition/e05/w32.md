## Overview

The design's option table declares the code listing and the long spellings the build admits, so no option the build accepts is one the contract refuses.

## Problem

- **The table refuses an option the checks rely on.**
  *CLI contract* refuses an undeclared option, its table declares no `-C`, and `make conformance` invokes `pf -C` to read the codes a build reports.
- **The prose names what the table omits.**
  The clause names a code-listing response and *Metadata failures* a build's own list of codes.

## Proposal

**The scene.** The [review](review.md#f3-the-option-table-omits-the-code-listing) found `parser` admitting `-C`/`--codes`, `--version` and `--help`.

- **The table declares `-C`.**
  A row states that `-C`, or `--codes`, prints every error and warning code the build can report, one per line, on standard output, and exits 0.
- **The long spellings are declared.**
  `--version` and `--help` are written beside `-v` and `-h`.
- **The pin moves.**
  The README's design link moves to the engineering commit carrying the amendment.
