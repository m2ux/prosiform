**Component:** main:src/prosiform/composition.py

## Overview

A link whose plain-text label is exactly one non-ASCII scalar is recognised as a composition directive, independently of deferral.

## Problem

- **No link requests placement.**
  Every link is a reference, deferred or not, and none asks that its target sit beneath the section naming it.

## Proposal

**The scene.** The closure recognises the deferral mark on a link's opening before anything else reads it.

- **The predicate.**
  The label, decoded and read as plain text, is one non-ASCII scalar; ASCII, multi-scalar labels, code, images and unresolved text are not directives.
- **Deferral first.**
  The deferral mark is read first, so a deferred directive is withheld and composed only when selected.
