**Component:** main:docs/composition.md

## Overview

A documentation page publishes the reserved grammar beside its fixtures, without assigning it an ontology meaning.

## Problem

- **No page states composition.**
  An author has no page describing the directive, its scope or its failures.

## Proposal

**The scene.** The docs index lists one page per subject.

- **A composition page.**
  The grammar, the destination scope, ordering, deferral and failures, each with a worked example drawn from a fixture.
- **Placement only.**
  The page describes the label as a placement request and assigns it no meaning about inputs, outputs or activities.

## Work Breakdown

| Part | Description |
| --- | --- |
| Analysis | List the fixtures each statement draws from. |
| Plan | Settle the page's sections. |
| Implementation | Write the page and list it in the docs index. |
| Review | Every example matches a fixture. |
| Test | Inspection of the page against conformance fixtures; `make vocabulary`, `make tables` and `make links`. |
