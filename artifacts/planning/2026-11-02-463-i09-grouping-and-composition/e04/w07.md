**Component:** main:src/prosiform/cli.py

## Overview

Any composition failure publishes no partial bundle, to stdout or to a named output.

## Problem

- **Composition adds failures after selection.**
  A failure raised while composing must stop publication as every other failure does.

## Proposal

**The scene.** The run publishes only after every bundle validates.

- **Nothing published.**
  A composition diagnostic stops the run before any bundle is written, whatever the output target.
