# Dispatch Text — October 2026

> Delivery · Created 2026-10-24

## Executive Summary

The dispatch instruction is injected into every mode bundle a skill compiles, so a long sentence is paid for once per bundle and read at the point an agent acts. This record states the form that sentence takes: one imperative clause, under seventy characters, with the detail left to the section it summarises.

The work matters because the text is the one part of a bundle that is repeated rather than composed. A skill with ten modes emits it ten times, and every word beyond the rule itself is cost with no added meaning.
