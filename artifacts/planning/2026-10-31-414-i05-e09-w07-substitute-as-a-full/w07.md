**Component:** src/prosiform/metadata.py

## Overview

The substitute as a source in its own right, stated and pinned against its own bytes: the conversion settings `metadata.decode` reads decide which group the source joins and what bounds the links it writes, so a substitute declaring a group contributes to that merged group beneath a member heading naming its own path, and one declaring a root bounds its own outgoing links. With the two corpus fixtures that show each and the unit cases that hold what a fixture cannot state.

## Problem

A redirect that carried the original's conversion settings would produce a document whose content came from one file and whose `group` came from another, and a group has one claimant per member. Equally, a substitute that inherited the *original's* root would have its own links bounded by a directory it does not live in, so a stand-in kept beside the tree under test could reach nothing.

Neither half is stated anywhere the contract is read. `metadata.Conversion` was documented as "immutable source settings and their original value locations", which says where the values came from and nothing about what they do, so the two obligations the epic names were held by the accidental shape of `read_document` alone. A later refactor that resolved settings once per authored identity — the natural shape for an overlay, which the epic refused — would have made both false with every existing test still green: no fixture declared either behaviour, and no case reached a substitute's own group or root.

## Proposal

**The scene.** `closure.inside` applies the mapping to the reference a caller authored and returns the substitute's `Reference` whole, carrying the substitute's path and its authored access walk. `cli.read_document` captures the bytes at that path and asks `source.content` for the conversion settings and, from `prosiform.root`, the effective root. `grouping.prepared` reads the member's group name from those bytes; `cli.required` reads every outgoing link within `source.root`.

**The design.**

- **Metadata follows the bytes.** A substituted reference normalizes to the substitute's path before the read, so `read_document` captures the substitute's bytes and derives its `group`, `group-depth` and `root` from them. No setting travels from the original, because no setting is read from anywhere but the file that is opened.
- **A substitute declaring a group joins it,** under the same depth agreement every contributing member is held to. A conflict is reported against the substitute's own declaration, at its own location and on the chain that reached it.
- **A substitute's root bounds its outgoing links.** The root resolves from its declaring file's directory, as any source's does, and a link it writes outside that root stays a citation: emitted as authored, resolved no further, never opened.
- **The key's side is exempt; the substitute's own root is not.** The exemption is for the mapping entry, which the invocation named. A substitute's own declarations bind its own content as any document's do.
- **The capture is shared.** A substitute reached by two routes is one source, captured once, rechecked once, and contributing one group membership.

## Fixtures

| Fixture | What its source tree and manifest declare |
| --- | --- |
| `fixtures/mock/a-substitute-declaring-a-group-joins-it` | `guide.md` and `notes.md` both declare group `rules` at depth `2`, and `guide.md` links `rules.md`, which declares no group. The run is given `-m rules.md=stand-in.md`, where `stand-in.md` declares group `rules` at depth `2`. The bundle merges three members beneath one `Rules` heading, and the substitute's sections appear under `### Stand In`, the member heading naming its own path. `guide.md` links `notes.md` so both declared members are reached by a reference rather than by a positional entry, which keeps the merge a statement about the closure. |
| `fixtures/mock/a-substitute-root-bounds-its-own-links` | `guide.md` declares no root and links `rules.md`. `stand-in/entry.md` declares `prosiform.root: .` and links `detail.md` beside it and `../outside.md` above its root. The run is given `-m rules.md=stand-in/entry.md`. The bundle carries the substitute and `detail.md`; `outside.md` is emitted as authored and never opened, so the bundle carries it as a citation and raises `W_RESOURCE_PORTABILITY` for nothing. |
